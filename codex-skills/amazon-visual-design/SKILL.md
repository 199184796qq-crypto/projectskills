# 亚马逊视觉设计

将用户提供的产品素材与卖点转化为统一、以转化为导向的亚马逊视觉体系。默认输出策略和提示词；仅在用户明确要求时生成图片。

## 收集信息

收集或合理推断：目标站点、类目、目标人群、价格带、产品尺寸与材质、变体、3–5 个可证明的核心卖点、品牌规范，以及现有的产品图、包装图和场景图。仅询问会实质影响产品主张、合规要求或视觉方向的信息。

先检查全部产品图片，再写提示词。保持产品的真实结构、颜色、标签、Logo、配件和比例。不得虚构认证、量化效果、医疗结果、对比结论、套装内容或用户未提供的功能。

### 包装配件与多部件成品识别

检查用户提供的每张实拍图时，区分主产品、包装内配件、可选配件、替换件、安装件和仅用于拍摄的道具。将已确认包含的配件纳入视觉方案，并说明它在买家决策中的视觉作用，例如展示完整套装价值、安装便利性、兼容性、收纳、清洁、维护或使用场景。不要把未确认包含的物品放入“包装清单”或主图。

当产品由多个部件组成、而用户仅提供局部或拆分状态的图片时，识别可见的连接关系、数量、方向和可能的安装方式；结合已提供的说明书、包装信息、尺寸或产品资料，还原最合理的最终成品形态。对无法确认的结构、数量或装配关系，明确标为待确认，不得凭空补全。生图提示词要同时指定“已装配完成的成品外观”和“必须保留的真实部件特征”，避免把零件误画成独立商品或遗漏套装内容。

## 调研与视觉诊断

在用户要求调研，或联网调研确有必要时，查看目标站点与类目的代表性头部竞品页面。只提炼可复用的视觉规律：图片顺序、背景、构图、证明方式、文字密度、场景、对比机制、A+ 叙事和差异化空白。不得复制竞品的受保护图形、文案、版式或品牌资产。

使用以下四层诊断：

1. **COSMOS**：明确类目线索、结果、场景、机制、顾虑与品质信号。
2. **A9 相关性**：让产品、使用场景和核心利益点一眼可见，并与潜在搜索意图和类目习惯对应。
3. **四种做图判断法**：对比、价值证明、视觉具象化、一致性。
4. **移动端检验**：每张图只承担一个主信息，并能在缩略图尺寸中读懂。

说明做出的假设，并标出需要用户确认的无依据主张。

## 四大作图策略

针对每一个卖点，先从下列四种策略中选出最能帮助用户快速理解与相信它的一种；不要为了凑形式而四种都用。必须在图片方案中标注采用的策略、视觉动作和预期解决的购买疑问。

1. **价值直观体现**：让买家看到图片时无需依赖长篇文字，就能立即理解产品带来的核心价值与卖点。优先用产品状态、使用结果、结构可视化或清晰的场景结果来表达。
2. **反直觉冲突**：有依据时，打破用户惯常认知，制造温和但鲜明的认知冲突与记忆点。必须用真实的产品机制、材料或场景证明，不得使用误导性夸张。
3. **极致对比**：用最直接、最强烈但仍真实可证的“使用前后”“传统方式与本产品”“不同状态”对比，让差异一眼可见。比较对象和结论必须可验证，并符合目标站点规则。
4. **情感共鸣**：让用户在视觉中看见与自己相似的人获得成功、便利、安心或愉悦，从而产生“我也想要”的代入感。选择贴近目标人群生活的真实场景和情绪，不使用虚假评价或未经证实的结果。

每张图优先服务一个卖点和一种主策略。若采用对比、结果或情绪化表达，明确写出画面证据、必要条件和不能声称的边界。

## 搭建视觉架构

创建 19 张图的方案：9 张商品页图片、8 张高级 A+ 图片、2 张品牌故事图片。可按类目调整顺序，但整体叙事保持为：识别产品 → 理解价值 → 建立证明 → 想象拥有 → 信任品牌。

输出前阅读 `references/image-system.md`。每张图片均包含：

- 编号、位置、目标、回答的用户问题和一句主标题。
- 构图、产品姿态与比例、背景/场景、所需道具和视觉证明方式。
- 符合目标站点语言、简洁且合规的图上文案。
- 可直接使用的英文生图提示词；明确要求产品还原、商业产品摄影、无伪造文字/Logo/标签；如需要后期排版，预留干净的文字安全区。
- 负面约束和所需输入素材说明。

## 提示词规则

按以下结构写生图提示词：`[图片目的] + [精确产品描述] + [主体/动作] + [环境] + [构图/镜头] + [灯光] + [风格] + [合规的视觉证明] + [负面约束]`。

除非图像模型能可靠生成文字，否则不要让模型生成文字；改为预留文字安全区并另行提供覆盖文案。遵循类目惯例和站点合规要求：主图通常应为纯白背景、只展示产品及确定包含物，不放徽章、文字覆盖或干扰性道具。

## 交付格式

先给出简短的定位、视觉方向、竞品机会（如已调研）和风险/假设。然后提供完整的 19 张图片表格，再按编号给出生图提示词。最后列出素材清单和制作顺序：先主图，再证明图与场景图，最后完成 A+ 和品牌故事。
