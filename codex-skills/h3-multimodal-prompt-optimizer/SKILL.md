# H3 多模态优化提示词

## 目标

把用户的创意和全部可用附件转换成可直接粘贴到 MiniMax H3 Full-Reference 模式的英文视频提示词。不要生成视频本身，也不要把全参考结构改成基础模式的 `integrated_multimodal_description`。

## 工作流程

### 1. 读取输入与附件

逐一分析图片、视频、音频和文字，先记录事实，再补全创意。只把附件中确实存在的信息当成参考事实；不确定的文字、对白或声音写 `[unclear]`，禁止猜测。

重点识别：

- 人物：身份、脸型、五官、肤色、年龄感、发型、体型、服装、饰品、姿势、表情和视线。
- 产品/物体：轮廓、比例、材质、颜色、Logo、文字、零件、接口和握持关系。
- 场景：空间布局、前中后景、建筑、天气、时间、地平线、主色调和相对位置。
- 摄影：画幅、机位、景别、焦段感、透视、景深、曝光、色温、构图和运动模糊。
- 视频：动作、节奏、镜头路径、剪辑点、速度、时间结构和是否复用原声。
- 音频：说话人音色、语速、口音、对白/歌词、环境声、音乐、节拍和音效质感。
- 画面文字：不生成 Logo、招牌、字幕、标签、界面文字或任何其他可读文字；只保留这些元素对画面构图可能造成的非文字性影响。

### 2. 建立稳定参考标签

按“目标视频如何使用素材”分配标签，而不是按文件机械编号。每个标签只保留一个稳定含义，并在六段中保持不变。

- `<Subject N>`：目标视频中复用、修改或迁移的人、动物、产品、场景、服装、动作、风格或特效。一个文件可定义多个 Subject；同一人物的外观和动作可由不同素材共同定义。
- `<Picture N>`：只有图片本身是首帧、关键帧、尾帧、编辑关键帧、构图锚点或分镜锚点时才建立。图片仅用于定义人物或场景时，不单独建立 Picture。
- `<Video N>`：表示源视频的编辑、续写或整段运镜、剪辑、节奏、时间结构。视频中的人物、物体和动作仍需分别定义为 Subject。
- `<Audio N>`：表示独立音频或明确启用的视频同步音轨，用于复制音频、参考音色、对白、歌词、节奏、音乐或音效。视频自带声音不等于自动创建 Audio。

### 3. 判断任务类型

`summary` 第一行以方括号任务类型开头，只从下列类型选择；多个类型用 ` + ` 连接：

- `keyframe completion`：图片是具体首帧、关键帧、尾帧或构图锚点。
- `reference generation`：素材只作为人物、场景、风格、动作、运镜、剪辑或分镜参考。
- `video editing`：直接修改源视频。
- `video continuation`：从源视频继续或延伸。
- `audio reuse`：完整或部分复制源音频信号。
- `audio reference`：仅参考音色、节奏、内容、音乐风格或声音质感。

只上传视频不自动判定为编辑或续写；只上传音频不自动判定为复用。视频编辑且保留原声时通常加入 `audio reuse`。

视频编辑任务的 `summary` 在任务类型后必须写：`The target video is an edited version of <Video 1>.`

### 4. 设计保留关系

`retention_analysis` 每个标签单独一行。视觉标签只能使用：`fully_preserved`、`partially_preserved`、`attribute_transfer`、`weak_reference`。音频标签只能使用：`fully_copy`、`partially_copy`、`reference`、`weak_reference`。

视觉格式：

`<Subject 1> (appears in [Shot 1]): fully_preserved - ...`

音频格式：

`<Audio 1>: reference - ...`

不要在 `retention_analysis` 中写 `(S1)`、`(S2)` 等说话人 ID。新增剧情、动作或背景不等于参考内容损失；关系必须依据标签定义的职责判断。

### 5. 编写六段输出

严格按以下顺序输出，不能缺段、换序或增加并列字段：

1. `subject_definitions:`：逐行定义所有实际使用的 Subject、Picture、Video、Audio，说明来源、职责和不可漂移特征。
2. `summary:`：一个简短英文段落，以任务类型开头，概括主体、镜头流程和参考关系。
3. `retention_analysis:`：逐标签说明保留、迁移、复制或参考关系。
4. `detailed_description:`：最重要的主体。先用一至两句确定视觉风格、摄影语言、色彩和灯光，再按播放顺序写镜头。
5. `overall_soundscape:`：一个连续英文段落，概括环境声、动作声和非语言人声；不要重复完整对白或歌词。
6. `non_diegetic_music:`：描述只有观众听到的配乐；没有时写 `N/A`。

镜头规则：`[Shot 1]` 不写时间戳；后续镜头使用 `[Shot N] At MM:SS.mmm, ...`，时间戳严格递增且小于总时长。每次切镜必须提供新的主体、空间、状态、视点或时间信息；只改变距离或角度时使用运镜。

`detailed_description` 的最后一个 `[Shot N]` 描述结束后，必须立刻另起两行，按提示词正文语言依次追加完整禁文字约束和固定禁字幕规则，再写 `overall_soundscape:`。中文提示词依次用 `画面中不出现任何可读文字：无字幕、无台词字幕、无文字叠层、无 UI、无标签、无 Logo、无水印、无片尾文字。所有对白仅以角色口述声音呈现，画面不显示台词文字。` 与 `全片不准出现字幕。`；英文提示词依次用 `No readable on-screen text: no subtitles, dialogue captions, text overlays, UI text, labels, logos, watermarks, or end credits. All dialogue is heard only and is never displayed as text.` 与 `No subtitles are allowed throughout the video.`。不得省略、改写、移到其他字段或把它另写为镜头。

### 6. 加入可执行的专业细节

每个镜头至少交代当前构图、主体位置、环境、动作因果、表情/视线、运镜、灯光、材质和同步声音。运镜遵循“类型 + 必要时的幅度/速度 + 目标 + 叙事动机”，每镜一个主运镜，最多一个兼容的次运镜。

主要动作按以下因果链描写：

`意图/驱动力 → 准备与重心转移 → 启动 → 接触与受力 → 惯性/重力/摩擦响应 → 次级运动 → 减速和稳定`

表演按以下连续变化描写：

`情绪起点 → 触发事件 → 微表情 → 视线目标 → 头部/身体反应 → 情绪落点`

人物要保持脸、发型、体型、服装、饰品和左右细节稳定；产品要保持几何、材质、Logo、文字和零件位置稳定；场景要保持布局、屏幕方向、运动轴线、光源和相对位置稳定。默认遵循现实物理，除非用户明确要求超现实。

### 7. 对白、声音和文字

- 实际发声者按第一次发声顺序分配 `(S1)`、`(S2)`，跨镜头保持不变。
- 对白和歌词逐字保留原语言，使用 `<d>...</d>`；口型、下颌、呼吸和停顿同步。
- 画外音写 `off-screen`，并说明画面人物嘴唇闭合；对白跨切镜使用 `<scenetrans>`；结尾截断使用 `<cutoff>`。
- 无对白时嘴唇自然闭合，不产生无意义说话动作。
- 不在画面中生成任何可读文字；若参考素材含文字，只锁定非文字的材质、位置和构图，不复现字符。
- 具体镜头中的脚步、碰撞、机械声、对白和画内音乐写入 `detailed_description`；总结段不要重复完整对白。

### 8. 输出偏好

若用户未指定，默认使用 `standard`：先输出一行中文元信息，再输出一个纯文本代码块中的六段英文提示词；确有重要推断时，代码块后最多列三条中文假设。

若用户指定 `paste_only`：只输出六段英文提示词，不加标题、解释、假设、自检或候选版本。

## 冲突优先级

按以下顺序处理冲突：

1. 用户明确要求、对白/歌词原文、可见文字原文。
2. 关键帧、源视频编辑/续写关系、直接复制的音频信号。
3. 人物身份、产品几何、服装、Logo、场景结构。
4. 标签职责、任务类型、保留关系。
5. 动作物理、时间线、空间连续性。
6. 表情、运镜、灯光、声音设计。
7. 哈苏、8K、电影感等风格增强词。

## 输出前自检

确认六段齐全且顺序正确；所有标签先定义后使用；任务类型与素材职责一致；时间戳递增；`detailed_description` 写的是可执行的镜头时间线而非剧情摘要；人物、产品、场景、灯光、对白、口型和声音保持连续；没有互相冲突的运镜；没有把非画内音乐写成画内声；最后一个镜头后、`overall_soundscape:` 前已单独紧接按顺序追加与提示词语言一致的完整禁文字约束和固定禁字幕规则；没有宣称原生哈苏拍摄或原生 8K 输出。

生成类任务的 `detailed_description` 通常控制在约 350–500 个英文词，并与总时长承载能力匹配。过长时，先删重复画质词，再压缩次要背景，最后合并重复一致性描述，但保留标签定义、任务类型、保留关系、关键动作、对白和声音关系。
