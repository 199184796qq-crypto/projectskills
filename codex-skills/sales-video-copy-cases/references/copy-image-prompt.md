# 口播文案文字图片提示词

## 使用规则

每次生成带货口播文案后，在文案下方附一个 `生成图片提示词`。这个提示词只用于把上面的口播文字做成图片展示，不生成商品画面，不生成真人画面。

如果口播文案配有拍摄建议，`生成图片提示词` 里只把关键卖点对应的可视化画面建议列进去。它们只是文字提示，不是让图片生成真实画面。

## 图片内容规则

- 图片只展示文字，不要人物、商品、场景、装饰插画。
- 文字内容必须来自上方口播文案，不要另写一套新文案。
- 关键词必须标在口播文字内部，比如加粗、变色、加底色、加重点符号；不要在图片里单独列“关键词”。
- 语气、表情、停顿等辅助信息也要嵌入口播文字内部，用括号或小标签标注，例如：`（惊喜）`、`（认真）`、`（压低声音）`、`（停顿）`。
- 只给关键卖点句添加 `画面建议：...`，普通铺垫句、情绪句、转场句不需要加。
- `画面建议` 必须和关键卖点对应，例如价格对比、数量铺开、拆箱、手持展示、咬开截面、冷链箱、快递送到门口等；不要单独放到图片外面列成另一套清单。
- 版式适合手机竖屏浏览，默认 9:16。
- 字要大、行距舒适、适合截图保存和照着念。

## 默认图片提示词结构

```text
生成一张竖版 9:16 纯文字口播文案图片。
画面只包含文字，不要人物、不要商品、不要背景插画、不要复杂装饰。
整体风格干净、清晰、适合短视频带货口播提词。
使用大号中文字体，黑白为主，重点词用高亮色或加粗标注。
把以下口播文案排版成适合手机阅读的分段文字，只在关键卖点句旁边保留对应的可视化拍摄建议：

{带有重点标注、语气标注、表情标注、关键卖点画面建议的口播文案}

要求：
1. 关键词直接在原文中高亮，不要单独列关键词。
2. 语气和表情提示直接嵌在对应句子旁边。
3. 只在关键卖点句下方增加一行小字 `画面建议：...`，画面建议只作为文字注释展示。
4. 画面建议必须对应当前关键卖点的可视化证明，不要和文案脱节。
5. 每段不超过 2-3 行，方便照着念。
6. 保留原文顺序，不改写文案。
7. 画面无水印、无logo、无多余英文。
```

## 文案内标注示例

```text
（惊喜）我做梦都没想到，**蒙牛官方雪糕组合**，这个价也能薅到。
画面建议：桌面铺开整组雪糕，展示品牌组合和数量感。

（认真）平时单支买真的不便宜，夏天家里孩子要吃、自己追剧要吃，几天就没了。

（强调）这次是**蒙牛官方组合**，不是杂牌，家里囤着更放心。
画面建议：展示外箱、官方发货信息、冷链包装或收货开箱。
```

## 输出位置

最终答案顺序：

1. 正式口播文案
2. 拍摄提示或画面建议
3. 生成图片提示词
4. 合规检查
