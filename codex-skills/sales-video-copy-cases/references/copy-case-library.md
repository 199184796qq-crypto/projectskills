# 带货视频文案案例库

## 食品试吃带货

### 1. 写实真人食品试吃转化口播

- 类型：食品短视频带货口播
- 适用产品：猪腿、鸭货、冰粽、熟食、零食、地方特产、礼盒装食品
- 目标人群：爱吃肉/爱囤货/家庭加餐/节日送礼/直播间冲动购买人群
- 触发词：食品试吃带货、接地气口播、真人吃播卖货、开盒试吃、咬开特写、家庭加餐、赶紧囤、链接下单
- 文案结构：强体验钩子 -> 开盒/拿起 -> 试吃感受 -> 质地特写 -> 价格活动 -> 催单
- 核心卖点：真实试吃、口感具体、画面有食欲、价格机制清楚、收尾催单自然
- 口感/质感词：香、入味、软烂、不柴、越嚼越香、汁感、肉质紧实、酱香、咸香微甜、过瘾
- 价格机制：`{价格}`、`{数量}`、`{活动节点}`、`{限时福利}`
- 成交动作：点链接、趁活动囤、家里加餐、追剧当零食、送人有面子
- 外部条件：最好配合人物真实照片、产品完整图、包装图、手持图、咬开/切开/撕开后的特写图。

#### 文案拆解

- 钩子：`这个{产品}一打开，香味真的很顶。`
  - 重点：先用闻到的香味做即时体验，比直接说好吃更真实。
- 试吃：`肉特别{口感1}，一点都不{负面口感}，{亮点部位}越吃越香。`
  - 重点：正向口感 + 排除顾虑 + 具体部位。
- 特写：`这个{味型}是进到{产品}里面的，{核心口感}，吃起来特别{感受}。`
  - 重点：解释为什么好吃，给镜头特写理由。
- 促单：`家里{使用场景}都很合适，趁活动还在，喜欢{品类}的赶紧{动作}。`
  - 重点：场景化收尾，不硬喊买。

#### 可套用模板

```text
这个{产品}一打开，香味真的很顶。
{核心部位/口感}特别{口感1}，一点都不{负面口感}，{卖点}越吃越香。
这个{味型}是进到{产品}里面的，{核心口感}，吃起来特别{感受}。
家里{使用场景1}或者{使用场景2}都很合适，趁活动还在，喜欢{品类}的赶紧{下单动作}。
```

#### 猪腿示例

```text
这个猪腿一打开，香味真的很顶。
肉特别软烂，一点都不柴，骨边肉越啃越香。
这个酱香味是卤进肉里的，咸香入味，吃起来特别过瘾。
想吃肉的真的可以囤，家里加餐或者追剧啃都很合适，趁活动还在赶紧拍。
```

#### 鸭货示例

```text
这个鸭子真的太香了，打开就能闻到酱香味。
肉很紧实，不柴，越嚼越香。
这个酱香味是进到肉里面的，咸香微甜，特别下饭。
家里来客人或者自己加餐都很合适，趁活动还在，喜欢吃鸭子的赶紧囤。
```

### 2. 分人群带货版本

- 类型：多受众短视频带货文案
- 适用产品：地方食品、礼盒、节日特产、家乡味产品
- 目标人群：本地人、外地人、在外打工的人、送礼人群
- 触发词：多受众版本、本地人文案、外地人文案、打工人家乡味、送礼场景
- 文案结构：人群身份 -> 场景共鸣 -> 产品理由 -> 下单动作

#### 本地人版本模板

```text
本地人应该都懂，{产品}好不好吃，一入口就知道。
这个{产品}{核心口感}，不是那种空有味道的。
平时家里加餐、朋友来吃饭，摆一份都合适。
趁现在活动还在，想吃的直接点链接。
```

#### 外地人版本模板

```text
外地朋友想尝尝{地方}味道，可以先试这个{产品}。
它不是那种特别夸张的味道，入口是{口感}，越吃越香。
自己吃方便，送人也不尴尬。
现在活动价还可以，想尝鲜的可以拍。
```

#### 在外打工版本模板

```text
在外面久了，有时候就馋这一口{家乡味/熟食}。
这个{产品}{核心口感}，吃起来有点像家里饭桌上的味道。
下班回家热一下，配饭或者追剧都舒服。
趁活动还在，给自己囤一点。
```

### 零食营销框架案例库

- 类型：零食带货文案框架／品牌种草内容／短视频口播结构
- 适用产品：薯片、坚果、果干、肉类零食、糖果、饼干、礼盒、地域风味零食
- 目标人群：追剧人群、办公室人群、学生、通勤人群、聚会与送礼人群
- 触发词：零食营销框架、零食文案案例、零食种草、零食带货口播、追剧零食、零食标题
- 文案结构：场景或情绪钩子 -> 产品特点/感官证明 -> 使用或分享画面 -> 具体活动信息 -> 自然行动引导
- 核心原则：不只说“好吃”，而是把产品特点翻译成某个人在某个时刻的可感知理由。

#### 框架分类与套用案例

| 分类 | 真实案例做法 | 可套用结构 | 示例文案 |
| --- | --- | --- | --- |
| 场景占位 | 王小卤将虎皮凤爪反复放入追剧情境，强化“看剧吃零食”的联想。 | 时刻 + 小麻烦/期待 + 产品解法 | 今晚的剧情可以虐，嘴巴必须有点盼头：一嗦脱骨的{产品}，追剧搭子到位。 |
| 情绪代言 | “有情绪”以考试、佐酒、办公室等场景和情绪重新命名零食。 | 情绪共鸣 + 给感受命名 + 产品陪伴 | 今天不想当大人，就当五分钟脆脆星人。打开{产品}，烦心事先靠边。 |
| 感官暴击 | 乐事的视觉叙事强调金黄、酥脆、调味颗粒等即时可见的口感证据。 | 动作/声音 + 口感层次 + 回味 | 轻轻一掰，先听见“咔”；入口是{风味}的香，嚼到最后还有一点回甜。 |
| 原料溯源 | 乐事用“从土豆田到包装袋”的路径讲原料与品质。 | 原料来源 + 制作过程 + 最终口感 | 这包{产品}从{原料/产地}开始，只做成你一口咬下去的{口感}。 |
| 反差猎奇 | 奥利奥以 BTS 联名、韩式糖饼风味和紫色饼干制造限定话题。 | 反常识提问 + 特色风味 + 试吃验证 | 谁把{风味}做成了零食？先别下结论，掰开这一口再说。 |
| 社交分享 | 奥利奥曾开放包装个性化定制，让零食成为可送出的共同创作。 | 关系对象 + 分享理由 + 送出动作 | 这包不是“给你吃的”，是给那个总说不饿却先伸手的人准备的。 |
| 人群身份 | 王小卤把产品扩展到出游、下午茶、送礼等生活时刻，塑造“快乐搭子”。 | 人群身份 + 当下需求 + 产品角色 | 给开会开到脑子发白、又不想吃太撑的人，一包刚刚好的{产品}。 |
| 共创互动 | 零食内容可用口令领券、投票选味、分支剧情等方式，把观看变成参与。 | 邀请选择 + 参与动作 + 结果兑现 | 下一包出麻辣、烧烤还是{风味}？评论区投票，票数最高的我们真做。 |
| 节日记忆 | 徐福记春节传播围绕年味、糖盒和礼赠体验建立仪式感。 | 记忆画面 + 情感连接 + 节日动作 | 小时候盼的是桌上的糖盒，长大后带回家的，是这一盒{产品}和一句“新年甜一点”。 |
| 促销转化 | OREOCodes 把买牛奶、扫码和领取优惠串成一次自然购物体验。 | 场景价值 + 具体组合/福利 + 行动引导 | 追剧补货别只买一包：{产品}组合装到手{价格}元，把这一周的嘴馋都备齐。 |

#### 商家卖点翻译

| 商家卖点 | 用户真正关心 | 可视化/口播证明 |
| --- | --- | --- |
| 多种口味 | 不容易吃腻，可按场景或口味偏好选择 | 摆出多包口味，逐个掰开或试吃 |
| 原料/产地 | 吃起来更安心，知道这一口从哪里来 | 原料、产地与制作过程的近景 |
| 酥脆/软糯/脱骨 | 第一口到底是什么感受 | 掰开、咬下、拉丝、脱骨等真实动作 |
| 礼盒/大包装 | 送人是否得体，聚会是否够分 | 装箱、摆盘、多人分享画面 |
| 活动组合 | 是否适合当前囤货场景 | 明确展示规格、数量、价格与活动时间 |

#### 使用边界

- 优先使用产品实际可证明的口感、原料、规格、价格、活动与库存信息。
- “限时”“最后”“全网最低”“零负担”“吃了不胖”等内容，只有在有依据时才可使用；默认改成“活动期间”“当前组合价”“适合解馋”等表述。
- 普通食品不写治疗、改善疾病、减肥保证等功效承诺。
