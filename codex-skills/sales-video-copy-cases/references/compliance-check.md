# 带货文案合规检查

## 使用规则

所有带货文案、口播脚本、开头、标题、卖点转译、千川素材、直播间引流文案，在最终输出前必须做合规检查，并在最终答案末尾报告检查结果。

## 必查风险

### 广告法高风险

- 绝对化：最、第一、顶级、极品、全网最低、全网第一、唯一、永久、100%、必买、必抢、必瘦、必赚、根治、治愈。
- 无依据承诺：一定有效、用了就好、吃了就瘦、包治、保证改善、稳赚不赔。
- 虚假稀缺：仅剩最后、马上没了、错过再也没有，除非用户明确有真实库存或活动依据。
- 虚假价格：全网最低、历史最低、亏本卖、倒闭价，除非有可证明依据，默认改成活动价、这波更划算、现在入手更合适。
- 医疗健康暗示：治疗、消炎、降血糖、降血压、修复疾病、改善病症。普通食品、日用品、美妆不得写治疗功效。

### 抖音电商常见风险

- 夸大效果：用了立马见效、吃了马上变好、一定回购、所有人都适合。
- 诱导违规：拿全家手机薅、刷单、恶意退货、绕平台交易、私下转账。
- 绝对价格刺激：不买血亏、必须拍、闭眼入、无脑冲，可改成喜欢可以看看、需要的可以囤、活动还在可以拍。
- 不当对比：踩竞品、贬低同行、没有依据的品牌对比。
- 食品夸张：吃了健康、养生治病、适合所有老人孩子孕妇。可改成口感、方便、家里囤着放心这类体验表达。

## 替换建议

| 高风险表达 | 建议替换 |
| --- | --- |
| 全网最低 | 这波活动价比较合适 |
| 必买/必须拍 | 需要的可以看看 |
| 不买血亏 | 现在入手更划算 |
| 100%有效 | 我用/吃着感觉更方便 |
| 治疗/治愈 | 日常使用更舒服/更省心 |
| 所有人都适合 | 多数家庭场景都能用 |
| 倒闭价 | 清仓活动价/福利价 |
| 拿全家手机薅 | 家里需要的可以多囤几份 |

## 最终报告格式

每次最终输出文案后，附：

```markdown
【合规检查】
- 广告法风险：
- 抖音电商风险：
- 已规避/替换：
- 仍需用户确认：
```

如果没有明显风险，写：

```text
未发现明显广告法或抖音电商高风险词；价格、库存、活动真实性仍需以实际商品页面为准。
```
