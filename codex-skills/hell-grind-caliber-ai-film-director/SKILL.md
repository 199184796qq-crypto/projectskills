# AI 电影导演

> 分层导演技能

## 安全边界

使用这个技能时，创作原创作品，不复制公开参考项目的角色名、剧情桥段、台词、镜头组合、独特视觉表达或品牌标识。目标是学习可复用的制作方法：高概念类型片设计、AI影像管线、视觉连续性和质量控制。

当用户要求“照着某作品做”时，转化为“同等工业完成度、不同世界观和人物关系”的原创方案。

## 核心公式

```text
高概念钩子 -> 小队角色动力 -> 神秘物件/禁忌入口 -> 多世界动作奇观 -> 情感代价 -> 生成资产圣经 -> 镜头工厂 -> 严选成片 -> 瑕疵自检
```

## 融合模块路由

根据任务自动加载参考模块：

- 需要角色演技、表情、台词、眼神、肢体反应时，读 `references/performance-acting-layer.md`。
- 需要Seedance/Higgsfield视频镜头提示词、镜头运动、空间调度、镜头语言、对白时，读 `references/seedance-cinedance-prompt-layer.md`。
- 需要角色图、场景图、道具图、画面关键帧、修图或图像提示词时，读 `references/lira-image-prompt-layer.md`。
- 需要蒸馏或复现电影级人物/场景/道具逼真度、光影、运镜、切镜、镜头连贯性和镜头语言时，读 `references/visual-realism-cinematography-language.md`。
- 需要完整AI长片开发框架、资产卡、镜头工厂表、质量评分时，读 `references/ai-feature-film-framework.md`。

默认顺序：

```text

```

## 工作流程

### 1. 高概念类型定位

先用一句话锁定类型卖点：

```text
普通人/边缘人小队 + 误触禁忌物件 + 被卷入异界战争/神魔规则 + 必须完成抢夺/护送/反杀任务 + 个人情感代价倒逼成长。
```

必须同时定义：

- 类型混合：动作、盗宝、奇幻、恐怖、黑色喜剧、成长、末世或战争。
- 观众承诺：爽点、奇观、压迫、幽默、悲剧、情感牵引。
- 世界冲突：人间秩序与异界规则如何碰撞。
- 制作抓手：最容易被AI生成稳定呈现的核心画面。

### 2. 角色小队设计

用“功能角色 + 情感缺口 + 视觉识别”设计小队。

每个主角必须有：

- 小队功能：领导、破解、肉盾、骗子、狙击、偷盗、灵媒、驾驶、背叛者。
- 情感缺口：债、愧疚、亲情、爱、恐惧、尊严、逃避、赎罪。
- 外观锚点：发型、服装、伤痕、饰品、武器或动作习惯。
- 生成锁：每次提示词固定的年龄、体型、服装、配色、道具。

### 3. 神秘物件与异界规则

把奇观绑定到可见规则，不让特效空飘。

至少建立三层规则：

- 物件规则：神器/碎片/符号如何出现、发光、开门、反噬、升级。
- 怪物规则：敌人从哪里来，弱点是什么，攻击如何影响现实物体。
- 空间规则：门户、地狱、遗迹、寺庙、废城、战场等空间如何互相连接。

每个规则必须有可拍证据：光、血、灰、裂缝、符号、回声、重力异常、影子变形、金属振动。

### 4. 视觉圣经

先做视觉圣经，再做分镜。

视觉圣经至少包含：

- 角色主视觉表
- 场景主视觉表
- 怪物/异界生物表
- 关键道具表
- 光色规则
- 镜头语言规则
- 特效物理反馈规则
- 全局负面提示词

### 4.5 角色表演层

表演不是“展示情绪”，而是“压力下的行为”。给每个有表演任务的角色写：

- 当前目标：此刻要从谁那里得到什么。
- 阻碍与代价：失败会失去什么。
- 策略变化：压迫、哄骗、拖延、威胁、求助、掩饰等。
- 行为节拍：每次信息变化都要有可见反应。
- 眼神生命：先听见/看见，再理解，再行动。

不要直接写“愤怒、悲伤、震惊”，要写角色如何追求目标，情绪从行为中长出来。

### 4.6 图像资产提示词层

为Higgsfield Soul / Soul Cinema / NBP /其他图像模型写资产提示词时，先判断任务类型：

- 角色一致性：锁定身份锚点、服装、发型、体型、道具。
- 场景/关键帧：锁定镜头、光线、空间结构、色彩和材质。
- 道具/产品：锁定材质、形态、比例、清洁背景。
- 修图：只写最小改变，并明确保持哪些内容完全不变。

提示词使用自然清晰的英文，不堆关键词，不把平台参数写进正文。

### 4.7 Seedance视频提示词层

为Seedance/Higgsfield视频生成写提示词时，先做四步静默检查：

```text
Deconstruct -> Diagnose -> Develop -> Deliver
```

输出前必须锁定：

- 第一帧必须有主体，不要空镜开场。
- 当前镜头只出现必要角色和道具，不带入上一场无关信息。
- 人物左右、朝向、视线、站位、手中道具不能含糊。
- 摄影机侧位、镜头焦段、运动路线和最终落点要明确。
- 光线方向、地标距离、物理运动和对白时点要可执行。

### 4.8 逼真度与镜头语言层

电影级真实感来自“可见证据”，不是高清词汇。每个镜头必须从以下层面锁定：

- 人物逼真度：皮肤油汗、伤口血迹、微表情、眼神焦点、发丝湿度、服装褶皱、动作重量。
- 场景逼真度：空间纵深、可互动物件、地面反光、尘埃/烟雾、墙面磨损、光源位置、环境脏乱逻辑。
- 道具逼真度：材质、重量、磨损、比例、握持方式、反光、破损前后状态。
- 光影真实感：自然光方向、侧逆光、阴影侧拍摄、低照度层次、局部高光、避免均匀平光。
- 运镜语言：镜头运动必须服务情绪、空间或动作，不为炫技而移动。
- 切镜逻辑：按动作、视线、声音、道具、情绪或因果切，不用随机快切。
- 连贯性：每镜承接上一镜的身体姿态、道具位置、光线方向、运动方向和情绪状态。

### 5. 提示词资产库

所有人物、地点、道具、怪物都要命名并编号。

推荐命名：

```text
CHAR_主角名
LOC_地点名
PROP_道具名
CREATURE_怪物名
FX_特效名
LOOK_全局影调
SHOT_镜头编号
```

每个资产卡必须写：

```text
资产ID：
名称：
视觉锚点：
材质/颜色：
状态变化：
禁止变化：
基础提示词：
负面提示词：
连续性备注：
```

### 6. 镜头工厂

AI电影不是一次生成完成，而是“多轮生成、严格筛选、再编辑”。

每个关键镜头按以下流程：

```text
剧情目的 -> 关键帧提示词 -> 运动提示词 -> 多版本测试 -> 瑕疵筛选 -> 连续性校正 -> 入剪辑池
```

对重场戏使用“压迫-临界-爆发-后果-钩子”链条：

- 压迫：敌人或环境压倒主角。
- 临界：角色付出身体或情感代价。
- 爆发：物件/能力/真相释放。
- 后果：敌人、场景、旁观者被改变。
- 钩子：更大的威胁或未解规则出现。

### 7. 场景类型模板

#### 盗宝/误触开局

```text
低成本现实空间 -> 角色偷盗/交易/逃跑 -> 禁忌物件异常 -> 小队分歧 -> 门户/怪物/追兵出现 -> 第一处不可逆后果。
```

#### 异界追逃

```text
陌生空间建立 -> 规则展示 -> 小队分散 -> 怪物逼近 -> 牺牲或背叛 -> 找到下一件物件线索。
```

#### 奇观动作场

```text
空间压迫 -> 动作调度 -> 物件激活 -> 环境反馈 -> 敌人被重新定义 -> 新代价。
```

#### 情感回收场

```text
喧闹后安静 -> 角色面对失去 -> 道具/伤口成为证据 -> 做出选择 -> 下一场任务被点燃。
```

### 8. AI瑕疵自检

每轮成片或提示词交付前检查：

- 人脸是否漂移。
- 手、武器、道具是否畸变。
- 服装、血迹、伤口是否延续。
- 门户/怪物/神器规则是否前后一致。
- 镜头轴线是否混乱。
- 动作是否清楚。
- 光色是否统一。
- 奇观是否遮挡人物核心动作。
- 台词和人性段落是否薄弱。
- 是否只有视觉冲击，没有情感代价。

## Pawprint规则

### PAW-HG-001 高概念一口气

- trigger：用户要做AI电影、AI长片、奇幻动作短剧或电影级动态漫。
- attention：故事是否能用一句话产生类型冲击。
- preference：保护清晰高概念，不用复杂设定稀释钩子。
- move：用“边缘人小队 + 禁忌物件 + 异界战争 + 情感代价”重组概念。
- visible_effect：项目更容易进入海报、预告片和第一场戏。
- boundary：不要套用原参考作品的具体人物、神器、门户或剧情。

### PAW-HG-002 资产先行

- trigger：需要生成多镜头、多场景或长篇AI影像。
- attention：角色、地点、道具是否会在多镜头中漂移。
- preference：先建立资产圣经，再写镜头提示词。
- move：为人物、场景、道具、怪物、特效建立ID、视觉锚点和禁止变化。
- visible_effect：多镜头连续性显著提升。
- boundary：单张概念图任务可简化资产卡，但仍要锁定主体特征。

### PAW-HG-003 生成多、筛选狠

- trigger：用户追求高完成度AI影像。
- attention：单次生成结果无法承担电影级质量。
- preference：用版本池和筛选标准代替碰运气。
- move：每个关键镜头生成多版本，只保留动作清楚、连续性稳定、瑕疵少的版本。
- visible_effect：成片质量由“提示词好坏”升级为“生产管线质量”。
- boundary：预算或时间有限时，优先把多版本资源集中在20%出彩镜头。

### PAW-HG-004 奇观必须有规则

- trigger：出现异界、怪物、神器、门户、法术、灾变。
- attention：观众是否知道奇观如何影响现实。
- preference：奇观不只是漂亮，而要改变空间、身体和剧情。
- move：给每个奇观建立触发、代价、视觉反馈和剧情后果。
- visible_effect：视觉效果更可信，剧情也更有推进力。
- boundary：梦境和幻觉可以不完全物理化，但要标注主观视角。

### PAW-HG-005 人性补强

- trigger：项目重视觉、重动作、重怪物。
- attention：角色是否只是跑、打、喊，没有情感驱动。
- preference：用个人代价和关系债务托住奇观。
- move：每个大场面前后加入情感缺口、关系选择或失去证据。
- visible_effect：作品不止是AI炫技，观众更愿意看完整片。
- boundary：短预告可弱化情感，但正片必须补足。

### PAW-HG-006 开放管线可追溯

- trigger：用户要批量生产、团队协作或后续复用。
- attention：提示词、资产、镜头版本是否可追踪。
- preference：让每个镜头能回到资产卡和提示词来源。
- move：建立资产ID、镜头ID、版本备注、入选理由和淘汰原因。
- visible_effect：团队能复盘、替换、扩展项目。
- boundary：个人快速测试可只记录入选版本，但关键资产仍需编号。

### PAW-HG-007 表演是压力下的行为

- trigger：镜头包含台词、对视、冲突、犹豫、隐忍、爆发或关系变化。
- attention：角色是否有具体目标、阻碍、策略和节拍变化。
- preference：不写抽象情绪，写可见行为。
- move：把“他很愤怒/悲伤/震惊”转成目标驱动的眼神、停顿、身体重心、手部动作和策略变化。
- visible_effect：AI视频中的表演更像真人反应，不像摆表情。
- boundary：群像远景可弱化微表演，但主角近景必须写清行为。

### PAW-HG-008 视频提示词先控风险

- trigger：用户要Seedance/Higgsfield视频提示词或电影级镜头运动。
- attention：第一帧、主体、空间、视线、左右、镜头侧位、光线、物理动作是否容易漂移。
- preference：稳定可控优先于华丽形容。
- move：用“场景上下文、输出设置、活跃参考、空间锁、第一帧锁、镜头运动、表演行为、质量锁”的顺序写视频提示词。
- visible_effect：生成结果更少空镜、错位、跳轴、错手、漂浮运动和无关角色。
- boundary：多镜头提示词必须拆开，每镜只保留当前可见可听内容。

### PAW-HG-009 图像提示词分模型路由

- trigger：用户要角色图、场景图、道具图、关键帧、修图或提示词优化。
- attention：任务是生成新图、建立角色一致性、场景关键帧，还是修已有图。
- preference：先选正确图像路线，再写提示词。
- move：角色用身份锚点和参考一致性；场景用镜头/光线/材质；修图用最小变化和保留清单；纹理清理只做表面质量修复。
- visible_effect：图像资产更稳定，修图更少误伤主体。
- boundary：不要把画幅、分辨率、平台按钮参数混进提示词正文。

### PAW-HG-010 逼真度靠证据而不是高清词

- trigger：用户要求人物、场景、道具达到电影级真实或网站级质感。
- attention：画面是否有足够的材质、重量、脏污、光线和物理接触证据。
- preference：真实感来自具体可见细节，不来自“8K、超真实、电影级”等空泛堆叠。
- move：为人物写皮肤/发丝/服装/伤口/眼神，为场景写空间/磨损/反光/空气，为道具写材质/重量/握持/状态变化。
- visible_effect：生成画面更接近实拍剧照，少塑料感和AI光滑感。
- boundary：细节不能挤爆主体；每镜只选择最支持剧情的真实感证据。

### PAW-HG-011 光影先定方向再定氛围

- trigger：需要写光影效果、影调、电影感或避免AI假亮。
- attention：光源从哪里来，人物在亮面还是阴影侧，背景如何分层。
- preference：先锁光线方向和质量，再写情绪氛围。
- move：明确自然光/火光/霓虹/雷光的位置、强弱、色温、反射面、阴影边缘和高光落点。
- visible_effect：画面有低照度层次、侧逆光轮廓、真实反射，不再均匀平光。
- boundary：玄幻能量光可作为辅助光源，但不能取代主光逻辑。

### PAW-HG-012 切镜靠承接

- trigger：需要镜头连贯、切镜手法、动作场或多镜头提示词。
- attention：上一镜结束点和下一镜起始点是否有共享线索。
- preference：切镜要靠动作、视线、声音、道具、运动方向或情绪因果承接。
- move：为每个切点标注承接方式，并锁定身体姿态、道具位置、左右关系、视线和光线方向。
- visible_effect：镜头像被剪辑过的电影段落，而不是散图拼接。
- boundary：故意跳切可以用于惊吓、幻觉或混乱，但必须标注主观或碎片化目的。
