# AI类型长片创作框架

## 一、公开资料蒸馏范围

本框架基于可访问的公开页面、官方课程目录和媒体报道蒸馏生产方法。不可访问的动态项目文件、未公开提示词、完整素材包、工程文件和账号登录内容不纳入事实声称。

可确认的公开信号：

- 参考项目被公开介绍为AI长片/开放项目。
- 官方课程强调从创意到镜头的完整AI电影管线，包括Elements、一致性、资产命名、地点和角色生成、模型测试、瑕疵识别、场景拍摄。
- 媒体报道显示其属于类型混合明显的动作/奇幻/盗宝/异界冒险项目，并采用小团队、较短周期、大量生成筛选的方式完成。
- 评论类报道指出其视觉动作和特效较强，但人类对白与细腻表演仍是AI长片容易暴露的短板。

## 七、电影级AI提示词结构

### 画面提示词

```text
主体资产ID + 外观锁定 + 当前状态 + 单一明确动作 + 场景资产ID + 光色规则 + 镜头景别 + 构图 + 材质细节 + 情绪氛围 + 类型质感
```

### 视频运动提示词

```text
镜头起点 + 摄影机运动 + 主体动作变化 + 环境物理反馈 + 特效触发/变化 + 镜头落点 + 下一镜承接
```

### 全局负面提示词

```text
不要复制任何现成影视角色，不要使用已有作品标志性角色造型，不要新增无关角色，不要改变服装和发型，不要让神器形态漂移，不要道具消失，不要肢体畸变，不要眼神错位，不要特效遮挡主体动作，不要光色突变，不要怪物规则前后矛盾。
```

## 八、预告片结构

```text
0-5秒：高概念视觉钩子
5-15秒：小队身份和禁忌物件
15-30秒：异界规则第一次显形
30-45秒：动作/追逃/怪物压迫
45-60秒：情感代价和团队分裂
60-75秒：最大奇观镜头
75-90秒：标题、反转或终极威胁
```

## 九、正片结构

```text
第一幕：误触禁忌，现实秩序崩坏。
第二幕前半：小队被迫学习异界规则。
第二幕中段：神器/怪物/敌对势力升级，小队关系破裂。
第二幕后半：付出不可逆代价，主角理解真正任务。
第三幕：进入敌方核心空间，以个人情感选择完成类型高潮。
尾声：世界没有完全恢复，留下续作或更大规则。
```

## 十、质量评分

每项0-2分，总分16分：

| 维度 | 判断 |
| --- | --- |
| 高概念清晰度 | 一句话是否能抓住类型卖点 |
| 角色辨识度 | 小队是否一眼可分 |
| 视觉连续性 | 人物、道具、场景是否稳定 |
| 奇观规则 | 特效是否有触发、代价和后果 |
| 动作清晰度 | 观众是否看得懂危险和反击 |
| 情感厚度 | 大场面是否绑定人物关系 |
| 生成可行性 | 提示词是否单主体、可控、可迭代 |
| 瑕疵控制 | 是否有清晰负面约束和淘汰标准 |

12分以下不要进入成片制作，先返工设定、角色或提示词资产。

## 十一、融合制作管线

新增三层专业管线：

```text
Lira图像资产层 -> Acting角色表演层 -> Cinedance视频镜头层
```

### Lira图像资产层

用于角色图、场景图、道具图、关键帧和修图。先判断模型路线，再写自然英文提示词。角色重一致性，场景重空间和光线，道具重材质和比例，修图重最小改变和保留清单。

### Acting角色表演层

用于所有有人物表演的镜头。每个主表演镜头都要定义：目标、阻碍、代价、策略、节拍变化、眼神生命和身体行为。不要直接写情绪，要写压力下的行为。

### Cinedance视频镜头层

用于Seedance/Higgsfield视频提示词。每镜都要控制第一帧、主体位置、左右关系、视线、身体朝向、镜头侧位、焦段、光线方向、物理反馈和负面约束。只写当前镜头可见可听内容，避免带入无关角色和旧场景残留。

### 逼真度与镜头语言层

用于人物、场景、道具真实感，以及光影、运镜、切镜、镜头连贯性。先写可见证据，再写审美词；先锁光线方向，再写氛围；先确定切点承接，再做快切或跳切。详见 `visual-realism-cinematography-language.md`。
