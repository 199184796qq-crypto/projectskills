# 角色表演层：AI视频演技提示词

## 核心原则

表演是压力下的行为，不是情绪展示。写提示词时不要让角色“表现愤怒/悲伤/震惊”，而要写角色想要什么、被什么阻碍、采用什么策略、何时改变策略，以及这些变化如何在眼神、身体和声音里被看见。

## 表演五要素

```text
角色目标：此刻要从谁那里得到什么。
阻碍与代价：什么挡住他，失败会付出什么。
策略：压迫、哄骗、求饶、拖延、羞辱、试探、威胁、掩饰。
节拍变化：策略失败、信息到来、力量关系改变时，行为必须变化。
连续状态：角色在开口前已有状态，镜头结束后状态仍延续。
```

## 眼神生命

每个近景和中近景都要写眼神逻辑：

- 先听见/看见刺激。
- 眼神短暂停住，角色理解信息。
- 目光转向目标或威胁。
- 身体随后行动。

不要写“眼神很有戏”这种空话。写“她先看父亲魂灯，再看李铁锤扣住她的手，最后把目光落回雷缸裂口”。

## 身体行为

身体不要只给台词配动作。身体可以和台词矛盾：

- 嘴上说信任，手指仍抓紧道具。
- 声音平静，肩膀却僵住。
- 眼睛看向敌人，脚步却下意识护住孩子。
- 想逞强，身体先后退半步。

## 台词表演

台词提示词要包含：

```text
voice level + pace + breath + interruption/pause + tactic
```

例：

```text
She speaks in a low, breath-held voice, forcing the words out slowly, using the line to convince herself as much as the man in front of her.
```

## 表演提示词模板

```text
Character performance: [角色] wants to [目标] from [对象], but [阻碍]. [角色] first uses [策略1], then when it fails, shifts to [策略2]. The change is visible as [眼神/停顿/身体/手部变化]. The emotion is restrained and behavior-driven, never exaggerated.
```

## 坏表演修复

| 问题 | 修复 |
| --- | --- |
| 只写情绪 | 改成目标、阻碍、策略 |
| 表情夸张 | 写克制反应、眼神思考、微小停顿 |
| 台词像朗诵 | 写呼吸、断句、听对方反应 |
| 角色像等cue | 写每秒都在听、判断、改变 |
| 情绪突变 | 加节拍变化和触发点 |

## 自检

- 角色此刻要什么？
- 谁或什么挡住了他？
- 失败代价是否足够高？
- 策略是否发生变化？
- 变化是否能被镜头看见？
- 眼神是否先于台词？
- 身体是否有独立生命？
