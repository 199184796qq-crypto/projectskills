# Seedance 2.5 官方手册工作流

## 先选择模式

根据用户目标选择一种主模式，并在输出中明确模式、素材用途和时长：

- **全能参考**：图像、视频、音频和文字混合输入，适合从零生成。
- **首尾帧**：用首帧/尾帧约束开头和结尾，中间用动作与运镜连接。
- **智能编辑/高级编辑/视频编辑**：只改指定区域或元素，要求“其余画面保持不变”；高级编辑可用框选、箭头、定位点和时间戳。
- **视频延长**：原视频不超过 30 秒；延长提示词只作用于新增片段，可连续套娃延长，单次 4–30 秒，极限 30+30=60 秒。
- **超长视频**：一次生成 30–180 秒；必须按时间轴/故事线写清楚段落和全局一致性。
- **白模渲染**：参考 Maya/Blender 白模的动作、站位、镜头路线和构图，生成最终材质与光影。
- **视频无缝转场**：输入前后两段视频，指定遮罩、运动、焦距、形状或空间转场，强调“不修改原素材内容”。
- **多宫格分镜**：把每格当作完整镜头而非单个人物/场景，按格号逐镜补齐构图、景别、运镜、动作和连续性。

## 生成提示词的固定结构

默认使用以下顺序，除非用户明确要求短提示词：

1. **全局参数（超长视频必写）**：模式、时长、画幅、分辨率、整体风格。
2. **素材描述**：按上传顺序写 `@图片1/@视频1/@音频1`，说明每个素材是人物、场景、动作、音色或参考镜头。
3. **一句话概述**：主体 + 地点 + 事件 + 题材/风格 + 特殊运镜。
4. **具体情节**：按时间轴或故事线写；每段同时包含画面、运镜、动作、台词/音效和必要的反向约束。
5. **全局补充（结尾）**：贯穿始终的角色身份、服装、场景、光影、机位、声音和连续性；再次强调不要字幕、不要 BGM 等禁止项。

时间轴用明确区间，例如 `[00:00-00:05]`；动作发生时写出触发条件、方向、速度、空间关系和结果，避免只写抽象形容词。

## 真人/动画角色写法

用“年龄/种族 + 肤色和皮肤质感 + 面部辨识特征 + 眼神与情绪 + 发型发色 + 服装材质与穿法 + 体型/气质/构图”建立身份锁定。多人场景为每个角色分别编号描述，最后加：面容、服装、体型和站位全片保持一致，不互换、不克隆、不变脸。

## 时间戳和镜头控制

把每段写成“镜头景别/机位 → 主体动作 → 镜头运动 → 光影与声音 → 段落结果”。涉及转场时明确转场媒介及连续性，例如：前景遮挡、甩镜、焦点转换、形状匹配、粒子扩散、穿越水面；同时指定不得黑屏、跳帧、硬切、闪烁或改变输入素材。

## 编辑类提示词

编辑任务必须先写“保留项”，再写“修改项”：

`保持原视频的构图、人物身份、动作节奏、背景和音频不变；仅修改 [对象/区域] 为 [目标效果]，从 [时间戳] 开始并在全片保持一致。`

去除字幕/BGM、局部消除、改变机位、绿幕、音色参考和多人参考都应明确“只改什么、其他什么不变”。

## 输出前检查

- 素材编号是否与上传顺序一致，引用是否说明用途。
- 时长、模式和输入限制是否匹配；超长视频为 30–180 秒，普通 Seedance 2.5 duration 为 4–30 秒。
- 是否有可执行的时间轴、景别、镜头方向、主体动作和声音设计。
- 是否在结尾加入全局一致性和禁止项。
- 编辑/转场任务是否明确保留原素材，避免模型重做整段视频。
- 复杂场景是否限制角色数量并区分每个人外观，减少双胞胎、换脸和穿模。

需要精确参数、输入格式、数量限制或官方功能说明时，读取 [官方手册要点](references/official-manual.md)。
