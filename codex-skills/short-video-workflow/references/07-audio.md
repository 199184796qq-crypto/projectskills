# 步骤7：声音资产

## 入口分支

先选择：`声音资产已准备好`或`系统根据分镜分析并给出声音建议`。

## 已准备好

提醒统一映射，如`女主=音频1`、`男主=音频2`。用户回复“完成”后进入步骤8，不强制上传。

## 系统分析

读取对话中的人物年龄气质、剧本、分镜台词和动作，输出：

1. 角色声线表：角色、年龄感、音色音高、语速咬字、气息、情绪基线、变化范围、禁止特征、音频编号。
2. 逐句台词表：镜头、角色、台词、语气、停顿、重音、语速、情绪目标。
3. 音效表：镜头、环境底噪、动作音效、道具音效、远近方向。
4. BGM策略：默认生成阶段关闭BGM，剪辑阶段统一添加；给情绪、速度和进入位置，不虚构文件。

优先选一段主要角色有对白的分镜生成无BGM测试视频，用于提取角色声线。系统只提供分析、提示词和外部制作方法，不声称已生成声音文件。

测试声音提示词：

```text
按角色声线规范、台词语气、停顿和重音生成对白；保持音色、音高、语速、年龄感和气息一致。只生成对白、环境音和动作音效，不生成BGM、字幕、文字、标题、气泡或水印。
```

## 完成标准

主要角色均有唯一声线规范与音频编号；全部台词已标注；环境音、动作音效和BGM策略明确。用户完成后进入步骤8。
