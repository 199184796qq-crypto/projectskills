# 步骤2：人物资产

说明人物资产可在外部生图工具完成，本阶段以关键提示词和验收清单为主。默认只给最终三视图与人物描述提示词；面部、发型、服装拆分提示词仅在用户索要时加载到回复。

## 建议资产

每个主要角色保存：角色定妆图、脖子以上的人物五官面部特写图、面部三视图、胸像三视图、全身正/侧/背面、服装细节图、人物文字描述。角色名、图片编号、音频编号保持一致。若角色后续会出现中近景、近景或面部特写，必须提醒用户为该角色补充一张清晰的脖子以上五官面部特写图，用于防止后续视频生成时换脸或脸型漂移。

## 最终三视图提示词

```text
融合已提供的面部、发型、服装和材质参考，锁定同一真人角色的脸型、五官比例、年龄感、发型、配饰、服装结构、颜色和材质。输出标准角色设定图：左侧清晰胸像，右侧同一角色全身正面、纯侧面、背面三视图；自然站姿，中性纯色背景，均匀柔光，真实皮肤、发丝和布料纹理。遵循项目固定比例及统一视觉的真实度，不新增设计、人物、文字或水印。
```

## 常用四视图提示词：左侧真人特写 + 右侧正侧背全身

用户要求“常用人物资产四视图”“左侧真人特写、右侧三视图”“白底四视图”“左侧特写右侧正侧背全身”时，使用该模板。输出时把已确认的人物面部、发型头饰、身材比例、服装结构、材质和配饰补入对应段落，不要只给通用版式。

```text
生成图中人物的真人形象四视图，白底图。左侧部分展示角色的精细真人特写肖像，其面部特征、骨骼结构、神态表情、发型及头部配饰必须与参考图严格一致，呈现自然的皮肤纹理、毛孔和发丝细节；高解析保留毛孔、细纹、绒毛、眉睫、发际线碎发与皮肤受光后的微小起伏，不磨皮、不锐化过头、不做人像美容，呈现摄影棚质感。左侧特写需要完全正脸，无动作，真人定妆照。

右侧部分展示该角色完全相同的全身真人照片，呈标准 A-pose 站姿，并以精确的三视图排列：正视图、侧视图和背面图。超模的身体比例、完整的服装设计、布料层次、鞋子及整体穿搭风格必须严格遵循参考图。所有服装和配饰均呈现真实的物理材质质感。

确保左侧特写与右侧三张全身图为同一个人物，保持年龄、肤色、脸型、五官比例、身材比例、发型、头部配饰、服装结构、服装颜色、鞋子和整体穿搭完全一致。画面为白底专业角色资产展示，规整排版，干净简洁，不要剧情动作，不要复杂场景，不要海报感，不要杂志大片感，不要文字、水印、边框或装饰图形。禁止脸型漂移、五官漂移、身材比例漂移、服装错色、配饰缺失、皮肤塑料感、过度美颜、廉价 CG 感。
```

## 最终四视图提示词：左右大头下方服装主体

用户要求“四视图”“左右大头下方服装主体”“上方面部特写、下方服装主体”“左下头部裁切的正面服装展示、右下背面全身”时，使用该模板。输出时把已确认的人物面部、发型头饰、身材比例、服装结构、材质和配饰补入对应段落，不要只给通用版式。

```text
生成图中人物的真人形象设定四视图，灰色摄影棚背景，整体为专业真人角色定妆参考板，规整排版，干净简洁，不是海报，不是杂志大片，不要剧情动作，不要复杂场景。整体版式严格分为上下两部分：上半部分占画面高度三分之一，下半部分占画面高度三分之二。

上方区域展示两张精细真人面部特写，左侧为正面面部特写，右侧为侧面面部特写。两张特写都以头部与肩颈为主，构图紧凑，清晰展示人物五官、骨骼结构、妆容、发型、头饰与神态。人物面部特征、发型、妆造、头部配饰必须与参考形象严格一致。皮肤质感真实自然，保留毛孔、细纹、绒毛、眉睫、碎发与皮肤受光后的细微起伏，不磨皮，不过度锐化，不做人像美容，呈现高解析真人摄影棚定妆照质感。

下方区域展示两张身体与服装参考图，左右排列。左侧图片必须是放大后的正面服装展示图，人物采用标准 A-pose 站姿。这一张图的重点不是完整全身入镜，而是“人物尺度明显放大”，让角色在画面中占据更大比例。左侧图片必须使用更近距离的正面取景，人物从肩颈下方开始入画，到鞋子结束，头部因画面放大而被完整裁切到画面之外。请注意，这张图不是普通远距离全身照，而是近距离放大的正面服装图：人物身体在画面中的占比要明显更大，上半身与下半身都要被放大展示，整体视觉效果像时装定妆板中的服装主体展示图。人物双肩、双臂、双手、躯干、腰部、腿部、鞋子必须完整保留，画面边缘只允许裁掉头部，不能裁掉手、脚或身体主体。左侧这张图必须比右侧背面图看起来更“近”、更“满”、更“放大”，让服装细节和身体比例更突出。禁止把左侧图做成普通小比例全身图，禁止人物在左侧图中显得太小，禁止头部仍然留在画面内，禁止只裁掉半个头或留出下巴、嘴巴、鼻子、头发边缘。

右侧图片为背面全身图，标准 A-pose，完整展示从头部到鞋子的背面全身。人物背对镜头，完整保留背面头部、发型背部、服装背面结构、鞋子与整体轮廓，用于展示角色背面造型。右侧这张图为常规完整背面全身展示，人物比例正常，不需要像左图那样放大裁切。

下方两张图必须为同一个人物、同一套服装、同一组配饰、同一身体比例。整体保持超模感修长比例，但不要夸张变形。服装设计、布料层次、鞋子、穿搭风格、服装结构与配饰样式必须严格遵循原图。所有服装与配饰都要呈现真实物理材质质感，布料有自然褶皱、垂坠和厚薄变化，金属有真实反光，皮革、丝绸、纱质等材质表现真实自然。若原图服装为开叉长裙，则左侧正面放大图中人物可自然一条腿向前迈出半步，以展示开叉结构和露腿效果，但整体仍需保持定妆照式稳定姿态，不要做走秀动作。

严格要求：上方两张脸部特写占画面上三分之一。下方两张身体图占画面下三分之二。左下图必须是“放大后的正面服装展示图”，人物在画面中的占比明显更大，头部因近距离取景被完整裁切出画面。右下图必须是完整背面全身图。禁止左下图做成普通比例全身小图。禁止左下图出现任何头部信息。禁止左右服装不一致。禁止人物比例漂移。禁止 AI 油腻感、塑料皮肤感、过度美颜感、廉价 CG 感。
```

## 非主工作流：人物防污染

用户要求“人物防污染”“防止人物被模型污染”“锁脸”“脸不要变”“不要换脸”“人物一致”“五官一致”，或人物资产阶段需要稳定真人角色面部时，使用该规则。该规则只作为人物资产阶段及后续分镜/视频提示词的按需增强，不加入主工作流状态机，不影响步骤推进。

先提醒用户：请为每个主要角色添加一张清晰的脖子以上人物五官面部特写图。特写图需要正脸或接近正脸，五官、脸型轮廓、眉眼走势、鼻型、唇形清楚，光线均匀，不要强遮挡、夸张表情、重滤镜或过度美颜。

唤醒后，在人物资产提示词、人物文字描述、分镜图提示词、首帧图提示词和最终视频提示词中，把以下防污染句自动加入对应角色描述之后。根据角色性别或角色名替换“女主”；如果是男主，改成“男主”；如果是其他角色，改成对应角色名。

```text
这是{角色名}的面部特写。当拍摄人物中近景、近景、面部特写时，人物五官必须严格参考对应角色面部特写图，保持脸型轮廓、五官比例、眼型、鼻型、唇形、眉眼走势一致，不得换脸，不得自动美化，不得生成新人物脸。
```

使用位置：
- 人物资产生成时：放在角色定妆图、四视图或人物文字描述的“面部与妆容 / 一致性限制”之后。
- 分镜图、首帧图和视频提示词生成时：放在对应角色的稳定人物描述之后、当前动作和镜头描述之前。
- 多角色项目中：每个需要稳定面部的角色都单独添加一条，不要把女主、男主或配角混用同一张面部特写图。
- 若用户没有提供面部特写图：先提醒缺失，不强制中断；可继续输出提示词，但必须标注“面部防污染参考图待补充”。

负面限制：禁止换脸、禁止脸型漂移、禁止五官比例漂移、禁止眼型鼻型唇形变化、禁止自动美颜成新人物、禁止把其他角色面部特征混入当前角色、禁止用通用网红脸替代角色脸。

## 按需拆分提示词

- 服装三视图：无头模特，正/侧/背面，锁定版型、结构、色彩、材质和鞋袜。
- 面部三视图：正面、45度、纯侧面，统一表情光线，锁定五官比例，不参考原图发型。
- 胸像三视图：正面、45度、纯侧面，锁定脸、发型、头饰、领口和肩部。
