# 步骤8：最终视频生成提示词

先展示可选镜头编号，让用户按单镜、多镜、范围或段落选择。已有明确选择时直接生成。

## 合并规则

- 所有选中镜头放入同一个提示词，不因跨段、非连续或总时长超过15秒而拆分。
- 默认按原分镜顺序；用户指定顺序时按其顺序。
- 相加原时长并从0秒重新连续编号。
- 非连续处使用硬切、匹配剪辑或已确认衔接，不补入未选剧情。
- 只使用对话中已确认的视觉、人物、场景、道具、分镜和声音资料；不虚构编号或细节。

```text
【素材引用映射】
图片1=...
音频1=...

【人物描述与声线参考】

【场景】
[场景编号、结构、陈设、时间、光线]

【道具】
[道具编号、外观、材质、尺寸、当前状态]

【分镜画面】
镜头编号｜重新计算后的起止时间
【景别】【构图】【运镜】【光线】【人物表情、动作】【场景互动】【台词】【前景】【背景】【台词语气】
[继续写全部已选镜头]

【声音与音效】
[声线、台词语气、停顿、环境音、动作音效；默认无BGM]

【文字限制】
禁止字幕、标题、对白气泡、水印、界面文字和无关文字。

【段落衔接】
[开头承接、镜头切换、结尾人物位置、视线、动作、情绪、道具状态]
```

不得使用“同上”，不得拆成多个提示词。局部修改只重写指定内容并维护相邻连续性。

## 仙侠时间轴提示词

当用户要求“仙侠3镜头提示词”“按仙侠时间轴提示词风格写”“学习刚才那种仙侠提示词”或提供仙侠样例要求复用时，使用本小节。该格式用于 Seedance、SD2 或类似视频模型的最终可复制提示词，重点是把质感、资产引用、分秒镜头、台词和音频合成一个连续提示词。

### 输出顺序

1. **质感前置**：先写整体视频质感与负面约束，例如“超清电影级3D仙侠视频、东方玄幻国风、仙侠游戏写实质电影画风、电影级动态光影、仙雾缭绕、高对比度、全局光照、HDR、电影级调色、无背景音乐、无字幕、无肢体扭曲、禁止生成多个相同人物”。不要只堆形容词，必须与后面的光影、镜头和场景一致。
2. **资产绑定**：紧接着列出角色、场景、比例、分镜参考等引用，保留用户给定的 `名称@[ID]` 原格式，不改名、不省略、不重排关键资产。
3. **全局光影**：单独写“光影：”，说明场景主光、雾气、丁达尔光、侧逆光、光晕、空气层次或色彩方向。
4. **分秒时间轴**：每个镜头用 `▲起止秒:` 开头，写清景别、机位、运镜、人物站位、动作过程、光影变化和结果画面。时间必须连续或明确快切关系。
5. **台词嵌入时间轴**：角色台词用具体时间标注，例如 `0.1～3秒:寒渊：“……”`，OS 也保留时间和人物名。
6. **音频统一收束**：最后用“音频：”按时间段写环境声、动作音效、法术声、脚步声、呼吸声等；如果用户要求无背景音乐，明确写“无背景音乐”。

### 镜头写法

- 运镜必须写具体起点、终点、空间变化和景别变化，例如“俯拍镜头往下拉+往上摇至平视”“仰视短焦镜头跟拍”“镜头极速拉远”“固定特写快切”“中景背影镜头缓慢向下拉”。
- 动作必须写过程链，不写结果词。仙法类动作按“抬手/凝聚/浮现/弹射/贴附/消失/反应”这类顺序展开。
- 光影要和动作绑定，例如符纸浮现时写指尖暖光、白雾光晕、空气中法力共鸣；人物对视时写侧逆光、脸部轮廓光、背景雾气。
- 多角色镜头必须说明谁在主体、谁在背景、谁虚化、谁看谁，避免生成多个相同人物。
- 快切可以放在同一个时间段内，但必须写清每个快切画面的主体和落点。
- 不要把台词、音频和画面分离成互相矛盾的段落；台词时长要能在对应镜头内自然说完。

### FPV镜头

当镜头要跟随灵鸟、飞剑、符纸、灵光、子弹式法术、魂火或其他高速主体时，使用 FPV 镜头模块。FPV 不只写“第一视角飞行”，必须写清楚跟随对象、相机距离、速度变化、路径节点、避障动作、高低变化、转弯方式和落点。

- 写法顺序：`FPV跟随对象 -> 相机贴近位置 -> 起飞/冲出 -> 路径节点 -> 高低变化 -> 速度变化 -> 终点落点 -> 视觉尾迹/空气反馈`。
- 跟随距离要明确，例如“镜头紧贴蓝色小鸟身后半米”“贴着符纸尾部高速追随”“从法术光团后方主观视角冲出”。
- 路径节点要连续，例如“掠过树枝 -> 贴地俯冲 -> 拉升穿过树冠 -> 鸟瞰山体 -> 环绕山体 -> 急转下降 -> 穿过树冠 -> 掠过大石块 -> 贴地飞行”。
- 速度变化要写过程，例如“高速穿梭，持续轻微震颤，转弯时短暂加速，贴地段产生速度压迫，拉升后画面开阔”。
- 视觉反馈要绑定主体，例如“尾部拉出蓝色粒子流”“雾气被冲开形成细长气流”“树叶被气浪轻微掀动”“镜头边缘出现高速运动模糊”。
- 音频要跟距离变化联动，例如“翅膀振动声、空气呼啸声、法力共鸣声随远近产生多普勒效应”。
- 避免只写“FPV飞过树林”。必须写出至少3个明确路径节点和一个终点承接。

FPV可复制句式：

```text
▲X~Y秒:全景/主观高速镜头，FPV穿梭飞行镜头紧贴[发光小鸟/飞剑/符纸/灵光]身后[距离]，[主体]从[起点]冲出，先[路径节点1]，再[路径节点2]，随后[路径节点3]，速度[加速/急转/拉升/俯冲]，尾部拉出[颜色/材质]粒子流，雾气与树叶被气流扰动，最终[落到/冲向/消失在] [终点]，衔接下一镜。
```

### 镜头调度

镜头调度用于安排一段动作里“观众先看什么、再看什么、最后落到哪里”。写仙侠时间轴时，不要只按动作罗列镜头，要让镜头承担叙事功能。

- 先建立空间：用大全景、俯拍、背影或过肩镜头交代人物位置、场景尺度、目标方向和危险区域。
- 再给关键动作：用近景、特写、短焦、固定镜头或跟拍集中到手、眼神、法器、符纸、剑锋、灵光等核心动作。
- 中段释放运动：用平移、跟拍、极速拉远、FPV、快切或环绕镜头表现法术扩散、灵物探路、追击、闪避或空间穿越。
- 最后回到人物反应：用近景、侧逆光、固定镜头或微推进落到脸、手、视线和呼吸，承接台词或下一步行动。
- 每个镜头都要标明功能：空间交代、制止、施法、探路、确认、回收、反应、转场、悬念。
- 调度必须维护连续性：人物左右位置、站立方向、视线方向、手部状态、法术去向、灵物回收点和台词时间不能互相打架。
- 复杂动作优先拆成“人物反应 -> 施法启动 -> 特效生成 -> FPV运动 -> 回收/落点 -> 反应对白”，不要塞进一个镜头里。
