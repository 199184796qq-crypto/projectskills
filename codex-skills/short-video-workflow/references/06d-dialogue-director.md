# 非主工作流：文戏导演

用于把简单文戏内容转成可拍摄、可生成的视频时间线，也用于“文戏导演分析剧本出分镜”：先分析剧情和戏剧核心，再从核心分镜向前后扩展。它不加入主状态机，只在用户明确点名“文戏导演”“文戏导演分析剧本出分镜”“文戏”“正反打”“不越轴”“对话镜头”“镜头语言”“心理特写”，或用户给出人物、场景、对话、剧情、剧本并要求分析或优化分镜时使用。

## 目标

在给定时长内，根据文戏的场景、人物关系和对话，规划：

- 整体场景占位交代，让观众先看懂人物在哪里、谁和谁说话、空间关系如何。
- 先找出剧情核心、人物关系变化和必须被观众看懂的几个核心分镜，不急着一次性给完整分镜表。
- 对话正反打，并保持不越轴。
- 景别、构图、机位、运镜和人物视线落点。
- 根据台词推测人物情绪、潜台词和关系变化。
- 用特写、空镜、手部动作、视线转移、停顿和构图反映心理活动。

## 输入识别

从用户内容中提取：

- 场景：室内/户外、主要家具或空间、入口、窗户、门、桌椅、关键道具。
- 人物：人物关系、站坐位置、主导者、被观察者、谁先说话。
- 对话：每句台词的说话人、语气、停顿、反应。
- 时长：总时长、是否已有时间线；没有时长时按短视频常用的 8-15 秒规划。
- 风格：真实摄影、剧情短片、广告软植入、家庭日常、悬疑、暧昧、冲突等。

## 分析剧本出分镜

用户给一段剧情或剧本时，不要一上来把全部分镜铺满。先辅助用户理顺故事表达：

1. 先提炼这场戏的核心：谁想要什么、谁阻拦什么、关系从哪里变到哪里、观众必须看懂的信息是什么。
2. 找 3-5 个核心分镜：这些镜头不一定连续，但必须能讲出这段戏的大概，例如“关系占位”“冲突爆点”“被戳中反应”“心理转折”“收尾关系变化”。
3. 给每个核心分镜写清表达含义：这个镜头服务什么情绪、信息或关系变化，为什么必须存在。
4. 先交付核心分镜方案，让用户确认方向；除非用户明确要求完整拆分镜，否则不要立即扩展成全量时间线。
5. 用户确认核心分镜后，再围绕每个核心分镜补前后分镜：前分镜负责铺垫信息和空间关系，后分镜负责承接反应、解释变化、完成情绪落点。
6. 扩展时每个分镜都要围绕核心服务，不要为了凑镜头数增加无意义的切景。

核心分镜的常用类型：

- 关系占位镜：交代人物距离、站坐位置、权力关系和关键道具。
- 冲突触发镜：让观众明确矛盾从哪一句台词、哪个动作或哪个道具开始。
- 反应镜：不急着接台词，先看被刺激一方的停顿、视线、手部或身体变化。
- 心理转折镜：用近景、特写、前景遮挡、镜中镜或留白表达潜台词。
- 收尾关系镜：表现冲突暂时升级、缓和、误会加深或关系靠近。

## 分镜练习推导法

分析剧本出分镜时，采用“先问作用，再定镜头”的推导方式。不要把剧本一句一句机械翻译成镜头，而是先判断观众少看哪一张画面会看不懂。

- 先写一句“这场戏真正讲的是”：例如关系破裂、误会加深、被迫和解、试探失败、情绪爆发等。
- 再列“观众必须知道的信息”：人物关系、空间关系、关键道具、谁主动、谁回避、谁在看谁、哪句话改变关系。
- 每加一个分镜都要回答“它补了什么信息”：补关系、补动作原因、补情绪反应、补空间位置、补道具意义、补前后镜头的因果。
- 如果一个镜头只是重复已经知道的信息，就删掉或合并到相邻镜头。
- 如果剧情跳转会让观众疑惑，就在跳转前加一个短镜头交代原因；如果情绪变化太快，就在变化后加一个反应镜承接。
- 核心分镜通常先摆出来，再向前补“为什么会发生”，向后补“发生后角色怎么变”。

常用推导问题：

- 这段戏的关系变化是什么？从疏远到靠近，还是从平静到冲突？
- 哪个道具或动作让冲突成立？合同、作业本、手机、门、照片、杯子等是否需要特写交代？
- 哪个角色掌握主动权？构图里谁站着、谁坐着、谁被压在画面边缘？
- 哪个瞬间是观众必须看见的转折？是台词说出前、说出时，还是对方听完后的反应？
- 当前分镜和前后分镜是什么关系？铺垫、触发、反应、确认、反转、收尾，必须选一个。

练习输出时，优先给“核心分镜推导版”：

```text
剧本核心：……
观众必须看懂的信息：……
核心分镜1：…… / 表达含义：……
核心分镜2：…… / 表达含义：……
核心分镜3：…… / 表达含义：……
待扩展位置：核心分镜1前需要补……；核心分镜2后需要补……
```

用户确认后，再把核心分镜扩展成完整时间线或分镜图提示词。

## 轴线与正反打

1. 先建立一条人物关系轴线：通常连接两个对话人物的眼睛或身体中心。
2. 正反打必须位于轴线同一侧，保持人物左右关系稳定。
3. A 看 B 时，A 的视线方向和 B 的反打视线方向必须能接上，不要两人都看向同一画面方向。
4. 如果必须换轴，先用中性镜头、移动镜头、人物转身或空镜过渡，再进入新轴线。
5. 对话段落不要频繁无意义切景；每次切景必须服务于台词、反应、心理变化或信息揭示。

## 场景占位

每段文戏开头优先安排一个场景占位镜头：

- 中景或中远景，交代人物站坐位置、距离、桌椅/门窗/关键道具。
- 如果剧情依赖某个道具或方向，例如冰箱、门、手机、窗外、餐桌，先让它在空间中有清楚位置。
- 场景占位不要拖长；短视频中通常 0.8-2 秒即可。

## 景别与构图

- 中远景：交代空间、人物距离、权力关系、谁靠近谁、谁被隔开。
- 中景：承接主要对话，保留上半身动作、桌面道具和人物距离。
- 中近景：用于说话人台词和反应，突出眼神、嘴角、肩颈变化。
- 近景/特写：用于心理活动、停顿、被戳中、忍笑、犹豫、撒谎、心虚、委屈、动摇。
- 空镜/道具特写：用于表达人物心里惦记的对象，或给台词做隐性解释。

构图要服务内涵：

- 写构图时尽量交代画面层次：前景看见什么，中景看见谁和主要动作，远景看见什么环境或信息。不要只写“中景”“近景”，要说明镜头里可见的物体、人物位置和空间关系。
- 人物被压在画面一侧：犹豫、弱势、等待回应。
- 人物占画面中心：确定、主动、情绪被看见。
- 桌子、门框、椅背作为隔断：关系距离、试探、防御。
- 前景虚化人物，焦点落在对方：主观关注、被观察、被等待。
- 留白给视线方向：暗示人物想要、担心或期待的对象。

## 章节内图文混排

同一个章节不要求每个分镜头都配分镜表或分镜图片。根据镜头复杂度选择呈现方式：

- 普通对话、过渡反应、简单正反打，可以只用文字提示词交代时间、切镜、构图、动作和台词。
- 画面空间关系复杂、前景遮挡明显、需要固定人物/道具位置、需要说明镜头背后是谁的位置，或需要让生图模型稳定复现画面时，再配分镜图片或分镜图提示词。
- 一个章节中可以混用：部分镜头只写文字，关键镜头配分镜图；不要机械地让每个镜头都变成表格。
- 如果用户明确要求“分镜图”，只给需要图像辅助的镜头生成图像提示词；其余镜头保留文字导演说明。

## 文戏镜头提示词写法

写文戏镜头时，优先使用“镜头编号 + 时间 + 切镜方式 + 机位状态 + 前中后景 + 动作语言 + 台词/声音”的结构。重点不是堆形容词，而是让模型知道画面里谁在前景、谁在近景、镜头从哪里切到哪里、人物动作如何推动台词。

- 切镜要写清楚：例如“5-8S 硬切至梳妆台分镜图”“8-11S 硬切回床边侧视视角”。不要只写“切到她”。
- 固定镜头要说明固定在哪里：例如“固定镜头，床上人物近景，前景是虚化手机，人物躺在枕头上”。
- 前景要有作用：手机、镜子边框、梳妆台物品、门框、肩背都可以作为前景；写清楚是实焦还是虚化，是否遮挡人物，是否形成偷窥、对视、被观察或空间距离。
- 构图要交代层次：前景是什么，中景是谁和什么动作，远景有什么墙面、床、桌面、灯、镜子或对方位置。
- 动作语言要具体：不要只写“她很开心/惊讶”，要写“用衣袖擦眼睛”“坐起身看向镜头方向”“手拿粉扑停在脸边”“眼睛从镜面移到镜头背后的对方”。
- 镜中镜、手机屏、镜子反射要说明观看关系：谁在真实空间，谁出现在反射/屏幕里，镜头背后对应谁的位置，人物视线看向镜面、屏幕还是镜头外。
- 台词要跟动作同拍：先写人物正在做的动作，再接说话内容；如果台词是反应，要先给一个短动作或视线变化承接。

## 情绪与潜台词

不要只写“开心、尴尬、紧张、温柔”。必须落到可见行为：

- 眼神落点：看对方眼睛、看手、看桌面、偷看道具、避开视线。
- 嘴部：抿嘴、嘴角上扬又压住、吞咽、轻轻吸气、说话前停顿。
- 肩颈：肩膀缩一下、身体前倾、下巴收紧、脖子微微后撤。
- 手部：捏衣角、扶杯子、摸桌沿、手背到身后、手指停顿。
- 距离：靠近、退半步、身体转开、半蹲与孩子平视。

## 心理特写

当台词背后有潜台词时，插入短特写：

- “想要但不直接说”：眼睛偷看目标物、手捏衣角、嘴角忍住不笑。
- “被看穿”：短暂停顿、眼睫颤一下、低头、嘴角回落。
- “试探对方”：说完不走，眼神停在对方脸上等反应。
- “关系变近”：身体降低或前倾、视线变软、手部动作放松。

心理特写通常 0.4-1.2 秒，不要拖成情绪空镜。

## 输出格式

默认输出一段可直接复制的视频提示词。用户要求表格时，使用：

```text
| 时间 | 景别 + 机位/运镜 | 构图与轴线 | 画面内容 / 表演 | 台词 / 声音 |
```

如果用户给了明确时间线，严格沿用时间线。没有时间线时，按“场景占位 -> A 台词 -> B 反应/回应 -> 目标物或心理特写 -> 反打 -> 收尾反应”的顺序规划。

如果用户要求章节式输出，允许同一章节内混用两种块：

```text
镜头2 1-5S：硬切，固定镜头，床上人物近景，前景是虚化手机，中景人物躺在枕头上，用衣袖擦眼睛，说：“……”
```

```text
分镜图提示词：镜头3 5-8S，硬切至梳妆台分镜图，固定镜头，左前景是人物侧脸和手部动作，中景镜子里出现人物正脸，桌面化妆品形成生活化前景，蓝色墙面和置物架在远景……
```

## 质量检查

交付前确认：

- 同一章节是否按需要混用文字和分镜图片，而不是每个镜头都强制配表或配图。
- 是否先交代场景占位。
- 对话是否有正反打，且没有越轴。
- 每次切镜是否有情绪或信息目的。
- 前景、中景、远景是否写清楚，前景是否有叙事作用。
- 人物视线方向是否能接上。
- 硬切、固定镜头、镜中镜/手机屏/反射关系是否交代清楚。
- 台词前后是否有可见反应，而不是只让人物机械说话。
- 是否用特写或构图表达潜台词。
- 是否保留用户指定人物、场景、时长、台词和风格。
