# 短视频分镜提示词模板知识库

本文件不是主状态机步骤。仅当用户明确说“给我一套短视频的分镜提示词模板”“把这段文案套上分镜提示词”“写出/给我分镜提示词”“按之前那种分镜提示词格式输出”“分镜拆解”“把文案拆成分镜画面提示词”等需求时读取。

目标：把文案、剧情或样片拆成可直接用于外部生图、图生视频或视频模型的格式化分镜提示词。输出时优先保留用户已确认的人物、场景、产品、地域、价格、口播和镜头数量。

## 使用前判断

- 如果用户只是处在正常短视频工作流第6步，仍使用 `06-storyboard.md`。
- 如果用户要生成单帧画面或外部生图提示词，仍使用 `06b-storyboard-images.md`。
- 如果用户要“模板”“套文案”“完整提示词结构”“每个分镜单独可复制”，使用本文件。
- 如果用户要求“分镜提示词优化”“提示词改成过程”“不要只写结果”“动作按时间段标注”“检查构图和动作冲突”，也使用本文件；这是分镜提示词优化规则，不加入主流程状态机。
- 如果用户要求“分镜拆解”，先把文案或剧情拆成可拍摄的镜头功能，再输出分镜画面提示词；这是辅助技能，不加入主流程状态机。
- 用户提供了参考图或样片风格时，先把视觉风格、场景质感、器材参数、人物锁定和场景锁定写进每个分镜。

## 分镜拆解

当用户要求“分镜拆解”或让你把剧情、文案、样片方法转成分镜画面提示词时，按以下顺序处理：

1. 先读懂文案里的场景、人物、人物关系、关键动作、对白和冲突，不要直接写视频提示词。
2. 把剧情节点拆成镜头功能：环境交代、人物关系、动作推进、对话冲突、反应特写、悬念收束或转场承接。
3. 不要把所有信息塞进一个大景别里。复杂段落优先拆成“全局环境镜头 + 人物关系镜头 + 关键对话/动作镜头 + 反应或收束镜头”。
4. 每个镜头先确定观众应该看什么，再写画面提示词；画面提示词必须服务该镜头功能。
5. 有对白时先按自然语速估算时长，再决定是否拆镜头；普通中文口语可按每秒约4-6个字粗估，并加入停顿和反应时间。
6. 分镜草图思维必须体现在提示词里：写清人物站位、前中后景、视线方向、运动方向、起点、经过位置和终点。
7. 分开写清【构图】【运镜】【人物动作】：构图只写空间安排，运镜只写镜头如何移动，人物动作只写角色可见行为和反应过程。
8. 若用户只要快速结果，可输出精简版分镜；若用户要可复制给视频模型，使用完整“单镜固定结构”。

分镜拆解的最小输出可以使用：

```text
**分镜N：镜头标题，约X秒**
【镜头功能】环境交代 / 人物关系 / 对话冲突 / 动作推进 / 反应特写 / 悬念收束
【构图】谁在画面左/右/前景/中景/远景，关键道具在哪里，人物视线指向哪里。
【运镜】镜头从哪里开始，到哪里结束，景别如何变化，运镜功能是什么。
【人物动作】按时间顺序写可见动作和微反应，不写抽象情绪结果。
【画面提示词】可直接复制给生图、图生视频或视频模型的画面描述。
【对白/声音】有则写清语气、停顿、重音；没有则写“无”。
```

## 输出原则

- 每个分镜都要能单独复制使用，不依赖上下文才看得懂。
- 每个分镜使用同一套固定模块，不要有的分镜缺项。
- 人物、服装、场景、道具、光线方向、器材参数要跨分镜保持一致。
- 计算分镜时长时，如果该镜有对白，必须按照完整对白在正常语气下说完所需时间估算，包含必要停顿、重音和情绪反应时间；不能为了贴合预设总时长随意压缩或胡编时长。
- 优化已有视频提示词时，先判断原文是否只写了结果；如果只写结果，必须改成可生成的过程链，写清“先发生什么、人物如何反应、再做什么、镜头如何跟随、最后落到什么状态”。过程链可以放在【人物动作】里按时间段标注，也可以在全文中连续叙述，但不能只保留最终结果。
- 把剧本中的人物情感、内心活动和感觉类词改成眼睛能看到的动作类描述，例如视线落点、停顿、吸气、吞咽、嘴角、下颌、手指、肩颈、身体重心和距离变化。
- 台词可以保留原文；表演描述写在【人物动作】中，不用解释创作过程。
- 对白不能只写“把话说出来”；必须根据场景和气氛标注语气、停顿、重音、节奏和情绪转折，让台词本身具备可表演性。
- 运镜使用专业影视描述，并说明运镜功能。
- 如果是静态图提示词，也保留【运镜】，但写成该镜头在视频中的运动方式；若用户只要单帧，可把运镜结果转成定格机位。

## 单镜固定结构

每个分镜按以下顺序输出：

```text
**分镜N：镜头标题**

【风格】
竖屏9:16，分镜时长约X秒，[视频类型/剧情类型/平台质感]，[器材或影像质感]，[不要项]。

【色彩倾向】
[主色调]，[场景材质颜色]，[产品/道具颜色点缀]，[整体饱和度与氛围]。

【光影】
[主光来源与方向]，[环境光/补光]，[人物脸部可见度]，[背景虚化或反光等细节]。

【镜头参数】
[相机/器材]，[镜头焦段与光圈]，[景别]，[机位高度]，[景深与焦点]。

【人物和场景】
人物A：[年龄、性别、发型、脸型/体型、服装、固定道具或当前状态]。
人物B：[年龄、性别、发型、脸型/体型、服装、固定道具或当前状态]。
场景：[大环境、空间结构、固定陈设、货架/柜台/门窗/背景、关键道具]。

【构图】
[主体位置]，[前景/中景/背景关系]，[人物视线与空间关系]，[视觉焦点]。

【运镜】
[专业运镜方式]，[起点到终点]，[焦点或拉焦变化]。运镜功能是[钩子/证据/反应/转折/产品展示/算账/价格转化/成交收口]。

【人物动作】
[刺激或意图] -> [0.2-1.5秒微反应] -> [手部/身体动作] -> [台词或沉默回应] -> [回落或承接动作]。

【对白】
人物A（语气/情绪/停顿/重音标注）：……
人物B（语气/情绪/停顿/重音标注）：……

【要求】
音乐：[需要/不需要/按用户原文写清]
字幕：[需要/不需要/按用户原文写清]
文字：[需要/不需要/按用户原文写清]
音效：[需要/不需要/按用户原文写清]
```

## 模块写法

### 【风格】

必须包含：

- 画面比例，如 `竖屏9:16` 或 `横屏16:9`。
- 分镜时长，如 `分镜时长约4秒`。
- 分镜时长必须由该镜头动作量和完整对白共同决定；有对白时先估算台词正常语速读完时间，再增加必要停顿和反应余量。若估算后超出用户指定总时长，必须说明需要压缩台词、拆镜或延长总时长，不能直接写一个不可能完成的时长。
- 内容类型，如 `真实生活感短视频截图`、`本地生活剧情广告`、`老式社区小卖部剧情短片`。
- 器材/质感，如 `索尼FX3电影感拍摄`。
- 明确排除项，如 `不要现代超市感，不要棚拍感，不要夸张漫画感`。

### 【人物和场景】

人物要分别写清：

- 年龄、性别、发型、脸型或体型。
- 固定服装、鞋子、围裙、饰品等。
- 当前镜头中拿着什么、站在哪里、面对谁。
- 不写“很生气、很开心、很满意”等结果词，改到【人物动作】里用可见动作表达。

场景要写清：

- 大环境类型，例如老式社区小卖部、街边雪糕店、办公室、餐馆后厨。
- 空间结构，例如门口方向、柜台位置、货架位置、人物站位。
- 固定陈设和道具，例如玻璃柜台、木质货架、雪糕纸箱、价格牌、手机、产品。
- 质感和氛围，例如暖色木架、门口自然光、玻璃反光、货架商品密集但虚化。

### 【构图】

必须说明：

- 谁在画面左侧/右侧/前景/中景。
- 关键道具是否是第一视觉焦点。
- 人物之间是否隔着柜台、桌子、门口、货架等空间边界。
- 视线关系是否清楚，例如顾客看老板、老板看纸箱、两人都看价格牌。
- 构图必须匹配动作发生的先后顺序。不要写“人物一开始已经站在某位置”，同时在【人物动作】里又写“人物从门内/电梯内/车内走出来”。如果角色尚未出现，应写“画面先对准入口，角色出现后移动到某位置”；如果角色在移动中，应写清起点、经过位置和终点。

### 【运镜】

常用专业写法：

- 手持稳定器跟拍推进：用于开场闯入、追随人物行动。
- 固定机位轻微前推：用于把注意力压到证据或关键道具。
- 中近景静态反打：用于放大人物停顿和反应。
- 轻微横向摇移：用于双人对话和反应承接。
- 主观视角推近：用于产品展示或人物视角转移。
- 近景固定机位下摇/上摇：用于从手部动作回到面部表情。
- 特写缓慢推近和焦点转移：用于价格、手机、按钮等转化信息。
- 中景稳定机位拉焦：用于从成交动作转到口播收口。

每条运镜后必须加一句“运镜功能是……”，说明它在剧情里的作用。

### 【人物动作】

使用可见动作链，不直接写感觉类词：

- 生气：眉头压低、下颌收紧、手指扣住物体、身体前压、视线钉住对方。
- 委屈：眼神从证据移到对方脸上、嘴角抿住、肩膀微收、说话前短暂停顿。
- 疑惑：手停在半空、眉毛抬起、眼睛在物体和对方之间切换、嘴唇微张。
- 想笑但忍住：嘴角短暂抽动、低头停顿、呼吸轻轻憋住、再抬眼看对方。
- 被说服：手从物体上松开、身体从前压变直、眉头慢慢松开、下巴轻点一下。
- 满意下单：肩膀放松、拇指按下按钮、嘴角轻轻抬起、身体不再前压。

优化已有提示词时，【人物动作】优先写成过程，不写成结果。可根据需要使用两种格式：

- 时间段标注：`0-2秒：入口/刺激出现 -> 2-4秒：人物初步反应 -> 4-6秒：确认线索 -> 6-8秒：动作升级 -> 8-10秒：收束状态`。
- 全文过程：用连续句写清动作先后，例如“门打开后人物出现，先低头看手机，再听到动静放慢脚步，随后借反光确认，最后加快离开”。

无论使用哪种格式，都要保证动作和【构图】一致：人物的起点、站位、视线方向、移动路径、道具位置不能互相打架。

动作链示例：

```text
顾客一只手拿手机，另一只手掰着手指计算；眼睛先盯着手指，随后短暂瞥向纸箱，眉头从紧压慢慢松开，嘴唇轻轻抿住，下巴点了一下。
```

### 【对白】

- 保留原文核心台词，必要时按镜头拆短。
- 一条分镜台词不宜过长；长台词拆到相邻分镜。
- 只要分镜里有对白，分镜时长必须能容纳完整对白在正常语气下说完；普通口语可按每秒约4-6个汉字粗估，再根据停顿、重音、反应和地方口语节奏增加余量。
- 角色名统一，例如 `顾客：`、`老板：`、`老板对镜头：`。
- 不把对白写成画面字幕，除非用户明确要求字幕。
- 每句对白都要结合当前场景和人物关系标注表演信息，至少包含语气、停顿或重音中的两项。
- 停顿用明确时长或省略号标注，例如 `停顿0.3秒`、`……`；重音用加粗或文字说明标注，例如 `**69.9**`、`“免费送上门”加重音`。
- 情绪转折要写在角色括号里，例如 `语气从质问转成自嘲`、`先平稳解释，后半句带轻松补充`。
- 对白标注要服务表演，不改台词原意；用户要求“不改台词”时，只添加括号标注、停顿和重音，不重写正文。
- 价格、福利、地名、行动号召等商业信息要标注重音或停顿，让观众能听清。

对白标注示例：

```text
老板（语气平稳，像把账摊开给顾客看；“118”和“69.9”加重音，中间停顿0.4秒）：线下40支 **118**，现在抖音线上——**69.9**。
顾客（先小声重复价格，语气从怀疑变成被说动；前半句后停顿0.5秒，后半句带半开玩笑的自嘲）：**69.9买40支？** ……那我刚刚气势，是不是有点多余？
```

### 【要求】

输出分镜提示词前，必须确认是否需要以下四项：音乐、字幕、文字、音效。用户已经在当前对话中明确说明时，不重复询问，直接写入。

- 音乐：用户肯定时写清音乐类型、节奏、情绪和进入/退出位置；用户否定时写 `音乐：不需要背景音乐`。
- 字幕：用户肯定时写清是否需要对白字幕、字幕位置、样式和出现规则；用户否定时写 `字幕：不需要字幕`。
- 文字：用户肯定时写清画面内是否需要标题、价格、卖点、行动号召等文字；用户否定时写 `文字：不需要画面文字`。
- 音效：用户肯定时写清动作音、环境音、转场音、提示音等；用户否定时写 `音效：不需要额外音效`。
- 用户只说“都要”时，四项全部写为需要，并根据视频类型补全合理细节。
- 用户只说“都不要”时，四项全部写为不需要。
- 用户只回答其中几项时，已回答的明确写入；未回答的只问一次，不自行假设。
- 肯定和否定同等重要，最终每个分镜或总要求区都必须写清，不允许省略否定项。

## 完整输出顺序

1. 先给所有分镜，不额外解释。
2. 每个分镜使用同样的模块顺序。
3. 如果用户要求“每个单独复制”，每个分镜之间用 `---` 隔开。
4. 如果用户提供了总时长，所有分镜时长加起来应尽量等于总时长或接近总时长；但有对白的镜头必须优先满足完整对白时长。若冲突，明确指出冲突，并给出“压缩台词、拆分镜头、延长总时长”三种处理方式中的可行方案。
5. 如果音乐、字幕、文字、音效是全片统一要求，可以先输出一次“全片【要求】”，再在每个分镜的【要求】里写具体执行；如果每镜不同，则每个分镜分别写清。

## 质量检查

交付前确认：

- 每个分镜都有画面比例和分镜时长。
- 有对白的分镜时长已按完整对白正常语速、停顿、重音和反应时间估算；没有出现对白说不完的虚假时长。
- 每个分镜都有【构图】和【运镜】，且运镜有剧情功能。
- 【构图】和【人物动作】已完成一致性检查：人物出现时机、起点位置、移动路径、视线方向和道具位置没有冲突。
- 如果用户要求把结果式提示词改成过程式提示词，最终稿已把结果改成动作过程；可以用时间段标注，也可以用全文过程，但不能只写最终状态。
- 每个分镜或全片总要求中已明确音乐、字幕、文字、音效四项；用户否定的项目也已写清。
- 人物外貌、服装、场景和关键道具跨分镜一致。
- 感觉类词和内心活动已改成可见动作。
- 对白已根据场景和气氛标注语气、停顿、重音和情绪转折，不是纯台词转录。
- 台词没有挤进单个短镜头导致不可拍。
- 价格、产品、地域、福利、行动号召等商业信息没有丢失。
