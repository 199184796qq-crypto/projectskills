# 步骤3与4：场景、道具资产

这两个阶段默认由用户在外部完成。只提醒和记录，不主动展开复杂提示词；用户明确索要时再针对当前资产提供一个提示词。

## 步骤3：场景资产

提示用户准备主要场景参考图，以及需要保持空间一致性的九宫格或多机位参考。若用户上传图片，可检查空间结构、固定陈设、光线方向和多机位一致性，但不得把检查设为推进条件。

用户回复“完成”后直接进入步骤4，不强制上传。

## 非主工作流：场景资产邪修

用户要求“场景图怎么出”“古代场景提示词”“场景资产方法”“影视场景资产”“场景图邪修”“场景资产非主流”，或步骤3需要快速建立可信古装/影视空间时，使用本规则。该规则只作为场景资产阶段的按需增强，不加入主状态机，不影响步骤推进。

核心方法：不要让模型直接空想“古风场景”。先找影视剧或电影中相似的真实场景截图作为“场景母资产”，再用文字补时代、地点、节日/时间、人群活动、道具陈设、光线天气和镜头景别。这样生成的场景更有空间逻辑、时代感和影视质感。

### 资产拆分

按镜头用途把场景母资产拆成三类：

- 远景资产：城池、街市、宫殿、山门、院落全貌。用于开场、转场、交代世界观和空间规模。
- 中景资产：街道、廊桥、阁楼、客栈、庭院、婚房、书房。用于人物行走、对话、相遇和冲突。
- 近景/功能资产：床榻、桌案、帘帐、灯笼、摊位、栏杆、窗户、屏风、茶具、酒旗。用于补真实细节、遮挡前景和情绪氛围。

优先生成横屏高清场景图。横屏范围大，后续可以裁竖屏、局部取景、推拉运镜或作为同一空间的多机位参考。

### 提示词公式

```text
参考图/母资产 + 朝代/时代 + 具体地点 + 时间/节日 + 空间结构 + 人群/活动 + 道具陈设 + 光线天气 + 镜头景别 + 影视质感
```

写提示词时避免只写“古风、唯美、电影感”。必须把可见物写清楚：建筑结构、前中后景、人群密度、摊位或家具、固定陈设、光线方向、空气质感和镜头远近。

### 可直接套用模板

```text
以参考图作为场景母资产，生成一张横屏高清古装影视场景图：[朝代/时代]的[具体地点]，[时间/节日/天气]，[空间结构与建筑关系]，[前景元素]，[中景人物或活动]，[远景环境]，[关键道具陈设]，[光线方向与空气质感]，[远景/中景/近景]，古装剧电影质感，真实空间透视，细节丰富但不杂乱，不要现代元素，不要文字、水印、UI。
```

### 示例

```text
以参考图作为场景母资产，生成一张横屏高清古装影视场景图：大唐长安城东市，端午节前夕，街道热闹非凡，来往百姓、赶马车送货的商人、骑马巡街的胡商络绎不绝，街道两侧有小贩摊位、五彩绳、艾草、香囊、酒旗，暖色夕阳从街巷尽头照进来，空气中有轻微烟尘，远景街市场景，古装剧电影质感，真实空间透视，细节丰富但不杂乱，不要现代元素，不要文字、水印、UI。
```

### 输出格式

用户只要方法时，输出：

```text
场景资产邪修方法：
1. 先找影视参考图做场景母资产
2. 拆成远景/中景/近景功能资产
3. 用公式补时代、地点、氛围、人群、道具、光线和景别
4. 优先横屏高清，后续裁竖屏和做多机位

复制模板：
[给出一条可直接复制的提示词]
```

用户已经提供项目内容时，直接按项目改写成可复制提示词，不要只讲方法。

## 步骤4：道具资产

提示用户优先准备会被手持、交换、反复出现或推动剧情的关键道具，为其保存稳定参考图或三视图，并锁定外观、颜色、材质、尺寸和初始状态。

用户回复“完成”后直接进入步骤5，不强制上传。

## 最小输出

当前处于步骤3时不要同时发送步骤4说明；处于步骤4时不要重复场景说明。
