# 短剧人物环境一致性

用于短剧分镜、关键帧、生图提示词与生视频提示词中的人物—空间连续性控制。目标是让人物在换景别、正反打、过肩、走位或多段生成后，仍处于同一个真实空间，而不是只维持表面的画面左右关系。

## 先建立场景连续性卡

在写提示词或修改镜头前，先从用户提供的素材中整理本场的连续性卡；只记录实际影响镜头一致性的事实：

- **人物锁定：** 每位角色的形象来源、服装、发型、随身道具、起始姿势、朝向、视线对象和允许移动范围。
- **环境锁定：** 一张干净的全景/空景作为空间母版；记录门、窗、走廊、电视墙、厨房门、沙发、桌子、植物等稳定锚点的真实位置与相邻关系。
- **站位锁定：** 为每位出镜角色指定相对环境锚点的位置、朝向、与他人的距离和遮挡关系。优先使用用户给的站位锚点图；没有锚点图时，写成简短站位表。
- **镜头锁定：** 当前镜头的观察位置、景别、前中后景、轴线侧、可见环境锚点，以及本镜末尾的人物/道具状态。
- **光线锁定：** 同场的时间、可见光源、环境光方向、人物补光目标和禁止漂移项。

不要把“画面左/右”单独当作真实站位。画面左右会因反打或机位翻转而改变；真正要继承的是“人物相对门、窗、家具和另一人物的关系”。

## 素材与站位方法

1. **环境母版优先。** 有全景图时，以全景图锁定房间结构、门窗、家具和动线。局部机位图只能补充该角度，不能推翻母版。
2. **站位锚点图单独使用。** 若用户提供带字母、色块、箭头或编号的站位图，它只用于后台规划。先把每个标记译成真实空间坐标，例如“律师坐在电视墙侧单人沙发，面向长沙发”“孩子躲在靠近电视墙的走廊转角后”。最终画面和提示词不得生成字母、箭头、色块、网格或标记。
3. **角色图、场景图、锚点图分工明确。** 角色图锁定外貌和服装；环境图锁定空间；站位图锁定位置和朝向。不要让任一张图承担另两类职责。
4. **多人场面使用座标表。** 三人以上时，为每人写“位置—朝向—视线—与最近人物距离—允许动作”。若有群演，按区域或队列锁定，不要求逐一识别无关背景人物。
5. **关键道具绑定环境锚点。** 文书、茶几、遗像、杯子等一旦影响后续镜头，就记录“在谁的哪一侧、放在何处、朝向谁、是否被拿起”。

## 输出时的写法

先给用户一份简洁的“素材—角色—环境—站位”映射；素材归属含糊时先询问，不凭文件名猜测。随后把连续性约束写入每个相关镜头或 H3 段落：

- 明确真实空间关系，而非只写“人物在左/右”。
- 每次切入正反打、过肩或新机位时，重申可见的环境锚点和人物面向关系。
- 新机位必须说明镜头在空间中的观察位置，以及因此产生的画面左右变化；不得让角色无故换边、换座、换朝向。
- 有前后段时，保存并复述上一段的结尾状态：人物位置、服装、手中道具、视线、表情、机位、构图、光线。
- 生成环境图时先锁定房间母版；生成单镜头时只改变摄像机位置或人物允许动作，不随意增删门、窗、厨房门、电视墙、家具和植物。

使用 H3 时，遵循现有 H3 技能的字段与本地素材编号规则；本技能只补充人物、空间和道具连续性，不替代 H3 的格式规范。若本技能直接输出或修改 H3 段落，则在该段最后一个分镜头结束后，另起两行，按提示词正文语言依次追加完整禁文字约束和固定禁字幕规则。中文提示词依次用 `画面中不出现任何可读文字：无字幕、无台词字幕、无文字叠层、无 UI、无标签、无 Logo、无水印、无片尾文字。所有对白仅以角色口述声音呈现，画面不显示台词文字。` 与 `全片不准出现字幕。`；英文提示词依次用 `No readable on-screen text: no subtitles, dialogue captions, text overlays, UI text, labels, logos, watermarks, or end credits. All dialogue is heard only and is never displayed as text.` 与 `No subtitles are allowed throughout the video.`。不得省略、改写、移到其他字段或另写成镜头。

## 镜头校对

生成或审阅每张图/每段视频后，按[镜头一致性检查表](references/镜头一致性检查表.md)核对。发现错误时先说明“哪条真实空间关系被破坏”，再给出最小修正：改机位、改人物位置、补充锚点，或重新生成局部镜头；不因一个局部镜头而改写已锁定的全景母版。

## 边界

- 本技能服务于用户已确认的剧本、角色资产和场景资产，不擅自改变剧情、服装、时间或人物关系。
- 当用户明确要求风格化空间、梦境、闪回或故意违反轴线时，先确认该偏离是剧情需要，再单独标注为例外，不污染常规连续性卡。
- 无法从现有素材确认门窗、家具或人物位置时，明确指出缺少的锚点图或全景图，不把猜测写成锁定事实。
