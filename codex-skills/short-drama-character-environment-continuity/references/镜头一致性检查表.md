# 镜头一致性检查表

用于对分镜图、关键帧、视频提示词和生成结果进行一次快速复核。

## 1. 人物

- 身份、年龄感、脸部特征、发型、服装、鞋履和随身物是否与角色图一致？
- 角色是否仍在预定的真实位置，而不是只在同一画面左右侧？
- 正反打后，身体朝向、视线对象、手中物和坐/站状态是否仍合理？
- 角色是否未经剧情动作就换座、换边、换装、换手拿道具或消失？

## 2. 空间

- 是否保留环境母版中必须存在的门、窗、走廊、电视墙、厨房门、家具、植物和地毯？
- 新镜头能否从母版中的某个真实机位拍到？看不到的物体应当是被遮挡或在机位背后，而非从房间消失。
- 家具朝向、沙发凸起、茶几位置和通行关系是否与母版一致？
- 对景与反打是否遵守同一条人物交流轴线；如故意越轴，是否有明确叙事理由？

## 3. 道具与动作

- 关键道具在谁手中、桌面哪一侧、是否翻页/收起/交接，与上一镜结尾是否一致？
- 动作是否有连续的起点、过程和停点，而非瞬间改变？
- 道具文字若非剧情必要，是否模糊且不可读；是否消除了无关 Logo、字幕、界面与水印？

## 4. 光线与时间

- 同场的时间、主光方向、窗光颜色、人物补光和整体曝光是否稳定？
- 新机位是否仍能解释当前光向，不出现突然的金黄夕阳、黑脸、过曝或强棚拍感？

## 5. 修正表达模板

当发现问题时，优先用下列形式写回提示词：

`镜头位于【真实机位】；【角色】固定在【环境锚点】旁，面向【对象/方向】；画面只可见【可见锚点】；【不可见锚点】因机位位于画外，不得被删除或替换；人物、道具、光线严格承接上一镜结束状态。`

例如：

`镜头位于卧室过道内、朝客餐厅反打；前景左侧必须保留过道墙体。橙棕色单人沙发靠近浅灰长沙发，二者之间保留低矮圆形茶几；电视墙因在摄影机背后不可见，不得生成到画面中。`
