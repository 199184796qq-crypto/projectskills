# H3 提示词与分镜指南

## 可复制的提示词骨架

```text
【参考素材】
@图片1：锁定……（身份/脸部/服装/产品/场景/构图）
@视频1：参考……（动作节奏/运镜/镜头语言）；不复制其中的文字或Logo。
@音频1：与@视频1配对，参考……（人声/口音/情绪/环境声）；对白按下文逐字说。

【核心创意】
主体……；地点……；发生的事件与动作……；整体风格……；拍摄设备/镜头……；一镜到底或剪辑方式……。

【时间轴】
0–2s：景别……，镜头从……移动到……，主体……，声音/对白……。
2–6s：……
6–10s：……

【约束】
保持……一致；动作自然连续；对白口型同步；不得新增人物/道具/Logo；
非叙事性音乐：N/A；不添加任何背景音乐，仅保留对白与现场音效。
```

## 资产映射写法

先列上传顺序，再列用途。例：`@图片1=主播身份锁定`、`@图片2=店面场景锁定`、`@图片3=产品包装细节锁定`。若使用首尾帧，写“@图片1为首帧、@图片2为尾帧”；若使用全能参考，写清哪些资产只参考动作、哪些资产必须保持产品或脸部特征。

## 一镜到底与多镜头

- 一镜到底：使用“连续单次拍摄、无剪辑、无跳切”，描述起点、路径、速度变化、终点和焦点转移；不要列出 Shot 1/2/3。
- 多镜头：按时间码写每一镜的景别、切点、主体连续性和声音；H3 对切点很敏感，切换时再次指出同一人物/物体和下一镜景别。
- 画外音、J-cut/L-cut 要明写“画外音”或“对白跨切继续”，否则模型容易把声音归给画面人物。

## 提示词自检

1. 是否按上传顺序标记了每个参考素材及其作用？
2. 是否写清主体外观、地点、动作方向、光线、镜头距离和速度？
3. 是否用时间轴拆出关键状态，并让对白长度匹配镜头时长？
4. 是否明确一镜到底或切镜方式，避免两者冲突？
5. 是否逐字保留用户要求的对白、包装文字和屏幕文字？
6. 是否在结尾写明不需要的元素，例如不加字幕、不加 Logo 或不加背景音乐？
