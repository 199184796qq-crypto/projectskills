# 人物资产提示词

从参考图中提取稳定、可复用的人物身份特征，生成可直接用于图像或视频模型的人物资产提示词。优先保证人物辨识度，不用泛化审美词替代具体观察。

## 硬性边界

- 只输出供用户复制到站外生图 AI 的提示词文字，不调用生图工具，不替用户生成图片。
- 启动时先显示 A、B、C 等工作流选择；未规划的工作流标记为“待规划”，不要自行虚构流程。
- 每次回复顶部显示工作流进度、步骤名称和当前步骤。
- 一个步骤一段独立代码块，确保用户可单独复制。
- 支持“返回上一步”“继续”“重新开始”，并同步更新进度。

## 工作流入口

用户选择 A 时，完整读取并执行 [references/workflow-a.md](references/workflow-a.md)。先提供两种入口：

1. **快速通道**：用户上传一张人物参考图；一次性输出第1—8步的全套纯文生图提示词，每步单独代码块。
2. **逐步通道**：严格按第1—8步推进，每次只输出当前步骤，等待用户确认、上传图片或要求继续。

不要在用户未选择入口时直接开始分析。

## 工作流程

1. 检查全部参考图，确认主角、可见范围、遮挡、角度、光线和画面失真。
2. 先提取不随场景变化的身份锚点，再记录服装、动作、环境等可变元素。
3. 按“整体轮廓 → 头脸结构 → 五官比例 → 局部标志 → 身体结构 → 发型服装”的顺序描述。
4. 将最影响辨识度的特征写入提示词前半段，并用明确的禁止项保护它们。
5. 根据用户需求输出单条还原提示词或完整人物资产组。
6. 若用户反馈“不像”，比较生成结果与参考图，定位偏差后只强化错误维度，不盲目堆叠形容词。

## 观察规则

- 只描述图中能确认的特征；遮挡区域标记为“参考图不可确认”，不要虚构。
- 使用相对比例：脸宽与脸长、眼裂宽度、眼距、鼻唇距离、肩头比、四肢粗细。
- 使用形态词：横向椭圆、短圆、低平、轻微上扬、外扩、内收、肉褶位置等。
- 区分自然特征与瞬时状态：骨相和五官属于身份锚点；笑眼、张嘴、转头属于表情动作。
- 不把摄影造成的广角变形、滤镜、磨皮、压缩噪点误认为人物特征。
- 婴幼儿人物重点记录头身比、额头、胎发、眼裂、脸颊、下巴肉褶、手脚和腹部形态。
- 多人画面先说明主角在画面中的位置、衣着或动作，避免串脸。

## 身份锚点层级

按以下优先级组织特征：

1. **一级锚点**：年龄感、性别呈现、族裔外观、脸部外轮廓、头身比例、体型。
2. **二级锚点**：额头与发际线、眉眼形态和眼距、鼻梁鼻头、唇形、下巴与下颌。
3. **三级锚点**：痣、雀斑、酒窝、疤痕、牙齿、肉褶、耳形、发旋等局部标志。
4. **造型锚点**：发型、头饰、服装版型、主色、图案和材质。

一级和二级锚点必须进入主提示词；三级锚点在可见时必须保留；造型锚点按用户是否要求换装决定固定或拆分。

## 提示词构造顺序

按下面顺序写成连续、可复制的自然语言，不输出零散关键词堆：

1. 还原指令：严格以参考图主角为唯一人物依据，不改变年龄感、脸型、五官比例和体型。
2. 人物总貌：年龄段、外观、头身比、体型和整体气质。
3. 头脸结构：头型、脸宽长比、额头、发际线、颧面、下颌、下巴。
4. 五官定位：眉、眼裂、眼距、鼻、口唇、牙齿、耳朵及其相对位置。
5. 识别细节：不对称特征、肉褶、酒窝、痣、胎发等。
6. 身体特征：肩颈、躯干、手臂、手指、腹部、腿部。
7. 固定造型：发型、头饰、服装、颜色、图案、材质。
8. 标准拍摄条件：中性表情、正面视角、平视、均匀柔光、纯色背景、真实皮肤、低畸变镜头。
9. 一致性声明与负面提示词。

不要让场景、运镜和氛围描写压过人物身份描述。

## 标准人物资产组

用户要求“人物资产”时，默认输出以下内容：

### 1. 人物身份档案

- 一句话人物定位
- 一级、二级、三级身份锚点
- 固定造型锚点
- 不可擅自改变的特征

### 2. 核心母提示词

输出一条完整提示词，用作后续所有资产的共同前缀。它必须只包含人物固定特征，不绑定具体剧情场景。

### 3. 标准定妆照

默认生成：

- 正面半身，中性表情
- 左侧面与右侧面
- 正面全身，自然站姿或适龄姿态
- 45度左前与45度右前

每条提示词都复用核心母提示词，只替换角度、构图和姿态。

### 4. 表情资产

生成前先询问剧情用途或角色所处情境，用剧情决定表情名称和情绪偏向；用户已明确给出剧情时直接使用，不再追问。默认可生成九宫格或十六宫格真人表情资产图提示词，表情应真实克制，保持头型、五官位置、发型、妆容、年龄感和服装不变，不让表情改变人物身份。

常用基础表情包括自然、专注、轻微微笑、疑惑、惊讶、紧张、疲惫、冷静、皱眉、生气、释然。根据剧情可替换为更贴合场景的表情名称，例如警觉、隐忍、心虚、压抑、松一口气、强撑微笑、被戳穿后的停顿、犹豫开口前、失望克制、愤怒压住。

### 5. 一致性约束

列出必须保持不变的脸型、五官、体型、发型和服装特征，并说明参考图使用建议：

- 有人物参考功能时，使用原图作为主参考，不仅粘贴文字提示词。
- 初次高度还原可从较高人物参考强度开始；若姿态被参考图锁死，再逐步降低。
- 同一资产组保持相同模型、画幅、镜头语言、种子或角色参考标识（平台支持时）。
- 文生图不能保证身份级复刻；需要高度一致时明确提示用户使用人物参考、角色参考或身份保持功能。

### 6. 负面提示词

负面提示词必须针对参考人物定制，优先禁止：脸型漂移、年龄漂移、眼睛放大、鼻梁美化、瘦脸、体型改变、发型改变、服装错色、图案缺失、皮肤塑料感、卡通化、肢体畸形、多人串脸、文字和水印。

## “不像”时的修正流程

按偏差类型定向修改：

- **脸型不对**：补充脸宽长比、下颌走向、下巴长度和脸颊体积，删除“精致、漂亮、上镜”等泛化词。
- **眼睛不对**：补充眼裂长宽、眼皮类型、眼尾方向、眼距及笑时变化，明确禁止大眼化。
- **鼻嘴不对**：补充鼻梁高度、鼻头形状、鼻翼宽度、唇厚和鼻唇距离。
- **年龄不对**：强化头身比、皮肤状态、牙齿、发量和适龄体态，禁止成人化或幼龄化。
- **体型不对**：写清肩颈、躯干、腹部、四肢粗细及肉褶位置，禁止自动瘦身。
- **服装不对**：逐项锁定版型、底色、图案大小、分布、材质和穿着方式。
- **仍然不像**：说明文字已接近极限，要求使用清晰正脸参考图、补充多角度图或提高人物参考权重。

每次修改都保留正确锚点，只替换或强化产生偏差的部分。

## 质量检查

交付前确认：

- 主角没有识别错。
- 固定特征与场景变量已分离。
- 提示词前半段包含一级和二级身份锚点。
- 没有把滤镜、表情或透视误写成永久特征。
- 资产组各条提示词没有改变人物年龄、脸型、体型和服装。
- 负面提示词针对当前人物，而不是通用模板。
- 输出可直接复制，不要求用户自行拼接关键模块。
