# 角色四视图

只输出提示词文本，不生成图片。先检查用户提供的参考图，提取可确认的脸型、五官比例、发型、头饰、体型、服装、鞋子、配饰与材质；不可确认的背面信息只写为“延续可见设计语言”，不得编造。

## 选择版式

默认使用**白底版**。用户提到“灰底”“上下布局”“左右大头”“服装主体”时使用**定妆板版**。

### 白底版：左侧正脸特写＋右侧正侧背全身

输出一条完整提示词，要求：
- 左侧为完全正脸、无动作的真人定妆特写。
- 右侧为同一角色标准 A-pose 的正视、纯侧视、背面全身图。
- 所有视图锁定年龄、肤色、脸型、五官、比例、发型、头饰、服装、鞋子和配饰。
- 纯白背景、摄影棚质感、无剧情、无文字、无水印、无边框。
- 明确禁止脸型/五官/比例漂移、服装错色、配饰缺失、塑料皮肤、过度美颜和廉价 CG 感。

### 定妆板版：上方双面部特写＋下方服装主体

输出一条完整提示词，要求：
- 灰色无缝影棚背景，上方占三分之一：左正脸特写、右侧脸特写。
- 下方占三分之二：左侧为肩颈以下至鞋子的近距离正面服装主体，头部必须完整裁出画面；右侧为从头到鞋的完整背面全身 A-pose。
- 左下图比右下图更近、更满、更突出服装细节，手脚和身体主体不可裁切。
- 统一使用摄影棚三点式打光：正左侧主光、正右侧辅助光、后右侧轮廓光。
- 锁定人物、服装、材质与配饰一致性；禁止普通远距离小全身图、左下图出现头部、服装不一致、比例漂移、AI 油腻感、塑料皮肤和过度美颜。

## 输出规则

先给出“使用版式：白底版/定妆板版”，再给一个独立的 `text` 代码块。将观察到的角色特征写入提示词前半段；不要留下占位符，除非用户没有提供参考图。
