# 猫咪蒸馏运行包
- 模式：MAKE
- 食谱：novel
- 目标：稳定完成任务，正式输出须通过八分质量闸。

## 必要任务槽位
- desire
- resistance
- scene_goal
- information_gap
- relationship_change
- exit_push

## 建造顺序
1. 明确场景目的和关系变化
2. 选择1条感知爪印确定切口
3. 选择1条品味爪印控制取舍
4. 选择2-3条手艺爪印完成结构
5. 最后最多加载2条声音爪印

## 已验证爪印
### PAW-001｜SENSE_JAR
触发：人物失踪或事实不明，现场仍保留日常物件
注意：物件的方向、数量和排列异常
偏好：先让可见证据说话，再下判断
动作：选一个不起眼的物件变化作为推理入口
效果：推理显得来自现场，而不是作者解释
边界：现场没有可验证物件时不使用；不能让物件直接给出完整答案
单篇上限：按原密度保守使用
替代动作：触发不成立时使用中性工艺，不强行模仿

### PAW-003｜TASTE_JAR
触发：段落里多句同时解释同一结论
注意：哪一个物件或动作已经足够承载意义
偏好：保留可见钉子，删除重复解释
动作：留下最强的具体证据，删去其后的同义解释
效果：文本更紧，读者获得参与推断的空间
边界：教学文本需要明确说明时慎用
单篇上限：按原密度保守使用
替代动作：触发不成立时使用中性工艺，不强行模仿

### PAW-002｜CRAFT_JAR
触发：对话双方回避真正问题
注意：重复动作是否暴露压力
偏好：用动作承载潜台词，少用解释
动作：让被问者重复一项日常动作，同时避开直接回答
效果：观众从动作读出防御和恐惧
边界：关键信息必须明确交代时不使用；连续使用会显得故作深沉
单篇上限：按原密度保守使用
替代动作：触发不成立时使用中性工艺，不强行模仿

## 空槽
- 本次要求的核心罐均有覆盖。

## 交付前质量检查
- 角色目标可见
- 信息差推动场景
- 至少一次关系变化
- 结尾产生下一步推动
- 角色口气未被统一
- 按任务完成度、具体性、爪印匹配、自然度、安全与泄漏五项各0—2分；总分不足8分不得交付。
- 完成后检查刻板化、语料偏斜、上下文坍缩、通用工艺冒名与原文拼贴。
- 不得声称代表本人、复制完整人格或拥有材料之外的私人知识。
