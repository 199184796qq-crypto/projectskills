# 洁净室隔离声明

本项目按洁净室原则重新设计。

## 允许输入

- 公开可访问、许可状态明确的 GitHub 项目文档；
- 通用的软件工程、知识管理、创作教学与评测方法；
- 本项目独立创造的爪印原子、五罐模型、九命工作流、斗猫对照、猫砂过滤、空槽协议和双索引编译。

## 明确排除

- 未公开的私有蒸馏引擎正文、目录结构、内部术语、规则文本、模板、样例与测试数据；
- 任何客户未授权的私人语料；
- 其他项目的源代码复制。

构建期间，私有母引擎仅做外部文件哈希与封存，不解压、不读取、不作为本项目设计输入。本包的目录、命名、运行模型、数据结构、测试方式与样例均独立编写。

## 稳定版加固

- 客户包不读取网络、不读取其他 Skill 目录、不执行语料代码；
- 构建期使用包外私有指纹库做反向扫描，指纹库与命中词不进入客户包；
- 交付包禁止符号链接、嵌套压缩包、缓存字节码、绝对路径和目录逃逸。
