# 猫咪蒸馏 Skill

> 稳定版目标：实用、能打、边界清楚。默认追求 8/10 的稳定交付，不追求完整人格复刻或无限题材迁移。

## 1. 它是什么

猫咪蒸馏 Skill 是一套“创作能力与表达模式编译器”。输入经授权的作品与互动材料，输出一个可运行的创作协作者。它学习的不是名人标签，也不是几句口头禅，而是可追溯的 **爪印原子（Pawprint Atom）**：在某类情境中，材料提供者先注意什么、如何判断、采取什么创作动作、造成什么可见效果、何时不应使用。

本 Skill 不使用意识复制、真人替身或身份延续等承诺。它交付的是：

- 有证据支撑的创作动作库；
- 可切换的表达与协作口气；
- 小说、剧本、专栏、营销文案四类生产食谱；
- 可检查、可纠正、可回滚的运行包；
- 证据不足时明确降级的诚实边界。

## 2. 三条总原则

### 2.1 行为优先

“犀利、温柔、有洞察”不是可执行规则。正式规则必须能回答：

1. 什么情境触发；
2. 他先注意什么；
3. 他做了什么动作；
4. 读者或合作者看见了什么结果；
5. 什么情况下这招不成立。

### 2.2 对照优先

高频不等于独特。某种写法可能只是题材惯例、平台格式或模型默认。候选规律必须经过“斗猫对照”：同一人的强样本与弱样本对照、不同载体对照、相邻创作者对照。无法区分个人特征与行业共性的，只能标为通用工艺，不能冒充个人爪印。

### 2.3 缺口明示

没有证据的槽位不得由模型偷偷补人设。运行时遇到空槽，必须选择：调用中性工艺、询问用户、缩小任务，或明确标注“此处为通用创作补位”。

## 3. 九命蒸馏工作流

每次新建项目严格按顺序执行：

1. **立案**：确定对象、用途、材料授权与输出边界；
2. **收粮**：登记来源、载体、日期、场景、人物关系与质量；
3. **洗粮**：去重、分离转述、恢复段落、标记缺损与污染；
4. **嗅迹**：从材料中提出爪印候选，不急着写人格总结；
5. **分罐**：候选进入感知罐、品味罐、手艺罐、声音罐或协作罐；
6. **斗猫**：用反例、弱样本和对照样本攻击候选；
7. **试爪**：用三个小任务验证能否迁移，不做大篇幅首秀；
8. **装笼**：编译为运行 Skill、机器账本和任务食谱；
9. **续命**：吸收用户纠正，版本化更新，保留旧结论与替代关系。

任何阶段缺少规定产物，不得跳到下一阶段。完整字段见 `docs/NINE_LIVES_WORKFLOW.md`。

## 4. 五罐模型

- **SENSE_JAR｜感知罐**：先看见什么，如何挑素材，什么会被忽略；
- **TASTE_JAR｜品味罐**：接受、拒绝、取舍与质量判断；
- **CRAFT_JAR｜手艺罐**：结构、场面、论证、台词、节奏等可复用动作；
- **VOICE_JAR｜声音罐**：句法、语域、标点、比喻取材和回应长度；
- **RELATION_JAR｜协作罐**：面对用户、编辑、伙伴、质疑者时如何交流和改稿。

五罐必须分开加载。写小说不应自动载入全部聊天人格；聊天协作也不应把小说旁白当日常口气。

## 5. 四口碗运行模式

### MAKE｜创作

根据任务选择小说、剧本、专栏或营销食谱。先从爪印库检索任务相关动作，再用中性格式容器完成作品。

### REWORK｜改稿

先诊断文本与已验证爪印的冲突，再给出局部修改；不得用“更文学”“更高级”等无证据标准覆盖材料提供者的习惯。

### PLAN｜策划

用于选题、构思、结构、场景、论证路线和方案比较。优先加载感知罐、品味罐和手艺罐。

### TALK｜协作对话

用于讨论、反馈、答疑和共同工作。优先加载协作罐与声音罐；必须明确这是经材料提炼的协作风格，不冒充本人。

## 6. 运行协议

收到任务后：

1. 判定模式与食谱；
2. 读取项目营养标签，确认材料覆盖是否足够；
3. 从任务索引取最多 8 个核心爪印，避免一锅倒；
4. 对每个爪印检查触发条件和禁用边界；
5. 缺少关键爪印时执行空槽协议；
6. 生成初稿或方案；
7. 运行猫砂过滤器，检查刻板化、语料偏斜、上下文坍缩、口癖过载和原文拼贴；
8. 运行“八分质量闸”：任务完成、具体性、爪印匹配、自然度、泄漏安全五项中，任务完成与泄漏安全不得为零，总分至少 8/10；
9. 输出作品，并附简短“本次调用说明”：用了哪些已验证能力、哪些是通用补位；
10. 用户纠正进入反馈卡，不直接覆盖旧记录。

## 7. 硬边界

- 不得根据姓名、MBTI、星座或公众印象自动造人格；
- 不得把一篇作品中的偶然写法升级成稳定规律；
- 不得复制来源材料的长句、罕见比喻或连续表达；
- 不得把平台格式当成人格；
- 不得让所有角色或所有文本使用同一种口气；
- 不得把证据不足的推断写成事实；
- 不得宣称复制意识、延续本人身份或代表本人发言；
- 不得在未确认来源权限时摄入私人材料；
- 不得将其他私有系统的目录、术语、规则或样例混入本项目。

## 8. 文件路由

- 建项目：`python tools/catdistill.py init <项目目录>`
- 扫描语料：`python tools/catdistill.py scan <语料目录> --project <项目目录>`
- 校验项目：`python tools/catdistill.py validate --project <项目目录>`
- 生成语料营养标签：`python tools/catdistill.py nutrition --project <项目目录>`
- 编译运行提示：`python tools/catdistill.py compile --project <项目目录> --mode MAKE --recipe novel`
- 泄漏检查：`python tools/catdistill.py leak-check --project <项目目录> --text <成稿文件>`
- 全包自检：`python tools/run_selfcheck.py`

详细方法见 `docs/`，完整跑通样例见 `examples/fictional_creator/`。

新增稳定版命令：

- 准备度检查：`python tools/catdistill.py readiness --project <项目目录> --mode MAKE --recipe novel`
- 生成三次试爪：`python tools/catdistill.py make-trials --project <项目目录> --recipe novel`
- 严格审计：`python tools/catdistill.py audit --project <项目目录>`
