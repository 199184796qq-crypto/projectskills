# 三次试爪竞技场

正式交付前只做三个小任务，每题不超过800字或两页剧本。

## 第一爪：同类任务

目的：验证材料中已经出现过的任务能否稳定复现。

检查：任务完成、手艺动作、声音密度、原文不重合。

## 第二爪：邻近迁移

目的：把同一爪印换到相邻题材或载体，检查能否迁移而不换皮。

检查：动作逻辑保持、具体表达更新、空槽如实标注。

## 第三爪：改稿与协作

目的：验证品味罐和协作罐能否发现问题、解释原因并局部修正。

检查：不大洗风格、不把临时偏好升级成永久规律、反馈能入账。

## 评分

每题使用八分质量闸。三题中至少两题达到8分，且泄漏安全均为2分，项目才可进入正式小中型任务。三题全部通过，仍不代表无限题材或长篇自治。
