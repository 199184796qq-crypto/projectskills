# 九命蒸馏工作流

## 第一命：立案

产物：`project.json`。

必须明确：蒸馏对象、允许材料、目标任务、禁止用途、是否需要协作口气、期望输出载体。没有授权状态说明时，不进入收粮。

## 第二命：收粮

产物：`sources.jsonl` 与语料营养标签。

每份材料登记：来源、日期、载体、场景、是否本人直接产出、完整度、质量、授权与备注。不能只收“代表作”，还要收普通样本、失败样本和不同对象下的互动材料。

## 第三命：洗粮

产物：清洗后的 `corpus/` 与污染报告。

操作：哈希去重、近似重复标记、作者与采访者分离、字幕噪声清理、段落恢复、转述标注、缺页标注。任何清洗不得覆盖原文件；原件保留在 `raw/`。

## 第四命：嗅迹

产物：`pawprints.candidates.jsonl`。

逐段问：这里发生了什么选择？材料提供者注意了哪个变量？做了什么动作？结果是什么？不要先写人格总结。一次只提出一个最小动作候选。

## 第五命：分罐

产物：五罐覆盖图。

把候选归入感知、品味、手艺、声音、协作。一个候选最多有一个主罐，可有两个辅助标签。若大量候选都落在声音罐，说明蒸馏停留在表层，应补任务过程、改稿记录或互动材料。

## 第六命：斗猫

产物：`contrast_report.md`。

每条重要候选至少接受一种攻击：

- 强样本与弱样本：只在好文章里出现，还是本人一直这样做；
- 不同载体：小说、访谈、聊天里是否保持；
- 同类作者：这是个人特征还是行业惯例；
- 反例：何时本人明确不用这招；
- 替代解释：是否其实由平台、编辑或题材造成。

经不起攻击的候选降为假设或通用工艺。

## 第七命：试爪

产物：三份微型考卷与评分卡。

推荐三题：

1. 同题材小样，验证声音与手艺；
2. 陌生题材小样，验证迁移；
3. 改稿任务，验证品味与协作。

每题不超过 800 字或两页剧本。先测后扩大，避免大稿掩盖问题。

## 第八命：装笼

产物：运行 Skill。

仅将 `tested` 或 `active` 爪印编译到运行包。建立任务索引、模式路由、四类食谱、空槽协议和猫砂过滤。机器账本与人类说明同时交付。

## 第九命：续命

产物：`feedback.jsonl`、版本记录与替代关系。

用户纠正必须记为：任务、原输出、问题位置、纠正原因、受影响爪印、处理结果。旧爪印不删除，而是标记 retired 或被新规则替代。每累计十条反馈，重跑三次试爪。
