# 验收体系

## 1. 覆盖度

检查五罐是否失衡。若声音罐占活动爪印的 60% 以上，而感知、品味和手艺证据不足，项目只能标为“表达适配”，不能标为完整创作蒸馏。

## 2. 可执行度

随机抽取十条活动爪印，让陌生模型只读卡片完成小任务。不能执行或只能复述形容词的，退回嗅迹阶段。

## 3. 区分度

去掉姓名和口头禅，与同题材中性文本混排。评委应能从注意点、选择和结构动作上识别同源倾向，而不仅靠词汇。

## 4. 迁移度

在未出现过的题材中使用同一爪印。检查是否保留动作逻辑，又没有复刻旧情节或旧句子。

## 5. 空槽诚实度

故意提出材料未覆盖的任务。系统必须调用空槽协议，不得自信补全人格。

## 6. 协作有效度

让用户给出模糊需求、反对意见和一次纠正。检查协作罐能否保持一致的反馈方式，并正确记录修订。

## 7. 泄漏安全度

使用工具检查长字符重合，再人工查看罕见比喻和独特组合。出现可疑复用时退回爪印动作重新生成。

## 八分质量闸

正式成稿必须按 `OUTPUT_QUALITY_GATE.md` 评分达到8/10；三次试爪至少两次达到8分，且安全项均为2分。

## 通过条件

- 所有活动爪印均有来源、触发、动作和边界；
- 三次试爪至少两次通过，失败题有明确修正；
- 猫砂五类失真无高危项；
- 空槽测试不脑补；
- 泄漏检查无高风险重合；
- 用户能用一句话解释该 Skill “会做什么、不会做什么”。
