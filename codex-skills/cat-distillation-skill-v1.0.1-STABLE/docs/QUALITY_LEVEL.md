# 实用强度档位

本 Skill 的默认目标是“稳定8分”，不是做成无限复杂的全人格系统。

## 8分意味着什么

- 能稳定完成小说场景、短剧场次、专栏段落、营销文案与改稿任务；
- 能学到材料中的注意点、取舍、结构动作和有限表达习惯；
- 能在陌生题材做有限迁移，但证据不足时会明确补位；
- 能接受用户纠正并逐步变稳；
- 不靠口头禅、原文拼贴或夸张人格标签制造“像”。

## 能力上限

本 Skill 不承担完整身份重建、私人心智推断、终身人格模型、无限长篇自治或本人替身承诺。它只编译任务相关、可追溯、可纠正的创作与协作模式。

## 不追9分以上的原因

更高层能力通常需要更重的证据工程、长期追踪和专门评测。客户版优先保证上手、稳定、可解释和低风险，不用复杂度冒充效果。
