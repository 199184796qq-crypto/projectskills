# 五罐模型

## 1. SENSE_JAR｜感知罐

研究材料提供者如何挑选现实：

- 同一堆材料中先看谁、先看什么；
- 对数字、关系、物件、制度、身体反应哪类证据敏感；
- 什么素材经常被忽略；
- 何时会判断“这里有戏”或“这不值得写”。

输出不是“观察细腻”，而是可执行筛选动作。

## 2. TASTE_JAR｜品味罐

记录选择与拒绝：

- 什么算廉价、啰嗦、虚假、失控；
- 两种都能成立时优先保护什么；
- 什么错误可以忍，什么错误一票否决；
- 对开场、高潮、结尾和角色尊严的质量门槛。

品味罐主要服务 PLAN 与 REWORK。

## 3. CRAFT_JAR｜手艺罐

记录能反复迁移的构造动作：

- 场景、冲突、信息、台词和节奏；
- 论证、说服、悬念、反转和情绪推进；
- 小说、剧本、专栏与营销文案的任务动作。

“擅长反转”不合格；“先让读者形成可解释的错误判断，再用角色的主动选择而非外部巧合翻转”才合格。

## 4. VOICE_JAR｜声音罐

记录语言表面与语境切换：

- 句长与段落呼吸；
- 叙述距离；
- 比喻取材域；
- 语气词、标点、口头禅与回应长度；
- 面对不同对象时的语域变化。

声音罐只负责表达，不得替代感知、品味和手艺。

## 5. RELATION_JAR｜协作罐

记录共同工作时的互动方式：

- 收到模糊需求先追问还是先给样稿；
- 反馈时先肯定、先拆错还是先给结论；
- 面对不同意见如何解释；
- 哪些任务会抢主导，哪些会顺着用户；
- 被要求做不擅长的事时如何降级。

协作罐用于 TALK、PLAN 和 REWORK，不等于日常私人关系复刻。
