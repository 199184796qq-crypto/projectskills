# 爪印原子模型

## 一、定义

爪印原子是本系统最小的可运行知识单位。它不是形容词，而是一条具备上下文和边界的创作行为。

标准闭环：

```text
触发情境 → 首要注意 → 判断偏好 → 创作动作 → 可见效果 → 失效边界
```

例如：

```text
触发：双人争执已经持续两轮，双方都在重复立场
注意：谁在回避真正的损失
判断：继续解释只会稀释冲突
动作：让弱势方停止辩解，改为处理一个无关的小物件
效果：沉默变成关系权力变化，而非空白
边界：不适用于需要交代关键信息的调查戏
```

## 二、字段

每条爪印必须包含：

- `id`：稳定编号；
- `jar`：五罐之一；
- `trigger`：可观察的触发情境；
- `attention`：材料提供者首先注意的变量；
- `preference`：选择时偏向保护什么；
- `move`：可执行动作；
- `visible_effect`：文本、画面或协作中的可见结果；
- `boundaries`：禁用条件与失败模式；
- `evidence_refs`：至少一个来源指针；
- `support_level`：strong / medium / weak / hypothesis；
- `counterexamples`：反例；
- `contrast_refs`：斗猫对照记录；
- `trial_refs`：微型试爪记录；
- `task_tags`：可用于哪些任务；
- `source_tags`：来自哪些载体与场景；
- `status`：candidate / tested / active / retired；
- `replaces`：替代的旧爪印；
- `notes`：补充说明。

## 三、准入规则

候选进入活动库前至少满足：

1. 动作能够被另一个模型执行，而不是抽象评价；
2. 有明确触发和边界；
3. 有两个独立片段支持，或一个片段加一次试爪成功；
4. 经过至少一种对照攻击；
5. 不依赖复制原文句子才能成立。

证据不足但值得保留的规则标为 `hypothesis`，不得自动进入运行提示。

## 四、双索引

每条爪印同时建立：

- 来源索引：作品、章节、访谈、聊天场景；
- 任务索引：开场、冲突、台词、转折、收尾、改稿、反馈等。

来源索引用于审计，任务索引用于运行。运行时不得扫描全部账本，只检索任务相关的最小集合。
