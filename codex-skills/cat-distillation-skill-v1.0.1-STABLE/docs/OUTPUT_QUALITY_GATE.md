# 八分质量闸

每份正式输出按五项各0—2分检查，总分10分。低于8分不得直接交付。

## 1. 任务完成度

- 0：漏掉核心要求或格式错误；
- 1：主体完成，但有明显缺口；
- 2：核心要求、载体格式与限制全部满足。

## 2. 具体性

- 0：空泛、套话、可替换成任何人；
- 1：有具体动作或证据，但不稳定；
- 2：关键段落都有可见动作、具体判断或清楚证据。

## 3. 爪印匹配

- 0：只用了口癖或完全无关；
- 1：调用了正确爪印，但触发或边界处理一般；
- 2：爪印在正确情境触发，动作和效果均可见，未越界。

## 4. 自然度

- 0：招式堆叠、机械模仿、角色同声；
- 1：局部生硬或密度偏高；
- 2：爪印融入任务，读者先感到作品成立，再感到风格一致。

## 5. 安全与泄漏

- 0：出现未授权来源、原文拼贴、路径越界或身份冒充；
- 1：无明确泄漏，但存在可疑重合或权限信息不完整；
- 2：来源已授权，泄漏检测清楚，空槽和通用补位已标注。

## 硬门

- 总分至少8分；
- “任务完成度”和“安全与泄漏”均不得为0；
- 任一高危猫砂项出现时，直接退回，不以总分抵消；
- 同一稿连续两次不过，停止小修，回到爪印选择与任务理解重做。
