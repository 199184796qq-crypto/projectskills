# 猫砂失真过滤器

猫砂过滤器用于清理蒸馏过程中最常见的五类失真。

## 一、刻板化膨胀

症状：一个明显口癖或招式被模型撒满全文。

检查：该特征在原材料中的真实密度是多少？是否只在特定对象、情绪或载体中出现？

处置：给爪印添加触发条件、冷却间隔和任务边界；超出原密度时降权。

## 二、语料偏斜

症状：只喂爆款，生成体永远高能；只喂采访，创作像演讲。

检查：语料营养标签是否覆盖普通样本、失败样本、不同载体与不同关系场景。

处置：补样本；补齐前对缺失区域标空槽。

## 三、上下文坍缩

症状：把不同年份、平台、对象和任务的表现混成一种固定人格。

检查：来源标签是否被保留；同一爪印是否只在单一场景成立。

处置：拆分爪印或增加上下文条件，不允许用“他一直如此”偷懒。

## 四、通用工艺冒名

症状：把“冲突要升级”“广告要有行动号召”等公共技巧当作个人特征。

检查：相邻创作者是否同样高频使用；移除姓名后是否仍有区分度。

处置：降级到中性食谱，不计入个人爪印。

## 五、原文拼贴

症状：新稿出现来源中的长连续片段、稀有比喻或独特组合。

检查：字符 n-gram 重合、稀有短语与人工复核。

处置：删除病灶，回到爪印动作重新生成；禁止只做同义词替换。
