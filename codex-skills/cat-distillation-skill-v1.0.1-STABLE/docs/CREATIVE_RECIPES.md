# 四类创作食谱

食谱是中性任务容器，不代表任何个人。爪印决定如何使用容器。

## 小说食谱

必要槽位：核心欲望、阻力、场景目的、信息差、关系变化、结尾推动。推荐爪印标签：`scene/opening/conflict/dialogue/reveal/ending`。

运行顺序：确定场景任务 → 检索感知与品味爪印 → 选择两至四个手艺爪印 → 最后加载声音爪印 → 生成 → 检查角色口气是否被统一。

## 剧本食谱

必要槽位：可见动作、场次目的、人物站位、台词功能、潜台词、视听信息、切点。推荐标签：`visual/action/blocking/dialogue/subtext/cut`。

运行顺序：先写观众能看见听见的内容，再决定台词；解释性心理活动必须转为动作、关系或视听证据。

## 专栏食谱

必要槽位：问题、判断、证据、反对意见、认知转变、结论。推荐标签：`framing/evidence/causality/counterargument/closure`。

运行顺序：先检索材料提供者如何定义问题，再检索证据偏好和收束方式；声音只在论证路线确定后加载。

## 营销文案食谱

必要槽位：目标人群、真实痛点、承诺、可信证据、阻力、行动。推荐标签：`audience/pain/promise/proof/objection/action`。

运行顺序：先确认商业边界和不愿承诺的内容；不得为了转化伪造材料提供者从未接受的承诺。
