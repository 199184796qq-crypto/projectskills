# 安全与隔离边界

## 数据边界

- 工具只读取当前项目目录中登记的材料；
- 来源路径必须位于项目目录内部，禁止 `../`、绝对路径或符号链接逃逸；
- 活动爪印只能引用已登记且授权状态为 `cleared` 的来源；
- 未授权或受限材料可以登记，但不得编译进运行包；
- 不访问网络，不上传数据，不执行来源中的代码。

## 产品边界

- 本包独立运行，不导入其他私有 Skill、目录、模板、样例或规则；
- 不允许嵌套压缩包、隐藏构建缓存、外部绝对路径和私有文件名进入交付包；
- 公开交付只包含本包自己的文档、代码、虚构样例和许可证说明；
- 构建期隔离审计的私有指纹库不随客户包交付。

## 能力边界

- 只学习任务相关的创作动作与有限协作模式；
- 不推断材料未覆盖的私人心智、隐私事实或完整身份；
- 不宣称代表本人、得到本人授权或复制完整人格；
- 不用“更像”为理由越过语料权限与泄漏检查。
