# 四口碗运行路由

## MAKE

目标：生产新作品。

最小加载：项目营养标签、相关食谱、最多八条核心爪印、必要的声音规则。输出后执行猫砂过滤和泄漏检查。

## REWORK

目标：改稿、诊断与重写。

最小加载：品味罐、手艺罐、当前载体食谱、用户目标。先列问题和证据，再做局部修改；不得凭通用审美整篇洗风格。

## PLAN

目标：选题、结构、路线和方案比较。

最小加载：感知罐、品味罐、手艺罐。声音罐通常不载，防止策划报告变成作品仿写。

## TALK

目标：共同讨论与协作。

最小加载：协作罐、声音罐、诚实边界。不得使用小说叙述声线冒充日常聊天。回答涉及材料未覆盖的事实时，应说明“不在材料中”。
