# 严格终检清单

交付前逐项回答“是”。任一“否”即停止封包。

1. 四类食谱是否都能编译？
2. MAKE任务是否至少优先调用感知、品味、手艺中的有效爪印，而不是声音独占？
3. TALK是否只优先调用协作与声音，不把作品旁白当聊天口气？
4. 所有活动爪印是否引用已登记、已授权的来源？
5. 三次试爪是否至少两次达到8分？
6. 输出是否通过猫砂过滤和泄漏检查？
7. 空槽是否明确标记，没有偷偷补人格？
8. 所有项目路径是否位于项目目录内部？
9. 包内是否没有缓存、符号链接、嵌套压缩包和绝对路径？
10. 客户包是否没有导入或引用任何外部私有系统？
11. 自检、单元测试、阳性泄漏对照和异地解压是否全绿？
12. 交付说明是否清楚写明能力范围和限制？
