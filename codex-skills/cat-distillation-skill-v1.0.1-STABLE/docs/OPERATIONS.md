# 运维与版本

## 版本规则

- 主结构变化：提升次版本，如 1.1；
- 新材料、新爪印和食谱修正：补丁版本，如 1.0.1；
- 每个项目拥有独立版本，不跟母 Skill 强绑定。

## 反馈处理

一条纠正不等于一条新规律。先判断它是：任务误解、爪印错误、边界缺失、声音过载、食谱问题或用户临时偏好。只有跨任务成立的纠正才升级为爪印。

## 回归节律

- 每新增十条反馈：重跑三次试爪；
- 每新增一个新载体：重跑上下文坍缩与区分度测试；
- 每次改动核心爪印：重新编译所有受影响食谱；
- 旧记录不物理删除，使用 `retired` 与 `replaces` 保留变更链。

## 稳定版纪律

- 母包只做补丁修复，不向完整身份重建方向扩张；
- 效果不够时先补证据、补对照、补试爪，不先加抽象层；
- 每次封包必须跑严格终检清单和包外隔离审计。
