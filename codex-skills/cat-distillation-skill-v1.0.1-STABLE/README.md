# 猫咪蒸馏 Skill v1.0.1-STABLE

一套面向小说、剧本、专栏、营销文案与创意协作的能力蒸馏工具。它将经授权材料编译成“爪印原子”与任务食谱，强调可执行、可追溯、可纠正，不宣称复制人格或复活本人。

## 快速开始

```bash
python tools/run_selfcheck.py
python tools/catdistill.py init /tmp/my-cat-project
python tools/catdistill.py scan ./my-corpus --project /tmp/my-cat-project
python tools/catdistill.py validate --project /tmp/my-cat-project
```

参照 `examples/END_TO_END_WALKTHROUGH.md` 完成首个项目。

## 核心新逻辑

1. **爪印原子**：把抽象风格改写成“情境—注意—判断—动作—效果—边界”的行为闭环；
2. **五罐模型**：感知、品味、手艺、声音、协作分开学习与加载；
3. **斗猫对照蒸馏**：强样本、弱样本、不同载体和相邻创作者互相对照，防止把行业共性当个人特征；
4. **猫砂失真过滤**：专治刻板化、语料偏斜、上下文坍缩、口癖过载和原文拼贴；
5. **空槽协议**：证据不足时不脑补，明确调用中性工艺或向用户询问；
6. **双索引编译**：每条规则同时按来源和任务索引，运行时只取最小必要集合；
7. **三次试爪**：正式装笼前必须通过三个小任务，而不是靠一篇“看起来很像”的大稿自证。

## 稳定版新增

- 按模式与食谱配罐，避免声音爪印压过手艺；
- 八分质量闸，达不到8/10不交付；
- 三次试爪竞技场与准备度检查；
- 活动爪印只能引用已登记、已授权来源；
- 路径越界、隐藏缓存、嵌套压缩包与未授权材料会被严格审计。
