# AI 人物真实感三招

用于“真实感三招”“表演链”“情绪递进”或“镜头参与”模式。按用户选择加载，不要机械地把全部细节塞进每个镜头。

## 1. 表演链

使用结构：

`前因动机 -> 眼神 -> 呼吸 -> 身体 -> 声音 -> 脸部细节`

- 先写人物收到的刺激、目标或前因，让反应有因果。
- 眼神写清落点、聚焦、回避、眨眼或视线转移。
- 呼吸承担情绪起势：吸气停住、变浅、紊乱、长吐气或恢复平稳。
- 身体只选与情绪强度相符的肩颈、重心、手部或距离变化。
- 有台词时写音量、语速、停顿、关键词和尾音，不改用户原台词。
- 脸部细节放在链条末端，避免先堆眉眼嘴形容词。

不要只写“崩溃大哭”“开心地笑”“非常生气”。把结果词拆成模型可执行的过程。

## 2. 情绪递进

不要让单个镜头直接输出最终情绪。按时间或事件设置状态锚点：

`尚未反应 -> 察觉刺激 -> 试图控制 -> 控制松动 -> 峰值或克制点 -> 余韵`

示例节奏：

`0-1 秒：视线停住，尚未反应；1-2.5 秒：眉间轻收，呼吸变浅；2.5-4 秒：嘴角试图维持平静，下颌开始发紧；4-5 秒：目光避开，长吐一口气，肩膀轻沉。`

规则：

- 给每阶段明确时间或触发事件。
- 每阶段只增加或改变 1-2 个信号。
- 前一阶段的动作要能自然导致下一阶段。
- 强情绪也先铺垫；不要在第一帧直接瞪眼、落泪或大叫。
- 短镜头只保留 2-3 个阶段，长镜头再展开完整链条。

## 3. 镜头参与表演

镜头语境会影响模型对情绪的判断。使用以下四层：

- **景别与运镜**：缓慢推近用于情绪逼近；轻微拉远用于疏离或失落；稳定近景用于克制；手持轻晃用于不安。
- **光影**：柔和侧光保留脸部层次；侧逆光强化轮廓与孤独；避免过平的正面光把微表情抹平。
- **构图**：压缩留白可制造压迫；人物偏侧并看向画外对象，可建立关系与动机；前景遮挡可增加窥视或距离感。
- **视线空间**：写清人物看向镜头、镜头左/右侧的对手、门口、地面或远处，避免无落点的空洞眼神。

镜头变化必须服务当前情绪节拍。不要同时使用快速推拉、旋转、摇移和大幅人物动作。

## 组合模板

`[人物处境与刺激]；[眼神落点与第一反应]，[呼吸变化]，[身体连锁动作]；在[时间/事件锚点]后，[情绪升级动作]；人物以[声音与台词方式]回应，[脸部细节与余韵]。镜头以[景别]从[起点]向[终点]做[运镜]，配合[光影]与[构图]，突出[情绪目的]。`

## 快速自检

- 情绪是否有前因，而非孤立表情？
- 是否写了眼神落点和呼吸？
- 是否存在至少两个连续状态，而非直接给结果？
- 镜头、光影、构图是否服务情绪？
- 是否控制动作数量并保留回落？
