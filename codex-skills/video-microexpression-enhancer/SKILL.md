# 视频微表情增强

把抽象情绪、感觉类词和内心活动改写成眼睛能看到的动作、微表情、姿态和反应节奏，形成可拍摄、可生成、连续且克制的人物表演。默认直接交付优化后的完整内容。

## 可选增强模式

用户可指定一个或组合多个模式：

1. **基础微表情**：按语境补充眼神、嘴部、呼吸、姿态与余韵；默认使用。
2. **真实感三招**：同时启用“表演链 + 情绪递进 + 镜头参与”，适合去除模板化 AI 表演。
3. **表演链**：使用“前因动机 -> 眼神 -> 呼吸 -> 身体 -> 声音 -> 脸部细节”，把情绪形容词改成因果明确的可见反应。
4. **情绪递进**：按时间锚点分阶段变化，不让人物直接跳到最终情绪。
5. **镜头参与**：让景别、运镜、光影、构图和视线空间共同表达情绪。

选择规则：

- 用户已指定模式时，直接应用，不重复询问。
- 用户要求“给我选择”“有哪些模式”或尚未提供待优化内容时，展示以上 5 项供选择。
- 用户仅说“增强微表情”时使用“基础微表情”，不因新增模式阻断交付。
- 用户强调“真人感、去 AI 味、人物表演像真人”时，优先使用“真实感三招”。
- 模式可组合，例如“情绪递进 + 镜头参与”。
- 启用第 2-5 项时，读取 [references/realistic-performance-three-methods.md](references/realistic-performance-three-methods.md)。

## 工作流程

1. 识别人物关系、场景目标、情绪起点、情绪转折、台词和镜头限制。
2. 确定用户选择的增强模式；未指定时按“可选增强模式”的默认规则处理。
3. 标出剧本中的感觉类词、心理判断和内心活动，例如“生气、委屈、心虚、尴尬、被说服、满意、想反驳、觉得不对劲”，并判断它们在画面中应由谁先表现。
4. 将内容拆成情绪节拍；每个镜头通常只保留一个主情绪和一个细微转折。
5. 读取 [references/microexpression-library.md](references/microexpression-library.md)，选择与语境匹配的动作模块。
6. 每个节拍选择 2-4 个有效信号，优先覆盖眼神、嘴部或下颌、呼吸、姿态中的不同层级。
7. 按“刺激或意图 -> 微表情起势 -> 身体连锁反应 -> 主要动作或台词 -> 余韵或回落”写入原提示词；若启用真实感三招，再加入所选的表演链、时间锚点或镜头语境。
8. 检查动作是否能在给定时长内完成，删除冲突、重复和过量动作。

## 改写规则

- 保留用户原有的人物、事件、场景、风格、时长、比例、镜头、台词和输出格式。
- 若其他视频技能已规定表格或模块结构，严格沿用；把增强内容写进人物表演、画面描述或动作字段。
- 不把“悲伤、愤怒、开心”等情绪形容词当成表演结果，必须转换成可见动作。
- 不直接写“他很紧张、她心里不服、老板有点心虚、顾客被说服了”等感觉类或心理类判断；改写为眼睛能看到的动作，如视线落点、短暂停顿、吞咽、吸气、嘴角变化、下颌收紧、手指用力、肩颈收放、身体重心和人与人之间的距离变化。
- 内心活动必须外化成行为链，而不是旁白式解释。优先使用“看见/听见刺激 -> 0.2-1.5 秒微反应 -> 手部或身体跟随动作 -> 台词或沉默回应”的顺序。
- 保留必要的情绪词只用于描述镜头目的或节拍名称；在最终画面、人物动作和提示词主体里，应以可见动作为主。
- 动作必须有先后关系，不要把眉、眼、鼻、嘴、头、肩和手同时机械堆满。
- 微表情应先于或伴随大动作出现；常用持续时间为 0.2-1.5 秒，具体服从镜头时长。
- 正面情绪也保留细微不对称、停顿和呼吸变化，避免持续微笑或夸张瞪眼。
- 低强度情绪使用眼神、呼吸和嘴角；高强度情绪再增加下颌、肩颈、躯干或手部反应。
- 多人物场景补充反应链：看见对方 -> 短暂停顿 -> 微表情泄露 -> 掩饰或回应。
- 有台词时，让表情、吸气、停顿和口型围绕关键词发生；未经要求不得改写台词原文。
- 无台词时，用视线落点、吞咽、呼吸、重心和手部小动作承担叙事。
- 除非用户要求分析或对照，最终只输出增强后的成品，不解释修改过程。

## 强度控制

- 克制：1-2 个微动作，幅度极小，适合写实近景、暧昧、冷漠和压抑。
- 自然：2-4 个连续动作，包含起势和回落；默认使用。
- 强烈：加入呼吸、下颌、肩颈或躯干反应，但保留动作顺序和恢复阶段。

用户未指定强度时，采用“自然”；写实、电影感、古装正剧默认偏克制，喜剧、动漫或强情绪短视频可适度放大。

## 输出适配

- 单段视频提示词：返回一段可直接投喂模型的完整提示词。
- 分镜表：保留列名和镜头数，在每个相关镜头的画面描述中加入表演细节。
- 剧本或台词：保持原文，在台词前后用括号或动作行补充表演。
- 静态图或分镜提示词：在人物和场景、人物动作或画面描述中，把感觉类词替换为可见动作，不保留“内心很...”这类不可见描述。
- 只有创意要求：补全人物表演链，但不擅自扩写无关剧情。
- 用户要求局部修改：只改指定句段，避免重写全部内容。

## 质量检查

交付前确认：

- 表情由情境触发，而不是孤立动作。
- 所有感觉类词和内心活动都已落到可见动作，没有把心理判断直接当成画面描述。
- 眼神有明确落点，头部和身体方向一致或存在有意义的反差。
- 呼吸、停顿、口型与台词节奏相容。
- 同一秒内没有过多动作，也没有互相冲突的肌肉状态。
- 每个情绪变化都有起势、峰值或克制点，以及必要的回落。
- 启用“情绪递进”时，每个阶段都有明确时间或事件锚点，没有直接跳到最终情绪。
- 启用“镜头参与”时，镜头变化有明确目的，且不与人物动作争抢同一时间预算。
- 增强内容没有改变用户明确指定的事实和格式。

## 简短示例

原句：

`女子生气地说：“我讨厌你。”`

增强：

`女子的目光骤然钉住对方，下颌收紧，胸口短促起伏一次；她身体微微前压，压低声音，一字一顿地说：“我讨厌你。”话音落下后仍绷着肩颈，没有立刻移开视线。`
