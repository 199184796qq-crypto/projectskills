# H3剧情延续提示词

根据上一段剧情继续设计下一段 MiniMax H3 视频。必须先读取并遵循 `minimax-h3-video-expert` 与 `h3-prompt-writing` 技能的官方格式；输出中文内容，但保留 H3 要求的字段名、标签和时间格式。

## 开始前的素材核对

要求用户逐项列出素材及用途，不能根据文件名猜用途。素材上限：9 张参考图、3 个参考视频、3 段参考音频。每项必须包含编号、文件或附件、用途和是否锁定。

必须存在一张“上一段视频最后一帧”。如果没有，停止生成提示词并要求用户提供尾帧；不能用普通角色参考图代替尾帧。

素材用途至少区分：

- 锁定人物/物体/场景参考：进入多参考锁定体系。
- 上一段尾帧：只读取其可见内容，用自然语言描述开头接续状态，不进入锁定体系，也不作为 H3 图片引用输入。
- 目标尾帧（如果用户另行提供）：只读取其可见内容，用自然语言描述片段结束状态，不进入锁定体系，也不作为 H3 图片引用输入。
- 视频参考：明确是动作、镜头、节奏、场景还是直接续接来源。
- 音频参考：明确是声线、对白、环境声、音乐、节奏还是直接复用音轨。

说话人编号执行永久一一对应规则：`<Subject N>` 必须使用 `(SN)`，并与其声线参考 `<Audio N>` 使用相同数字。不得按首次发声顺序、对白先后、段落顺序或本段是否发声重新编号。例如米小乐为 `<Subject 1>` 时永远使用 `(S1)` 和 `<Audio 1>`；米大乐为 `<Subject 2>` 时永远使用 `(S2)` 和 `<Audio 2>`；如玉为 `<Subject 3>` 时永远使用 `(S3)` 和 `<Audio 3>`。该规则优先于官方示例中的发声顺序编号。

如果用户没有说明某个素材的用途，先询问，不得擅自决定。用户可一次提供多种素材，但必须给出清晰映射。

## 参考标签规则

除所有尾帧图片外，锁定的图片、视频和音频按 H3 全参考格式定义：

- 人物、物体、场景等可复用视觉内容使用 `<Subject N>`。
- 作为锁定来源的图片使用 `<Picture N>`，并在对应 Subject 定义中说明来源。
- 有明确结构、动作或镜头作用的视频使用 `<Video N>`。
- 声线、对白、音乐或环境音参考使用 `<Audio N>`。
- 凡用户明确指定用途为“上一段尾帧”或“目标尾帧”的图片，绝对禁止分配 `<Picture N>`、`<Subject N>` 或其他素材标签，禁止通过 Subject 定义间接绑定，也不得接入 H3 多参考图片输入。
- 正文和“参考设定”中都禁止用“图片1”“图1”“第1张图片”“尾帧图”“附件名”或 `<Picture N>` 等写法指代尾帧。必须先观察尾帧，再把构图、人物姿态、视线、表情、服装、物体位置、景别、镜头角度、场景、光线和色彩等可见事实改写成不含素材引用的自然语言。
- 尾帧是提供给提示词作者观察的上下文资料，不是提供给 H3 的生成素材。成品提示词中禁止出现“首帧锚点”“关键帧锚点”“从该图开始”“从 `<Picture N>` 开始”“以该图为准”“该图拥有最高优先级”“工作流续接状态和该图拥有绝对优先级”“该图所呈现的上一段最终画面”或任何同义、变体、暗示性表述。不得在 `summary` 的任务类型中因为这张尾帧加入 `keyframe completion`。
- 若用户口头把尾帧称作“图1”，但另有一张真正上传给 H3、用于锁定人物或场景的 `<Picture 1>`，必须严格区分两者：尾帧的口头编号不得进入提示词，也不得占用或改变 H3 素材编号；真正上传的 `<Picture 1>` 仍按实际用途与对应 `<Subject N>` 明确关联。
- 每个由真实上传参考图锁定的对象，都必须在 `subject_definitions` 中使用“`<Subject N> 是来自 <Picture N> 的……`”或等价明确句式建立关联。不得因为删除尾帧引用而误删真实角色图、场景图或物体图与 `<Subject N>` 的对应关系。
- 上一段尾帧的自然语言状态只写入开头 1.5 秒的 `detailed_description`；目标尾帧的自然语言状态只写入结尾对应时间段的 `detailed_description`。不得在 `subject_definitions`、`summary` 或 `retention_analysis` 中留下任何尾帧图片标签、编号或文件指代。

锁定人物参考在整个提示词中保持身份、年龄、脸型、发型、体型、服装、配饰和色彩一致。尾帧只约束开头接续构图，不得让尾帧画面锁住后续剧情。

## 输出格式

先在代码块外写“参考设定”，明确哪些非尾帧素材接入 MiniMax H3 多参考、哪些素材是音频/视频参考。对于尾帧，只能写“上一段结尾可见状态：……”或“本段目标结束状态：……”并直接描述画面内容；不得写出图片编号、图片名称、附件名、素材标签，也不得说“哪一张是尾帧”。正文同样不得把尾帧写成或暗示成锁定图片。

然后严格按以下顺序输出完整提示词：

```text
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

正文使用中文；字段名以及用于非尾帧素材的 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>`、`[镜头N]`、`<d>` 和时间格式保持标准 H3 写法。对白必须放在 `<d>[中文] ...</d>` 中，并逐字保留用户指定内容。

`detailed_description` 中最后一个 `[镜头N]` 的镜头描述结束后，必须立刻另起两行，按提示词正文语言依次追加完整禁文字约束和固定禁字幕规则，再进入 `overall_soundscape:`。中文提示词依次用 `画面中不出现任何可读文字：无字幕、无台词字幕、无文字叠层、无 UI、无标签、无 Logo、无水印、无片尾文字。所有对白仅以角色口述声音呈现，画面不显示台词文字。` 与 `全片不准出现字幕。`；英文提示词依次用 `No readable on-screen text: no subtitles, dialogue captions, text overlays, UI text, labels, logos, watermarks, or end credits. All dialogue is heard only and is never displayed as text.` 与 `No subtitles are allowed throughout the video.`。不得省略、改写、移到其他字段或另写成镜头。

## 剧情和时间编排

根据用户指定时长计算镜头时间，不压缩关键对白。若有对白，先估算自然语速所需时长，再留至少 0.3–0.5 秒停顿；需要“说完后才移动/抬头/切镜”的动作，必须把画面锁定写成明确时间区间。不能只写“说完后”，要写具体时间。

连续剧情默认按以下顺序组织：

1. 00:00.000–00:01.500：首句统一写“保持上一段结尾完全相同的构图”，随后用简洁自然语言描述该构图中的人物位置、姿势、表情、景别、机位、场景、光线和可见背景；不得提及任何图片、尾帧、附件或素材标签。除非用户另有要求，不开始新动作。
2. 00:01.500 之后：才开始本段新剧情，并写清镜头移动、动作先后和状态变化。
3. 参考图没有时间属性；如果角色或服装在片段中改变，必须靠镜头结构和文字描述完成变化，不能写“参考图从某秒开始生效”。
4. 需要动作顺序时，使用“先……再……最后……”并给出时间区间；禁止让模型在对白未结束时提前移动视线或切镜。

## Motion Context 链式规则

使用 H3 Motion Context 时，遵循 `references/motion-context.md` 的完整规则。核心设置固定为：

- 第一段：旁路/关闭 Motion Context，`Save Latent clip_index = 1`。
- 后续段：开启 Motion Context，`Load Latent = 要续接的上一段编号`，`Save Latent = 当前制作编号`。
- 示例：第2段 `Load 1 / Save 2`，第3段 `Load 2 / Save 3`。
- `context_length = 22`，`audio_context_length = 24`；从 22 开始，不擅自改成其他值。
- 不向 `context_frames` 接线；重试时不改编号，满意后才同时递增 Load 和 Save。
- 记住 Trim 会移除开头固定帧，导出文件比生成时短约 0.92 秒；提示词时间按生成时长写，不能按裁剪后文件重新倒推。
- 使用普通 butt join 拼接，不需要 crossfade；关闭 Spectrum，Turbo LoRA 可能降低音频质量。

## 质量检查

输出前逐项检查：

- 是否存在且正确描述上一段尾帧；所有尾帧是否都只保留自然语言画面内容，且完全没有图片编号、图片名称、附件名、`<Picture N>`、`<Subject N>` 或其他直接/间接素材引用。
- 是否从“参考设定”、六段正文和所有补充说明中移除了“图片1”“图1”“第1张图片”“尾帧图”等尾帧指代写法。
- 是否彻底删除“首帧锚点”“关键帧锚点”“从该图开始”“以该图为准”“该图拥有最高优先级”“工作流续接状态”以及其他把尾帧暗示为 H3 输入素材的表述，并确认任务类型没有因此加入 `keyframe completion`。
- 开头 1.5 秒是否明确写出“保持上一段结尾完全相同的构图”，且后续只用简洁自然语言描述可见构图、人物状态、场景和光影。
- 是否只锁定用户指定的人物/物体/场景参考。
- 所有真正上传给 H3 的角色图、物体图和场景图是否仍分别与对应 `<Subject N>` 明确关联；尾帧的口头编号是否未占用或扰乱这些正式 `<Picture N>` 编号。
- 是否定义了每个实际使用的 `<Subject>`、`<Video>`、`<Audio>`，且没有悬空标签。
- 是否包含完整六段 H3 字段并按正确顺序排列。
- 时间是否递增且不超过总时长；对白是否有足够时长和结束停顿。
- 是否明确写出“说话期间画面锁定/动作不发生”，避免边说边移动。
- 是否保持人物、服装、空间和声音跨片段连续。
- 最后一个 `[镜头N]` 后、`overall_soundscape:` 前是否单独紧接按顺序追加了与提示词语言一致的完整禁文字约束和固定禁字幕规则，且未生成字幕、文字、Logo、水印或其他可读画面内容。

如果关键素材或用途缺失，先提出最少量的澄清问题，不输出猜测版提示词。
