# H3 Motion Context 链式续接规则

此文件记录 H3 Motion Context 的固定工作流，供主技能在生成提示词和工作流设置时引用。

## 首段

- 还没有上一段可续接内容时，旁路或关闭 H3 Motion Context。
- `Save Latent clip_index = 1`，按普通 H3 流程生成。

## 后续片段

- 开启 H3 Motion Context。
- `Load Latent clip_index` 填写要继续的上一段编号。
- `Save Latent clip_index` 填写当前正在制作的编号。
- 第2段为 `Load 1 / Save 2`；第3段为 `Load 2 / Save 3`，依此类推。
- 不向 `context_frames` 接线；保存的 latent 已经携带画面和声音连续性。

## 重试和成功后的编号

- 不满意时直接重新排队，不修改编号；重试会重新加载上一段并覆盖当前失败结果。
- 满意后，下一段同时把 Load 和 Save 各加 1。

## 节点参数

- `context_length = 22`；可用视频上下文长度只有 5、22、39、56，默认从 22 开始。
- `audio_context_length = 24`；24 帧约为 1 秒声音，3 的倍数能落在音频网格上。
- 关闭 Spectrum。Turbo LoRA 可能损害声音质量，出现音频变闷或距离感异常时优先检查它。

## 接缝和时间

- 新片段开始时，固定帧会重新出现在开头；Trim 节点会移除这些固定帧。
- 使用 22 帧上下文时，导出链式片段比生成时短约 22 帧（约 0.92 秒）。
- 提示词内的时间对应较长的生成版本；例如写在 4.0 秒发生的动作，裁剪文件中约在 3.08 秒出现。
- 片段使用普通 butt join 拼接，无需 crossfade。

## 提示词连续性

- 每个后续片段开头先复述上一段结尾：人物、衣服、位置、构图、动作和视线必须一致。
- 固定状态至少保持一个呼吸、重心变化或视线微变，避免画面像冻结；然后再开始新动作。
- 22 帧上下文约 0.92 秒，实际变化通常安排在生成后约 1.5–2 秒更稳。
- 参考图作用于整个片段，没有“从第几秒起生效”的设置；人物或服装变化必须由镜头和剧情完成。
