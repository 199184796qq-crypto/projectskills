# H3 上下文多集合成提示词

将长内容拆成多个可独立运行的 MiniMax H3 提示词段。每段保留官方格式，拥有标题、时长、从 `00:00.000` 重新开始的内部时间轴，并与下一段硬衔接。

## 用户持久执行规则：只交付图片顺序与提示词

当用户调用本技能来制作 H3 视频时，助手的职责仅限于两项：

1. 列出本次每一段实际需要使用的图片、音频和参考视频，以及用户在 H3 中上传这些素材的顺序与对应关系。
2. 输出可直接复制的 H3 六段式提示词。

### 可复制排版铁律

每次 H3 交付默认使用两个顶级代码块；**本段存在角色对白、画外音或人物归属旁白时，必须追加第三个顶级代码块“时间轴对白”**，顺序固定：

1. 第一个代码块仅为“素材上传顺序”。图片行写作 `图片N：文件／用途 → <Picture N> → <Subject N> 名称`；音频行写作 `音频N：文件／用途 → <Audio N> → <Subject N> (SN) → reference／fully_copy`；视频行写作 `视频N：文件／用途 → <Video N> → 作用`；
2. 第二个代码块仅为完整 H3 提示词，第一行必须是该段版本号 `【第N集｜第M场｜第K段 Vx.y】`，第二行必须是该段的 `第K段：标题（时长：…秒，全片区间：…）`；
3. 若本段有对白，第三个代码块仅写可复制的时间轴对白：按视频本段本地时间升序逐句列出 `00:00.000 - 00:00.000`、说话角色和完整台词；无人说话的区间明确写“无对白”。时间轴必须与第二个代码块中的镜头时间、说话人和 `<d>[Chinese] ...</d>` 台词逐字一致；不得概述、改写、漏句或加入视觉说明。
4. 仅列本段实际需要的素材类别；未使用图片、音频或参考视频时不列该类别。代码块之外不写版本说明、解释、表格、写作卡片或其他内容。

不得使用 `:::writing` 写作块、引用块、嵌套代码块；不得把素材上传顺序与完整 H3 提示词放进同一个代码块。用户明确指定其他格式时，才可按其要求覆盖本铁律。

## 用户固定输出合约（除非用户明确修改，否则不得变化）

以下是该用户 H3 交付的不可变硬规则，后续修改提示词、续写提示词或重写提示词时必须完整保留，不能因篇幅、模型格式、技能示例或助手判断而省略、弱化或替换：

1. 每次 H3 交付默认使用两个顶级代码块：第一个只列素材上传顺序，第二个只列完整 H3 提示词；只要本段含有对白、画外音或人物归属旁白，必须追加第三个“时间轴对白”代码块。该块按本段本地时间升序逐句列出起止时间、说话角色和完整台词，并与 H3 正文逐字一致；代码块外不写解释。
2. 每次新稿或修改稿必须有可追溯版本号。第二个代码块第一行固定写 `【第N集｜第M场｜第K段 Vx.y】`，第二行再写 `第K段：标题（时长：…秒，全片区间：…）`。首稿为 `V1.0`，每次用户要求的普通修改依次递增小版本，不覆盖旧版本。
3. 凡出现角色对白、角色画外音、人物归属旁白、短信／手机消息朗读或任何可理解角色人声，必须使用用户明确指定的音频模式：角色专属声线，或包含本段全部角色台词的通用多角色音频。若同段同时提供两种模式，必须先明确它们各自覆盖的角色或时间范围；同一句台词不得同时绑定两种模式。音频必须在素材上传顺序、`subject_definitions`、`retention_analysis` 和实际 `[Shot N]` 中锁定；缺少对应素材时不得输出带该句台词的 H3 成稿。
4. 每个 `<Audio N>` 都必须在 `subject_definitions` 中独立成行，不能埋在任何 `<Subject N>` 长段落内。角色专属模式下，`<Subject N>` 使用 `(SN)` 与专属 `<Audio N>`；通用多角色音频模式下，一个 `<Audio N>` 必须列明覆盖的所有角色与 `(SN)`、`fully_copy`／`reference` 类型、声线归属、台词顺序和口型同步责任，不得伪造多条专属音频。每句台词都必须连续写成“`<Subject N> (SN)`＋适用的`<Audio N>`绑定＋说话动作＋完整`<d>[Chinese] ...</d>`”。禁止在 `<Audio N>` 与 `<d>` 之间插入其他角色、嘴唇状态、镜头或动作；相关状态只能放在完整台词前或 `</d>` 后。
5. 每段在 `detailed_description` 的最后一个镜头后，必须原样保留完整禁文字约束与“全片不准出现字幕。”两行。
6. **全局风格继承铁律：** 已确认的全局视觉风格是唯一母版。每段提示词必须从该母版原样继承影视类型、画风、影调／色彩关系、景深质感、人物补光目标和禁项；不得为某一段自行改写、简化、替换或加入相冲突的风格词。场景时间、主光方向、环境光和补光只能作为“本场现场光线”追加，绝不能覆盖全局影调或改变作品类型。全局风格若需变化，必须由用户明确要求先建立新版本，再同步应用到后续所有段落。
7. **素材可用性铁律：** “素材上传顺序”是唯一的素材准备清单；缺少必要外部素材时，只在该清单对应行标记“需提供”。正式 H3 六段式中，所有已引用的 `<Picture N>`、`<Audio N>`、`<Video N>` 一律按已可用处理，禁止出现“用户提供”“用户上传”“已上传”、文件名、缺失说明、待提供说明或任何上传流程描述。未引用外部素材的普通角色、道具、环境或音效，直接写其可执行的文字外观、状态和动作描述；不得写“由模型生成”或任何素材来源说明，不追问、不虚构素材标签。

### 《假意家人》当前全局视觉母版 V1.0

仅在制作《假意家人》时，后续每一段必须原样继承以下基线：写实都市家庭悬疑短剧；竖屏9:16；现实主义电影感、正常直线透视、真实生活尺度；低饱和、中性自然影调；白天以灰白、米色、原木、浅棕、深蓝灰为主，室内为暖白而非浓橙或金色滤镜；夜景为深蓝城市窗光与柔和暖白室内灯的轻微冷暖关系；人物面部使用不可见大面积柔光，保留真实肤质、眼神高光与服装纹理；禁止黑脸、死黑眼窝、过曝、逆光剪影、强棚拍感、光向跳变、赛博霓虹、网红滤镜、背景重构与家具漂移。场景描述只能落实这些基线，不能将其改为广告片金色晨光、过度电影滤镜或其他不一致风格。

除此以外，不做任何代办动作：不得打开或操作 H3／海螺／浏览器页面，不得上传素材，不得提交生成，不得生成图片或视频，不得检查登录、额度、支付或生成结果，也不得替用户切换到图生视频流程。

执行时遵守以下简化规则：

- 用户已确认的角色、场景、全局风格和素材映射直接沿用；不要重复索要或重新确认。
- 先在输出中给出“本段所需素材与上传顺序”，再给出该段 H3 提示词。只列本段实际需要的图片、音频与参考视频；若本段完全没有外部素材，明确写“本段无需上传素材”。
- 未提供主道具图片时，默认由模型按剧本生成；不得为手机、纸巾、工具、样板箱等道具逐项追问或阻塞提示词交付。
- **对白声音素材铁律：** 每段先确认每条音频覆盖的角色或时间范围。角色专属声线模式为每位说话人上传对应 `<Audio N>`；通用多角色音频模式只上传一条包含其覆盖范围内角色声音、台词顺序与时长的 `<Audio N>`，由 H3 按其中声线和时间为对应人物对口型。两种模式可在同段共存，但覆盖范围必须互斥；禁止把通用音频拆写成未提供的角色专属音频，也不得将角色专属音频误写为整段原音。
- 每条 `<Audio N>` 必须独立写入 `subject_definitions`，并在 `retention_analysis`、实际 `[Shot N]` 和时间轴对白中保持同一模式与标签。专属模式下，同一角色的所有台词复用其 `<Audio N>`；通用模式下，每个说话角色的镜头均写明使用同一条通用 `<Audio N>` 对口型。
- **台词标签连续铁律：** 每句台词的“`<Subject N> (SN)`＋使用`<Audio N>`声线＋说话动作＋完整`<d>[Chinese] ...</d>`”必须是一句连续、不可打断的表达。禁止在声线绑定与 `<d>` 之间插入另一角色、嘴唇状态、镜头、动作或解释。旁听角色闭嘴、人物动作与表情等要求，必须写在完整台词句之前，或写在 `</d>` 之后。
- 没有对白的角色不需要为凑格式上传音频；环境声、音效和无人物归属的底噪不视为角色对白声线。
- 默认分段符为 `===`；除非用户明确要求其他符号，不再单独询问。
- 完成“图片顺序 + 提示词”后立即停止，等待用户下一步指令。

本规则优先于本技能中关于外部平台操作、素材逐项确认、主道具逐项审计和额外执行动作的要求；但不改变 H3 六段式字段、跨段连续性、禁文字规则和用户明确指定的素材绑定。

## 收集与确认

识别用户提供的文字、图片、音频、视频、首帧、尾帧、角色、环境、总体风格、总时长、分段时长或时间区间。

### 开剧视觉基调确认（首次写本剧提示词前必做）

在为一部新剧首次输出分段提示词前，必须先向用户确认四项全剧视觉锁定：**影视风格、整体画风、影调/色彩关系、人物补光方案**。用户尚未提供时，用简短清单逐项询问；用户已在剧本、参考图或此前对话中明确提供时，先简要复述这四项并请其确认，不得自行补全或替换。

- 这四项是全剧不可漂移的视觉基线。每个段落的 `subject_definitions`、`retention_analysis` 与 `detailed_description` 都要重新落实与本剧一致的风格、画风、影调和补光要求，不得只写“同前”或省略。
- 每一场还要建立该场专属的现场光线锁定：时间段、可见主光源、环境光方向与颜色、人物面部补光方向/面积/强度、曝光目标和禁止项。该场的所有段必须重复并保持同一现场光线方案。
- 场地发生变化时，必须根据新地点的结构、可见灯具、窗光/夜景/自然光和剧情时间重新规划该场现场光线，再写入该场每一段；不得把上一场的灯光、影调或补光描述机械迁移到新场地。

### 视觉、影调与补光输出硬门槛（每段必检，零遗漏）

每次输出任何一个 H3 段落提示词时，以下内容都是**硬性必写项**，不得因篇幅、复用同场景、已在前段写过、用户只要求某一镜或只要求修改动作而省略。缺少任一项的提示词视为未完成，不得交付。

- 在每段的 `subject_definitions` 中明确写出本剧的影视风格、整体画风、全局影调/色彩关系和人物补光目标；必须使用用户已经确认的具体描述，不能只写“影视感”“明亮”或“同前”。
- 在每段的 `retention_analysis` 中明确锁定：全剧视觉基线不可漂移；人物脸部曝光、自然肤质、眼神高光、服装材质层次与背景冷暖关系不可因切镜、运镜或情绪变化而变差。
- 在每段的 `detailed_description` 开头必须先完整写出两层光线方案，之后才能开始 `[Shot 1]`：
  1. **全剧视觉基线**：影视类型、画风、影调/色彩关系、景深/质感，以及人物面部补光的整体目标。
  2. **本场现场光线锁定**：剧情时间；画面内可见主光源；环境光的方向与颜色；不可见影视补光的机位方向、面积、强度和作用范围；人物面部与黑/白服装的曝光目标；以及禁止出现的光线问题。
- 人物补光不能只写“补光”二字。必须说明其为不可见的大面积影视级柔光或用户指定的方案、来自镜头哪一侧/何种方向、覆盖哪些角色与面部区域、强度相对可见主光源的关系，以及不得出现的黑脸、逆光剪影、死黑眼窝、过曝、可见灯具、强棚拍感或光向跳变。
- 同一场的所有段，现场灯光、时间、色彩关系、补光方向和曝光标准必须逐字或等义重复；新场景则必须重新规划，不得照搬。
- 每次交付前先自检：读者只复制当前这一段，是否也能完整获知并执行该剧的影视风格、画风、影调、可见光源、环境光、补光与曝光限制；若不能，必须补全后再输出。

### 多参考素材映射确认（首次出提示词前必做）

在起草任何 H3 提示词前，先向用户展示并确认“素材—角色—用途”映射。不要只根据文件名、画面内容或剧情自行把素材分配给人物、声线或关键帧。

- 每张图片都要确认其 `Picture N` 标签、对应的是谁或什么（角色、场景、道具、首帧、尾帧或构图参考），以及它要绑定的 `<Subject N>`。例如，`<Picture 1>` 可以确认绑定为公寓场景，`<Subject 1>` 为该公寓环境；但不能把未确认的人像自行分配给如玉、米大乐或米小乐。
- 用户在已有素材工作流中新增上传图片、音频、视频或道具资产时，先判断用户是否明确说了“替换哪一个已有 `Picture N` / `Audio N` / `Video N` / `<Subject N>`”。若未明确，绝不可自行把新素材替换到某个现有资产上；先列出当前可能被替换的相关素材及其用途，询问用户“这个新素材要替换哪一个，还是作为新的参考加入？”。只有用户明确指定后，才能更新素材绑定、保留规则和后续提示词。若用户明确说“替换 `<Picture 4>`”或等效表述，则直接按该指向替换，无需重复询问。
- **尾帧参考例外：** 用户上传图片并明确称为“尾帧”“最后一帧”“上一段结尾画面”或等效表述时，不把它当作需要映射、替换或新增编号的素材；不要询问它替换哪个 `Picture N`，也不要创建 `<Picture N>`。直接从画面提炼必要的构图、机位、人物位置、表情、道具与光线状态，改写进上一段最后一个镜头的结尾描述。若存在下一段，在其 `00:00.000–00:01.500` 写明严格承接该文字化结尾状态；尾帧图本身不在最终提示词中作为资产或关键帧标签出现。
- 每条音频都要确认其 `Audio N` 标签和模式。角色专属声线模式需确认对应人物、永久说话人编号 `(SN)`，以及 `fully_copy`／`reference`；通用多角色音频模式需确认覆盖的全部角色及各自 `(SN)`、台词顺序、时间范围、`fully_copy`／`reference` 和对口型责任。不得把“有声音的素材”默认视为对口型原音，也不得把一条通用音频误认成只属于第一个说话人。
- 每条视频都要确认它是动作/运镜/节奏参考、源视频剪辑、续接起点，还是含有要复用的同步音频；首帧与尾帧也要确认属于哪一段、承担何种关键帧职责。
- 角色没有形象素材时，可以用文字定义 `<Subject N>`，但必须明确告知用户这是文字生成角色；不得虚构 `<Picture N>`。音频没有角色映射时，不得输出 `<Audio N>`。
- 只要任一素材归属、声线归属、口型同步方式或关键帧职责不明确，先暂停提示词生成并用简短表单向用户询问。优先询问：`Picture N 是谁/什么？`、`Audio N 对应谁？`、`Audio N 是对口型原音复用还是仅声线参考？`、`若复用原音，复用哪句台词或哪个时间段？`、`Video N/首尾帧用于哪一段？`。

确认后，先输出一份简洁的“全局素材绑定清单”供用户核验：`Picture N → Subject N → 作用`、`Audio N → Subject N/(SN) → fully_copy 或 reference → 台词/时间段`、`Video N → 作用`。只有用户认可该清单后，才生成中文 H3 提示词。

### 剧本文本主道具审计与逐项确认（首次出提示词前必做）

在素材绑定之前，先阅读用户给出的剧本、分镜或动作描述，提炼本次画面中真正的**主道具**：会被角色拿取、使用、观察、交接，或直接影响剧情与镜头连续性的物件。不要把普通背景家具、餐具摆件、装饰物一律当成主道具；只保留剧情动作和识别所必需的项目。

- 先给出简洁的主道具候选清单，说明每件道具在本段中的动作与连续性作用。
- 然后必须**一次只询问一件主道具**，等待用户回答后再询问下一件。用户对每件道具可选择：`提供素材`、`由模型生成`、`不需要/改写动作`。
- 用户选择`提供素材`时，询问或接收该道具图片，并分配未占用的永久 `<Subject N>` 与对应 `<Picture N>`；在最终提示词中必须以“`<Subject N>道具名是来自<Picture N>的……`”明确绑定，并在实际出现的段落引用。
- 用户选择`由模型生成`时，仍分配永久 `<Subject N>`，写清外观、材质、尺寸、颜色、初始位置和被谁如何使用；不得虚构 `<Picture N>`。
- 用户选择`不需要/改写动作`时，从分镜与最终提示词中删除该道具及依赖动作，并在继续询问前简短说明镜头将如何调整。
- 只有在所有主道具逐项确认完毕后，才能生成全局素材绑定清单和中文版 H3 提示词。绑定清单需新增一项：`主道具：Subject N → Picture N 或文字生成 → 关联角色与段落`。

必须确认段落分隔符：用户未指定时，用一句话询问“每段之间用什么重复分隔符？例如 `===`。”用户已指定时，原样使用。不要自行换成其他字符。

仅在缺少总时长或无法确定分段方案时追问。用户给出总时长但没有区间时，可自动分段：单段不超过其当前 H3 工作流允许的单次时长；未知上限时优先按不超过 15 秒的连续片段划分。

## 统一六段式输出（最高优先级铁律）

**不管输入属于多参考生视频、纯文生视频、单图生视频、首帧生视频、首尾帧生视频、尾帧生视频，还是上述形式的任意组合，每一个段落一律按照多参考 Ref2VA 六段式格式化输出。绝对禁止使用 T2VA、I2VA、FL2VA、L2VA 三字段格式或任何其他字段结构。**

每一段都必须严格按以下顺序完整输出六个字段，字段不得缺失、换序、合并或增加并列字段：

1. `subject_definitions`
2. `summary`
3. `retention_analysis`
4. `detailed_description`
5. `overall_soundscape`
6. `non_diegetic_music`

只有文字时，同样建立并完整描述实际使用的 `<Subject N>`，但不得为文字锁定虚构 `<Picture N>`、`<Video N>` 或 `<Audio N>`。有首帧、尾帧、图片、视频或音频时，按素材的实际职责建立相应参考标签，并在六段式中定义和使用。没有画外配乐时，`non_diegetic_music` 必须写 `N/A`；没有特殊环境声时，`overall_soundscape` 仍须明确描述自然环境底噪或静音要求，不能删除字段。

## 全局锁定与分段锁定

先建立不在最终提示词中单独输出的“全局连续性清单”：总体视觉风格、画风、色调、影调、空间关系、角色外观、服装、道具、声音关系和用户要求锁定的内容。

将清单完整落实到每一段的开场描述或 `subject_definitions`。不得在后段省略为“同上一段”；每段必须可脱离其他段单独复制运行。

无论是文生视频还是参考生视频，人物、场景和道具都必须在所有段内全程锁定，不得在不同段之间改号、换号、重号或复用不同对象的编号。

### 对象标识与每段必要定义（硬性规则）

为全片每个对象分配永久的尖括号对象标识：`<Subject 1>`、`<Subject 2>`、`<Subject 3>`，按首次实际出现的顺序编号。对象定义必须使用“`<Subject 1>小马是……`”或英文“`<Subject 1> The little pony is ...`”这一明确句式；不要写“锁定的小马”“同一匹小马”“该角色”之类没有对象标识的替代写法。

在 Ref2VA 的 `subject_definitions`、`summary`、`retention_analysis` 和 `detailed_description` 中也必须使用同一套 `<Subject N>` 标识。**严禁**改写成 `<S1>`、`<Character 1>`、`<Object 1>` 或任何另一套编号；这些写法会破坏用户要求的全局唯一锁定编号。

只要某个对象在本段实际出镜、发声，或为本段首尾连续性所必需，就必须在本段的 `subject_definitions` 中重新定义该对象，并在 `detailed_description` 的 `[Shot 1]` 时间线之前落实其开场状态。定义详略按下列“已指定参考图时精简描述”规则执行。

#### 已指定参考图时精简描述（用户规则，优先于完整重写）

**只要 `<Subject N>` 已明确指定对应的 `<Picture N>`，就不用太详细地重复描述图片中已经清楚呈现的内容，只描述重点。**

- 人物已绑定 `<Picture N>` 时，必须明确写出人物身份、五官／脸型、肤色、发型和整套服装；需要时补充鞋履、饰品、年龄感与体型。再写本段初始位置与朝向、关键表情或身体状态、正在使用的关键道具，以及相对参考图发生的必要变化。不得只写“来自 `<Picture N>`”或只锁定角色名；`retention_analysis` 必须复核上述外观在全段、跨镜头与相邻段一致，并明确禁止变脸、变发型、换装、年龄漂移和无授权增减饰品。
- 动物或物体已绑定 `<Picture N>` 时，只写对象身份或用途、参考关系、本段位置、状态、朝向及剧情需要强调的标志性特征。不要逐项复述图片中已经明确的材质、颜色和结构。
- 环境已绑定 `<Picture N>` 时，必须明确标为“强锁定”或“参考”。强锁定时，写清必须保持的空间结构、户型轴线、关键家具／门窗／陈设、时间、窗外状态、主光方向和不可变化项，并在 `retention_analysis` 再次锁定跨镜头不变。仅作参考时，明确列出只参考哪些要素（例如空间气质、家具类别、局部构图、色彩关系或光线方向）以及哪些部分允许因剧情调整。不得只写“环境来自 `<Picture N>`”或“参考环境”，也不要让模型自行猜测参考范围。
- `<Picture N>` 仅作为人物、物体或环境的外观来源时，直接写在对应 `<Subject N>` 定义内，不单独展开图片内容。只有图片承担首帧、尾帧、关键帧、构图锚点或分镜规划职责时，才单独定义 `<Picture N>`，且只说明它的用途、对应镜头和必须对齐的重点。
- 在 `retention_analysis` 和 `detailed_description` 中直接复用已经定义的 `<Subject N>` 与 `<Picture N>`，重点写保留关系、动作、位置、镜头、情绪、声音和状态变化；不要再次重复外貌、服装或环境清单。
- 精简描述不等于弱化锁定。对象编号、图片对应关系、关键身份、空间关系和本段发生的变化仍须明确且前后一致。
- 没有绑定任何参考图片或视频的对象，仍须写出足以稳定生成的可见特征；直接结束对象描述，不得虚构参考标签，也不得输出“文字定义对象”“文字锁定对象”“无参考对象”或任何解释性尾注。
- 后段可额外写“严格承接上一段结尾”，但这句话只能说明连续性，绝不能替代完整锁定描写。
- 对象不在该段的剧情、画面、声音或 `00:00.000–00:01.500` 衔接窗口中出现时，才不写该对象；不要为凑完整性占用其标签。
- 视觉对象、说话人和声线音频使用永久一一对应编号：`<Subject N>` 必须使用 `(SN)`，其指定声线参考必须使用 `<Audio N>`。不得按首次发声顺序、对白先后、段落顺序或本段是否发声重新编号。即使某对象在本段不说话，其 `(SN)` 与 `<Audio N>` 仍为后续段落永久保留。该规则优先于官方示例中的发声顺序编号。

用户可为某一段额外锁定或替换参考。只在该段定义并使用该参考，同时明确它覆盖或不覆盖哪些全局锁定项。未被明确替换的全局锁定保持不变。

### 参考生视频的按段独立资产编号（用户规则，优先）

当用户制作的是**参考生视频**时，每一个“段”都是可独立运行的素材单元，不向上一段继承参考标签；即使相邻段属于同一场、同一地点或剧情连续，也按当前段实际附带的资产重新建立映射。

- 每进入一个新段，重新盘点该段实际使用的人物图、场景图、道具图、声音与视频；本段图片从 `<Picture 1>` 重新编号，后续按本段素材顺序递增。不得因为上一段曾使用 `<Picture 4>`，就在新段跳号、复用其旧含义或在提示词中提及它。
- 本段的 `<Subject N>`、`<Audio N>` 和 `<Picture N>` 也按本段局部映射重新规划。前后段的剧情连续性通过文字化的尾镜状态、人物位置、服装、动作、道具和现场光线来锁定，而不是通过继承上一段的标签。
- 即使新段继续使用同一张原始素材，也默认在新段重新从 `<Picture 1>` 规划；只有用户明确要求跨段沿用编号时，才可继承。
- 这条按段独立规则覆盖“全局唯一对象编号”中跨段继承编号的要求；角色身份、剧情关系、服装、空间关系和同场现场光线仍按剧本保留，但引用标签以当前段的局部映射为准。

### 全局唯一的对象编号

在起草所有段落前，先建立不在最终提示词中单独输出的“全局对象登记表”。每个锁定人物、动物、物体或环境只能拥有一个永久 `<Subject N>` 编号，按其在全片首次实际出现的顺序分配，之后绝不改号、重号或复用。

- `<Subject 1>` 一旦确定为某个对象，在任何后续段落再次出现时都必须仍写 `<Subject 1>`，并保持相同身份与锁定描述。
- 某段不出现 `<Subject 1>` 时，绝对不要在该段定义、提及或占用 `<Subject 1>`。如果该段实际出现的是全局登记表中的第二个对象，就直接使用 `<Subject 2>`，不得因 `<Subject 1>` 缺席而改编号为 `<Subject 1>`。
- 每个段落只重新定义该段实际出镜、实际发声、实际作为画外音来源，或为首尾 `00:00.000–00:01.500` 连续性所必需的 `<Subject N>`。对每个保留对象，逐段用“`<Subject N>对象名是……`”写明本段定义和参考对应关系：已绑定 `<Picture N>` 的对象按“已指定参考图时精简描述”规则只写重点，未绑定视觉参考的对象才完整写出稳定生成所需的可见特征；编号仍服从全局登记表。
- 用户提供但在该段剧情、画面、声音和连续性中都没有实际作用的对象、图片、视频、音频，一律从该段删除；不要为了“全局完整”保留闲置标签。
- `<Picture N>`、`<Video N>` 和 `<Audio N>` 也只在实际被该段使用时出现。每个已出现的 `<Subject N>` 必须在该段对象定义中明确写出它与本段实际素材的对应关系，例如“`<Subject 1> is ... from <Picture 1>`”；没有对应素材时只输出完整外观、状态和空间描写，不虚构素材标签，也不解释素材缺失。

因此允许某段的对象定义从 `<Subject 2>` 或 `<Subject 4>` 开始；这不是编号错误，而是全局唯一编号的正确表现。

### 站位图、占位图与构图标注图

当用户提供人物站位图、彩色色块占位图、平面调度图或带箭头/文字的构图标注图时，将它视为**幕后空间规划参考**，而不是最终视频应出现的视觉素材。

- 先确认图中每个颜色、符号或标注分别对应哪个 `<Subject N>`、起始位置、终止位置、朝向与允许移动范围；再把这些信息改写为相对于真实场景锚点的文字约束，例如“窗边远侧餐椅”“餐桌近侧儿童座位”“靠厨房门洞的右后侧餐椅”。
- 若站位图同时带有真实场景底图，仍以用户指定的干净场景图作为 `<Subject N>` 的环境外观来源；站位图只提供人物空间坐标、镜头构图或走位规划。
- 在 `subject_definitions` 中单独定义该 `<Picture N>` 的幕后用途；在 `summary`、`retention_analysis` 与每个相关镜头中重复落实人物的空间锁定。人物的座位、朝向、进入路径和允许动作在切镜、摇镜、跟拍后不得互换或漂移。
- 必须明确写出：站位图不是画面内容、不是首帧或关键帧；最终视频完全删除图中的颜色块、彩色矩形、轮廓线、箭头、文字、数字、网格、标记及示意图。不要把这些视觉标记误生成为道具、服装、背景装饰或屏幕文字。
- 站位图只锁定空间关系，不替代真实角色图、场景图、道具图或音频的素材绑定。人物外观仍来自各自确认的角色参考；环境外观仍来自确认的场景参考。
- 对于含多机位或运镜的段落，优先将每个人的位置持续绑定到同一组真实空间锚点，并在每次硬切后的开场状态重申可见位置。若镜头改变导致某人暂时出画，也不得改变其在场内的固定位置。

## 分段时间与硬衔接

使用以下外层结构。**每一段的第一行都必须是版本号，第二行必须是段标题；二者绝不可省略、合并到正文、放到段尾，或只写在首段。**

```text
【第N集｜第M场｜第1段 V1.0】
第1段：标题（时长：8秒，全片区间：00:00.000 - 00:08.000）
<本段完整 H3 官方提示词>

===

【第N集｜第M场｜第2段 V1.0】
第2段：标题（时长：8秒，全片区间：00:08.000 - 00:16.000）
<本段完整 H3 官方提示词>
```

### 段标题硬性格式

每段必须严格使用下列“版本号＋标题”格式，并把版本号作为该段可复制内容的第一行、标题作为第二行：

```text
【第N集｜第M场｜第6段 V1.0】
第6段：终焉之刃（时长：8秒，全片区间：00:40.000 - 00:48.000）
subject_definitions:
...
```

- `第N段`、标题、时长和全片区间四项缺一不可；数字、标题、时长和区间必须和实际段落一致。
- 分隔符 `===` 后的下一行必须立刻是下一段版本号；版本号后的下一行必须是下一段标题；标题后的下一行必须立刻进入该段官方字段，例如 Ref2VA 的 `subject_definitions:`。
- 不得只输出 `subject_definitions:`、`summary:` 等官方字段来开始一段；这视为段标题缺失。
- 英文版和中文版都必须保留完整段标题。标题可按用户提供的原始语言保留；用户明确要求翻译标题时，两个版本各自使用对应语言，但格式、段号、时长和区间必须完全一致。

遵守以下硬规则：

1. 所有段时长相加必须等于用户指定总时长，交付前自行核算。
2. 每段镜头时间从本地 `00:00.000` 开始；全片时间只写在段标题中。
3. 每段最后一个镜头的最后状态，必须与下一段本地 `00:00.000–00:01.500` 的状态完全一致：角色、服装、发型、道具状态、位置、身体朝向、手势、视线、表情、环境、光线、景别、机位和构图均不得突变。
4. 下一段在本地 `00:00.000–00:01.500` 明确写出“严格承接上一段结尾”的可见状态，只允许呼吸、眨眼、布料轻动等微动作；`00:01.500` 后才推进新动作或切镜。默认承接窗口不得写成 2 秒；仅当用户明确要求时才能延长。
5. **分段边界禁止打断任何正在进行的说话（最高优先级硬规则）。** 每个段落都必须在无人说话的静默区间结束，下一段也必须从没有正在延续的说话状态开始。任何一句对白、画外音、旁白、歌唱或其他人声，从发声开始到该次发声自然结束，必须完整位于同一个段落内；不得在一个人说到一半时结束本段，不得使用 `<cutoff>`、`<scenetrans>`、省略号、音频淡出或跨段续说来规避此规则。
6. 若原计划的分段边界落在说话过程中，必须重新划分相邻段落的时长和全片区间，把边界移动到该次发声结束后的无人说话区间；必要时同时调整镜头切点、动作节奏、对白开始时间或前后段承载的剧情。重新划分后，**任意单段时长都绝对不得超过用户规定的单段时长上限**。不得为了保全一句对白而延长到上限之外；若一句连续人声本身长于单段上限，则必须在不改变用户原意的前提下，把台词改写为可在自然停顿处分开的多次完整发声，并确保每次发声及其所属段落均不超限。用户要求逐字保留台词时，不得改词，只能通过调整语速、发声起点、镜头和前后段时长，使完整台词落入单段上限；仍无法满足时必须先向用户说明冲突并请求调整。
7. 不同段需换参考时，前段结尾先到达下一段参考所需的共同状态；不得用瞬间换装或突然换场逃避衔接。
8. 首段不写“承接上一段”；末段仍需完整收束。
9. **全片禁文字固定收尾规则：** 每一段的 `detailed_description` 中，最后一个 `[Shot N]` 的镜头描述结束后，必须立刻另起两行，按提示词正文语言依次追加完整禁文字约束和固定禁字幕规则。中文提示词依次用 `画面中不出现任何可读文字：无字幕、无台词字幕、无文字叠层、无 UI、无标签、无 Logo、无水印、无片尾文字。所有对白仅以角色口述声音呈现，画面不显示台词文字。` 与 `全片不准出现字幕。`；英文提示词依次用 `No readable on-screen text: no subtitles, dialogue captions, text overlays, UI text, labels, logos, watermarks, or end credits. All dialogue is heard only and is never displayed as text.` 与 `No subtitles are allowed throughout the video.`。不得省略、改写、移到段标题、其他字段或段落外，也不得把它另写成一个镜头。

详细检查见 `references/continuity-contract.md`。

## 官方写作要求

- 默认按官方要求用英文写字段内容；对白、歌词和画面内文字保留用户原始语言，放在 `<d>[Chinese] ...</d>` 或英文双引号中。
- 用户明确要求中文提示词时，可将描述改为中文，但字段名、字段顺序、标签、时间格式和关键帧对齐句式仍保持官方结构。
- 首镜明确风格、构图、主体、环境和初始状态；后续镜头使用递增的本地切点。
- 写清景别、机位、运镜类型、幅度、速度、动作链、表情、视线、空间关系、环境声和对白来源。
- 直接复用音频时写 `fully_copy`；只模仿音色、语气或节奏时写 `reference`。不要混淆二者。
- 画外音使用 `says in an off-screen voiceover`，并在 `<d>` 后明确画面人物嘴唇保持闭合。
- 不虚构用户没给出的图片、视频、音频、人物名或原声音频内容；原声文字未知时写“完整播放 <Audio N>”，不要猜测台词。

## 中文先行与英文确认版

除非用户明确要求“立即同时输出中英文”或“只要英文”，默认采用两阶段交付：

1. 素材绑定清单获得确认后，先只输出一套**完整、可独立复制的中文版** H3 提示词。中文版必须包含全部段标题、时长、全片区间、用户确认的分隔符、参考关系、全局 `<Subject N>` 编号与完整六段式字段；字段名、字段顺序、标签、时间格式和关键帧对齐结构保持官方格式。
2. 等待用户审核中文版本。若用户提出修改，继续只更新中文版，直到用户明确表示“确认”“不修改了”“中文定稿”或等效意思。
3. 只有在中文版本确认定稿后，才输出同方案的**完整英文版**。英文版必须可独立复制，段数、顺序、时长、全片区间、分隔符、素材引用与对象编号必须和中文定稿版完全一致；对白、歌词和画面内文字仍保留其原始语言。

不得在首次草稿中自动附带英文版；不得按段交替输出中英文；不得在用户还在修改中文方案时提前翻译英文版。若用户明确指定只要中文，则中文定稿后不再自动输出英文版。

## 交付前检查

逐段检查：

- 是否无条件使用了 Ref2VA 多参考六段式，并且完全没有输出 T2VA、I2VA、FL2VA、L2VA 三字段结构。
- 每段是否严格按 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music` 的顺序完整输出六个字段。
- 本段只要存在角色对白、画外音或人物归属旁白，是否在素材块和完整 H3 提示词之后额外输出了第三个独立、可复制的“时间轴对白”代码块；其中每句的起止时间、说话角色和台词是否与 `<d>[Chinese] ...</d>`、镜头时间及 `<Audio N>` 绑定逐字一致；无人说话区间是否明确标记“无对白”。
- **素材可用性审计：** “需提供”是否只出现于素材上传顺序；正式 H3 六段式是否完全删除“用户提供”“用户上传”“已上传”、文件名、缺失／待提供、上传流程、“由模型生成”及任何素材来源说明；无外部参考对象是否只保留可执行的文字外观、状态和动作描述。
- **视觉硬门槛：** 每段的 `subject_definitions` 是否明确写出全剧影视风格、整体画风、影调/色彩关系与人物补光目标；`retention_analysis` 是否锁定人物脸部曝光、肤质、眼神高光、服装层次与背景冷暖关系；`detailed_description` 是否在 `[Shot 1]` 前同时写出全剧视觉基线和本场现场光线锁定。任一缺失即不得交付。
- **现场光线硬门槛：** 是否具体写出剧情时间、可见主光源、环境光方向与颜色、不可见补光的机位方向/面积/强度/覆盖对象、曝光目标和禁止项；是否杜绝“同前”“按之前灯光”“有补光”等无执行信息的省略写法。
- 每段是否可单独复制运行，且没有“同上一段”“见前文”等依赖。
- 本地镜头切点是否递增且落在段时长内。
- 所有段时长之和是否等于总时长。
- 每一个分段边界是否都落在无人说话的区间，边界前的对白、画外音、旁白、歌唱或其他人声是否已经自然结束，边界后是否不存在上一段延续过来的人声。
- 是否不存在用 `<cutoff>`、`<scenetrans>`、省略号、淡出或跨段续说来掩盖人声被切断的情况。
- 若因对白重新划分过段落，重新计算后的每一段是否仍未超过用户规定的单段时长上限，且所有段时长之和仍等于总时长。
- 相邻段是否在下一段本地 `00:00.000–00:01.500` 保持同状态承接，且未默认延长到 2 秒。
- 每段的 `detailed_description` 是否在最后一个 `[Shot N]` 结束后、`overall_soundscape` 之前，单独紧接按顺序追加了与提示词语言一致的完整禁文字约束和固定禁字幕规则；是否没有把它们误写为新镜头、段外说明或其他字段内容。
- 所有对白、原声、歌声、环境声是否完整位于单一段内。
- 总体风格、锁定对象和未被覆盖的参考是否全程一致。
- 全局对象登记表中每个对象是否只对应一个永久 `<Subject N>`，且缺席对象没有被其他对象占号。
- 每段是否只保留实际出镜、发声或连续性必需的对象和参考，闲置对象及其素材是否已删除。
