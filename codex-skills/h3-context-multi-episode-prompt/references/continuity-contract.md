# H3 多集连续性契约

## 结尾状态卡

每个段落在内部记录一张结尾状态卡：

- 人物/物体：身份、服装、发型、道具、左右手状态
- 空间：坐标、身体朝向、与其他主体距离、前后景关系
- 表演：视线、表情、嘴唇开闭、动作停点
- 镜头：景别、机位高度、镜头朝向、焦段感、构图、是否运动
- 环境：地点、时间、光源方向、天气、可见物、声音状态

下一段的 `00:00.000–00:01.500` 必须把这张状态卡重新写进该段提示词，视觉上无缝接续。

## 全局主体编号

- 为全片每个锁定人物、动物、物体和环境建立一次永久 `<Subject N>` 编号。
- 缺席的主体不在该段定义，也不能被另一个主体借用其编号；因此某段可以从 `<Subject 2>` 或更大的编号开始。
- 每段只保留实际出镜、发声或连续性必需的主体。用户提供却未使用的主体和关联素材必须删除。
- 每段中保留的主体要重新写明与本段实际 `<Picture N>`、`<Video N>` 或 `<Audio N>` 的对应关系；纯文字锁定则直接注明为文字锁定。

## 边界安排

- 对白、唱词、原声、明显动作和切镜应在段内完成，不跨分隔符。
- 若前段在运动，先在结尾完成动作并稳定构图，再进入下一段的 1.5 秒承接。
- 若下一段需要切镜，在前 1.5 秒之后再切；切镜前后仍需维持可辨认的主体、空间和状态连续。
- 段落末尾避免未完成的挥手、转身、落物、开门、说到一半或音频未结束。

## 段内时间写法

- 每段内部重置为 `00:00.000`。
- 第一镜没有切点；第二镜开始写 `At 00:SS.mmm`。
- 外层标题标注全片区间，仅用于人类编排，不能替代段内时间轴。
