# 飞书 + 百度网盘 + Git 协作操作模型

## 唯一事实源

| 系统 | 管理内容 | 不管理内容 |
| --- | --- | --- |
| 飞书 | 项目、任务、负责人、审核、问题单、变更单、每日推进 | 正式剧本和大媒体文件的唯一版本 |
| Git | 规则、剧本、分镜、提示词、资产清单、剪辑清单、版本历史 | 大图、音频、视频、剪辑工程 |
| 共享百度网盘 | 角色图、场景图、道具、音频、候选视频、可剪辑视频、剪辑工程、成片 | 任务状态与最终文本版本 |

不要在群聊、私人电脑或多个云文档间制造第二份“正式版本”。

## 飞书任务表

建立项目/集数、任务、资产、变更与问题、版本索引五张关联表。任务表最少包含：

- 任务编号、项目/集/场/镜头、岗位、负责人、审核人、截止时间；
- Git 输入文件与版本、网盘资产链接与版本、网盘交付目录；
- 状态、输出 Git 提交、输出网盘链接、问题/变更单、修改摘要。

状态固定为：`待排期 → 待输入 → 可执行 → 制作中 → 待审核 → 已确认`，另有 `阻塞`、`需复核` 和 `已失效`。

为每个岗位建立“我的可执行任务”视图：岗位匹配、负责人为当前成员、状态为“可执行”。成员打开任务卡，核对输入后，将状态改为“制作中”；这就是领取任务。

## 百度网盘媒体目录

```text
《项目名》/
  02_角色场景道具资产/
  03_音频与配音/
  05_视频候选/
  06_已审核可剪辑素材/
  07_剪辑工程与代理文件/
  08_审片版/
  09_正式成片/
  99_历史归档/
```

候选视频不能直接供剪辑使用；导演/审核人确认后才能进入“已审核可剪辑素材”。剪辑师把素材下载到本地工作盘后剪辑，不在同步网盘目录直接编辑工程。

## 岗位交接

| 岗位 | Git 交付 | 百度网盘交付 |
| --- | --- | --- |
| 编剧 | 剧本、改动说明 | 仅必要参考资料 |
| 分镜 | 分镜、镜头与资产需求清单 | 分镜图或关键帧 |
| 素材 | 资产清单、版本与链接 | 角色、场景、道具、声音资产 |
| 视频生成 | 提示词、模型参数、生成记录 | 候选视频、审核后视频 |
| 剪辑包装 | 剪辑输入清单、版本说明 | 工程、审片版、正式成片 |

所有交付命名包含范围、用途和版本，例如：`第01集_第02场_镜头05_女主回头_可剪辑_V1.1.mp4`。

## 变更控制

问题单用于缺输入、权限、资产缺失和横向协作；变更单用于上游设计修改。变更单要记录当前依据版本、问题证据、可选方案、受影响文件/任务/资产/视频、返工成本、决策人与批准后的新版本。未经批准，不得自行修改上游正式稿。
