# 打戏多图版（25-28S）

这是一个分阶段的动作分镜与视频提示词工作流。必须先阅读并遵循 [完整源文件](references/source.md)。

核心执行顺序：

1. 识别并锁定用户提供的角色、服装、武器、能力、动作风格和场景；必要时用简短剧情描述补足目标、冲突、战术变化、环境因果和结局。
2. 输出 2–3 句剧情简介与 16 格文字镜头大纲（每格包含建议时长、景别/机位、可见主体、画面动作、衔接作用），检查总时长是否为用户指定值，未指定时按 25–28 秒设计。
3. 输出确认问题并暂停。未得到明确确认，不得调用图像生成工具，不得输出分镜图或视频提示词。
4. 用户确认文字大纲后，严格按大纲生成 4×4 黑白分镜图；逐格检查并在必要时直接返修整张原图，随后再次请求用户确认。
5. 用户确认分镜图后，才根据已确认的 16 格逐格生成视频提示词，保持角色身份、服装、武器、场景、180 度轴线、动作因果和镜头连续性不变。

绝对门禁：文字大纲确认前不出图；分镜图确认前不出视频提示词。用户只说“继续”“先看看”“差不多”等模糊表达时，不视为确认；应根据当前阶段追问一次明确确认。

输出应简单描述剧情，但不能牺牲 16 格镜头大纲的可执行性。完整模板、阶段状态机、图像自检、返修和最终视频提示词格式均以 `references/source.md` 为准。
