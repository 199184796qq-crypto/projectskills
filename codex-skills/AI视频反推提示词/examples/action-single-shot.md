# 示例：单镜动作

## 状态骨架

站立观察 → 压低重心 → 向右爆发冲刺 → 急停半蹲

## 过渡桥

### A → B
远处传来警报，人物停止观察并屈膝，双肩前压，重心降低。

### B → C
右脚蹬地，人物向右前方突然加速；摄影机低位平行跟随；外套延迟向后甩动。

### C → D
人物在障碍物前急停，脚掌滑动半步，身体下沉，以半蹲姿态稳住。

## Compact Prompt

夜晚工业走廊，一名穿深色外套的成年人物先站立观察，听见警报后迅速屈膝压低重心，右脚猛蹬地面向画面右前方爆发冲刺；低机位摄影机与人物平行跟随，外套下摆延迟向后甩动；人物在前方障碍物前急停并半蹲稳住。保持运动方向连续，避免突然环绕镜头。
