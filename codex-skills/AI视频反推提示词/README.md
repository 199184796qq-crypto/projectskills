# SceneRelay Reverse 1.0

SceneRelay Reverse 是一套关键状态接力式 AI 视频反推 Skill。

它把一段视频拆成：

```text
关键状态 A
→ 过渡桥
→ 关键状态 B
→ 过渡桥
→ 关键状态 C
```

最后将这条状态链编织成可直接用于 AI 视频模型的提示词。

## 适合谁

- 需要快速反推 AI 视频提示词的人
- 经常遇到动作中间断裂的人
- 需要处理短多镜视频的人
- 希望生成失败后快速定位问题的人

## 核心优势

- 不靠标签词堆砌
- 不要求复杂工具
- 状态结果清楚
- 动作过程容易执行
- 多镜接口明确
- 生成失败时从最早偏差点修复

## 推荐使用

将整个文件夹安装为 Skill，或将 `SKILL.md` 作为系统指令使用。
