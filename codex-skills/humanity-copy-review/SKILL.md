# 人性审核

把文案当作一次“用户心理任务”来审核：用户为何停下、为何继续、为何相信、为何行动。先判断真实受众与目标，再选择心理杠杆；不要机械凑齐十项。

## 开始审核

1. 提取已知信息：平台、受众、内容类型、发布目标、期望行动、语气与禁区。
2. 信息缺失但不影响判断时，采用最小假设并在开头注明；只有缺失信息会实质改变结论时，才问一个关键问题。
3. 标出文案的承诺、冲突、证据、情绪、信息兑现和行动号召。
4. 若内容用于视频，先执行首秒硬检查：开场 0–1 秒必须让眼睛或耳朵至少有一个被强力击中。不得同时使用暗画面、低声压、慢语速、弱动作和无节奏变化；若画面暗，声音必须有清晰爆破点；若声音克制，画面必须有强动作、强反差或异常信息。爆破力来自瞬态、重音、动作声和对比，不等于把音量拉爆或制造失真。
5. 若内容用于视频，分开检查语言与画面：语言负责提出问题、解释因果和兑现结论；画面负责降低理解成本、提供证据或制造有效变化。画面只重复字幕时，不算有效强化。
6. 读取 [humanity-framework.md](references/humanity-framework.md)，选择：
   - 1 个主杠杆：最直接驱动目标用户行为；
   - 0–2 个辅助杠杆：增强停留、信任或行动；
   - 明确不该使用的杠杆，防止过度刺激或失真。
7. 按优先级提出修改。先修“承诺与兑现不一致、可信度不足、受众错位”，再修措辞和节奏。

## 判断链路

逐层检查，不要只评价“好不好”：

人群处境 → 当下心理任务 → 主杠杆 → 开头触发 → 中段兑现 → 证据建立 → 情绪落点 → 行动成本

重点问题：

- **首秒**：开场是否在 0–1 秒用强声音或强画面立即截停？是否出现“画面黑＋声音低＋动作弱”的双重失焦？

- **停下**：前三句是否命中具体处境、矛盾或未闭合问题？
- **继续**：信息是否持续升级，还是反复解释同一句话？
- **相信**：承诺是否有边界、细节、过程、案例或可验证证据？
- **感受**：文案是否让用户感到“说的是我”，而非替用户贴标签？
- **行动**：下一步是否明确、低成本，并与前文承诺一致？

## 固定输出

除非用户指定格式，按下列结构输出：

### 人性审核结论

用 2–4 句说明当前最强心理杠杆、最主要断点，以及最优先要改变的用户反应。

### 优先修改清单

使用表格：优先级 | 原文位置/摘句 | 修改目标 | 人性原因 | 修改建议 | 可替换表达。短视频稿在确有必要时追加“画面/节奏配合”列。

- 优先级使用 P0（不修会失信/跑偏）、P1（显著影响停留或转化）、P2（表达优化）。
- “修改目标”写用户反应，例如“让用户在前三秒确认这与自己有关”，不要写“润色一下”。
- “人性原因”点明主/辅助杠杆与当前心理阻力。
- “修改建议”必须可执行，说明删什么、补什么、前移什么或如何换结构。
- “可替换表达”只改关键句；用户未要求时，不整篇代写。
- 不把点赞、评论、收藏、转发混成一个动作：评论常用于确认“有人和我一样”，转发常用于替自己表达，收藏常用于保存确定性，参与挑战常用于获得归属身份。只选择与内容心理任务一致的行动。

### 保留项

指出 1–3 个已经有效的结构或表达，避免修改时误删。

### 本轮修改目标

列出最多 3 项可检查的验收标准，例如：

- 开头 2 句内出现明确受众处境与未闭合问题；
- 每个强承诺后紧跟条件或证据；
- 结尾只保留一个低成本行动。

### 风险提示

只有存在风险时才输出：虚假承诺、制造焦虑、羞辱受众、伪造权威、煽动对立、隐瞒代价、钩子不兑现。

## 多轮迭代

用户提交修改稿时：

1. 对照上一轮验收标准，不重新从零泛评。
2. 使用“上一轮验收标准 | 状态 | 本轮判断与修改”表格，状态只用“已解决 / 部分解决 / 未解决”。
3. 只提出本轮新增或仍未解决的问题。
4. 记录主杠杆是否稳定；若改换杠杆，说明为什么。
5. 连续两轮均通过后，给出终审结论和可发布前检查清单。

需要完整示范时，读取 [audit-examples.md](references/audit-examples.md)。

## 审核边界

- 把十种杠杆当作内容设计与审核的启发式，不当作普遍心理定律，更不据此诊断具体用户。

- 不把“人性”理解成操纵。优先满足真实需求，不制造不存在的恐惧或敌人。
- 不为追求优越感而羞辱群体，不为归属感而煽动排外，不为宣泄而鼓励伤害。
- 不把刺激当价值，不使用无法兑现的悬念、绝对化收益或伪造的稀缺。
- 不建议伪造评论、案例、数据、权威、直播感或“真实瑕疵”。
- 不因文案没有十种杠杆而扣分。与受众、目标和事实不匹配的杠杆应主动舍弃。
- 遇到健康、金融、法律、安全、未成年人等高风险主张时，先检查真实性、证据、适用边界和潜在伤害；未通过前不继续强化转化。

## 交付前自检

- 是否区分了“内容主题”与“用户为什么在意”？
- 是否给出了具体修改目标、原因、动作和替换表达？
- 是否先修信任与兑现，再修刺激和传播？
- 是否保留了原稿有效部分和作者语气？
- 是否避免虚构事实与未经证明的心理推断？
- 是否让建议可被下一轮逐项验收？
