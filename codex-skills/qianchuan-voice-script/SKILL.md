# 千川素材口播声线

## 目标

根据产品、人群、文案情绪与投流场景，选择能抓住注意力且有可信销售感的口播声线，输出可直接交给真人或语音工具使用的完整文本。

## 工作流程

1. 判断产品品类、价格带、目标人群、使用场景和文案的核心情绪。
2. 选择最匹配的地域与性别。地域指口音或语言气质，不得借此虚构产品产地、品牌背景或主播身份。
3. 用具体、可执行的词描述声线，不使用空泛词语。
4. 保留用户文案的核心事实、卖点和行动指令；只为口播顺畅度调整断句、语气和节奏。用户要求改写时才重写内容。
5. 在全文案中嵌入必要的中文全角圆括号情绪指令，并用标点补充节奏和情感。
6. 输出前检查格式、引号、事实和首秒抓力。

## 声线选择

综合以下维度选择，不固定套用地域刻板印象：

- 地域：普通话、京腔、东北、川渝、河南、山东、江浙、两广等；没有明确地域价值时优先使用自然普通话。
- 性别：根据目标受众的信任来源、产品气质和使用场景决定，不机械按品类分配。
- 年龄感：少年、青年、轻熟、中年等。
- 音色：明亮、清脆、厚实、沙哑、温润、磁性、颗粒感等。
- 状态：爽利、亲切、克制、兴奋、笃定、烟火气、专业感等。
- 节奏：快慢、轻重、停连、爆发点和收束方式。

声线描述必须说明：

- 音色与年龄感
- 语速与节奏
- 开场方式
- 主要情绪变化
- 重音或收尾方式

## 首秒规则

- 开场零到一秒必须先抓耳，首句使用清晰重音、短促爆发、节奏突变或有冲击力的动作感。
- 爆破力不等于全程喊叫或音量拉满。依靠瞬态、咬字、重音、停顿和反差制造抓力，避免削波、刺耳和失真。
- 开头不得低声含糊、缓慢铺垫或连续弱读。
- 后文要有强弱变化，不能从头到尾保持同一音量和情绪。

## 情绪标注规则

- 只使用中文全角圆括号：`（情绪或表演指令）`。
- 指令写动作和表达方式，例如：`（突然加重）`、`（压低后停半拍）`、`（像分享秘密）`、`（笑着加快）`。
- 将指令放在情绪变化发生前，短而明确，通常二到八个字。
- 一段只在真正发生变化时标注，避免每句话都加括号。
- 括号内不得写要朗读的正文，不得写镜头、运镜、字幕、商品链接等画面指令。
- 不使用中文双引号、中文单引号、英文双引号或英文单引号包裹任何正文或情绪提示，防止语音工具把引号内容当成口播正文。

## 标点表演规则

- 感叹号表达爆发、惊喜、强调，但避免句句使用。
- 问号制造追问、质疑或互动。
- 逗号控制短停，句号负责明确收束。
- 省略号表达余味、迟疑或压低后的停顿。
- 破折号表达突然转折、悬念或重音前的蓄力。
- 可通过短句、独立成句和重复形成节奏；不能只靠括号说明情绪。
- 避免生僻符号、表情符号和可能被语音工具误读的装饰字符。

## 固定输出格式

除非用户明确要求解释，只输出以下三部分，不添加标题、分析、备注、建议或 Markdown 代码块：

地域性别：地域加性别声线

声线描述：一段完整、具体、可执行的声线说明

全文案：
嵌入情绪指令并完成标点表演的全文案

示例：

地域性别：川渝青年男声

声线描述：音色明亮带轻微颗粒感，语速偏快，开场短促有爆发力，中段像熟人分享一样自然，卖点处咬字加重，结尾利落催单但不嘶喊。

全文案：
（开场猛起）这个鸭子，长得是真不讨喜！可你先别划走——（咬重）听这个脆响！外皮焦香，里面还嫩得冒汁……（笑着加快）下酒、追剧、嘴馋的时候，撕一块就停不下来！

## 交付检查

输出前逐项确认：

- 第一行是否只有地域性别。
- 第二行是否为具体声线描述。
- 第三部分是否包含完整文案，而不是节选。
- 情绪提示是否全部使用中文全角圆括号。
- 是否完全没有使用任何单双引号。
- 情绪是否同时通过标点、断句和词序表现。
- 首句是否具有明确抓耳点。
- 是否避免全程喊叫、过度标注和不自然播音腔。
- 是否没有添加未经用户提供的功效、价格、销量、产地或稀缺性事实。
