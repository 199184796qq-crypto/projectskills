# 首尾帧视频参考模板

## 首帧模板

`视频总时长为【X】秒，画面从输入图片中的场景开始。保持主体的身份、外貌、服装、比例、位置、姿态和背景结构与首帧一致。主体先【动作一】，随后【动作二】，环境中的【动态元素】自然响应。镜头采用【运镜】并保持主体清晰、构图稳定。接近结尾时，动作逐渐减速，主体最终停留在【结束状态】，镜头同步稳定并短暂停留。整体呈现【风格】，避免闪烁、抖动、变形、瞬移、跳帧、面部漂移、额外肢体和背景漂移。`

## 尾帧模板

`视频总时长为【X】秒，最终自然、准确地过渡到输入图片。视频开始时，主体位于【初始位置】，处于【初始姿态/朝向】；主体身份、五官、发型、服装和身体比例始终与尾帧一致。主体先【动作一】，随后【动作二】，逐渐到达尾帧的位置、姿态、朝向和表情。镜头从【初始视角/景别】开始，采用【运镜】，逐步对齐尾帧的角度、景别、构图和空间关系。结尾前动作减速，最后准确匹配尾帧并自然停留，避免突然切换、强行溶解、跳帧和主体变形。`

## 首尾帧模板

`视频总时长为【X】秒，从第一张首帧开始，连续过渡到第二张尾帧。主体保持身份、外貌、服装、比例和关键结构稳定，先【动作一】，随后【动作二】，再完成【动作三】，从首帧的【起始状态】自然到达尾帧的【最终状态】。镜头从首帧视角开始，采用【运镜】逐渐调整到尾帧视角、景别和构图。头发、衣服、树叶、烟雾、水面或灯光提供连续环境动态。接近结尾时主体和镜头同步减速，对齐尾帧位置、姿态、朝向、表情和背景关系，最终自然稳定，不使用闪白、硬切或强行溶解。`

## 时长时间轴

| 时长 | 推荐结构 |
| --- | --- |
| 3 秒 | 0–0.5 秒启动；0.5–2.5 秒完成一个动作；2.5–3 秒减速停留 |
| 4–5 秒 | 0–1 秒建立状态；1–4 秒完成主要动作；末段稳定 |
| 6–8 秒 | 前 1–2 秒启动；中段完成 1–2 个动作；末 1–2 秒对齐目标状态 |
| 9–10 秒 | 0–2 秒建立；2–5 秒第一阶段；5–8 秒第二阶段；末段进入最终状态 |
| 10 秒以上 | 拆成多个阶段，每阶段一个清晰目标 |

## 运镜短句

- 固定：`镜头保持固定，仅通过主体和环境动态形成运动。`
- 推进：`镜头缓慢向主体推进，主体逐渐占据更大画面比例。`
- 拉远：`镜头平稳拉远，逐渐展示完整空间和结束构图。`
- 横移：`镜头向右横移，保持主体清晰并产生自然背景视差。`
- 跟拍：`镜头以匹配主体的稳定速度跟随移动。`
- 环绕：`镜头以克制幅度围绕主体移动，保持主体比例和空间关系稳定。`
- 升降：`镜头缓慢升高/下降，调整视角但保持透视自然。`

## 通用一致性约束

`保持人物身份、五官、发型、服装、颜色、身体比例和左右细节一致；保持产品轮廓、材质、Logo、文字、零件和比例一致；保持建筑、道路、家具、地平线和背景结构稳定；避免面部漂移、手部畸形、额外手指、额外人物、肢体融合、物体复制、材质变化、文字乱码、背景漂移、闪烁、抖动、穿模、瞬移、跳帧和光线方向突变。`
