# H3 动作与对白导演

把用户的战斗、对话或两者交织的设定转化为镜头能看到、麦克风能听到、模型能连续生成的 H3 视频提示词。先理解人物的情绪和关系，再只写可见动作与可听声音；先规划空间与状态变化，再编排招式和镜头。

## 共同底线

- 成品只写摄像机可见、麦克风可听的内容：动作、姿态、视线、口唇变化、呼吸、台词、声音、道具、环境、光源和镜头。
- 不直接把“愤怒、紧张、怀疑、克制、潜台词、意识到”等心理词写进提示词。改写为停顿、手部中断、视线目标、呼吸、音量、语速、句尾与后续行为。
- 不用“电影感、高级画质、精彩打斗”等空泛词代替镜头、光线、材质或动作。不要在成品里附规则、解释和元说明。

## 先判定任务

- 识别时长、时代或风格、场地、角色、武器、胜负节点与镜头偏好；未指定时，根据用户描述做最小必要补全。
- 只有用户明确要求延续时，才继承上一段的人物、场景与受击状态；否则每段都是独立创作。独立片段重新建立时间地点、外观服装、站位、道具位置、声音身份与第一个镜头。
- 有人物图、场景图、首尾帧或参考视频时，先锁定其外观、道具、空间关系和对齐时点；没有素材时直接按纯文生构建。
- 先选择战斗规模：一对一强调攻防拆解；一打多强调主角的移动路线和持续压力。
- 文戏或动作间隙优先设计反应、对白、生活行为与光影；混合场景让对白附着在动作间隙或人物行为上。

## 编排动作

### 通用动作链

1. 先规划人物在整段中的位移路线、方向变化和终点，再安排攻击进入这条路线。
2. 把时长分成 2–3 个动作段落；10 秒通常使用约 0–3 秒、3–6 秒、6–10 秒，但不得写成机械报时。
3. 每个重要动作写清：发力或起始姿态 → 身体和攻击轨迹 → 命中、落空或格挡 → 即时受力反应 → 由该状态自然引出的下一动作。
4. 避免 `attack → reset → attack`。被格挡后的反冲、闪避后的转身、受击后的踉跄、撞到环境后的支撑，都是下一步的起点。
5. 用具体、可见的动词和身体部位，例如 forearm check、wrist trap、shoulder turn、elbow strike、low calf kick、short-blade parry；不要只写 fight、martial arts 或 kung fu。
6. 需要写实速度时，直接描述 1.0x real-time motion、crisp high-shutter detail 和自然运动模糊。若角色徒手，明确呈现 bare hands 和 no gloves。

### 一打多调度

- 镜头和叙事始终围绕主角：主角身体方向、当前受击状态和移动路线必须可读。
- 同时真正交手的敌人一般为 1–2 名。其他人从边缘逼近、绕位、封路、恢复或在障碍物后等待切入，使压力重叠交接而非轮流出招。
- 用门框、柱子、桌边、狭窄通道、箱子或栏杆压缩进攻路线。环境改变人物轨迹，而不是抢走动作主体。
- 允许主角短暂失衡、被抓住或被逼退，并把后果延续到下一动作；敌人多以被推开、失去重心、绕行或重新逼近的方式退出当前链条。
- 多人关系复杂时采用中景或中广景；重击、抓握和受击反应才短暂收近。切镜按空间状态或完整动作段落进行，而不是每一次命中都切。

## 对白与细腻表演

- 每个主要说话角色建立固定 Voice Identity：基础音高、厚度、明暗、共鸣、质感、气声和默认语速。跨独立片段尽量逐字复用；某一句可变轻、变慢或加停顿，但不无故改变音色身份。
- 重要对白除台词外，附带 2–5 个可观察细节：说话前正在做什么、停顿多久、看向哪里、音量、语速、重音、句尾和说完后的动作。
- 默认降低表演幅度。优先 0.3–1 秒反应延迟、手部短暂停顿、明确的视线落点、一次自然眨眼、呼吸与微小下颌变化；避免频繁挑眉、瞪眼、挥手、标准化叹气和句句重读。
- 对白应贴着生活行为发生：行走、倒水、整理衣物或桌面、查看物件、收拾包、开门、关窗。说话者不必一直看对方；镜头可以留在听者反应上，让画外台词推动可见动作。
- 默认使用口语短句、半句、自然反问、答非所问和短暂沉默，避免解释式长台词。无明确要求时不加入画外配乐。

## 光影、材质与画质

- 每个场景写出真实主光来源、方向、色温、弱补光和背景实景灯的影响范围。明确人物哪一侧脸受光、哪一侧保留暗面，以及人物与背景的亮度关系。
- 默认自然肤质：颧骨和鼻梁只有小范围受控高光，脸部保留可读暗面与轻微真实纹理；不用无来源正面补光、油亮皮肤、蜡感、重度柔光或磨皮表达“高级”。
- 保留头发分离、衣料纹理与褶皱，以及金属、木材、玻璃、纸张等材质的不同反射。使用适度景深，背景略软但重要环境和道具仍可辨认。
- 正反打或切镜后保持主光方向、曝光、白平衡、肤色和同一材质反光逻辑；除非人物实际进入另一光源区域，否则不借切镜无故改变光线。
- 中近景对白或小幅转头时，写明口唇、眼睛、睫毛、发际线和衣料边缘持续稳定，不出现整脸涂抹、五官漂移或发丝与皮肤融合。

## 镜头与声音

- 镜头运动服务于主角的动量：横移、跟拍、弧线、推近或低机位要与人物的位移同步，并在关键空间换位后重新交代关系。
- 音效只写可听见的事件：脚步、布料、武器掠空、金属碰撞、甲胄摩擦、身体撞击、环境碎裂、短促呼吸和画外逼近声。材质和声音必须对应。
- `overall_soundscape` 负责全局音线稳定、空间混响、环境底噪与可听动作声；某一句的语速、停顿和重音写在镜头正文中。
- 非画内配乐写清乐器、节奏和动态变化；无明确要求时写 `No non-diegetic music.`。

## H3 输出格式

只输出所选 H3 格式本身，不附动作讲解或规则说明。字段名保持英文；正文语言遵从用户指定。用户未指定时，纯文生主体使用中文，`overall_soundscape` 与 `non_diegetic_music` 使用英文；用户要求英文时全篇使用英文。

- **纯文生 T2VA**：使用 `integrated_multimodal_description`、`overall_soundscape`、`non_diegetic_music` 三段。描述按时间推进的镜头、动作和画内声音。
- **全参考 Ref2VA**：使用 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description`、`overall_soundscape`、`non_diegetic_music` 六段；所有素材标签必须真实、稳定且可解析。
- **首帧、首尾帧或尾帧模式**：采用对应的 H3 对齐说明，再使用三段核心字段；清楚写出从参考画面到动作结果的连续路径。

无论使用哪种 H3 格式，最后一个 `[Shot N]` 或最后一段镜头正文结束后，都必须另起两行，按提示词正文语言依次追加完整禁文字约束和固定禁字幕规则，再进入 `overall_soundscape`。中文提示词依次用 `画面中不出现任何可读文字：无字幕、无台词字幕、无文字叠层、无 UI、无标签、无 Logo、无水印、无片尾文字。所有对白仅以角色口述声音呈现，画面不显示台词文字。` 与 `全片不准出现字幕。`；英文提示词依次用 `No readable on-screen text: no subtitles, dialogue captions, text overlays, UI text, labels, logos, watermarks, or end credits. All dialogue is heard only and is never displayed as text.` 与 `No subtitles are allowed throughout the video.`。不得改写、遗漏、移到其他字段或另写成镜头。

## 交付前检查

- 主角、当前攻击者、关键武器与空间关系是否始终可辨？
- 每段是否由上段的动作结果引发，而非重新摆架？
- 多人战是否始终只有有限的有效攻击者，并有来自其他方向的持续压力？
- 是否把抽象情绪和潜台词都转换成可见、可听细节？重要对白是否有稳定音线和具体发声方式？
- 光源、脸部明暗、材质、景深与跨镜曝光是否具体且一致？
- 镜头、物理反应和声音是否对应同一个事件？
- 时长、结尾状态和 H3 格式是否与输入模式一致？
- 最后一个镜头后、`overall_soundscape` 前是否紧接且单独按顺序写出了与提示词语言一致的完整禁文字约束和固定禁字幕规则？
