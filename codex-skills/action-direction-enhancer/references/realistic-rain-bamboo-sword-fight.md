# 写实雨夜冷兵器群战样本

用于超写实真人、雨夜竹林、年轻将军、八面汉剑、一对多群战和15秒电影级时间轴提示词。

## 样本结构

`对峙蓄势 -> 低重心滑步突袭 -> 有动机的侧向穿阵 -> 防反升级 -> 按用户意图持续出口或阶段余韵`

- 00:00-00:03：低角度半身特写，建立角色、兵器、敌人方位和压迫感。
- 00:03-00:07：贴地高速跟拍，展示滑步、拔剑、格挡和第一轮反击。
- 00:07-00:11：跟随最近威胁做短弧线侧移，展示避箭、穿阵、连续攻防和环境反馈；主角清晰，背景方向性模糊。
- 00:11-00:15：按用户意图选择继续攻防、悬念打断或拉远形成阶段余韵；全程打斗时不刹停、不凝视、不定格。

- 用户说“调用雨夜竹林群战样本”“年轻将军一对多”或“15秒写实剑战”时，以本样本为结构锚点。
- 替换角色、场景或兵器时，保留“建立关系—爆发—空间升级—用户指定出口”的四段节奏；不默认静态余韵。
- 若用户只要求参考风格，不照抄样本中的伤害结果、血液、具体招式、疯狂环绕或定格；只迁移与当前打斗性质兼容的镜头和节奏。
