# 多人打斗导演方法

用于多人围攻、国风群战、以少对多、先守后攻、动作补位和电影化套招设计。

## 七项基础原则

1. **战斗关系**：标明主角、第一攻击者、第二补位者和旁观威胁。
2. **动作清晰**：每段只安排一组主要攻防，避免多人同时乱动。
3. **空间明确**：写清人物位于主角左、右、前、后，以及彼此距离和攻击通道。
4. **场景承载风格**：用庭院、灯笼、雾气、月光、湿润青石等建立国风氛围。
5. **镜头服务招式**：景别必须能看清攻防路径；运镜不能抢夺动作信息。
6. **冷暖对比**：冷色环境光与暖色实景光分离人物和背景。
7. **材质真实**：衣料、积水、火光、雾气、地面反射和受力反馈要符合物理逻辑。

## 五项提示词必填

- **进攻顺序**：谁先出招，谁后补位。
- **防守反应**：主角怎样下潜、侧移、格挡或借力。
- **反击动作**：主角使用什么明确招式，击向哪个方向。
- **连招节奏**：前一动作的结束状态如何触发下一动作。
- **结尾方式**：按用户意图选择持续打斗、悬念中断或阶段决胜；只有明确要求时才做定格。

## 武指式主结构

`主角遇敌 -> 以少对多 -> 先守后攻 -> 连续反击 -> 阶段结果或持续出口`

可加入“可控破绽”：

1. 主角主动留下一个可见空当。
2. 第一名敌人沿空当进入攻击。
3. 主角用最小幅度化解，并移动到第一名敌人侧面。
4. 第一名敌人的身体或攻击轨迹阻挡第二名敌人。
5. 主角完成反击后立刻回收架势，转向下一威胁。

## 三人格斗时间轴示例

- **0-1.2秒**：主角位于中心；红衣敌人从左侧连续出拳，白衣敌人从右侧准备高位踢击。主角降低重心观察夹击。
- **1.2-2.5秒**：主角下潜避开左侧拳路，贴近湿地向右低位滑行；右侧高踢从主角上方掠过，两条攻击线交错但不重叠。
- **2.5-3.8秒**：主角从蹲伏状态短促发力，反击左侧敌人身体侧面；对方弯腰后退，主角借其肩部稳定身体。
- **3.8-5.2秒**：主角蹬地腾空并顺时针转体，以横向踢击反击右侧敌人；命中瞬间短暂慢放，随后恢复正常速度。
- **5.2-6.5秒**：主角落回中心，脚掌踏入积水；左侧敌人恢复并重新冲入。
- **6.5-7.5秒**：主角后脚扎稳，打出短距离重拳；对方沿受力方向后退。
- **7.5-8秒**：主角刚化解左侧威胁，右侧敌人的下一次攻击已进入路径；镜头保持主角与最近威胁清晰，动作持续。

## 镜头、光影与材质

- 使用约35毫米标准电影视角，避免广角近距离造成肢体畸变。
- 镜头只在人物换位提供空间时做短弧线移动，从正面偏左过渡至侧面；不得为了炫技持续环绕。
- 主要使用中景和中近景，保证全身攻防动作可辨认。
- 仅在关键命中瞬间加入轻微可控震动；慢动作只有用户明确要求时才使用，并限制为单个关键瞬间。
- 冷蓝月光从后上方勾勒轮廓，暖色灯笼或火光从侧后方提供环境层次。
- 湿润石板产生倒影、水纹和溅水；衣袍必须有重量、惯性和受力摆动。

## 通用模板

```text
【人物与站位】
主角位于{中心/前景位置}；敌人A位于{方向与距离}，负责第一轮攻击；敌人B位于{方向与距离}，在A攻击结束后补位；其余敌人保持在背景威胁位置，不同时进入。

【动作时间轴】
{时间段1}：A使用{攻击动作与路径}先攻，主角以{下潜/侧移/格挡}化解；B开始从{方向}进入补位。
{时间段2}：主角利用{脚步与重心变化}反击A的{身体区域/兵器线}，并移动到{新位置}，使A暂时阻断B的攻击线。
{时间段3}：B完成{第二攻击}，主角从上一动作结束姿态直接衔接{第二次防守与反击}。
{时间段4}：根据用户选择，让主角继续处理{下一威胁}、被{新威胁}打断，或形成不冻结的阶段优势。

【镜头】
使用{焦段感}中景至中近景，镜头沿{方向}做平滑弧线移动。只在{关键命中}加入短促震动；用户明确要求慢动作时才在单个瞬间使用，随后恢复正常速度。不要无规则跳切，不要越轴。

【环境】
{场景}，{冷色环境光}与{暖色实景光}形成冷暖对比。地面、衣料、雾气、水花和火光遵循真实物理反馈。

【负面限制】
不要所有敌人同时攻击，不要人物重叠穿模，不要攻击方向不明，不要主角无原因瞬移，不要连续慢动作，不要镜头持续疯狂旋转，不要廉价能量特效，不要塑料材质。
```
