# 动作提示词写作风格

动作性质决定“能发生什么”；提示词写作风格决定“怎样呈现给用户”。两者独立选择。先锁定人物、场景、物理层级、动作因果和镜头逻辑，再按用户选择的格式组织文字。

## 选择规则

- 用户明确说“全文描述”“动作链”“按秒”“分镜”“按这个格式写”时，严格采用对应风格。
- 用户给出示例时，保留其标题层级、分段密度、箭头符号、时间标注和负面提示词位置；只替换为新的内容。
- 用户未指定时，默认用“模块化完整提示词 + 按秒箭头动作链”，特别适合15秒左右的动作视频。
- 风格不能改变打斗性质：现实特工仍遵守现实惯性，武侠和动漫必须另有明确授权。
- 默认不写帧率、分辨率、具体相机/镜头品牌或内部物理标签；用实际可见的运镜、焦点、景别、动态模糊、光影和环境反馈代替。

## 1. 全文沉浸式电影描述

**适用**：用户说“全部提示词”“一整段”“全文描述”“不要小标题”。

**写法**：把成片质感、场景、人物、连续动作、运镜和限制写成一个连贯段落；动作仍用因果顺序，但不使用时间标签或列表。

**骨架**：

`时长与镜头方式 -> 场景与可用道具 -> 人物对比 -> 连续攻防过程 -> 焦点/动态模糊 -> 结尾方式 -> 负面约束`

## 2. 箭头动作链

**适用**：用户说“动作链条”“用 -> 链接”“不要删招”“动作加量”。

**写法**：每个箭头都承接前一步的重心、方向、距离、主动权或道具位置。

**骨架**：

`攻击启动 -> 防守/闪避 -> 受力反馈 -> 位置变化 -> 环境回应 -> 反击/反解 -> 下一威胁`

**要求**：不把人物复位；不把“快速、猛烈”当作动作；每次接触都写可见身体或环境反馈。

## 3. 按秒时间轴

**适用**：用户给出时长，要求“0-3秒”“15秒”“节奏”“一镜到底”。

**写法**：按2-4秒划分阶段；每段写清当前站位、动作链、镜头锚点、焦点和下一段出口。时间轴可以内部使用箭头动作链。

**骨架**：

`0-3秒｜切入攻防`  
`3-6秒｜换位/环境互动`  
`6-10秒｜压迫与反解`  
`10-13秒｜主动权再交换`  
`13-15秒｜持续出口或用户指定结局`

## 4. 镜头分镜脚本（第一镜、第二镜直述）

**适用**：用户说“6个镜头”“自行设计分镜”“分镜表”“多镜头”“第一镜、第二镜这样写”。

**写法**：每个镜头只承担一个叙事动作功能，直接以“第一镜：”“第二镜：”自然描述景别、机位、人物动作、环境反馈和切镜出口；不要把同一套动作从多个角度重复播放。

**直述骨架**：

`第一镜：用[景别/机位]建立[场景、人物站位、首次威胁]。`  
`第二镜：镜头[运动方式]跟随[第一轮攻防]，突出[清晰主体/环境反馈]。`  
`第三镜：切到[受力者或关键道具]，展示[失衡、转向或动作结果]。`  
`第四镜：镜头穿过/绕过[场景节点]，完成[环境互动与换位]。`  
`第五镜：用[景别/机位]表现[反击或局势升级]。`  
`第六镜：保留[持续出口、悬念或阶段结果]，按用户要求结束或继续。`

**简写骨架**：

`镜头1｜景别/机位｜建立空间与首次威胁`  
`镜头2｜景别/机位｜第一次攻防`  
`镜头3｜景别/机位｜受力或失衡`  
`镜头4｜景别/机位｜环境互动与换位`  
`镜头5｜景别/机位｜反击或局势升级`  
`镜头6｜景别/机位｜持续出口、悬念或阶段结果`

## 5. 模块化完整提示词

**适用**：用户给出或要求固定栏目，例如“基础成片参数、场景、人物设定、完整时序动作链、运镜质感链、负面提示词”。

**写法**：严格保留栏目与顺序。把按秒时间轴放进“完整时序动作链”，把镜头锚点、景别、焦点和模糊规则放进“运镜质感链”。

**固定栏目**：

1. 基础成片参数
2. 场景
3. 人物设定
4. 完整时序动作链
5. 运镜质感链
6. 负面提示词

## 混合使用

常用组合：

- `模块化完整提示词 + 按秒箭头动作链`：动作视频默认首选。
- `全文沉浸式电影描述 + 末尾负面约束`：适合直接粘贴进视频生成器。
- `镜头分镜脚本 + 每镜箭头动作链`：适合6镜头或更长的战争、武侠、群战段落。

无论使用哪种风格，都保留：人物一致性、空间连续、动作因果、每次接触的受力反馈、明确焦点主体，以及不定格的持续出口（如果用户要求全程打斗）。
