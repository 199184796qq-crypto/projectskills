# 打斗导演与摄影决策

在打斗性质确定之后、编排具体动作之前，依次决定：`剧情功能 -> 强度 -> 摄影策略 -> 景别序列 -> 连贯方法`。镜头服务动作和剧情，不以炫技为目标。

## 目录

- 剧情功能先于招式

## 1. 剧情功能先于招式

先锁定一个主要剧情功能，再选择动作、速度和镜头。不得让同一15秒片段同时承担所有目的。

| 剧情功能 | 动作组织 | 摄影重点 | 合理出口 |
| --- | --- | --- | --- |
| 逃生／脱身 | 打开路线、摆脱纠缠、穿过出口 | 通道、障碍、追击距离 | 成功拉开或新威胁截断路线 |
| 捕获／控制 | 缩短距离、限制移动、反解再控制 | 双方重心、手臂关系、出口封锁 | 暂时控制或再次挣脱 |
| 保护／护送 | 主角持续处于威胁与被保护者之间 | 三者位置、遮挡和撤离方向 | 护送继续，不停下展示胜利 |
| 拖延／守口 | 守住门口、楼梯、桥面或狭窄节点 | 地标和攻击通道 | 防线变化或增援／新敌人进入 |
| 对决／证明 | 双方主动权、技法与性格对比 | 完整身体动作、关键反应 | 阶段优势、悬念或继续交锋 |
| 生存／任务 | 短促解决最近威胁并恢复任务方向 | 肩后威胁、装备重量、目标位置 | 角色继续移动或重新执行任务 |
| 救援／突破 | 穿越阻挡并向目标不断接近 | 距离缩短、空间节点、时间压力 | 到达下一节点或遭遇更大阻力 |

剧情功能决定动作“为什么发生”，打斗性质决定动作“能做到什么”，两者都锁定后才选择强度和摄影策略。

## 2. 强度不是特效等级

| 强度 | 节奏表现 | 动作密度 | 镜头表现 | 常见用途 |
| --- | --- | --- | --- | --- |
| S1 一般/克制 | 有观察、犹豫、试探和完整恢复 | 约每2–3秒一个主要攻防结果 | 稳定观察或缓慢跟随，较长停留 | 街头冲突前段、角色试探、压迫感铺陈 |
| S2 激烈 | 短促爆发、主动权频繁交换、恢复时间压缩 | 约每1–2秒一个主要攻防结果 | 反应式跟拍、动作点切换、命中后短震 | 写实混战、功夫片主体、战争近战 |
| S3 高燃 | 距离、高度或尺度持续升级，几乎没有空转 | 约每0.8–1.5秒改变一次主要关系，但每段仍只有一个清晰结果 | 多层次调度或高难度一镜到底，清晰锚点优先 | 武侠高潮、动漫能力战、功夫片决战 |

强度只控制节奏和关系变化，不能突破已锁定的物理/特效等级。街头打斗可以很激烈，但仍不能突然出现武侠身法；战争近战可以高压，但不等于高燃炫技。

## 3. 摄影策略选择

### O1 固定/观察式

- 适用：空间小、情绪压迫、动作不复杂、需要看清人物选择。
- 做法：固定机位、有限摇移或缓慢推进；让人物进入和离开构图。
- 优点：真实、紧张、表演清楚。
- 禁止：把复杂长连招塞进静态大全景，拍成监控录像。

### O2 多角度分镜

- 适用：复杂攻防、多人物、需要强化命中和主动权变化。
- 做法：先用全景/中远景建立位置，再以中景完成主要攻防，近景只抓启动、碰撞或身体反馈；动作进行中切换，保持方向一致。
- 优点：信息清楚、节奏可控、冲击力强。
- 禁止：每一拳都切镜、同一动作重复展示、无因果跳到另一侧轴线。

### O3 一镜到底

- 适用：场地有明确通道和障碍物、动作能拆成4–6个连续节点、角色移动本身是看点。
- 做法：每个节点只使用一个主运镜；在转弯、遮挡、命中、主动权变化时交接镜头锚点。
- 优点：沉浸、空间连续、速度感强。
- 禁止：持续旋转、无目的环绕、同时要求复杂连招和多次大幅升降。

### O4 伙伴/主观跟随

- 适用：战争、追逐、逃生和临场感强的近战。
- 做法：锁定角色肩后或其运动路径；镜头反应稍晚于威胁，保留有限自然晃动和遮挡。
- 优点：紧迫、代入感强、适合狭窄空间。
- 禁止：第一人称与第三人称自由切换、持续抖动导致动作无法辨认。

选择规则：动作本身需要完整观看时优先O1/O2；空间穿越是核心时优先O3；临场威胁与任务压力是核心时优先O4。敌人多、动作方向复杂或场地无法连续通过时，不强行选择一镜到底。

### 性质到导演方案的默认映射

| 打斗性质 | 常用强度 | 首选摄影 | 选择依据 |
| --- | --- | --- | --- |
| 现实街头打斗 | S1–S2 | O1或O2；空间狭长且动作简单时可O3 | 真实反应、局促和失衡比炫技重要 |
| 真人功夫电影 | S2，决战可S3 | O2或O3；试探段可O1 | 需要看清完整身体动作与攻防套路 |
| 武侠电影高燃 | S2–S3 | O2为主，明确飞动路线时O3 | 需要同时表现兵器、身法、高低差和空间奇观 |
| 动漫高燃特效 | S3 | O2为主，单一高速追踪段可O3 | 需要关键姿势、尺度切换和特效分层 |
| 战争片近距离格斗 | S2 | O4或O2 | 威胁、任务方向、装备和临场压力优先 |

场地修正：窄小封闭空间减少大幅环绕；长廊、屋顶、楼梯和连续门洞适合O3；多人开阔混战优先O2；战壕、废墟和遮挡密集空间优先O4。用户明确指定拍法时保留其要求，但仍要指出与场地或动作复杂度的冲突并主动简化动作。

## 4. 景别的功能

- **大全景/远景**：交代场地、人数、出口、火力或高低关系；不承担细小攻防。
- **全景/中远景**：看清完整身法、腿法、兵器长度和多人站位，是功夫与武侠的主要动作景别。
- **中景**：看清腰肩关系、近身交换和道具互动，是多数真人格斗的核心景别。
- **中近景**：强化受力、压迫、抓握变化和人物反应，不连续承担复杂全身动作。
- **近景/特写**：只用于眼神、手部启动、兵器接触、扳机前的戏剧信息或命中反应；不要用特写完成整套动作。
- **低角度/高角度**：用于力量、规模、脆弱或地形关系，不能只为“酷”而频繁切换。

常用景别序列：

- 街头写实：中景建立纠缠 -> 中近景看受力 -> 中景看失衡与脱离。
- 真人功夫：全景/中远景看完整动作 -> 中景看格挡反击 -> 全景重新确认位置。
- 武侠高燃：大全景建立空间和高低差 -> 中远景看兵器与身法 -> 近景抓关键交锋 -> 大景别展示位移结果。
- 动漫特效：近景建立关键姿势 -> 极端大景别展示尺度与能力 -> 中景重新锁定人物攻防。
- 战争近战：肩后中近景发现威胁 -> 中景看纠缠和遮挡 -> 较宽景别恢复任务方向。

### 近身纠缠、抱摔与反解

- 使用中景或中远景保持两人的腰胯、肩线、脚步和地面接触同时可见；镜头锚点放在双方共同重心处。
- 控制建立时可短推近，出现反解、失衡或摔落时立即交给平衡被改变的一方，并随其下沉；恢复起身时再适度抬升。
- 背后控制用肩线、衣料和人物身体遮挡表达接触，不依靠喉部特写或真实压迫细节制造冲击。
- 避免连续脸部特写、无理由绕到人物另一侧、只拍上半身而看不到失衡来源，以及用碎切掩盖不完整的摔投动作。

## 5. 连贯性与顺滑度

1. 开场建立人物左右位置、视线轴、主要移动方向、出口和障碍物。
2. 切镜尽量发生在动作已经开始时，下一镜延续相同方向、速度和身体姿态。
3. 同一动作不重复从多个角度播放，除非用户明确要求重放或慢动作。
4. 镜头锚点只在威胁、命中、主动权或主要运动对象改变时交接。
5. 一镜到底通过门框、柱子、人物掠过前景等自然遮挡完成重构图，不凭空跳位。
6. 高速时保持当前主动角色或受力角色清晰，只让背景产生方向性动态模糊。
7. 每段结尾必须留下下一段的动作出口：视线、脚步、兵器方向、逼近者或新的空间节点。

顺滑不是所有动作等速。使用“启动清楚 -> 加速通过 -> 接触/错位 -> 惯性反馈 -> 下一威胁”的速度曲线；不要用持续快放、全程慢动作或无差别镜头抖动代替节奏。

## 6. 成熟电影经验的抽象原则

以下只提取可复用的导演原则，不复制某位演员或导演的标志性桥段。

### 香港环境道具型动作喜剧

- 先建立清楚空间，再让桌椅、门窗、楼梯、器皿成为连续动作因果。
- 道具既是障碍也是临时解决方案，动作失败、恢复和人物反应同样重要。
- 以全身景和中景保证动作可读，镜头跟人物路线移动，不靠碎切掩盖动作。

### 传统功夫片的精准展示

- 强调架势、线条、步法、节奏和刚柔转换；动作短而清楚，攻防关系完整。
- 主要使用中远景/全景展示身体，命中与逆转才进入中近景。
- 摄影保持稳定，让表演本身产生速度和力量，不用持续晃动制造假冲击。

### 香港武侠片的空间诗意与高燃调度

- 利用屋顶、栏杆、竹林、长廊和高低差形成飞动路线，兵器、衣袂和环境共同画出运动弧线。
- 大景别展示轻功与规模，关键交锋用中近景，镜头升降和横移都有动作原因。
- 奇观必须建立在人物意图、兵器距离和落点之上，不能只剩风、尘和剑气。

### 美式枪战与战争近战

- 以威胁位置、掩体、任务方向和团队关系推动镜头，不为了展示招式而停战。
- 肩后跟随、中景空间和短促反应镜头形成紧迫感；声音、烟尘、装备重量和视线变化承担大量冲击。
- 只描述电影画面与人物反应，不输出可操作的武器使用或战术教学步骤。

### 现代冲击型动作片

- 先用宽景建立攻击线，命中后把镜头交给受力者，再迅速返回新的威胁。
- 动作的重量来自脚步、惯性、身体反馈和环境响应，而非无限镜头抖动。

```text
【导演方案】
- 剧情功能：逃生／捕获／保护／拖延／对决／生存任务／救援突破
- 强度：S1／S2／S3，原因
- 摄影策略：O1／O2／O3／O4，原因
- 景别序列：
- 连贯方法：动作轴、切镜点或锚点交接
- 速度曲线：启动 -> 加速 -> 接触/错位 -> 反馈 -> 下一威胁
```
