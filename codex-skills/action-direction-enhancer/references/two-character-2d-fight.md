# 2D 双人格斗动画

用于高动态 2D 双人格斗、音频卡点战斗、楼顶对决和双方技法差异明显的动画提示词。

## 输入锁定

先提取并保留：

- 角色 A、角色 B 的姓名、外观、服装和左右特征。
- 各自擅长的距离与技法。
- 场景边界、地面材质、障碍物和危险边缘。
- 参考音频承担的用途：只控制节奏、重拍、停顿或速度。
- 画风、光影、运镜、特效和最终对峙状态。

异色瞳按角色自身左右眼锁定，不按观众画面左右判断。每次角色转身或镜头换位后仍保持同一生理左右关系。

## 技法分工

让双方形成不同战斗语言：

- 近身型：小幅闪避、直线快拳、短距离膝击、贴身压迫。
- 中远距离型：长距离踢击、扫腿、回旋踢、后撤招架、抓取和摔投。

不要让双方同时使用全部招式。每次交换只保留一个主攻者和一个明确防守者。

## 连续节拍

按以下顺序组织：

1. **冲入**：角色 B 从中远距离加速接近，角色 A 原地压低重心等待。
2. **试探**：B 用步法或低位攻击逼迫 A 露出反应，A 只做小幅让线。
3. **上下段组合**：B 先完成下段回旋踢，支撑脚落稳并回收后，再衔接上段回旋踢。
4. **贴身反击**：A 从踢击外弧内切近身，用短直拳连续反击；拳路短、收拳快。
5. **后撤招架**：B 后脚先撤，前脚跟退，同时用前臂偏转拳线，不站桩硬接。
6. **抓取摔投**：B 在最后一拳回收时进入抓取，控制 A 的上臂与躯干，通过转髋和换步完成影视化摔投。
7. **空中恢复**：A 被抛出后收腹团身，完成一次清晰空翻，打开身体并屈膝落地。
8. **对峙**：双方各退至安全距离，重新建立架势，呼吸和衣摆逐渐回落。

攻击、防守、失衡和恢复必须逐步发生。不要让回旋踢、快拳、摔投和空翻在同一秒同时出现。

## 镜头与卡点

- 冲入：低机位跟拍或侧后方追随。
- 上下段踢击：中景侧拍，保持双腿和双方距离完整可见。
- 快拳：短暂推进至中近景，镜头不要绕到拳路另一侧。
- 摔投：切换为稍宽的全身景别，完整展示重心转移和抛物线。
- 空翻落地：跟随飞行路径轻微抬升，再下降到落地点。
- 对峙：镜头停止快速运动，稳定双人构图。

根据参考音频标记动作重拍，但不输出参考音频本身：

`重拍1=冲入启动；重拍2=下段踢完成；重拍3=上段踢峰值；连续小拍=快拳；强重拍=摔投；尾拍=落地与对峙。`

## 特效与安全

- 气流从脚下蹬地、拳腿加速和身体旋转产生，并沿动作轨迹拖曳。
- 接触使用擦身、偏转、衣料抖动、发丝甩动和冲击气流表达。
- 不表现真实伤害细节；摔投使用影视化错位，落地动作包含屈膝缓冲。
- 特效不能遮住关键肢体、攻防方向或角色脸部身份特征。

## 输出模板

```text
【角色锁定】
角色A：{外观与左右特征}；技法：{近身闪避/快拳/膝击等}。
角色B：{外观与左右特征}；技法：{中远距离踢击/扫腿/摔投等}。

【场景与风格】
{2D画风、场景、明暗关系、电影滤镜和画质要求}。

【动作时间轴】
{冲入} -> {试探} -> {上下段组合攻击} -> {贴身快拳反击} -> {后撤招架} -> {抓取摔投} -> {空中恢复落地} -> {对峙}。
每段写清站位、距离、攻击路径、防守方式、重心变化、收势和下段承接。

【镜头与特效】
每个节拍只使用一个主要运镜；气流和冲击特效跟随身体发力与拳腿轨迹。

【音频约束】
只参考{音频名称}的节奏、速度和重拍安排动作，不复制、不混入、不输出该音频内容到背景音频。

【负面限制】
不要角色身份互换，不要左右眼特征镜像错误，不要招式同时发生，不要攻击穿模，不要无发力动作，不要镜头越轴，不要特效遮挡关键动作，不要复制参考音频。
```
