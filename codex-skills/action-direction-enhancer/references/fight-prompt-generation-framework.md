# 打斗提示词生成框架

## 0. 总决策链

按固定顺序完成：

`剧情目的 -> 打斗性质与物理/特效层级 -> 场景资源 -> 人物动作签名 -> 主辅动作类型 -> 强度与摄影策略 -> 景别和镜头锚点 -> 时间轴攻防 -> 身体与环境反馈 -> 焦点和动态模糊 -> 结尾 -> 稳定性约束`

任何后续选择不得推翻前面的硬约束。高燃不自动提高物理等级；一镜到底不自动增加动作数量；人物外观标签不自动等于战斗能力；丰富动作不等于无因果堆叠招式。用户明确启用“动作链优先模式”时，动作数量可以超过默认建议，但动作因果、空间连续、场景锁定和影视化安全表达仍是硬约束。

## 1. 先选主类型，再选辅类型

| 主类型 | 叙事作用 | 场地信号 | 动作语言 | 首选镜头锚点 |
| --- | --- | --- | --- | --- |
| 徒手硬派 | 力量、冲突、受力 | 酒馆、仓库、拳台、巷道 | 挥击、格挡、顶撞、失衡、回收 | 受击者 |
| 灵巧身法 | 速度、技巧、反差 | 窄巷、桌椅、屋顶、竹林 | 闪避、切角、侧踢、借位、回身 | 敏捷主角 |
| 控制与摔投 | 近身控制、逆转 | 空地、走廊、台阶、栏杆 | 拉扯、破平衡、转向、脱离 | 两人重心交界处 |
| 兵器对决 | 距离、节奏、危险边界 | 庭院、雨巷、甲板、古寺 | 试探、格开、擦过、换线、收势 | 持器物人物或器物 |
| 远程投射 | 路径、精度、跨尺度 | 长街、楼顶、废墟、树林 | 准备、释放、追踪、规避、再定位 | 器物／投射物 |
| 力量碾压 | 重量、压迫、环境反应 | 工地、石殿、仓库、狭道 | 重击、扑撞、落地、逼退、追压 | 受击者 |
| 巨物对灵巧角色 | 尺度、压迫、机动性 | 废墟、大殿、桥梁、峡谷 | 巨物扫压、低位闪离、绕侧反击 | 尺度关系；低机位升起 |
| 多人围攻 | 空间拆解、以少制多 | 市场、院落、停车场、酒馆 | 引位、逐个处理、换线、遮挡、撤步 | 主角及最近威胁 |
| 追逐跑酷 | 距离变化、追近、逃离 | 屋顶、楼梯、街巷、车站 | 加速、翻越、转弯、回身、再冲刺 | 被追者或追击者 |
| 环境道具 | 场地参与、局势反转 | 酒馆、厨房、码头、工厂 | 推移、遮挡、阻断、借高低差 | 正在互动的角色 |

只允许用一个主类型解决核心冲突；需要变化时，以一个辅类型承接。例如：`古代酒馆 = 徒手硬派 + 环境道具`，`深夜老巷 = 灵巧身法 + 力量碾压`，`废墟BOSS战 = 巨物对灵巧角色 + 远程投射`。

## 2. 场景资源扫描

按以下顺序检查场景，而不是凭空添加不存在的道具：

1. **移动通道**：空地、走廊、桌间过道、楼梯、屋顶边缘。
2. **高低差**：台阶、桌面、栏杆、窗台、平台。
3. **阻挡物**：门框、柱子、摊位、柜台、车辆、梁柱。
4. **可互动道具**：椅子、桌子、灯笼、绳索、锅具、木箱、雨水、碎石。
5. **画面光源**：街灯、窗光、火盆、霓虹、车灯；它们用于定焦、逆光轮廓与动作切换。

道具只能服务于已有动作：脚步改变 -> 碰撞或擦过 -> 道具回应 -> 产生下一条路径。避免让道具无故爆裂或突然出现。

## 3. 动作节拍配方

每个节拍写成：

`主动者 + 起始距离/站位 -> 可见动作路径 -> 对方防守或错位处理 -> 身体反馈 -> 环境反馈 -> 下一个威胁/位置`。

动作变化不等于连续堆招。每个节拍至少改变一项：距离、水平高度、左右方向、谁掌握主动、或使用的场地障碍。

安全的影视化接触用擦身、遮挡、镜头错位、衣物与头发带动、后仰半步、失衡后回收来表达；不要写可模仿的真实伤害步骤或画面化伤害细节。

### 3.1 动作链优先模式

当用户说“动作加量”“不要删招”“不要管过载”“动作链优先”“保留完整动作链”，或给出一条高密度动作链并要求原样保留时，执行以下覆盖规则：

1. 让用户指定的动作数量和顺序覆盖本框架的默认节拍数量；不主动删招，不提示动作过载，不另给精简版。
2. 把每个动作整理成微节拍：`上一动作结果/位置 -> 下一攻击启动 -> 防守/反解 -> 身体反馈 -> 新位置/道具反馈 -> 下一动作`。
3. 让上一动作的重心、朝向、距离、抓握、道具位置或主动权直接触发下一动作；不让人物复位后重新开始。
4. 把数个微动作编入同一个有动机的镜头段；只有威胁来源、主动权、运动高度或空间方向发生明显变化时才切换镜头锚点。
5. 全程锁定角色身份、场景边界、屏幕方向、既有道具、当前受力者和主角清晰度；背景动态模糊只跟随真实运动方向。
6. 只修复乱码、主体不明、直接矛盾或无法衔接的动作顺序；用最小过渡或影视化安全替代表达保留原意，不因默认时长密度删除动作。

## 4. 近身纠缠、控制与摔投

当主类型是“控制与摔投”时，每个复杂交换必须能看出：

`进入贴身 -> 控制意图建立 -> 对方反解或降低重心 -> 主动权转移 -> 失衡/换位/安全落地 -> 恢复或下一次控制`

- 镜头锚点放在双方共同重心处，以中景或中远景展示腰胯、肩线、脚步和地面关系；失衡发生后把锚点交给受力者。
- 抱摔、翻摔和拖带必须先出现可见的距离缩短与平衡变化，再出现落地结果；不让人物无原因腾空或超长飞退。
- 反解必须改变至少一项：控制者、身体朝向、站立高度、与障碍物关系或移动通道；不能只写“轻松挣脱”。
- 背后锁抱或锁喉式画面使用肩线遮挡、衣物拉扯、呼吸和身体反应表达压迫，不描写真实颈部压迫、关节破坏或可照做的操作步骤。
- 体型、性别和外观不直接决定胜负。让结果由时机、重心、速度、人物动作签名和环境位置支持；没有证据时不宣称具体门派或专业水平。
- 默认情况下，15秒可安排6—8个总节拍，其中4—6个是清楚的控制结果或主动权变化；动作链优先模式不设数量上限，但仍至少覆盖一次高低变化、一次前后／侧背关系变化、两次主动权交换和一次真实场景互动。

## 5. 镜头选择与焦点规则

| 目的 | 机位与运动 | 清晰对象 | 模糊对象 |
| --- | --- | --- | --- |
| 展现敏捷 | 侧后肩位、髋部高度横移、短促甩镜修正 | 敏捷主角与关键肢体 | 反向掠过的环境 |
| 展现力量 | 命中后交给受击者，短促震动后跟随其后撤或滑移 | 受击者身体反馈 | 攻击者或背景 |
| 展现器物路径 | 手部特写 -> 器物前方/侧方 -> 后方追随 | 器物或投射物 | 地面与两侧景物 |
| 展现尺度 | 低机位随巨物上扬或下压，随后保持地标关系 | 巨物轮廓与小角色 | 远景环境 |
| 展现近身纠缠 | 中近景保持双方腰肩关系，必要时短推近 | 两人的接触线与表情 | 前后景浅景深 |

每 1–3 秒只设定一个主镜头动作：跟随、横移、上升、下沉、推进、拉远或短甩。镜头抖动只发生在着地、碰撞或急停之后，不要持续抖动。

## 6. 动作变化门槛

给每个节拍标记它实际改变了什么：

- `D 距离`：远距、进入、贴身、脱离或重新追近。
- `H 高度`：站立、低位、腾越、落地或高低差转换。
- `R 方向`：左转右、正面转侧面、前进转后撤或穿过障碍物。
- `I 主动权`：A主攻、B化解、B反击、A重新压迫。
- `P 道具/地形`：桌面、门框、栏杆、积水、碎石等真正改变动作路线。

相邻两个节拍不能只重复同一种距离和方向。5秒至少覆盖3种变化，8—10秒至少覆盖4种变化，15秒至少覆盖5种变化。增加“迅猛、凌厉、高燃”等形容词不算动作变化。

推荐主动权链：`A启动 -> B化解并抢回主动 -> A受力或被迫换位 -> B追击/利用场地 -> A重新回应`。角色可以暂时停顿观察，但不能无理由站着等待对方完成长连招。

## 7. 失败模式与负面约束

交付前删除或重写以下内容：

- 静态大全景从头拍到尾，像监控录像。
- 同一秒塞入转身、腾空、格挡、反击和复杂环绕运镜。
- 镜头持续360度旋转、持续抖动或无动机甩动。
- 主角、对手和背景同时模糊，没有清晰锚点。
- 只写“快速重击”，没有脚步、身体路径、防守处理和可见结果。
- 冲击波、烟尘或镜头震动先于接触出现。
- 道具在镜头中途凭空出现，或只为了爆裂而爆裂。
- 多名敌人排队等待，或所有人同一时刻扑上却没有攻击通道。
- 一镜到底中人物左右位置、移动方向或出入口突然交换。
- 用户要求全程打斗时，擅自加入摆姿势、胜利凝视或结尾定格。

可直接加入完整提示词末尾的稳定性约束：

`人物外观与服装保持一致，空间方向连续，动作遵循重心与惯性，不瞬移、不漂浮、不肢体畸变；每次接触都有身体反馈，主动作人物保持清晰，背景只产生方向性动态模糊；无持续乱晃、无无动机环绕、无全画面模糊、无凭空出现的道具；除非明确要求，不使用慢动作和结尾定格。`

## 8. 交付评分

每项20分，总分低于80分必须重写：

1. **动作逻辑**：能看出谁先出招、对方如何处理、主动权如何变化。
2. **空间连续**：距离、左右方向、障碍物、出入口前后一致。
3. **动作变化**：节拍改变距离、高度、方向、主动权或场地关系。
4. **镜头可执行**：每段只有一个主运镜，清晰锚点和模糊方向明确。
5. **反馈完整**：身体反应、衣物/发丝和环境反应由真实动作触发。

## 9. 节拍功能与速度设计

每个节拍只能承担一个主要叙事功能，相邻节拍不要重复同一功能：

1. **切入**：直接进入威胁、逼近或第一次攻防，不做无关铺垫。
2. **试探/拦截**：建立双方节奏、距离和反应方式。
3. **压迫**：一方连续推进，另一方被迫退让或改变路线。
4. **化解/逆转**：防守方通过闪离、格开或换位夺回主动。
5. **位移**：双方越过桌椅、门框、台阶或其他空间节点。
6. **升级**：改变高度、距离、武器、参与人数或危险区域。
7. **持续出口**：下一次攻击已启动或威胁进入画面，让动作继续流动。

速度感来自“预备短、路径清楚、反馈及时、下一威胁立刻出现”，不是用形容词或随机堆招代替因果。默认模式按建议节拍数量控制密度；动作链优先模式不设数量上限，但每个微节拍仍需保留：启动信号 -> 动作路径 -> 防守处理 -> 受力/失衡反馈 -> 下一动作触发。慢动作只在用户明确要求时使用。

结尾按用户意图选择：

- **全程打斗**：最后一秒仍有攻防变化，下一次攻击已经进入路径；不摆姿势、不凝视、不定格。
- **悬念中断**：新威胁进入画面或双方位置发生危险变化，在动作未解决时结束。
- **阶段决胜**：允许一方暂时取得优势，但保持呼吸、脚步或环境运动；除非明确要求，不做冻结画面。

## 10. 模型提示词优先级

按以下顺序组织完整提示词：

1. **硬约束**：剧情目的、打斗性质、物理/特效层级、时长、画幅、一镜到底或分镜、是否全程打斗、是否允许慢动作/定格。
2. **角色锁定**：人物数量、外观、服装、左右特征、武器和战斗属性。
3. **空间锁定**：起始站位、屏幕方向、主要通道、障碍物与已存在道具。
4. **时间轴动作**：谁先动、怎样处理、身体反馈、位置结果和下一威胁。
5. **镜头调度**：每段锚点、单一主运镜、景别、清晰对象与背景模糊方向。
6. **质感层**：光影、胶片、镜头参数、材质、天气、声音和环境细节。
7. **稳定性约束**：人物一致、空间连续、无瞬移畸变、无全画面模糊和无动机运镜。

如果提示词过长，优先删去重复的“电影感、震撼、高燃、超写实”等形容词和重复设备参数；保留角色、空间、动作因果、镜头锚点与稳定性约束。

## 11. 人物动作签名

在设计时间轴前，为每名主要角色确定六项：`架势高度、偏好距离、移动路径、动作节奏、防守反应、动作后的恢复方式`。从中选择至少两项作为全程不变的动作签名，再允许一项在局势升级时发生变化。

| 角色属性 | 动作签名 | 受力/恢复表现 | 镜头语言 |
| --- | --- | --- | --- |
| 敏捷型 | 低重心、短步切角、斜线进入、迅速脱离 | 被逼退后立刻侧移重新找线 | 侧后肩位或髋部高度贴身跟随 |
| 力量型 | 宽站距、直线推进、动作幅度大、压缩空间 | 接触后惯性明显，回收稍慢但持续压迫 | 命中后把镜头交给受击者，短震后跟随 |
| 精准型 | 动作紧凑、浪费少、优先拦截和换位 | 小幅卸力，迅速恢复稳定架势 | 稳定中近景，关键手部或眼线短推近 |
| 野路型 | 节奏不规则、突然加速、动作过度承诺 | 落空后身体带出较大惯性，需要重新找平衡 | 反应式手持，急停后才出现轻微晃动 |
| 防守反击型 | 先让出半步、保护中线、等待对方暴露路线 | 吸收压力后通过侧移或格开抢回主动 | 中景保持双方关系，逆转时短横移 |
| 控制型 | 主动缩短距离、持续保持接触、通过转向和高低变化争夺位置 | 控制失败后先释放半步再重新进入，不僵持等待 | 中景锁定双方共同重心，主动权转移时交接锚点 |
| 远程型 | 保持距离、释放后立刻换位、利用遮挡 | 遭逼近时先脱离再重新建立发射线 | 手部 -> 器物 -> 飞行路径 -> 目标交接 |
| 巨物/BOSS型 | 启动较慢、覆盖范围大、动作改变周围空间 | 每次动作都带动地面、尘土或大型道具回应 | 低机位随其上升或下压，保持小角色清晰 |

常用角色对比：

- `敏捷型 vs 力量型`：斜线切角对直线压迫；镜头在敏捷主角和受击者之间有动机地交接。
- `精准型 vs 野路型`：紧凑拦截对大幅冲撞；用稳定镜头与反应式手持形成节奏反差。
- `防守反击型 vs 多人围攻`：主角通过让线、遮挡和位置关系逐个处理最近威胁。
- `远程型 vs 近身追击者`：核心冲突是距离不断缩短与重新拉开，而不是站定互射。
- `小型敏捷角色 vs 巨物`：以地标保持尺度关系，用低机位升降展示压迫和逃脱路线。

角色描述必须进入最终提示词，并直接影响动作。不要只写“冷酷少女、暴躁少年”后仍给双方相同的步法、相同的攻击幅度和相同的受力反应。外观信息只能支持画面一致性；战斗能力若无明确证据，使用“动作机制上的对比选择”，不要宣称具体武术门派或真实专业水平。
