# 动作语言参考

按“镜头为什么要这样拍”选择词，而不是把术语连写。

## 机位、景别与构图

| 目的 | 可用表达 |
|---|---|
| 看清身体接触与细节 | 近景、中近景、从肩后贴近跟拍 |
| 保留双方距离与攻击轴 | 中景、全身双人镜头、侧向两人构图 |
| 建立速度与场景路线 | 广角全景、贴地低机位、沿街道纵深构图 |
| 建立重量和压迫 | 略低机位、低机位、虫视仰拍 |
| 建立规模或后果 | 高位俯视、超远全景、城市外侧远景 |
| 建立力量悬殊 | 防守者留在前景压框，攻击者置于远景/高空 |

## 摄影机运动与对应功能

| 目的 | 优先选择 | 用法 |
|---|---|---|
| 跟随前冲、奔跑、飞行 | 跟拍（Tracking / Chase Cam） | 沿主体主运动轴同行 |
| 跟随横向闪避或击飞 | 横移跟拍（Truck）或甩镜（Whip Pan） | Whip Pan 用于突然转向或受力飞出 |
| 强调接触前的威胁 | 短促推进（Push In） | 用在蓄力、即将命中或眼神确认 |
| 揭示空间、范围或后果 | 倒拉（Pull Out） | 用在冲击、法阵扩张、墙体倒塌之后 |
| 环绕人物或法阵 | 弧线环绕（Arc / Orbit） | 用于展示人物与周围空间的关系 |
| 跟随上升、坠落或高度改变 | 抬升/下降、仰拍上摇、向上追踪 | 与垂直运动同向 |
| 强调冲击 | 手持轻震、命中瞬间震动 | 不取代实际的身体或环境反馈 |

## 高动态镜头节奏设计

高动态不是持续高速跟拍，而是利用观看方式的连续反差。设计时同时改变其中一到两项：**距离、方位、高度、运动轴、速度、稳定度、画面主体**。每次变化都要由动作触发。

### 可复用的镜头接力

| 动作触发 | 镜头接力 | 产生的节拍 |
|---|---|---|
| 起跑或冲刺 | 贴地倒跟 → 侧向并行追拍 → 从人物肩后越过 | 速度由地面推入人物主观方向 |
| 拔剑/蓄力 | 高速跟拍突然压进剑柄或眼神特写 → 冻住极短一拍 → 剑光切出 | 高速中的瞬间压缩与爆发 |
| 空翻/旋身闪避 | 摄影机与身体同轴滚转 → 攻击擦身时突然稳定半拍 → 翻到攻击物背后继续追 | 观众先失重，再看清“差一点命中” |
| 击飞/撞墙 | 从施力者侧后方跟拳 → 沿飞行方向甩镜 → 贴着裂缝或碎石反向拉开 | 力量从身体传进环境，再释放规模 |
| 踏墙变向 | 跟在背后冲向墙面 → 踏点瞬间切到墙外侧俯视 → 人物从镜头下方斜穿而出 | 让改变方向本身成为镜头转折 |
| 高空俯冲 | 先从地面虫视仰拍锁住落点 → 随人物上升到俯视 → 在坠落时回到贴地追击 | 同一次动作里完成高度反转 |
| 召唤或法阵扩张 | 近景贴人物旋转 → 沿法阵纹路向外抽离 → 拉到超广景揭示覆盖范围 | 从人到空间的尺度爆发 |
| 巨型攻击落下 | 镜头先藏在防守者前景/武器后方 → 攻击临近时快速穿过扬尘或剑光 → 切到高空看冲击波外扩 | 威胁、遮挡、释放的三段式 |

### 节奏原则

- 不要连续重复同一种“追拍”。高速中应至少发生一次远近、上下、正反、稳定/失重或主体焦点的反转。
- 极短稳定、定格、静态凝视可以成为更快动作的反拍；它们不是降速，而是为下一次爆发蓄压。
- 可让摄影机暂时被剑光、碎石、墙体、尘埃或角色身体遮挡，再从遮挡另一侧接住下一节拍；这能形成有因果的激烈转场。
- 每个切镜都要能回答：它是为了看清起手、接触、受力、空间结果，还是对手的响应？答不上来就不要切。

## 双人对决接力

美型双人战斗的密度来自攻防权不断互换，不来自长时间的飘浮、转圈或单次对波。

```text
A 进攻 → B 用明确路径拆解 → B 立刻反击/抢位 → A 被迫回应 →
攻击命中、擦过或被转移 → 环境/衣袍/特效记录结果 → 下一轮攻防起点
```

例如广袖对决：

`A 的广袖横扫封住桥面 → B 下腰从袖底穿出，衣摆扫过水面 → B 反手缠住 A 手腕 → A 借缠力翻身踏上柱顶 → B 的第二道飘带追向柱顶 → A 甩袖切断飘带，碎光与花瓣被风压卷入瀑布。`

环境美术应成为交手路径：踏飞檐、借浮石变向、穿过水帘遮挡、用宫柱断开追击轴、让云雾与花瓣显示冲击波方向。

## 空间、交互与受力

### 空间方向

- 从画面左/右前景切入，沿对角线掠向远景
- 从高空斜向俯冲，落向街道中央
- 沿墙面/屋檐/塔楼外轮廓贴行
- 向右后方横飞、向后翻滚、贴地滑退
- 围绕目标顺时针/逆时针环绕，再垂直攀升

### 交互结果

- 贴身掠过但没有命中
- 擦过肩部，衣料被能量掀起
- 正面命中胸口/腹部/地面落点
- 攻击撞在屏障上，被吸收、偏转或反弹
- 冲击波先抵达，主体被掀离地面
- 两股能量在指定汇聚点正面碰撞

### 受力反馈

- 身体向内压缩、上身猛折、肩部后甩
- 双脚离地，沿拳力方向横飞
- 落地翻滚，鞋底拖出碎石和火花
- 地面以落点为中心开裂，裂缝呈放射状向外传播
- 墙体从撞点开始龟裂、凹陷、炸碎
- 碎石沿受力方向喷出，尘土被冲击波卷起

## 粒子与魔法特效

粒子必须附着于动作并说明功能：

- 沿肢体旋转轨迹拖尾：解释速度和转身
- 从命中点向外撕裂逸散：解释受力或能量泄露
- 沿建筑轮廓螺旋上升：解释追逐路线和高度
- 向中心收束，再扩散成法阵/屏障：解释形成过程
- 径向爆散，形成环形冲击波：解释碰撞结果
- 在本体周围依次凝聚成分身：解释能力归属与阵列结构

## 推荐强度梯度

用可见尺度递增，不要只增加形容词：

`近身威胁 → 闪避或命中 → 街道/屋顶追逐 → 塔楼或高空的垂直升级 → 召唤/屏障 → 城市级后果`

一个段落应只兑现一个核心结果。例如：

- 闪开攻击
- 粒子化脱离
- 到达塔顶
- 重型落地
- 魔法阵展开完成
- 屏障接住攻击
- 冲击波波及城市
