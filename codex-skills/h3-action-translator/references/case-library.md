# H3 高动态战斗结构案例库

本库记录已获用户授权的案例所提炼出的**结构原则**，供 `h3-action-translator` 在新生成任务中随机抽取。它不是完整提示词库；当前任务的人物、场景、能力、胜负和时长始终优先。

## 使用规则

1. 先以题材、战斗距离、角色关系、可用场景锚点和镜头目标筛选。
2. 随机选一张主卡，必要时再选一张辅助卡；不要把多张卡的全部招式生硬拼在一起。
3. 只借用“结构原则”和“可迁移手法”；替换为当前任务的角色、能力、空间与物理后果。
4. 每次抽取后，仍需遵守动作、镜头、环境三条并行接力，以及双方攻防权交换。

## 奇幻与仙侠

### C01. 粒子追逐、塔楼上升与城市级终爆

- 适用：双色或多色能量对决、魔法追逐、古城/大型建筑场景、从单体战斗升级到场景级爆发。
- 战术结构：高速投射物贴身威胁 → 闪避者粒子化脱离 → 两股能量流追逐并争夺路径 → 借最高建筑垂直上升 → 高点正面碰撞 → 余波覆盖城市。
- 镜头节奏：低机位临界擦身 → 追逐横移 → 环绕建筑的向上跟随 → 高空反转视角 → 冲击波吞镜后超广景释放。
- 环境递进：衣摆/碎石/小型建筑受风压 → 沿途建筑被撞碎 → 塔身震动与空气扭曲 → 城市尺度尘云与冲击波。
- 可迁移手法：用“沿建筑轮廓攀升”替代空泛飞行；让粒子流的路线承担战术追逐。

### C02. 高速剑修的分段爆发与镜头反差

- 适用：单人对多人、剑术或冷兵器高速度场面、需要强烈起势和连续战术升级的短片。
- 战术结构：站立蓄势 → 地面爆裂起跑 → 瞬间拔刃建立杀意 → 贴地连续斩击 → 升空转为俯击/范围压制 → 近景发现威胁并变向突刺 → 落地后以强姿态留下下一段钩子。
- 镜头节奏：极低机位高速推进 → 刀锋或关键接触短暂压缩/定格 → 跟拍加速 → 高低机位反转 → 360度环绕中插入面部近景 → 冲击后快速后拉恢复空间尺度。
- 环境递进：起跑先令地面开裂 → 刀光割碎护甲或障碍 → 范围攻击引发连续地爆 → 最终落地产生尘土和碎石环。
- 可迁移手法：镜头不一直“快”，而是在最危险的接触点短促压缩，再立刻放大速度反差。

### C03. 广袖、飘带与衣袍作为武器的双人对决

- 适用：仙侠、舞蹈性武打、长衣袍/长袖/飘带为核心动作道具、优美空间中的高密度双人战。
- 战术结构：一方广袖封锁路径 → 另一方从袖底、袖侧或衣摆遮挡中拆解 → 反手缠腕、抢高度或抢侧后方 → 原攻击者借缠力/场景支点再反攻 → 双袖或掌力正面受力后被反冲送入下一段。
- 镜头节奏：云海或建筑俯冲建立尺度 → 压进衣袖边缘近景 → 被衣摆完整遮住后改变视点 → 水帘/飞檐后方窥视贴身攻防 → 塔楼垂直跟随 → 冲击波外侧倒拉。
- 环境递进：花瓣、铃铛、水雾先受风压 → 桥栏、浮石成为借力与变向点 → 瀑布受冲击弯折 → 塔楼和云海承受大范围余波。
- 可迁移手法：衣袍必须承担攻击、遮挡、缠绕、转向或受力，不能只在背景飘动。

### C04. 不对称近战与远程领域的空间争夺

- 适用：一方擅长贴身压制，另一方依靠重武器、远程能力或范围攻击维持距离的奇幻战斗。
- 战术结构：近战方强行贴近并以短连击压缩空间 → 远程方用大范围攻击打开距离 → 近战方以佯攻、低位切入或翻滚穿越封锁 → 远程方以垂直/横向大招重置战场 → 双方在最大招式处正面相撞 → 同时被余波推出不同方位。
- 镜头节奏：低机位强调近战威胁 → 环绕镜头展示距离争夺 → 仰拍远程大招的高度与范围 → 极近景确认双方表情与身份 → 最终后拉呈现左右分置的对峙。
- 环境递进：起步碎石与兵器火花 → 水面、地面或建筑承接范围攻击 → 冲击波留下爪痕、滑痕和残余能量。
- 可迁移手法：能力不是展示轮次，而是各自争夺“应该站在多远”的工具。

## 写实近身

### C05. 狭窄饭店中的桌椅、玻璃与惯性连锁

- 适用：写实市井格斗、餐馆/酒吧/室内公共空间、重体型角色、需要拳拳到肉与场景破坏的短片。
- 战术结构：即时道具起手或环境阻断 → 对手硬抗并以擒抱/投掷反抢 → 身体撞穿桌椅但通过翻滚或支点卸力 → 一方借断裂物或地面高度差攻击下盘 → 失衡者仍抓住对手拖入缠抱 → 两人的合力撞向玻璃或出口，留下未决胜负。
- 镜头节奏：从桌椅缝隙贴地推进 → 接触时手持震动并压进近景 → 随抛摔绕过桌面 → 从断桌/桌布/飞溅物后重新找到主体 → 近身缠抱时被迫压缩 → 玻璃爆裂后高速倒拉到外部空间。
- 环境递进：酒水、碗碟、椅子先被撞开 → 木桌从受力点开裂坍塌 → 碎片、汤汁和家具改变脚步路径 → 玻璃隔断从局部裂纹发展到整体破裂，室内外空间被打通。
- 可迁移手法：每一个环境破坏都必须成为下一步的障碍、掩护、支点或滑行路径，不能只作爆点装饰。

## 通用阶段结构

### C06. 开始、升级、高潮、结束的五段推进

- 适用：10–25秒的任何双人或多人动作短片，需要完整而非平铺的情绪曲线。
- 时间职能：开场建立双方能力与第一次接触 → 升级一展示各自常规压制法 → 升级二以更强反制改变战术位置 → 高潮让前面已建立的能力最大化正碰 → 结束以余波、位置和残余姿态收束。
- 三线要求：每一阶段都同时规定本段战术结果、由动作触发的镜头变化、由受力触发的环境变化；每段的出口必须成为下一段的起点。
- 可迁移手法：高潮不是额外塞进一个新技能，而是把前面反复建立的两种核心力量推到最大后相撞。
