# 视频反推参考

## 目标

把参考视频拆成能复用的动作与镜头结构，而不是把原片写成感想。高动态视频的重点是识别：同一大动作下有多少连续微节拍、它们如何接力、镜头怎样伴随或反转观看方式。

## 拆解顺序

### 1. 全局风格堆栈

从直接可见内容记录：

- 世界/类型与场景空间
- 影像质感、色彩、主光与天气
- 角色外观、服装、武器和动作气质
- 特效语言与物理反馈
- 剪辑密度、摄影机语言与声音

区分可见事实与推测。看不清的内容标为“未确认”，不要补写精确设定。

### 2. 时间码与镜头层级

先标出真正的切镜；每个镜头再记录段内微节拍。每段使用：

```text
时间：
大动作结果：
关键状态接力：
镜头/视点接力：
接触与受力：
环境反馈：
画面出口：
```

高动态片段不要仅标“快速打斗”。例如应写：

`起跑 → 拔剑 → 镜头压入剑刃 → 转身闪开 → 剑光擦身 → 甩镜接住受击者 → 碎石遮挡转场`。

### 3. 过渡桥

每一关键状态之间记录：

```text
状态 A → 状态 B
触发：
主体路径：
摄影机配合：
环境与特效：
结束条件：
```

高动态桥可包含多个连续微节拍，但必须仍属于同一动作结果；不要把无关剧情拼在一条桥里。

### 4. 连续标记

跨镜头核对五项：

- 人物：脸、服装、姿态、伤势
- 道具：武器、长袖、披风、关键物体的位置和状态
- 方向：人物、攻击物和摄影机的运动轴
- 光线：主光方向、色温、昼夜/特效光源
- 情绪：压迫、冷静、愤怒、爆发或疲惫的连续性

## 输出给用户

默认依次输出：

1. 一句话视频骨架
2. 全局风格堆栈
3. 按时间码的镜头与微节拍表
4. 关键过渡桥与连续标记
5. 可复用规律：动作密度、镜头节奏、特效/环境功能
6. 若用户要求改写：替换映射与新的 H3 时间轴提示词

## 视频到新提示词的转换

明确分成两列：

| 保留 | 替换 |
|---|---|
| 动作接力、时间结构、运镜节奏、构图或环境互动 | 人物、服装、武器、场景、能力、色彩、剧情 |

改写后仍必须保持源视频中每个动作出口能推动下一段；不要只保留主题词而丢掉高动态镜头结构。
