# H3 Action Translator

## 目标

把用户脑中的动作，变成模型和观众都能读懂的镜头内因果链。不要把镜头术语、华丽形容词或粒子特效当成动作本身。

动作的最低完成单位是：

`机位与构图 → 发动者动作与方向 → 响应者动作与方向 → 接触/落空/格挡结果 → 受力或粒子反馈 → 环境后果 → 摄影机响应/下一段衔接`

每个时间轴段必须把这条链写完整；若该段没有接触，必须明确写“未命中、擦身而过、被闪开、尚未接触”之一。用户只给出概念时，作出最少且合理的空间补全，并在“采用的动作假设”中列出；不要停下来索要摄影术语。

## 时间轴的三条并行接力

高动态时间轴不是只记录“角色做了什么”。每一段都必须同时推进三条彼此因果关联的变化线：

`动作线：谁取得或失去什么战术位置 → 镜头线：摄影机为何改变距离、方位、高度、速度或稳定度 → 环境线：该次力量怎样使地面、建筑、空气、水、碎屑、光线或道具发生可见变化`

例如：`贴身斩击被巨剑格住 → 镜头被兵器冲击震退并切入低机位 → 碎石从脚下受力点炸开，烟尘遮住画面后带入下一轮追击`。环境不必每段都出现无缘由的大爆炸；但在高动态战斗中，必须留下与当次动作相符、且可延续到后段的扰动、破坏或受力痕迹。开场可用风压、碎石、河面波纹等较小反应建立力量，升级后再让地面、建筑、河流或空间承受更大后果。

在时间轴之前，必须先写一段**整体纲领（summary）**。它是全片的总约束：用一段简洁的自然语言锁定时长、冲突双方、事件的升级路径、最终结果，以及统一的视觉/物理基调。它回答“这支片从哪里开始、会升级成什么、最终落在哪里”，但不替代镜头执行。后续每个时间轴段都必须兑现纲领中承诺的事件；纲领不得塞入时间轴中没有执行的额外能力或剧情。

整体风格也必须按独立维度拆解后再写入纲领，而不是把它们误算成多个互斥“风格”。至少区分：世界/类型气质、影像质感、色彩与光线、摄影机语言、物理运动反馈、特效语言；分辨率、HDR 等属于画面规格，不等于一种美术风格。只保留用户指定或任务真正需要的维度。

## 高动态提示词的强制创作链

生成高动态战斗提示词时，必须依次完成以下六层；不得只写其中任意一层就交付：

1. **风格堆栈**：拆清世界/类型、影像质感、色光、动作气质、摄影机语言、物理反馈、特效语言和画面规格。
2. **时间地图**：先分配每段时长，分别写明该段的动作结果、镜头变化、环境结果、动态密度与画面出口。
3. **整体纲领**：由时间地图反推成全片的开场威胁、升级路径、高潮结果和统一风格约束。
4. **动作接力**：每个时间段把一个大动作拆成连续关键状态；方向、接触关系、受力和环境后果必须在链内兑现。
5. **运镜与环境接力**：为同一条动作链单独设计视点、距离、高度、速度、稳定度和切镜节奏，并设计环境从微小扰动到场景级后果的受力递进；运镜必须制造速度与反差，不能只作记录。
6. **整合输出**：完整提示词中的每个时间段都同时包含动作接力与运镜接力，并以前一段的动作出口驱动下一段。

高动态模式默认追求高密度、强节拍、连续接力与不寻常但有动机的镜头变化；不得为了“保险”自动简化、降载或把镜头调度写成单调跟拍。

用户说“测试”而没有给出时长时，默认制作 **10 秒**高动态版本；用户明确指定其他时长时，以指定时长为准。

## 结构案例库抽取

生成新的高动态战斗提示词前，读取[结构案例库](references/case-library.md)。先按用户当前题材、角色关系、战斗距离、场景可破坏物和预期镜头气质筛选匹配案例；若有多个匹配项，随机抽取一个作为主参考，最多再抽取一个作为辅助参考，以避免每次使用同一节奏。

只迁移案例卡中标明的**结构原则**：战术对抗关系、阶段递进、动作/镜头/环境三线接力、特定的镜头节奏或环境升级方式。不得复制原案例的人物外观、世界观、专属能力、专属场景、完整句子或胜负结果；用户当前的锁定事实永远优先。案例库用于生成，不用于用户只要求翻译、诊断或逐段分析的任务；用户提供参考视频时，优先做视频反推，不以随机案例替代可见事实。

## 双方对决的咬合密度

两名或多名角色对决时，不能把“同时升空、绕圈、飘带交错、一次碰撞后分开”当作完整战斗。每个时间段都要标明当前主动攻击者与响应者，并形成至少一条可读的对抗接力：

`主动攻击 → 对方闪避/拆解/格挡 → 立即反击或抢占位置 → 原攻击者再响应 → 可见的命中、落空、受力或环境后果 → 下一段出口`

高动态段可以在一条大动作内连续交换多次攻防权。衣袍、广袖、飘带、武器或发丝必须参与攻击、遮挡、转向或受力，不能只作为漂亮的背景动画。美丽场景也必须被动作穿过、借力、扰动或作为构图尺度，而不是占用战斗时间的静态展示。

## 参考视频反推模式

当用户提供或指向参考视频时，先做可见画面的反推拆解，再写新的 H3 提示词。不得只用“国风、很快、电影感”等印象词概括视频，也不得把不清楚的动作、镜头或能力伪装成事实。

1. 先区分用户要保留的内容（动作节奏、机位、运镜、构图、角色、场景、声音之一或多个）和要替换的内容。
2. 按真实切镜和时间码建立时间地图；每个镜头继续细分为关键状态、动作微节拍、镜头/视点接力和画面出口。
3. 对每个相邻状态写出触发、主体路径、摄影机配合、环境反馈和下一状态可见的结束条件。
4. 维护连续标记：主体外观/姿态、关键道具或衣袍、运动方向、主光关系、情绪或战斗强度。跨镜头时明确哪些保持、哪些变化。
5. 先输出“视频反推拆解”，随后才输出按用户替换要求改写的高动态 H3 时间轴；若用户只要求分析，则不擅自生成新剧情。

视频反推时读取 [视频反推参考](references/video-reverse.md)。

## 大纲与半成品扩写模式

用户可以提供一句概念、整体大纲、分段剧情、零散镜头笔记，或已经写到一半的提示词。无论输入细度如何，都要用本技能补齐缺失的层，而不是只复述用户原文。

### 事实优先级

- 用户已经写明的人物、能力、武器、场景、胜负、命中关系、时间点和镜头结果是**锁定事实**，不得擅自改写。
- 用户没有写明的动作桥、空间方向、机位、运镜节奏、受力、环境反馈、特效路径、画面出口和风格细节是**待补空位**，应主动补齐。
- 如补全必须引入会改变故事走向的重大内容，列为“采用的动作假设”；一般的镜头与空间补全直接完成，不因缺少摄影术语而停下。

### 扩写方法

1. **概念/大纲输入**：从整体纲领、风格堆栈和时间地图开始，再把每个事件扩写成动作接力与运镜接力。
2. **分段大纲输入**：保留用户的段落顺序和每段结果；为每段补充微节拍、接触关系、物理后果、镜头节奏与段落出口。
3. **部分镜头或半成品提示词输入**：逐句保留已有的明确设定；只在相邻句子之间补过渡桥、空间连续性和可拍摄细节。除非用户要求重写，不删除或替换已有核心动作。

输出时可先用“锁定事实 / 本次补全”两行简要说明边界，然后交付完整时间轴。

## 硬原则

1. **先把抽象词翻译成可拍摄结果。** “震撼、压迫、激烈、很快、很重、优雅”不能单独承担动作信息。必须改成可见的路径、姿态、距离变化、物理结果或环境反应。
2. **所有关键动作都有空间方向。** 写清从哪里到哪里、朝向、相对位置或沿何物运动，例如“从画面右后方斜向俯冲”“沿塔楼外轮廓螺旋上升”“向右后方横飞”。
3. **动作、受力、环境必须因果连续。** 命中不是结尾：要写身体如何变形/移动，或屏障如何承受；再写墙体、地面、碎石、尘土、空气或光线如何响应。没有接触则不要凭空加入爆炸。
4. **摄影机必须响应动作目的。** 高动态段可以在同一时间段内包含多个机位、运镜和明确切点；但每个微节拍的摄影机变化都要服务刚发生或即将发生的动作结果。允许 Orbit、Whip Pan、Tracking、Push In 的连续接力，不堆砌与动作无关的炫技运动。
5. **一个大动作由关键状态连续接力。** 每 1–2 秒可设定一个主要战术结果：闪开、命中、变形、到达、召唤完成、格挡或爆发；该结果内部要由连续的微节拍构成，例如“起手/蓄势 → 发动 → 临界接触 → 对方响应 → 结果 → 动作出口”。高动态模式要主动提高微节拍、视点和镜头变化密度；不因“信息过多”而自动删减。微节拍不是无关动作或无意义切镜，后一节拍必须由前一节拍推出。
6. **镜头连续性如实写。** 只有空间、主体、时间和摄影机运动连续时，才能写“一镜到底”。有切镜时明确切点、下一镜景别及主体位置；可用粒子、尘埃或冲击波吞没画面作为自然转场，但不能把切镜误称一镜到底。
7. **保持能力与结果归属。** 不擅自增加用户未给的武器、怪兽、伤害结果或角色能力；攻击者、闪避者、分身/法术所属必须始终一致。
8. **先有纲领，再有分镜。** 纲领负责全片递进与高潮，时间轴负责把它变成可观察的镜头动作。若写“连续”，默认指连续推进的事件链；只有全程不切镜且摄影机运动、空间和主体都连续时，才能明确写“一镜到底”。
9. **运镜调度是独立的高动态创作层。** 除了设计角色的关键状态接力，还要为每一段设计镜头的距离、方位、高度、速度与切换节奏。主动创造“追逐 → 压缩细节 → 突然失重/反向 → 冲击后的空间释放”等反差，而非每段都用正面跟拍。每一次反常的镜头变化必须由拔剑、变向、擦身、受力、撞击、落地、法阵扩张等事件触发。

## 工作流程

1. 从用户输入提取：人物/能力、场景锚点、动作意图、胜负或命中关系、时长、参考素材和不可改变的设定；同时把整体风格拆为世界/类型、影像质感、色彩/光线、摄影机语言、物理反馈、特效语言与画面规格。若是测试且未指定时长，设为10秒。
2. 先规划时间地图：将总时长分给递增的动作阶段，并为每段标记“主要战术结果、段内关键状态接力、镜头/视点接力、环境受力与破坏结果、镜头节奏对比、最后的画面出口”。时长不是平均切分；它要匹配该段容纳的状态数量、预期动态密度和结果的冲击力。高动态任务优先让同一大动作连续接力多个状态与镜头，并让镜头本身形成追逐、压缩、失重、反转与释放的节奏；环境应从开场的微小受力反应，随战斗升级为可读的空间改变。各段之间不得重叠或留白。
3. 根据时间地图写整体纲领：概括开场威胁、每次尺度或局势升级、最终冲突结果、统一画面基调。它应足够短，不能挤占时间轴的具体动作信息。
4. 对每一段先产出“动作翻译卡”，再写成自然语言镜头。卡片字段固定为：
   - 时间与本段动作结论
   - 段内关键状态接力：按顺序列出多个彼此因果相连的微节拍；高动态任务不设上限
   - 段内镜头/视点接力：写清每一微节拍是延续同一镜头、转换运镜，还是明确切镜
   - 段内环境状态接力：写清哪次动作造成何种扰动、破坏或受力痕迹；哪些碎片、裂缝、烟尘、水流、道具或光线状态必须延续到下一段
   - 镜头节奏：本段如何在远近、上下、正反、快慢、稳定/失重之间形成反差，以及每次变化的动作触发点
   - 机位、景别、构图与主体相对位置
   - 摄影机主运动及其目的
   - 发动者：起手、身体动力、路径与速度
   - 响应者：闪避、格挡、受击或反击的路径
   - 交互结果：命中/擦过/格挡/未接触
   - 特效：附着在何处、沿何路径变化、承担什么叙事功能
   - 物理与环境反馈：从哪个受力点开始，向哪里扩散
   - 出口：画面以什么动作、方向或遮挡衔接下一段
5. 再交付一段可直接粘贴的 H3 提示词：整体纲领置于时间轴之前；时间轴逐段把关键状态接力写成连贯镜头语言，即景别/主体位置 → 动作推进 → 运镜 → 接触结果 → 反馈 → 出口；需要切镜时写明“切至”。

## 输出格式

默认输出顺序如下：

1. **整体纲领**：先交代全片的冲突、递进、高潮和视觉/物理总基调。
2. **动作意图与采用的动作假设**：只列用户未提供、但为完成空间化所作的最少补全。
3. **逐时间轴动作翻译卡**：每个时间段都标注一个主要战术结果，以及该结果内部的关键状态接力。不得跳过接触关系、受力反馈或镜头出口。
4. **可直接粘贴的 H3 完整提示词**：中文，先放整体纲领，再以时间轴组织；不需要把每个英文术语保留，优先中文可拍摄描述。若有台词，标明说话者和声音呈现方式。
5. **执行备注**：默认不对高动态密度作降载建议；仅在用户明确要求稳定、简化或排查生成问题时，才讨论精确人数、同秒形态变化或镜头冲突等执行风险。

当交付完整 H3 提示词时，在最后一个时间轴描述后，另起两行原样追加：

`画面中不出现任何可读文字：无字幕、无台词字幕、无文字叠层、无 UI、无标签、无 Logo、无水印、无片尾文字。所有对白仅以角色口述声音呈现，画面不显示台词文字。`

`全片不准出现字幕。`

## 术语使用

先按动作功能选镜头，再决定是否写英文术语。高动态任务还必须设计不寻常但有动作动机的镜头变化节奏。需要扩充运镜、空间、交互、受力、环境反馈和镜头节奏时，读取 [动作语言参考](references/action-language.md)。

## 质量检查

交付前逐段核对：

- 删掉所有镜头术语后，动作因果仍然成立吗？
- 整体纲领是否清楚交代开场、升级路径与最终结果，且每一项都能在时间轴找到兑现？
- 每一段是否同时推进了动作、镜头与环境三条变化线，并使镜头变化与环境结果由刚发生的动作触发？
- 风格描述是否分清了世界/类型、质感、色光、摄影机、物理、特效与规格，而没有把无关或互相冲突的标签堆在一起？
- 每一时间段是否只有一个大动作结果，但内部有连续的关键状态接力，而不是多个无关动作的堆叠？
- 双方对决中，是否持续发生主动攻击、拆解/闪避、反击或抢位的攻防权交换，而不是只让人物优雅飞行或一次碰撞后分开？
- 衣袍、广袖、飘带、武器与美丽环境是否实际参与了攻击、遮挡、路径、受力或构图，而不是停留为装饰？
- 高动态段的运镜是否具有独立节奏和明确动作触发点，而非重复同一种跟拍或随机炫技？
- 是否写清了攻击/闪避/受击的方向，以及双方的相对位置？
- 是否明确了命中、未命中或格挡？
- 特效是否解释运动、能力或冲击，而非漂浮装饰？
- 环境破坏是否有清楚的受力来源和扩散方向？
- 环境状态是否跨段延续并随战斗升级，而不是每段重新出现完好的场景或无缘由的爆炸？
- 镜头运动是否只服务本段最重要的动作结果？

若任一答案为否，先改写该时间段，而不是靠增加“电影感、史诗、震撼”等词掩盖问题。

- 用途说明：将用户的战斗、追逐、撞击或魔法动作想法翻译为可执行的 MiniMax H3 时间轴分镜与提示词。适用于需要明确机位、运镜、空间方向、接触关系、受力反馈和环境后果的动作视频；不用于只需静态画面或泛泛创意讨论的任务。
