# 项目初始化契约

## 交付边界

| 系统 | 负责人初始化的内容 | 长期事实源 |
| --- | --- | --- |
| Git | 规则、剧本、分镜、提示词、清单、岗位技能、模板与版本记录 | 文本与规则 |
| 飞书 | 任务、审核、问题、变更、每日推进和成员岗位 | 动态状态 |
| 个人百度网盘 | 每位成员的 API 交付中转目录 | 待审核媒体 |
| 百度网盘团队空间 | 审核后公共资产、可剪辑素材、工程、审片版、成片 | 正式大媒体 |

## Git 授权与提交门禁

- Git 授权只针对**当前项目仓库**：成员用自己的 GitHub／Git 账号克隆、拉取和推送，不共享负责人账号、访问令牌或 SSH 私钥，也不获得其他仓库权限。
- 项目负责人保留仓库管理和受保护 `main` 的合并权限；制作成员获得当前仓库所需的读取与任务分支写入权限；仅查看者只读。需要更细的 Read／Write／Maintain／Admin 分级时，优先将项目放在 GitHub Organization 中管理。
- 成员领取任务后，在 `member/<成员标识>/<任务编号>` 分支提交本岗位文本；提交信息带岗位、范围与版本。完成后推送该分支并创建合并请求，负责人或指定审核人通过后合并 `main`。
- 对 `main` 启用仓库规则或分支保护：要求合并请求审核、阻止直接推送、阻止强制推送与删除。规则应允许负责人在紧急情况下按项目约定处理，而不是让所有成员拥有绕过权限。
- 可推送的只有规则、剧本、分镜、提示词、清单、审核记录和轻量文档。图片、音频、视频、剪辑工程和凭据由 `.gitignore` 排除；发现误提交立即停止后续交付并由负责人处理，不以覆盖提交掩盖敏感内容。

## 飞书初始化清单

建立以下六张关联表：

1. **项目／集数**：项目、集数、阶段、总负责人、当前版本。
2. **任务**：任务编号、范围、岗位、负责人、审核人、归档管理员、输入 Git 文件与版本、媒体输入、个人盘交付目录、个人盘输出链接、团队归档目标／链接、归档状态、Git 输出提交、状态、问题／变更、修改摘要。
3. **资产**：资产编号、类型、版本、用途、来源、团队空间链接、审核状态、关联任务。
4. **问题与变更**：类型、依据版本、证据、影响范围、返工成本、方案、决策人、结论、关联任务。
5. **版本索引**：交付物、Git 路径、版本、状态、批准人、关联任务。
6. **成员与岗位**：成员、允许岗位（多选）、当前状态、飞书身份、交付根目录。

任务状态固定为：`待排期 → 待输入 → 可执行 → 制作中 → 待审核 → 已确认`；例外状态为 `阻塞`、`需复核`、`已失效`。为每个启用岗位建立“我的可执行任务”视图：岗位匹配、负责人为该成员或未分配、状态为“可执行”。

## 网盘目录与流转

成员个人盘中的任务目录采用：

```text
/《项目名》_个人交付中转/<成员>/<任务编号>/
```

团队空间中的正式归档目录采用：

```text
《项目名》/
  02_角色场景道具资产/
  03_音频与配音/
  05_视频候选/
  06_已审核可剪辑素材/
  07_剪辑工程与代理文件/
  08_审片版/
  09_正式成片/
  99_历史归档/
```

成员的官方 MCP 仅上传个人盘绝对路径。审核通过后，归档管理员导入团队空间、比对文件名／大小／版本／用途、填写团队空间链接，再将任务确认。候选视频在审核确认前不得进入 `06_已审核可剪辑素材/`。

## 个人岗位接入 Markdown

实际文件存放在项目仓库外的受控目录，或在仓库的已忽略目录中；绝不包含飞书 App Secret、管理员令牌或其他成员的个人凭据。

```markdown
# 《项目名》｜<成员姓名> 岗位接入

- 项目 Git 地址：<Git URL>
- 飞书显示名：<成员姓名>
- 允许岗位：<岗位 A>、<岗位 B>
- 个人盘交付根目录：/<项目名>_个人交付中转/<成员姓名>/
- 团队空间权限：读取已归档资产／按任务下载

## 交给 Codex 的指令

加入 <项目名> 项目：<Git URL>。我的姓名是 <成员姓名>，允许岗位是 <岗位列表>。
飞书和个人网盘连接信息已通过接入包提供。请按 README 与
skills/project-onboarding/SKILL.md 初始化；只领取本人且岗位匹配的“可执行”任务。
我承担多个岗位时，分别读取对应 roles 与 skills，但每张任务只按其责任岗位执行。
```

凭据另行通过受控渠道提供：个人受限飞书令牌、项目多维表格标识、该成员自己的百度网盘 Access Token。成员的 Codex 应将它们保存到被 Git 忽略的本地连接文件中。
