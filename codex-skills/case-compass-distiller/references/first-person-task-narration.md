# 第一人称闯关式任务旁白

仅在用户要求第一人称探店、体验、县城日常或“边行动边吐槽”的任务型 Vlog 时使用。本参考来自一个已分析样本的抽象观察，不代表通用公式。

## 叙述机制

1. 先抛出具体、可检查的任务或有限资源，再马上进入行动。
2. 用第一人称即时判断人物、场景和下一步，但把判断写成主观、可被推翻的现场反应。
3. 将现场对话与镜头外旁白分层：现场负责把事情办下去，旁白负责自嘲、误判、庆幸或给观众补充风险。
4. 每遇到收费、拒绝、流程或尴尬，先承认卡点，再给出合法、尊重对方的替代方案；不要诱导虚假身份、欺骗或占便宜。
5. 用“目标 → 接触 → 阻碍 → 调整 → 小进展 → 下一关”的小循环推进，结尾保留结果或下一步。

## 语言与节奏

- 以短句为主，动作或对话后补一句 8–20 字的反应旁白。
- 旁白保持“嘴硬但知道自己在冒险”的自嘲：夸大自己的勇气，再立即承认准备不足或风险。
- 包袱来自自我反转、现场误判和预期落差，不嘲笑普通人、服务人员或具体群体。
- 让观众比现场人物多知道一点主角的临场盘算，但不把旁白写成全知解释。

## 可替换骨架

```text
今天的任务是【具体目标】；我手里只有【真实资源/限制】。
这位【人物/店主】看起来【主观观察】，我先试着问一句。
现场对话：提出清楚、尊重边界的请求。
旁白：坏了，遇到【阻碍】；我原本以为【预期】，现在得换个办法。
现场对话：给出对双方都有价值的替代方案。
旁白：这一步虽然不算赢，但至少没有白来。下一关是【下一行动】。
```

## 自检

- 任务、资源和交换条件是否真实清楚？
- 旁白是否服务于行动推进，而不是每句都硬抖包袱？
- 是否避免模仿来源的具体措辞、身份、事件和独特比喻？
- 是否避免把“大胆”写成欺骗、施压或占他人便宜？
