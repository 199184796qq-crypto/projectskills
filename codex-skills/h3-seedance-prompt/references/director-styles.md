# 导演风格库（影调/美术风格速查）

来源：`I:\BaiduSyncdisk\ClaudeProject\StoryboardArtist\.claude\skills\storyboard-designer\references\director-styles\`（分镜设计skill的美术指导知识库）。24位导演一人一档，`director-styles/<导演名>.md`，内容直接搬运未改动（美术风格描述是通用的，不需要针对H3/Seedance重写）。

**用途**：回答"影调"类问题——某个导演的色调/摄影介质/光线/镜头节奏具体是什么，以及怎么把这套风格注入H3/Seedance 2.5的提示词。这是`cinematography-guide.md`（管镜头设计判断）之外的第三层知识：**风格/影调层**——同样的镜头设计，套上不同导演的影调会长得完全不一样。

## 怎么用

1. 用户点名导演风格（"王家卫风格"）或某个玩法模板需要一个默认美术基调时，先查下面的**风格速查表**定位，再读`director-styles/<导演名>.md`拿完整方案。
2. 每个导演档案的**美术方案**五项——时代与地域/摄影介质/色彩基调/光线偏好/全局风格Tags(英文)/排除词——直接改写成H3的"核心创意"里的题材/风格描述，或Seedance的"一句话概述"里的风格描述，**排除词**改写成"不想要"/负向控制那一段。
3. 没有人物/场景参考图、纯靠风格描述撑画面时（H3的"纯文字生成"模式），这套风格档案尤其有用——案例库里的具体風格词比自己现场编靠谱。

## 自动匹配原则（用户没点名导演时，按题材/情感/视觉自动挑）

**题材类型**：青春成长→岩井俊二/侯孝贤/今敏；黑帮警匪→杜琪峰/昆汀/北野武；武侠动作→胡金铨/张艺谋；喜剧→伍迪·艾伦/昆汀；科幻→诺兰/维伦纽瓦/库布里克；悬疑惊悚→希区柯克/大卫·芬奇。

**情感基调**：浪漫唯美→王家卫/宫崎骏/蒂姆·伯顿；现实主义→贾樟柯/杨德昌/侯孝贤；黑暗阴郁→大卫·芬奇/塔可夫斯基；明快温暖→宫崎骏/北野武。

**视觉风格**：对称美学→韦斯·安德森；胶片质感→王家卫/库布里克；水彩手绘→宫崎骏/今敏；哥特暗黑→蒂姆·伯顿。

**跟我们5个玩法模板的对应关系（可选默认风格，用户没指定时可以参考）**：
- 时尚模特"高级/冷感/极简"风格 → 可参考库布里克/丹尼斯·维伦纽瓦的极简冷峻
- 时尚模特"复古/胶片"风格 → 可参考王家卫/库布里克的胶片质感
- 穿越Vlog去中世纪欧洲/武侠世界 → 胡金铨的水墨武侠美学（如果是东方古代背景）
- 换装"赛博朋克/未来反光"风格 → 可参考诺兰的冷蓝/灰/橙或吕克·贝松的高饱和冷暖对比

## 单个导演档案里有什么（示例：王家卫）

```
基本信息：国籍/出生/代表作
风格特点：几条最核心的视觉/叙事特征
美术方案：
  - 时代与地域
  - 摄影介质（比如"柯达Vision3 500T 35mm胶片"——这个可以直接写进H3/Seedance的画面描述里）
  - 色彩基调（比如"温暖昏黄"）
  - 光线偏好（比如"黄金时光、霓虹灯、室内暖光"）
  - 全局风格Tags（英文，可以整段附在提示词结尾，H3/Seedance都认得混合中英文的提示词）
  - 排除词（负向控制，对应H3的"不想要"或Seedance的负向描述）
适用场景：几个关键词
```
