# 希区柯克 (Alfred Hitchcock)


**基本信息**
- 国籍：英国/美国
- 出生：1899年8月13日（卒于1980年4月29日）
- 代表作：《惊魂记》《后窗》《迷魂记》《群鸟》《蝴蝶梦》

**风格特点**
- 被誉为悬疑大师
- 经典的希区柯克式变焦
- 创造"麦格芬"概念
- 开创心理惊悚类型
- 经典的金发女郎形象
- 偷窥和窥视主题
- 精妙的蒙太奇剪辑
- 每部影片都客串

**美术方案**
- **时代与地域**：当代都市/经典时期
- **摄影介质**：35mm胶片，经典质感
- **色彩基调**：高对比度，黑白/彩色
- **光线偏好**：戏剧性光线、阴影、夜景
- **全局风格Tags**：suspense thriller, voyeuristic theme, Hitchcock zoom, psychological tension, classic cinema, visual storytelling, blonde protagonist, urban mystery
- **排除词**：fast-paced, action-oriented, warm, cheerful, romantic, naturalistic

**适用场景**
- 悬疑惊悚
- 心理紧张
- 偷窥主题
- 经典悬疑
