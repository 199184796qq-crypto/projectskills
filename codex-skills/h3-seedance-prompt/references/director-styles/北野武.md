# 北野武 (Takeshi Kitano)


**基本信息**
- 国籍：日本
- 出生：1947年1月18日
- 代表作：《菊次郎的夏天》《花火》《座头市》《玩偶》

**风格特点**
- 将黑色幽默与暴力场面完美结合
- 动作场面干脆利落
- 镜头语言冷静客观
- 情感表达含蓄克制
- 兼具狂暴的暴力与极致的温情
- 善于用平淡的生活细节展现人性
- 与久石让长期合作，音乐与画面高度契合

**美术方案**
- **时代与地域**：当代日本/江户时代
- **摄影介质**：35mm胶片，冷峻质感
- **色彩基调**：冷色调（蓝/灰），局部暖色点缀
- **光线偏好**：自然光、黄金时光、室内散射光
- **全局风格Tags**：Japanese dark comedy, violence mixed with tenderness, calm detachment, minimal composition, summer vibes, melancholic humor, Joe Hisaishi music, stoic expression
- **排除词**：vibrant colors, warm tones, romantic, action-heavy, stylized, emotional

**适用场景**
- 暴力美学
- 黑色幽默
- 温情治愈
- 日本背景
