# 第一部分：写作方法论

## 总体定位

单段30秒视频直出，单次可输入图像/音频/视频最多50个参考素材，具备更强指令控制，专业级可控的视频编辑与延长能力，原生支持10余种语言生成。官方口径："长叙事×强参考×准编辑×多语言"的工业级新阶段。模型创作能力持续深化，画面真实感显著增强，在光影表现、表演理解与执行、镜头运动上都更接近真实拍摄。

**官方总结判断（可直接引用）**：Seedance 2.5 相比 2.0，不是像 2.0 相比 1.5 那样"跨代式、断代式"的跃迁，而是面向真实生产场景做的系统性补强——更长时长生成、更丰富多模态参考、更稳定编辑/续写能力，以及宽高比/音画衔接/可控性/工作流适配的优化。把 Seedance 从"效果惊艳的创作模型"推进到"更接近端到端工业化视频生产"的阶段。

**官方也有自己的调优Skill**（跟本skill目标不同——本skill是同时产出两套模型格式，官方skill是单独调优Seedance 2.5一个）：
```
npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" --skill sd25-pe --yes
```
使用方式：AI对话框输入 `/sd25-pe` + 提示词内容。

## 多模态典型能力清单（R2V能力全景）

Seedance 2.5 支持文本、图片、视频和音频等多模态输入的灵活组合。下表按任务类型列出典型能力：

| 任务类型 | 支持的R2V能力/任务 | 能力细化说明 |
|---|---|---|
| **参考生视频** | 主体参考 | 参考人/物/场景/虚拟角色等主体的外观ID/声音；主体图参考；主体音视频参考；主体图+主体音色音频参考 |
| | 运动参考 | 参考图/视频的运动/动态信息：动作/表情/运镜/创意/特效等运动参考；运动+主体参考 |
| | 白模参考/渲染 | 输入粗粒度或细粒度白模视频参考其动态信息、进行渲染：白模参考；白模参考+主体参考；白模参考+主体参考+场景参考 |
| | 风格参考 | 参考图/视频的风格：风格图/视频参考；风格图/视频参考+主体参考 |
| | 音频参考 | 参考音频的音乐/台词/音色等声音信息：音频（音乐/旋律/台词/音色）参考；音频+主体参考 |
| | 宫格分镜/故事板参考 | 参考分镜图的主体/构图/动作/剧情等信息：多宫格分镜参考；分镜+主体参考 |
| | 关键帧参考 | 输入单/多个图作为关键帧生成视频：关键帧分镜参考生视频；首帧/首尾帧参考生视频（严格通过`content.role = first_frame/last_frame`控制） |
| **编辑视频** | 视频指令编辑 | 通过文本对视频画面进行增删改编辑，支持输入时间戳指定编辑生效时段——增加：主体/服饰/运镜/特效/…；修改：主体/主体局部/风格/背景/颜色/材质/运镜/机位/…；删除：主体/字幕/水印/… |
| | 视频参考图编辑 | 通过文本+参考图对视频画面进行增删改编辑，支持输入时间戳指定编辑生效时段 |
| | 视频音频编辑 | 对视频声音进行增删改——增加：人声/音乐/音效/…；修改：人声/音乐/音效/…；删除：人声/音乐/音效/… |
| **延长视频** | 视频延长 | 向前/向后延续输入的视频，可要求画面/音频无缝衔接：向前延长/向后延长；向前/向后延长+主体参考 |
| **其他** | 一键成片 | 输入多个图/视频生成短片，可添加文字/贴纸/转场/等：素材一键成片；素材+参考视频一键成片 |
| | 视频无缝转场 | 输入两段视频，模型生成补全间隙实现无缝转场 |
| | 组合能力 | 上述提及能力的自由组合应用 |

## 任务类型：先判断"有锁定"还是"无锁定"

Seedance 2.5 从传入素材最终是否会锁定输出视频属性，把任务区分为两类（2.0 没有这个区分）——这是产出 Seedance 提示词前**第一件要判断的事**：

- **有锁定**：素材会严格成为输出视频时间轴上的一段，是模型输出去适应传入的素材，因此会锁定输出视频的宽高比、甚至时长。
- **无锁定**：仅对素材进行语义上的参考，因此用户可以指定输出视频的宽高/时长属性。

### 有锁定：编辑 / 首尾帧 / 延长

编辑/首尾帧/延长会根据输入素材自动锁定部分生成参数，不支持用户自定义。

| 任务类型 | 任务详细定义 | 对输出视频锁定的说明 | 触发关键词 | 示例 |
|---|---|---|---|---|
| **视频编辑** | 输入视频，要求对视频的画面或音频进行增删改等编辑操作，支持额外输入图片/视频/音频引导编辑结果 | 锁定输出视频的宽高比，严格对齐用户输入视频的宽高比；锁定输出视频的时长，基本对齐用户输入视频的时长（受模型输入帧处理机制影响，输出视频时长可能与输入存在轻微差异，最大约0.3秒，只是部分过渡帧被压缩，内容基本对齐输入、保持完整/不变；如果用Seedance2.5生成的视频作编辑输入，输出时长不会有差距）；建议 `output_format` 使用mov格式 | 编辑视频、增加/加上、删除/去掉、修改/替换/改成…或其他相关描述 | `@video1 中加一些小动物`；`把 @video1 的人物修改为 @image1`；`删掉 @video1 的背景音乐` |
| **首帧/首尾帧** | 输入1张图作为首帧生成视频/I2V，或输入2张图分别作为首帧和尾帧生成视频 | 锁定输出视频的宽高比，严格对齐用户输入视频的首帧图（如果输入尾帧与首帧画幅不一致，尾帧会被拉伸，因此建议输入画幅一致的首帧和尾帧）；时长支持用户自定义 | 通过 `content.role` 取值控制，需设置为 `first_frame`/`last_frame` | — |
| **视频延长** | 输入视频进行向前/向后延长，通过prompt描述延长生成的内容，支持额外输入图片/视频/音频 | 锁定输出视频的宽高比，严格对齐用户输入视频的宽高比；时长支持用户自定义；建议 `output_format` 使用mov格式 | 向前/向后延长、延续、续写…或其他相关描述 | `向后延长 @video1，@image1 的角色从天而降...`；`续写 @video1 前5s，@video2 女人入画说...` |

### 无锁定：参考任务 / 多宫格分镜 / 关键帧

参考类任务对输出视频的宽高比和时长没有来自输入素材的锁定，特别注意以下两类任务：

| R2V能力 | 推理策略说明 |
|---|---|
| **多宫格分镜/故事板** | 生成画面**不是**严格对齐分镜图：输入多宫格分镜图（多个分镜合并在一张图），生成视频画面不会严格对齐分镜图（比如分镜中具体的画面细节），分镜图主要提供大致的剧情参考。推荐使用相对简约的线稿分镜图，并通过prompt补齐分镜图中没有的信息（如动作、运镜和风格等基础信息） |
| **关键帧** | 生成画面**对齐**关键帧：将多张独立的分镜图（可能包含首/尾帧分镜图）作为关键帧输入，生成视频画面相对严格对齐输入图；时长支持用户自定义 |

## 素材输入建议

| 场景 | 输入建议 |
|---|---|
| 输入素材总上限 | 图片：最多30张4K分辨率以内的图片；视频：最多10段视频，所有视频总时长不超过30s；音频：最多10段音频，所有音频总时长不超过30s |
| 主体音视频，建议输入多少个主体 | 1-5主体效果较好；更多可尝试6-10主体，但稳定性下降、可能需要抽卡 |
| 主体音视频，建议输入多长时间 | 5-10s时长效果较好；更长时长稳定性下降、可能需要抽卡 |
| 主体图，建议输入多少个主体 | 1-8主体效果较好；更多可尝试9-12主体，但稳定性下降、可能需要抽卡 |
| 不同视角主体图的输入效果差异 | 1-5主体，「单视图」「多视图」均可；超过5主体，「单视图」效果较稳定，如需输入多视角，建议拆分为多张不同视图输入，而非输入一张包含多视角的图 |
| 宫格图参考，建议输入多少个分镜 | 多宫格目前更适用于15个以下分镜；推荐火柴人/线稿分镜，不推荐在分镜图上写过多文字 |
| 白模参考，建议粗粒度还是细粒度 | 简单建模（粗粒度）参考效果较好，建议仅用简单几何体拼接表示人物/物体/动物等 |
| 视频编辑，建议输入多长的视频 | 20s以内效果较好；更长时长稳定性下降、可能需要抽卡 |
| 视频参考图编辑，建议输入多少张图 | 1-5张参考图效果较好；更多可尝试6-8张，但稳定性下降、可能需要抽卡 |
| 视频延长，建议的格式 | 为获得最佳的声画衔接效果，输入视频、输出视频均采用mov格式 |

## Prompt写作公式（"把 Seedance 2.5 当作视觉内容生产者，用导演思维写结构化Prompt"）

### 基础写作

1. **（R2V）素材指代**：明确每个图/视频/音频的编号（按上传顺序）与用途（谁是形象/谁是音色/谁是动作/谁是场景……）
2. **一句话概述**：主体+地点+事件+题材/风格+特殊运镜……
3. **具体情节描述**：镜头顺序/时间轴均可，用时间戳或"镜头N"切分，逐段描述画面具体内容/运镜/动作/台词/音效，尽量正向描述；反向描述支持字幕、音频控制（如"不要字幕""不要bgm"）
4. **结尾**：补充说明贯穿始终的画面细节（机位/运镜/环境/场景/声音/氛围）

### 参考类（多素材映射）

- 素材变多后，映射和指代关系说明非常重要，按上传顺序对应编号（图1/视频1/音频1），每个素材做文本绑定
- **不建议只在图片里呈现映射信息**（如图片上写"张三"再在prompt里写"张三在学校里……"，容易导致多人混淆或重复角色）
- 多主体逐一列清映射关系：`img1-2是人物1，对应音频1；img3-4是人物2，对应音频2`
- 分工要具体到"参考什么"，部分参考要写明"参考哪一部分"：`参考视频1中施法的动作，视频2的环绕式运镜`
- 参考素材本身已足够精准时，只做"指代"、减少画面复述：`严格参考视频1的动作与运镜，顺序与视频保持一致`（不用再具体写"先抬手、再转身……"）

### 编辑类

明确修改的范围和内容，可配合时间戳部分编辑，尽可能说明修改内容从A到B的过程。
- 示例：`仅编辑视频1中男人的台词，修改为"你不要过来啊"，口音调整为东北口音`
- 示例：`把视频1中4-6秒男人喝咖啡的动作改变为拖地，其余内容不要变化`

### 首尾帧

- 优先用 `content.role = first_frame/last_frame`（会锁定宽高比，严格对齐首帧图）
- 也支持 `role = reference_image` 在prompt中指定具体图片为首尾帧（不锁宽高比，效果相近但不完全匹配）

### 时间戳

- 以"1秒"为单位；指定时间段内容少模型会自由发挥，内容过多会导致过度剪切或剧情遗漏
- **不建议**用时间戳控制频率/频次（如"一秒摇头3次"）
- 支持：明确时间区间（注意连续性，避免"0-3秒...5-6秒..."跳跃表达，应写`0-3秒......3-7秒.....7-15秒`）；时间点控制（`第5s快速向左横移转场`）；相对时间控制（`张三呆滞站在原地，3秒后周围人纷纷摇头`）

### 负向控制

- 字幕：`不额外加入对白字幕` / `不要字幕`
- 音频支持更细维度单独控制（音效/BGM/对白）：`无bgm，只生成环境音和动作音` / `不要任何声音`

## 进阶写作

- **镜头语言**：基础景别（大全景/全景/中景/近景/特写）、运镜（推/拉/摇/移/跟/环绕/俯冲/后拉/上摇/手持晃动）、机位（低角度/俯视/第一人称）可直接写；热门运镜（一镜到底/希区柯克变焦/航拍视角/FPV/子弹时间/手持镜头/回弹变速）可直接写；过于小众专业的名词需转换为**[名词+描述性解释]**（如"移焦，画面焦点发生平滑转变，原本清晰的前景树木变模糊，背景人物由模糊变清晰"）；转场要写清触发点与方式（`第5s快速向左横移转场（向左擦除+自然叠化）`）
- **动作/表情描述**：动作优先用概括性描述（"连续做了几组高抬腿和空翻"），只在少数记忆点动作上写具体细节，不重复写相同动作；表情建议写描述性语句、减少成语（"津津有味地吃饭"→"脸上带着满足的笑容，大口地吃饭"）
- **白模参考/渲染**：文本中写明希望参考白模的什么元素（仅运镜和运动 vs 光影变化也要参考）；叠加输入参考图时需写明参考图和白模的对应关系；建议在prompt中详细描述希望生成的内容且需与白模内容吻合；**粗粒度白模**建议仅用简单几何体拼接（不建四肢/翅膀等精细部位，否则容易导致四肢僵化，若已建则要补全动作序列）；**细粒度白模**建议提供不含轨迹线/坐标线/相机cone等干扰信息的清晰视频（这类信息会泄露到生成结果里，且无正向价值）
- **多宫格分镜/故事板**：≤15个分镜为宜，过多（如18宫格）容易静止/顺序错乱；避免过度锐化/杂乱的AI直出分镜图，不在分镜图上写过多文字；避免prompt前后矛盾；宫格图不严格对齐分镜内容，严格对齐需求改用关键帧参考；**推荐火柴人/线稿分镜**三步法：①写明参考素材指代关系 ②写整体故事梗概 ③按分镜完整描述情节内容（可组合时间戳明确剧情逻辑）；概念分镜/关键帧设计可直接简写prompt（"按照分镜图的顺序，构建一个完整的故事剧情，运镜合理连贯"）
- **关键帧参考**：视频需要严格按分镜图生成时使用，独立按顺序传入，**prompt第一句要写明**"以图片x至图片x的顺序作为关键帧"

## 与 Seedance 2.0 的差异点（4条）

1. **响应时间戳**：2.0 不响应时间戳只响应镜头序号，2.5 响应整数秒的时间戳
2. **支持多视图**：2.0 不建议用多视图作主体参考，2.5 可以支持
3. **自由宽高比**：2.0 输出宽高比只有固定6档，2.5 可通过控制输入素材支持 [0.4, 2.5] 之间任意宽高比输出
4. **提升V2V画质**：2.5 输出支持 MOV 格式，在延长/编辑任务中更好保持颜色与亮度一致性、声画一致性

# 第二部分：官方提示词案例库（按任务类型分类）

## 白模参考/渲染

**粗粒度白模**（含运镜/切镜/光照）：以白模参考视频 `<video1>` 作为整支视频唯一的运镜、镜头节奏、景别变化、主体运动轨迹和镜头调度参考，严格保持白模视频的镜头顺序、机位变化、运动方式和节奏，不改变镜头结构，不新增镜头，不改变主体运动逻辑。结合各阶段关键帧参考图，生成一部30秒电影级3D动画短片，整体风格梦幻、童话、温暖，具有儿童幻想色彩，角色外形与各阶段的关键帧保持一致，不要改变角色形象，人物表情情绪随场景变化而改变。0-3s（首帧参考）：镜头由全景俯视缓缓推向地上的小女孩，小女孩坐在房间的地毯上玩飞机，起身左转，右手使劲一挥将手里的飞机放飞。3-5s：飞机从左至右穿过房间悬挂的星星挂件，小女孩乘坐飞机进入幻想的天空。5-8s：镜头继续侧跟，以小女孩为中心的环绕。8-10s：镜头环绕到小女孩驾驶的飞机背面、飞机开始缓缓俯冲海面。10-19s：小女孩继续向海底游去，一条鳐鱼游过来入画。19-23s：小女孩从时空裂缝冲出来到幻想宇宙。23-24s：前景小女孩和星球开始前翻转并逐渐幻化消失。24-28s：俯视镜头持续推进，小女孩躺在地毯上熟睡。28-30s：镜头继续推进绘本，随后爸爸进入画面。整体要求：所有画面均参考对应关键帧，白模视频仅作为运镜、镜头运动和角色动画参考，不参考画面内容。最终输出30秒16:9横构图宽屏视频。**建议**：白模视频主体不要建【四肢/翅膀】等可能涉及精细运动元素，仅含躯体即可，容易影响生动性导致四肢僵化；如果建了，要把对应元素的动作序列补全，避免四肢僵化问题。

**细粒度白模**（服务于建模完整，重点解决重渲染场景，给"白模上色"获得更好更丰富的渲染效果）：将视频1进行白模渲染，无bgm，只生成环境音和动作音。渲染要求：背景为深蓝与紫色色调的夜晚赛博朋克都市，密集的摩天大楼，楼宇间是巨大的全息广告牌与霓虹灯光，数个飞行器在空中穿梭，闪着微弱的灯光，发出微弱的机械声响；人物为一个身着黑色夜行衣的小浣熊，身影为一道剪影，脚步小心翼翼；人物移动的地点是摩天大楼中的一栋楼的屋顶。**建议**：提供的细粒度白模视频，尽量不含【轨迹线】【坐标线】【相机cone】等信息，容易泄露到生成后的视频中，且这类信息并不会对渲染细粒度白模视频产生任何正向价值。

## 总结（官方原话，可直接引用）

Seedance 2.5 相比 Seedance 2.0，并不是一次像 Seedance 2.0 相比 Seedance 1.5 那样「跨代式、断代式」的跃迁。Seedance 2.0 已经完成了核心生成能力的明显突破，而 Seedance 2.5 是在此基础上面向真实生产场景做系统性补强：包括更长时长生成、更丰富的多模态参考、更稳定的编辑/续写能力，以及在画面宽高比、音画衔接、可控性和工作流适配上的优化。因此，Seedance 2.5 的价值不只是「单条视频效果更好」，而是让模型在可复用、可交付、可规模化生产这些关键环节上更进一步。它把Seedance从「效果惊艳的创作模型」，继续推进到更接近端到端工业化视频生产的阶段。
