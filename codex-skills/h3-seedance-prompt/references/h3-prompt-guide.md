# 第一部分：写作方法论

## 参数速查

- 输出时长：4-15 秒
- 输出宽高比：首/尾帧模式跟随输入图原始比例；文生视频/全能参考模式支持 21:9、16:9、4:3、1:1、3:4、9:16 六档（全能参考模式也可选自动，由 H3 判断）
- 分辨率：768p（已开放，短边768px或总面积约1M像素）/ 1440p（**官方推荐**，短边1440px或总面积约3.7M像素；768p结果可升级至1440p）
- 帧率：24 FPS
- 声音：全部结果带声音输出，原生双声道
- 输入：首/尾帧入口 0-2 张图（宽高比 5:2~2:5）；全能参考入口图片≤9张、视频≤3段（单段2-15秒，总≤15秒）、音频≤3段（须配图/视频，不能单独输入）；混合输入总上限12个文件
- 提示词字数上限：7000 字符
- 语言：TTS 精准覆盖11种语言（中/英/日/韩/法/德/西等），可衍生探索40余种

## 整体公式

```
完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明
```

### 1. 参考素材说明

告诉 H3 每个上传素材是干什么用的。
- 写清素材编号（按上传顺序）：@图片1、@音频2、@视频3
- 写清每个素材的用途：人物参考（锁脸/形象）/ 物体参考（锁物体）/ 场景参考（锁场景）/ 关键帧（锁帧，首尾帧需明确提出）/ 音色参考（锁音色）/ 故事板（按分镜生成镜头内容）/ 风格参考（生成类似风格）/ 构图参考（生成对应构图）/ 音频复用（生成视频音频直接复用）/ 音频部分复用（某轨道/某时间段部分复用）/ 动作参考（锁动作）/ 运镜参考（锁运镜）/ 视频编辑（对已有视频增删改）
- **没有上传素材时整段跳过**
- 有非常想保持的特征建议明确写出来，一致性更好
- 音频复刻涉及人声对白/歌词内容时，强烈建议补充具体歌词文本

示例：`@图片1 提供了xx角色的形象，@视频2提供了动作参考。`

### 2. 核心创意

一句话锁定全片信息，必须包含：
- **主体**：谁/什么
- **地点**：在哪里
- **事件**：在做什么
- **题材/风格**：什么调性（写实/动画/电影感/广告片/纪录片……特殊风格如赛博朋克/霓虹灯美学/涂鸦风等）
- **特殊运镜**：要不要特殊镜头（航拍/一镜到底/慢动作……），默认会切镜；环绕运镜建议写 `truck left+pan right` 或 `truck right+pan left`，而非直接说"环绕运镜"；切镜风格可选普通切镜(cut)/叠化切镜(fade)/随节奏卡点切镜/快切
- 元素与引用素材有直接关联的，用 @图片1/@音频1/@视频1 强调

示例：`一位穿汉服的年轻女子（@图片1）在樱花纷飞的庭院里舞剑，古典国风，电影质感，一镜到底。`

### 3. 画面过程说明

按时间轴或故事线分段写，每个分镜/时间段包含：

**想要**（画面里要出现什么）：画面景别+内容+运镜+动作+台词+音效
- 以切镜shot作为时间戳分段，每个shot内部写清景别/具体内容/shot内运镜/台词/音效
- 台词长短尽量和镜头长短对齐（很多口型问题来自这里）
- 一句台词跨shot，用"接着上个shot继续说"表明
- 元素与素材有关联时用 @图片1/@音频1 强调
- 想要视频中出现具体文字/Logo/标题/标语/按钮文案，必须把文字原文写出来

**不想要**（不要出现什么）
- 不想要背景音乐要明确写：`非叙事性音乐：N/A`（或英文格式 `"non_diegetic_music": N/A`），并声明不要额外添加背景音乐

**其他原则**
- 尽量少写比喻句，多写看得见的画面——H3 更擅长理解明确画面指令，不擅长意会抽象比喻
- 有台词必须写明具体内容

### 镜头怎么拆

- H3 有基础分镜能力，对切镜点遵从较强
- 台词长短和画面变化要合乎每个shot长短逻辑，不要一个3秒shot说一大段话
- 支持跨shot台词（J-cut, L-cut），只要明确写出一句台词跨了哪些shot
- 画内说话人角色要写清是哪个角色；画外说话人写清"画外音"；发生画内外转化可明确写出
- 切镜一致性：切镜时写清切到什么景别、具体主体是之前哪个角色，有助于跨镜头一致性

## 三类模式怎么写

| 模式 | 写法要点 | 示例 |
|---|---|---|
| **多模态参考融合**（上传多素材） | 每个素材写清角色：@图片1→人物参考(锁脸)，@视频1→动作参考(锁动作)，@音频1→节奏/情绪参考 | "@图片1是人物参考(锁这位女子的脸)，@视频1是动作参考(用里面的舞剑动作)，@音频1是情绪参考(古风配乐)。让这位女子在樱花庭院里按视频里的动作舞剑。" |
| **图生视频**（上传图片） | 只传1张图要说清是首帧还是尾帧；传2张图(首+尾)时H3不会自动加切镜，只补两帧之间的动作/光影/声音 | "@图片1是首帧参考图：女子持剑站在樱花树下。让她从持剑起势到舞剑完毕，自然衔接，不要切镜。" |
| **纯文字生成**（无参考素材） | 描述要更具体（主体外观/场景细节/动作都写清），多用"大全景交代空间+中景承载动作+特写强调细节"的分层写法 | "写实自然纪录片风格，电影级真实光影。清晨薄雾中，广阔湿地芦苇荡里，一只优雅的白鹤单腿站立在浅水中，缓慢转头看向镜头。柔和逆光，雾气在光束里飘动。" |

## 容易踩的坑（输出前自查）

| 常见问题 | 怎么改 |
|---|---|
| 只写一段话没分段 | 按3段公式拆开写 |
| 素材上传了但没说用途 | 补一句"@图片1是XX参考" |
| 想用音乐但说"不要BGM" | 这两个矛盾，要么删一个，要么分场景写 |
| 想一镜到底但写了很多分镜 | 全文保持一段情节描述，删掉【镜头N】结构 |
| 想要主角脸一致但没传图 | 一定要上传人物参考图，并标注"人物参考" |
| 提示词太短（没素材可参考时） | 至少写出主体外观+场景细节+动作+风格 |

**轻悬疑犯罪电影片头**（贯穿全片分层规则写法的代表案例，值得整段抄结构）：生成一支15秒16:9横版轻悬疑犯罪电影片头。整体风格参考这些图的视觉语言：复古日系动画片头、硬边剪影、漫画拼贴、非对称分屏、强烈几何色块、英文片头署名、少量日文片假名装饰、爵士犯罪气质。氛围是60%悬疑、40%爵士：神秘、酷、灵动、有都市犯罪感，不恐怖、不沉重，也不要变成欢乐爵士MV。片头动效要像动态图形拼贴：黑底线框先出现，分屏边界快速划出，色块和画格逐块贴入；人物剪影、道具特写、英文署名跟随鼓点依次滑入、弹出、遮罩揭示。不要普通写实剧情动画，要片头包装感。英文署名要清晰可读，允许有动效：细线框先画出，名字从框内滑入，字母逐个出现，被色块遮罩揭示，最后短暂停住。不要新增中文，不要乱码，不要让英文错拼。全片规则：所有英文署名和职位只出现一次。不要重复同一个职位，不要重复同一个人名，不要让同一个人担任多个职位。转场形式要丰富：圆形黑胶遮罩、车门竖切、人物长影擦屏、红线切割、巨大英文字母遮罩、分屏边框重组、色块硬切、画格逐块贴入。所有转场跟随鼓点，干脆、悬疑、灵动、有漫画拼贴感。不要柔和溶解，不要流体转场。BGM：原创15秒片头音乐，60%悬疑、40%爵士。以低音持续音、紧张弦乐拨奏、冷感合成器脉冲、低音鼓、稀疏爵士鼓刷、walking bass片段、低音萨克斯短句和短促铜管点缀组成。前2秒神秘低频和踩镲建立悬疑，第3秒进入低沉鼓点，第6秒加入爵士贝斯律动，第10秒出现短促萨克斯/铜管riff，最后2秒用紧张和弦加鼓点定格。整体神秘、酷、带犯罪感，爵士只占40%，不要太欢快，不模仿任何现有旋律。
