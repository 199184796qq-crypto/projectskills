## 零、导演思维六大自检（最重要，每次设计镜头前必查一遍）

原文件强调：**先用这六条检查每个镜头是否"物理上可行+导演意图清晰+剪辑衔接合理"，再套场景模板**，不要先套模板再填内容。

### 0.1 机位决定视野——不能描述这个机位看不到的东西

每个景别+角度组合有物理可见范围，写完每个镜头自问："从这个机位，摄影师能看到我描述的所有内容吗？"

| 机位 | 能看到 | 看不到 | 常见错误 |
|---|---|---|---|
| 侧面中景 | 人物侧脸、轮廓、肢体动作 | 人物正对的屏幕/书本/手机内容 | ❌ 侧拍人物+描述电脑屏幕内容 |
| 背面跟拍 | 人物背影、前方环境 | 人物正面表情 | ❌ 背面跟拍+描述表情变化 |
| 俯拍特写(桌面) | 桌面物件、手部动作 | 人物面部、站起动作 | ❌ 俯拍桌面+描述人物站起来 |
| 过肩拍A | A的后脑/肩膀 + B的正面 | A的表情 | ❌ 过A肩+描述A的表情 |
| 正面近景(腰部以上) | 面部表情、上半身动作 | 脚部动作、地面物件 | ❌ 近景正面+描述脚踢东西 |

看不见就切镜：需要同一场景不同视角的信息时，拆成多个镜头，不要塞进一个视角矛盾的镜头里。

### 0.2 动作拆分原则——一个镜头只承载一个空间范围内的动作

动作跨越空间范围时（从桌面到口袋、从站立到蹲下、从这头走到那头），必须切镜。

| 景别 | 能承载的动作范围 | 不能承载的动作 |
|---|---|---|
| 特写 | 手指微动、眼神变化、物件细节 | 全身移动、蹲下站起、从A处到B处 |
| 近景 | 上半身动作、面部表情变化、手到胸口的动作 | 脚部动作、弯腰蹲下、跨越空间 |
| 中景 | 半身以上动作、站起坐下、拿放物品 | 精细手指动作、微表情、远距离移动 |
| 全景 | 全身动作、走动、人物间位置变化 | 面部微表情、物件细节 |

**这是最容易犯的错**：比如"人物从远处快步走向对方，伸手想要抓住对方"这类跨空间的位移动作，不能塞进"特写"或"近景"——特写/近景只能承载"手指微动、表情变化"这种小范围动作，走过去、伸手抓这种全身位移必须用全景/中景，或者拆成"中景走近→近景/特写伸手瞬间"两个镜头。

### 0.3 声音/文本必须视觉化——模型生不出定制音效和文字内容

| 剧本里的非视觉元素 | 视觉化方案 |
|---|---|
| 脚步声/敲门声 | 脚部特写跟拍/手敲门特写 |
| 手机铃声/消息提示音 | 屏幕亮起特写 |
| "几个月后/几年后" | 季节变化空镜/日历翻页/环境对比 |
| 角色的内心独白 | 微动作外化（见下第五节） |
| 音乐/背景音 | 不处理（在具体情节描述结尾统一交代BGM要求，别指望模型自己配乐） |

### 0.4 镜头意图驱动——先问"观众该感受什么"，再选机位/景别/运镜

```
正确顺序：意图（观众该感受什么）→ 机位 → 景别 → 运镜
错误顺序：模板（中景→近景→特写）→ 填入动作描述
```

| 导演意图 | 推荐机位 | 原因 |
|---|---|---|
| 让观众看到证据/线索 | 特写 | 聚焦细节 |
| 让观众感受两人之间的张力 | 过肩镜头 | 同时看到双方空间关系 |
| 让观众感受孤独/渺小 | 全景/远景+大空间留白 | 人物在空旷环境中显得渺小 |
| 让角色情绪直接冲击观众 | 正面近景/特写 | 面部表情无遮挡传递给观众 |

### 0.5 表演动作链设计——不写情绪标签，写身体会做的物理动作

Seedance/H3能生成动作，但不能直接理解抽象情绪词。

| 情绪标签 | ❌ 直接写 | ✅ 动作链设计 |
|---|---|---|
| 焦虑等待 | "女主焦虑地等待" | 女主抬头望向门口方向，又低头看手表，轻轻叹气 |
| 心虚掩饰 | "男主心虚地掩饰" | 男主干笑一声，目光躲闪，手指不自觉搓裤缝 |
| 惊喜感动 | "女主惊喜感动" | 女主脚步停住，嘴唇微张，眼眶逐渐泛红，伸手捂住嘴 |
| 克制的悲伤 | "男主克制地悲伤" | 男主收紧交握的双手指节泛白，然后缓缓松开，深吸一口气 |

方法：代入角色→从大到小设计（先全身姿态，再肢体，最后微表情）→加入"穿帮"细节（真实的人掩饰时会有不自然的小动作）。

### 0.6 跨镜头剪辑衔接三规则——最容易犯错、也最硬性的一条

**规则A：景别跳切禁止（至少隔一级）**

景别层级：远景(1) ‹ 全景(2) ‹ 中景(3) ‹ 近景(4) ‹ 特写(5)。相邻两镜（包括跨场景的衔接处）景别不能相同或差1级时角度变化<30°（见规则B），更不能同景别直接相切。

| 情况 | 判断 |
|---|---|
| 相同景别，角度变化<30° | ❌ 必须修改 |
| 相邻景别(差1级)，角度变化<30° | ❌ 必须修改 |
| 跨两级以上(差≥2级) | ✅ 允许，无角度限制 |
| 场景切换(地点不同) | ✅ 可吸收 |

修改手段：改角度（≥30°）或跳一个景别（差2级）。

**规则B：30度规则（角度变化不小于30度）**

相邻两镜如果拍的是同一主体，机位角度变化必须超过30度，否则观众会觉得画面"跳了一下"。简化判断：相邻镜头的拍摄角度至少要换一个类别（正面/侧面/背面/过肩/俯拍之间切换），不要在同一类别里微调。

**规则C：越轴禁止（180度规则）**

两个角色对话/对峙时，摄影机必须始终在两人连线（轴线）同一侧。跨过轴线会导致人物左右关系突然翻转。简化处理：如果镜1中A在画面左侧、B在右侧，同场景后续镜头要维持这个左右关系。

**豁免**：剧本明确要"快切"效果的镜头（跳切感是表达意图）；闪回转场（有视觉隔断）。

## 一、景别规范

| 景别 | 英文 | 画面范围 | 叙事功能 |
|---|---|---|---|
| 远景 | Long Shot | 人物占画面1/4以下 | 交代环境、营造氛围 |
| 全景 | Full Shot | 人物全身+完整环境 | 展示人物与环境关系、完整动作 |
| 中景 | Medium Shot | 膝盖以上 | 平衡人物与环境，对话/互动 |
| 近景 | Medium Close-up | 腰部以上 | 突出表情情绪，弱化环境 |
| 特写 | Close-up | 肩部以上或局部 | 强调细节、情绪高潮 |
| 大特写 | Extreme Close-up | 局部细节(眼睛/嘴唇) | 极致情绪、悬念 |

**递进规律**：常规叙事由远及近（远景→全景→中景→近景→特写：环境→人物→互动→情绪→细节）；情绪爆发后平复则由近及远（特写→近景→中景→全景）。

**常见错误**：景别跳跃过大（远景直接切特写，观众迷失）；单一景别过长（全是特写，视觉疲劳，3-4个景别组合形成节奏）；景别与动作不匹配（特写拍全身动作）；忽略环境交代（一上来就近景对话）。

## 二、运镜方式

| 运镜 | 视觉效果 | 叙事功能 |
|---|---|---|
| 固定机位 | 稳定、客观 | 对话、静态场景 |
| 推镜(Push In) | 聚焦主体、制造紧张 | 情绪升级、细节揭示 |
| 拉镜(Pull Out) | 展示环境、制造疏离 | 场景揭示、情绪降温 |
| 摇镜(Pan) | 展示宽度、跟随移动 | 展示场景宽度 |
| 移镜/跟拍(Track/Follow) | 跟随主体、代入感 | 人物行走跟随 |
| 环绕(Orbit) | 立体感、戏剧化 | 强调主体、戏剧时刻 |
| 升降(Crane) | 气势感 | 开场、结尾、大场面 |
| 希区柯克变焦(Dolly Zoom) | 推镜+同步后退，背景延伸/压缩，心理冲击 | 发现真相、情感崩溃瞬间 |
| 手持抖动(Handheld) | 真实感、紧迫感 | 追逐/逃跑、情绪激动写实场景 |

**稳定性优先**：推荐缓慢、平稳的运镜；快速/剧烈运镜易产生画面抖动变形，慎用；避免方向突变的运镜组合（快速推镜→快速拉镜）。幅度建议：推/拉镜10-30%，摇镜30-60°，环绕30-90°。

**按情绪选择**：平静/抒情→固定机位/缓慢推镜；紧张/悬疑→推镜/缓慢环绕（避免拉镜，会分散注意力）；欢快/动感→跟拍/移镜（避免固定机位，太沉闷）；孤独/疏离→拉镜（避免推镜，会过于亲密）。

## 二.5、特殊镜头/光学技法（按故事情绪匹配检索，非移植——自行调研补充）

**这一节不是从"分镜师"skill移植的**（该库没有专门覆盖这些光学技法），是应EV要求"搜罗一圈特殊运镜设计"专门调研补充的。跟上面"二、运镜方式"的区别：那张表讲的是**摄影机怎么动**（推/拉/摇/移），这一节讲的是**镜头/光学选择本身**带来的画面质感（广角畸变/长焦压缩/浅景深虚化），以及几个专门收编进来的复合技法（希区柯克变焦/荷兰角/甩镜——这几个之前散落在别处，这里统一整理并补上"适用故事/情绪"）。

**用法**：不是按技法名去套用，是反过来——**先看用户的故事/场景带着什么情绪需求，再去下面的"匹配速查"里找对应技法**，命中了才用，没有需求硬套一个"炫技"镜头只会显得违和。每个事件最多用1个特殊光学技法点缀，别堆砌。

| 技法 | 视觉效果 | 适用故事/情绪 | 写入H3/Seedance提示词的注意事项 |
|---|---|---|---|
| 广角镜头(Wide-Angle) | 视野开阔，能同时容纳主体+环境；靠近拍摄时透视夸张变形（贴近镜头的手/脸显得异常大） | 环境交代的开场镜头；狂欢/失控/精神亢奋的主观视角（畸变强化混乱感）；喜剧化夸张效果；贴身动作戏想让观众"身临其境" | 写"广角镜头，视野开阔，边缘轻微畸变"配合具体构图；模型对精确畸变还原有限，别期待物理级焦段模拟 |
| 长焦镜头(Telephoto) | 压缩空间感（远近物体被"拍扁"贴近）；浅景深，背景强烈虚化；视角窄，有"偷窥感" | 偷窥/跟踪/狗仔式监视；人物与环境的疏离孤立（背景虚化把人从环境中"抽出来"）；克制的思念/凝望（隔着距离看一个人）；体育竞技临场紧张感 | 写"长焦镜头压缩空间，背景虚化模糊，人物与远处环境形成若即若离的构图"；旅行Vlog/穿越Vlog想表达"融入环境却格格不入"的孤独感时可点缀用 |
| 移焦/拉焦(Rack Focus) | 焦点在两个不同距离的对象间平滑转移，引导观众视线 | 悬念揭示（先虚化再"揭开谜底"式变清晰）；因果呈现（从触发物转到反应者，或反之）；对话场景里突然拉焦到前景关键道具的情绪转折 | **这是单镜头内部效果，不是切镜**——写在同一个"镜N"描述里，如"镜3：镜头焦点从前景的信封缓缓转移到背景中逐渐凝重的表情"，不占用额外镜号，不受0.6跨镜头衔接三规则约束 |
| 移轴摄影(Tilt-Shift) | 选择性对焦制造"微缩模型"错觉，世界像玩具般疏离 | 上帝视角俯瞰城市的疏离荒诞感；梦境/回忆/意识改变状态（今敏式心理场景）；把宏大场面处理得有点滑稽的喜剧化解构 | 效果高度依赖后期，纯文字prompt很难精确复现，写"移轴摄影效果，画面呈现微缩模型般的疏离质感"效果不保证，**只用于空镜/转场镜，不用于关键叙事镜头** |
| 鱼眼镜头(Fisheye) | 极端广角+强烈边缘畸变，接近180°视野 | 迷幻/失控/精神错乱/醉酒的主观视角；极限运动/说唱MV式风格化冲击；喜剧夸张效果 | 风格太强烈会喧宾夺主，**全片最多点缀1处**，不适合叙事/情感场景；跑酷模板想要更强"极限运动风格化"时可选用 |
| 希区柯克变焦(Dolly Zoom/Vertigo Shot) | 推镜同时反向变焦，主体大小不变但背景空间剧烈延展/压缩，眩晕感 | 发现真相/心理崩溃/世界突然变形的冲击瞬间（经典案例：《迷魂记》恐高眩晕、《大白鲨》海滩发现鲨鱼） | 对AI视频模型是较难的复合运镜，简化写法"镜头缓慢推近人物的同时背景空间产生扭曲延展般的眩晕感，营造真相揭露的心理冲击"，不追求物理精确变焦补偿；已在"二、运镜方式"表列过，这里补充故事匹配细节 |
| 荷兰角(Dutch Angle) | 画面水平线倾斜，制造不稳定/失衡感 | 角色心理失衡/精神失常/醉酒/受冲击后的主观状态；危险人物出场的不安感；动作场面的混乱感 | **是构图选择，不一定要配合旋转运镜**——固定倾斜机位比旋转运镜更容易被模型还原，写"镜头以倾斜角度构图，画面水平线明显倾斜"；对应"二、运镜方式"表里的"倾斜旋转"条目，二者可以分开用（倾斜构图不动 vs 倾斜着旋转） |
| 甩镜(Whip Pan) | 快速横向/纵向甩摆，运动模糊覆盖画面瞬间 | 戏剧化转场（场景/时间跳跃）；强化冲突反转的瞬间；"来不及看清"的仓促混乱感；快速甩镜从A甩到B可以建立两个主体的强关联/对比 | 已经是`play-templates.md`里Vlog/穿越/跑酷模板的默认转场手法之一，"建立主体强关联"这个用法是本次新补的额外用途；转场用途见play-templates，这里是理论依据 |
| 微距镜头(Macro) | 极端近距特写，景深极浅，拍摄微小物体/纹理细节 | 情感物件细节特写（戒指纹路/信纸褶皱/水珠质感）；产品/美食内容的质感展示；"世界被放大"的沉浸细节感 | 比"大特写"更极端的镜头选择，是第六节"五感镜头系统"里触觉/嗅觉细节呈现的具体镜头术语补充 |

**匹配速查（按故事/情绪反查技法，这是主要用法）**：
- 悬念/信息揭示 → 移焦
- 心理眩晕/真相冲击/世界突然变形 → 希区柯克变焦
- 精神失常/心理失衡/危险感 → 荷兰角
- 偷窥/监视/疏离孤独 → 长焦压缩
- 环境交代/身临其境/荒诞夸张 → 广角
- 梦境/回忆/游戏感疏离 → 移轴（慎用，仅空镜）
- 迷幻失控/极限运动风格化 → 鱼眼（慎用，全片≤1处）
- 戏剧化转场/建立关联/反转瞬间 → 甩镜
- 情感物件细节/触觉嗅觉呈现 → 微距

## 二.6、导演/摄影师签名镜头（技法本身就以人名命名，比上面的通用光学技法更具体）

EV指出："特殊运镜手法是类似导演名字开头的，一般是某位导演或者摄影师发明的"——这类技法跟`director-styles.md`里的"整体美术风格"不是一回事：`director-styles.md`讲一个导演**全片**的色调/摄影介质/节奏基调；这里讲的是他们各自发明/带火的**某一个具体镜头动作或构图**，可以只在关键的一镜里单独调用，不需要把全片都改成那个导演的风格。同样遵守"按情绪需求反查，不硬套"的原则。

| 签名镜头 | 发明/带火的人 | 具体操作 | 适用故事/情绪 | 提示词写法与注意事项 |
|---|---|---|---|---|
| 库布里克凝视(Kubrick Stare) | 斯坦利·库布里克(《发条橙》) | 人物头部低垂，双眼从眉骨下方向上斜视镜头，正面近景/特写 | 精神失常/极度压抑愤怒/濒临失控边缘的角色瞬间；反派"黑化确认"时刻 | 这是**表演+构图组合**，不是运镜——写"正面近景，人物头部低垂，双眼从眉骨下方向上斜视镜头，眼神阴冷偏执"，具体动作描述比抽象说"库布里克凝视"更容易被模型还原 |
| 昆汀后备箱镜头(Tarantino Trunk Shot) | 昆汀·塔伦蒂诺(《低俗小说》等) | 机位置于汽车后备箱内部，仰拍后备箱打开瞬间的人物 | 把观众代入"被困/受制于人"的被动压迫视角；犯罪/公路片的黑色幽默签名时刻 | 写"镜头置于汽车后备箱内部视角，仰拍后备箱打开瞬间的人物"；跟我们5个玩法模板关系不大，适合有犯罪/公路元素的自由创意场景 |
| 迈克尔·贝环绕运镜(Bay Shot) | 迈克尔·贝(《变形金刚》系列) | 低角度长焦镜头360度环绕主角，主角同步做站起/抬头等垂直动作，常配慢动作 | 英雄登场/关键抉择后的气场瞬间；动作片高潮燃点 | 写"低角度镜头缓慢360度环绕人物，人物同步抬头挺身，慢动作强调气场"；是"二、运镜方式"里"环绕(Orbit)"的升级版（加低角度+垂直动作+慢动作三个修饰）；**换装模板"揭示新造型"瞬间可作为比固定环绕更燃的备选**，但对模型是更复合的运镜，只在明确要"炸/燃"效果时用 |
| 山姆·雷米震颤主观镜(Raimi Shaky POV Cam) | 山姆·雷米(《鬼玩人》) | 贴地疾驰的主观视角，模拟某种未知力量/怪物逼近，画面剧烈晃动 | 恐怖/惊悚片里"未知威胁正在逼近"的追逐感，不用露出追逐者本体就能制造恐惧 | 写"镜头以贴近地面的主观视角疾速穿越环境，画面剧烈晃动抖动，仿佛某种未知力量正在逼近"；只适合恐怖/惊悚向自由创意，跟我们5个玩法模板不搭 |
| 德帕尔玛分屏对焦(De Palma Split Diopter) | 布莱恩·德帕尔玛 | 画面前景与背景同时清晰对焦，中景反而虚化，前后景信息同时呈现 | 需要同时展示"两个空间层各自在做什么"且强调因果（前景是动作，背景是浑然不知的当事人）；故意让观众意识到"镜头在操控视觉"的高张力揭示时刻 | 写"画面前景与背景同时清晰对焦，中景虚化，前景[A的动作]与背景[B的状态]同时呈现"；AI还原难度较高，偏炫技，**慎用，全片最多1处**，适合悬疑/惊悚类自由创意的关键揭示镜 |
| 斯皮尔伯格脸(Spielberg Face) | 史蒂文·斯皮尔伯格 | 正面近景/特写，人物微仰头，脸上呈现惊叹敬畏的表情，常配逆光/暖光反射 | 人物第一次看到震撼景象/奇迹瞬间的反应镜头——不拍景象本身，只拍"看的人"就够传递震撼 | 写"正面近景，人物微微仰头，眼中带着惊叹与敬畏，脸上有暖光反射"；**跟旅行Vlog/穿越Vlog模板高度契合**——人物初见地标/新时空场景时插入一个这样的反应镜，比单纯拍环境空镜更有情绪代入感 |
| 王家卫抽帧降格(Wong Kar-wai Step-Printing) | 王家卫/摄影师杜可风 | 降低拍摄帧率(模拟12/8/4fps)配合慢门快门，运动物体产生拖影残影 | 都市孤独感、暧昧不清的情感状态、时间流逝的诗意感 | 写"画面呈现降格拖影效果，背景人流呈流动残影，主体相对清晰凝滞，营造时间凝滞般的疏离感"；跟`director-styles/王家卫.md`是同一件事的两层——那份档案讲全片整体美术基调，这里给出"这一镜具体怎么写"的执行细节，两者配合用 |
| 小津安二郎正反打直视镜头(Ozu's Direct-Address) | 小津安二郎 | 对话双方各自略微偏向镜头方向说话(不完全对视对方)，180度机位切换 | 克制、疏离、生活流的家庭对话场景；东方美学的静观视角 | 写"镜头正面平视，人物略微偏向镜头方向对话，不完全侧对彼方"；跟第三节"双人对话标准模板"的过肩镜头是同一场景的两种流派选择——过肩强调空间张力，小津式直视强调克制疏离，按场景基调二选一，不要混用在同一场对话里 |

**跟希区柯克变焦的关系**：希区柯克变焦(Dolly Zoom)也是一个签名镜头(见二.5)，之所以单独放在通用光学技法表里，是因为它已经完全脱离"希区柯克"这个具体名字变成行业通用词汇，比这张表里其他几个更常用、更该放进默认工具箱；这张表收录的是相对更小众、更需要"知道出处才会用对场合"的签名镜头。

**匹配速查（按故事/情绪反查签名镜头）**：
- 精神失常/黑化确认瞬间 → 库布里克凝视
- 被困/受制于人的压迫视角 → 昆汀后备箱镜头
- 英雄登场/燃点高潮 → 迈克尔·贝环绕运镜
- 未知威胁逼近的恐怖追逐感 → 山姆·雷米震颤主观镜
- 前后景因果同时呈现的高张力揭示 → 德帕尔玛分屏对焦
- 初见震撼景象的反应镜（旅行/穿越Vlog常用）→ 斯皮尔伯格脸
- 都市孤独/暧昧情感的时间质感 → 王家卫抽帧降格
- 克制疏离的家庭生活流对话 → 小津式正反打直视

## 三、角度与构图

### 垂直角度
仰拍（人物高大威严，英雄出场/权威人物）；平视（客观自然，标准场景）；俯拍（人物渺小弱势，展示环境/结束感）。

### 水平角度
正面（直接坦诚，情绪镜头/自我介绍）；侧面（轮廓感，行走/侧面特征）；背面（神秘悬念，跟随镜头）；斜侧面（最自然，大多数场景的标准选择）。

### 特殊角度
过肩镜头（对话场景，建立人物空间关系）；主观视角POV（代入感）；鸟瞰（大场面/命运视角）。

### 双人对话标准模板（很重要，我们的"将军夫人"类场景直接适用）
```
镜1：双人中景拍摄，固定机位，两人相对而立/而坐；
镜2：过人物A肩中景拍摄（过肩），固定机位，人物B说话；
镜3：过人物B肩中景拍摄（过肩），固定机位，人物A回应；
镜4：正面近景拍摄，固定机位，情绪收束；
```
**过肩镜头位置规则**：双人互动场景，**过肩镜头固定放在第2或第3镜**（中间位），作为对话关系的核心建立镜头。镜1用双人全景/中景建立位置，最后1镜用正面近景/全景收束。

### 复合构图句式（多人物/元素的空间层次）
- `[人物A]站在画面[位置]前景`
- `镜头穿过[人物A]，看到[人物B]`
- `[人物A]在前景[动作]，背景中[人物B][动作]`
- `透过[物体]拍摄[人物]`

### 避坑
角度过于单一（15秒全是正面，至少切换2-3个角度）；角度跳跃过大（正面直接切背面，用侧面/斜侧面过渡）；过肩镜头方向混乱（保持一致的轴线关系）；仰俯角度过度（以平视为主，特殊角度点缀）。

## 四、升格与慢镜头

**判断标准（核心）**：这个动作如果以正常速度播放，会不会因为太快而看不清楚、或情绪来不及被感受到？——是→用升格；否→去掉升格，改用特写。

**适合升格**（爆发性、速度快的动作）：冲向/推开/碰撞跌落/瞬间破碎/突然拉住。
**不适合升格**（已是慢动作，加了没用）：慢慢松开手、指尖一根一根离开、缓缓低下头、轻轻触碰、眼泪缓缓滑落——这些用特写就够，叠加升格是技术手段的误用。

**节制原则**：每个事件最多1个升格镜头；不超过总镜头数的20%；升格前后要有正常速度的镜头形成对比。

---

## 五、表情与微动作

### 必加表情的景别
近景/特写/大特写必须包含表情或眼神描写；中景可选（情绪转折时建议加）；全景/远景一般不加（人太小看不见）。

### 表情描写要求
- 简洁优先：控制在5-8字以内，不要大段心理描写
- 只写"能被镜头拍到的东西"，不写内心独白
- 避免抽象词：❌"感到幸福"→✅"嘴角上扬"
- 表情要与肢体动作协调，不要矛盾

### 微动作外化库（面部微表情AI还原能力有限时，用身体其他部位替代）

| 情绪 | 微动作 |
|---|---|
| 纠结 | 手指绞在一起、来回踱步、目光在两点间游移 |
| 压抑 | 攥紧拳头、指节泛白、肩膀紧绷、深呼吸 |
| 释然 | 手指松开、肩膀下沉、长出一口气 |
| 崩溃 | 手掌捂住脸、身体蜷缩、抽泣 |
| 顿悟 | 眼睛突然睁大、猛地抬头、手指点向某处 |
| 自我怀疑 | 手指摸向脸/下巴、低头看地面、双手抱臂 |

三层外化优先级：微动作（最易实现）> 物件代理（中等，如"信滑落""冰块融化"）> 环境映射（最稳定，如光影变化/风声）。

## 六、五感镜头（氛围场景/无强剧情冲突时用）

**核心理念**："泡一杯茶的镜头可以比一场爆炸更动人"——没有强烈剧情冲突时，用感官细节代替事件驱动。

优先级：视觉（最容易）> 听觉 > 触觉 > 嗅觉 > 味觉（最难）。每个事件用1-3个感官维度，避免堆砌。

**关键原则**：
- 听觉镜头必须有声源画面（观众要看到声音的来源，避免纯抽象声音描述）
- 嗅觉镜头必须有气味来源的画面
- 味觉镜头通过食物画面+品尝动作暗示，不直接说"好吃"

这条对**旅行Vlog/穿越Vlog**这类氛围导向的玩法特别有用——比如在地标前不一定非要一个"剧情动作"，一个"风吹起衣角+远处传来市集叫卖声"的五感组合镜头，比干巴巴的"人物张望"更有质感。

## 七、陈旧桥段黑名单（写情感/重逢/思念类场景前必查）

以下桥段过度使用已丧失冲击力，或AI生成质感差，应主动规避：

| 桥段 | 为什么要避免 | 替代方向 |
|---|---|---|
| 手写纸板接机（"我爱你"） | 视觉平淡，观众情感免疫 | 熟悉的小动作（蹭头顶）、直接奔跑拥抱 |
| 奔跑拥抱后原地转圈 | 单纯转圈过于符号化 | 加入道具细节；或改为用力扑抱后紧贴不动 |
| 窗边看雨发呆 | 情绪太被动，缺乏行动张力 | 整理对方遗留物品、翻看旧照片有具体反应 |
| 泪水顺脸颊慢动作滑落 | AI难精确控制泪珠位置，易诡异；情绪过于直白 | 咬唇、攥紧衣角、转身背对镜头——留白比特写眼泪更有力 |
| 打开手机相册反复刷照片 | 动作单一，AI难生成屏幕内容协调画面 | 拿出实物纪念品、重访对方喜欢的地点 |

**判断标准**：这个桥段是不是近3年超过50%的爱情短片都在用？依赖文字信息（纸/屏幕字幕）传递核心情感的，优先转化为视觉动作。

**跟"将军夫人重逢戏"的关系**：这条戏没有落进上面的黑名单（拱手行礼→报名号→伸手快步走近，是具体的古装礼仪动作而非烂梗），但"眼眶泛红几乎带上哭腔"这个方向是安全的，避免真的写"泪水慢动作滑落"这种AI容易翻车的细节。

## 八、快切与蒙太奇（跟我们自己的"遮挡式转场"是两套不同机制，别混）

**原库定义**：在单个镜头内部嵌多个短促子画面，用"。"分隔，让模型在一次生成窗口内自行衔接成紧凑蒙太奇——跟外层镜头之间用"；"分隔是两套分隔符。

```
镜N：快切镜头，画面包括：[子画面1，景别+动作]。[子画面2]。[子画面3]。[子画面4]。
```

**必用场景**：剧本/需求明确要"快切"效果的仪式流程（签约/开工/婚礼筹备）、并列蒙太奇（展会全貌/城市晨曲/晨起洗漱链）、跨场景同主题并列。

**⚠️ 禁用场景（重要）**：情感细腻表达、单一完整动作、**表情承载戏**、**对白场景**——这几类别用快切，快切节奏不足以承载表演和对话。**我们的"将军夫人重逢戏"这类对白情感戏，正确做法就是不用快切，走常规镜1/镜2/镜3/镜4分镜，这条规则确认了这个选择是对的。**

**跟我们的"遮挡式转场"（换装/旅行Vlog/穿越Vlog/跑酷用的那套）的区别**：
- 快切=同一个镜头内部塞多个不同地点/不同主体的短促画面，靠模型自己在单次生成里衔接
- 遮挡式转场=镜与镜之间用一个连贯的运动（甩镜/环境遮挡物）做无缝过渡，强调"看起来是一镜到底"
- 两者不是同一套机制，不要混用同一套写法去实现另一套效果。快切是"信息浓缩密集展示"，遮挡式转场是"伪装成连续长镜"。

## 使用方法（跟主SKILL.md的衔接）

设计任何多镜头内容（自由创意场景 or 5个玩法模板）时，在套用具体公式之前，先走一遍：
1. **判断场景类型**：情绪/情感表达 → 近景+特写为主；动作/行为展示 → 全景+中景为主；对话/互动 → 中景+过肩切换；环境建立 → 远景+全景开场；氛围/无强冲突 → 走五感镜头。
2. **过"导演思维六大自检"**（第零节），尤其0.2动作拆分和0.6剪辑衔接三规则——这两条最容易翻车。
3. **查"陈旧桥段黑名单"**（第七节），如果创意撞上了黑名单里的桥段，主动换一个更具体的替代方向。
4. 确认没问题后，再套`h3-prompt-guide.md`/`seedance25-prompt-guide.md`里各自模型的公式把内容写成最终提示词。
