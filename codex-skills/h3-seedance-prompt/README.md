# h3-seedance-prompt

给一个简单的视频创作需求，同时按 **MiniMax H3** 和 **Doubao Seedance 2.5** 两套官方提示词规则，各自补全成一版可直接使用的完整提示词，方便两边都试、对比效果。

## 产出什么

| 输入 | 输出 |
|---|---|
| 一句话创意（可带参考图/视频/音频） | 两版完整提示词：MiniMax H3 版 + Seedance 2.5 版，各自标注生成模式/任务类型 |
| 命中已固化的"玩法模板"（换装/旅行Vlog/穿越Vlog/时尚模特/跑酷） | 按模板的追问问题收集信息后，同样产出两版提示词 |

内容固化自两份官方手册（H3：飞书使用手册；Seedance 2.5：火山方舟提示词指南），两份手册各自持续更新，需要同步时手动重新读取（见 `SKILL.md` "手册维护"一节）。

## 安装

```bash
git clone <repo-url> ~/.claude/skills/h3-seedance-prompt
# 或项目级：<project>/.claude/skills/h3-seedance-prompt
```

无额外运行依赖，纯文本方法论 + Claude 的 Read 工具。

## 用法

在 Claude Code 里直接描述创意，或明确说"用H3和Seedance写个prompt"触发：

```
/h3-seedance-prompt 一个炫酷的时尚女装广告，15秒，快速踩点的感觉
```

也支持已固化的图片驱动玩法模板（换装/旅行Vlog/穿越Vlog/时尚模特/跑酷），比如：

```
帮我做一个换装视频，男性，风格酷炫
生成一个埃及旅游的Vlog的10秒的，男性
```

## 设计要点

- **两版不是互相翻译**：H3和Seedance 2.5的公式、术语、参数体系都不同（比如H3是离散宽高比档位，Seedance 2.5无锁定任务支持连续比例），各自套各自的规则，照抄同一句话会漏掉对方模型特有的要素。
- **案例库比抽象公式更可靠**：遇到跟需求相近的场景，优先去`references/`里的官方案例库找结构相近的范例改内容，尤其是"贯穿全片分层规则"这种复杂写法，单靠公式描述不出来。
- **三层知识分工**：`h3-prompt-guide.md`/`seedance25-prompt-guide.md`管"语法"（怎么把创意写成模型认得的格式）；`cinematography-guide.md`管"设计判断"（该用什么景别/角度/运镜，镜与镜怎么衔接才不穿帮，包括按故事情绪反查的特殊镜头/导演签名镜头）；`director-styles.md`管"风格/影调"（某个导演的色调/摄影介质具体是什么）。三层可以叠加使用，不是互斥的。
- **玩法模板的转场机制**：`play-templates.md`里的换装模板用的是"遮挡式转场"（转场动作要有物理/情节动机，比如披衣/关水龙头/捡东西，而不是凭空的孤立遮挡动作），一整条视频只换一次装；旅行Vlog/穿越Vlog/跑酷则用蒙太奇式连续跟拍+甩镜/环境遮挡物做无缝转场，让多场景读起来像一镜到底。

## 内置的摄影/导演知识

设计镜头不只是套H3/Seedance的语法公式，`cinematography-guide.md` + `director-styles.md` 还带了一整套镜头设计判断力：

- **导演思维六大自检**（设计任何多镜头内容前必查）：机位决定视野边界、动作拆分原则（跨空间的位移动作不能塞进特写/近景）、声音文本视觉化、镜头意图驱动、表演动作链设计（把抽象情绪词换成具体身体动作）、跨镜头剪辑衔接三规则（景别跳切禁止/30度规则/越轴禁止）
- **基础语法**：景别规范、运镜方式、角度与构图（含双人对话标准模板）、升格慢镜头的使用判断、表情与微动作外化库、五感镜头系统、陈旧桥段黑名单（重逢/思念类场景避坑）、快切与蒙太奇的适用边界
- **特殊光学技法**（按故事情绪反查，命中才用）：广角、长焦、移焦/拉焦、移轴摄影、鱼眼、希区柯克变焦、荷兰角、甩镜、微距——每条都标了"适合什么情绪的故事"
- **导演/摄影师签名镜头**（同样按情绪反查）：库布里克凝视、昆汀后备箱镜头、迈克尔·贝环绕运镜、山姆·雷米震颤主观镜、德帕尔玛分屏对焦、斯皮尔伯格脸、王家卫抽帧降格、小津安二郎正反打直视
- **24位导演的影调/美术风格库**：王家卫、希区柯克、诺兰、宫崎骏、胡金铨、昆汀、张艺谋等24人一人一档（时代地域/摄影介质/色彩基调/光线偏好/风格Tags/排除词），用户点名某个导演风格，或某个玩法模板缺一个默认美术基调时直接调用
