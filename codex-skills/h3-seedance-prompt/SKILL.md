# h3-seedance-prompt — 一个创意，两套官方格式的提示词

方法论在 `references/` 下两份文件里，动手前先读对应那份（或两份都读，因为要同时产出两版）。**每份文件都分两部分**：第一部分是写作方法论（公式/要素/踩坑/参数），第二部分是官方案例库（真实验证过的完整提示词文本，按场景/任务类型分类）——遇到跟用户需求相近的场景，先去案例库里找结构相近的范例改内容，比凭空套抽象公式更可靠，尤其是"贯穿全片分层规则"这种复杂写法（H3案例库里的大字幕MV/手绘特效两个超长范例）单靠公式描述不出来。

- `references/h3-prompt-guide.md` —— MiniMax H3 公式、三类模式、踩坑表、参数速查 + 案例库（品牌大片/视觉创意包装/MG动效/AI剧情/产品电商/数字体验游戏/硬件工业/动画风格化/多模态参考/精准编辑，共30余条案例）
- `references/seedance25-prompt-guide.md` —— Seedance 2.5 公式、有锁定/无锁定任务分类、进阶写作、跟2.0的差异 + 案例库（多模态能力清单/白模渲染/多宫格分镜/关键帧参考/编辑视频三种/延长/一键成片/无缝转场）
- `references/play-templates.md` —— 五个固化的"图片驱动"玩法模板（换装/旅行Vlog/穿越Vlog/时尚模特/跑酷），每个模板都写好了触发问题和创意公式，命中就直接按模板走，不用现场发明
- `references/cinematography-guide.md` —— **⭐ 从专业"分镜师"skill移植的摄影/导演方法论，管"设计判断"（该用什么景别/角度/运镜，镜与镜怎么衔接才不穿帮），跟前两份"管语法"的文件互补。设计任何多镜头内容前必须先过一遍这份文件的"导演思维六大自检"（尤其动作拆分原则+跨镜头剪辑衔接三规则），再套H3/Seedance的公式写出来——这条不是可选项，之前吃过亏（景别同景相切的硬伤）。另含二.5/二.6两节自行调研补充的"特殊镜头/光学技法"和"导演签名镜头"（广角/长焦/移焦/移轴/鱼眼/希区柯克变焦/荷兰角/甩镜/微距 + 库布里克凝视/昆汀后备箱镜头/迈克尔贝环绕/雷米震颤主观镜/德帕尔玛分屏对焦/斯皮尔伯格脸/王家卫抽帧/小津正反打），都按"故事情绪匹配速查"组织——创意里出现对应的情绪/场景需求时才调用，不硬套**
- `references/director-styles.md` + `references/director-styles/<导演名>.md`（24个文件）—— **影调/美术风格库**，管"风格判断"：某个导演的色调/摄影介质/光线/节奏具体是什么、怎么注入提示词。用户点名导演风格（"王家卫风格"）或某个玩法模板缺一个默认美术基调时查这里；先看`director-styles.md`的速查表定位，再读对应导演的完整档案拿"美术方案五项"（时代地域/摄影介质/色彩基调/光线偏好/全局风格Tags/排除词）改写进提示词。

## 工作流程

**0. 先判断是不是命中已固化的玩法模板**

用户如果上传了一张形象照片、需求听起来像"换装/变装""去XX旅游拍Vlog""穿越到XX""时尚穿搭大片""跑酷/城市穿梭"，先查 `references/play-templates.md` 有没有对应模板——命中了就按模板里写好的触发问题去问（换装/时尚模特问性别+风格；旅行Vlog问目的地，且**必须核实真实地标，拿不准就WebSearch，不能编**；穿越Vlog问目的地/时代，只拍穿越结果不拍穿越过程；跑酷可选问城市风格），再用模板给的创意公式往下走第3步。没命中任何模板才走下面通用的第1、2步。

**1. 先判断创意性质，这决定两套模型各自落在哪个模式/任务类型里**

用户给的需求是：纯新建（文生视频）/ 有参考素材（图/视频/音频）融合 / 编辑或延长已有视频？

- **MiniMax H3** 三类模式：多模态参考融合 / 图生视频（首尾帧） / 纯文字生成
- **Seedance 2.5** 先判断有锁定（编辑/首尾帧/延长）还是无锁定（参考任务/多宫格分镜/关键帧/纯文字）——这是 Seedance 2.5 独有的第一道判断，H3 没有这个区分

**2. 素材信息不全就主动追问，不要默认按纯文字模式生成**

用户提到"用这张图/这段视频"但没说清用途（人物参考？场景参考？运镜参考？动作参考？）时，主动问清楚——两套提示词共用同一份素材清单，只问一次。

追问要具体，别抽象地问"能补充素材信息吗"：直接问"这张图是想锁人物长相，还是锁场景，还是锁运镜/风格？"

**2.5. 多镜头内容先过导演思维自检，再动笔（不可跳过）**

只要创意会拆成2个以上镜头（几乎所有情况），先读 `references/cinematography-guide.md` 的"零、导演思维六大自检"，重点检查：
- **动作拆分**：有没有把跨空间的位移动作（走过去、伸手抓、跑向、跳起来）塞进特写/近景这种小范围景别里？——这类动作要么用全景/中景整段承载，要么拆成"中景走近→特写/近景到达瞬间"两镜。
- **跨镜头剪辑衔接三规则**：相邻两镜景别是否至少隔一级（不能中景接中景）？角度变化是否≥30°？双人场景左右位置关系是否全片一致？
- 对话/情感戏额外查一遍"陈旧桥段黑名单"（第七节），别落进烧焦的烂梗。
- 判断这条内容该不该用"快切"（第八节）——情感戏/对白戏**禁止**用快切，硬要蒙太奇感就用`play-templates.md`里那套"遮挡式转场"，两者不是一回事。
- 顺手查一遍第二.5/二.6节的"匹配速查"——如果创意里出现悬念揭示/心理崩溃/精神失衡/偷窥孤独/初见震撼景象/黑化瞬间等对应情绪，可以调用对应的特殊光学技法或导演签名镜头点缀（每个事件最多1处，没匹配上就不用，别硬塞）。

**3. 分别按各自公式产出完整提示词**

- **MiniMax H3 版**：参考素材说明 + 核心创意 + 画面过程说明；最后一个镜头结束后必须另起两行，按提示词正文语言依次追加完整禁文字约束和固定禁字幕规则。中文提示词依次用 `画面中不出现任何可读文字：无字幕、无台词字幕、无文字叠层、无 UI、无标签、无 Logo、无水印、无片尾文字。所有对白仅以角色口述声音呈现，画面不显示台词文字。` 与 `全片不准出现字幕。`；英文提示词依次用 `No readable on-screen text: no subtitles, dialogue captions, text overlays, UI text, labels, logos, watermarks, or end credits. All dialogue is heard only and is never displayed as text.` 与 `No subtitles are allowed throughout the video.`。不得省略、改写、移到段落外或将其写成新镜头。
- **Seedance 2.5 版**：素材指代 + 一句话概述 + 具体情节描述（时间戳精确到整数秒） + 结尾

两版内容对应同一个创意，但**不是互相翻译**——各自套各自的公式和术语（H3的"景别+运镜+动作+台词+音效"分shot写法 vs Seedance的"时间戳/镜头N"+"有锁定/无锁定"判断），照抄同一句话过去会漏掉对方模型特有的要素。

**4. 每版提示词后标注模式归属；踩坑自查在心里做，不要打印出来**

- 标注这版属于哪种生成模式/任务类型（比如"H3：图生视频·首尾帧模式" / "Seedance 2.5：无锁定·关键帧参考"）
- 输出前对照各自手册的"容易踩的坑"表格自查一遍，踩雷的地方直接改掉再输出——**这一步只用来自己把关，不要把自查过程写进最终回复**，用户只要模式标注和干净的提示词，不要看到"自查：XXX"这种内部检查记录

**5. 参数体系不同，别把同一个数字照抄两边**

| | MiniMax H3 | Seedance 2.5 |
|---|---|---|
| 时长上限 | 4-15秒 | 单段30秒直出 |
| 宽高比 | 离散6档 + 1440p推荐/768p | 有锁定任务对齐输入素材；无锁定任务支持[0.4,2.5]任意连续比例 |
| 参考素材上限 | 全能参考图≤9/视频≤3段/音频≤3段，混合总≤12个文件 | 图≤30张/视频≤10段(总≤30s)/音频≤10段(总≤30s)，总上限50个 |

用户需求里如果暗示了具体宽高比/时长/素材数量，两版要分别按各自上限处理——超出 H3 的15秒上限或超出 Seedance 的50个素材上限时，在对应那版提示词后面提醒限制，别硬凑一个不合规的版本。

## 输出格式

```
## MiniMax H3 版
[完整提示词]
模式：XXX

## Seedance 2.5 版
[完整提示词]
任务类型：XXX
```

## 手册维护

两份手册的原始来源都标注"持续更新中"（H3 在飞书 wiki，Seedance 2.5 在火山方舟 doccenter，两者都需要能渲染 JS 的方式读取——飞书用 `lark-cli docs +fetch`，火山方舟用浏览器保存成 `.mhtml` 再本地解析）。这次内容是固化的快照，以后手册更新了需要用户主动说"帮我更新一下这个skill"才重新读取同步，不要自己定期去查。
