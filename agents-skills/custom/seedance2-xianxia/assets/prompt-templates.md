# 可复用提示词模板

## 模板1：角色动作型

```
[角色描述]身着[服装描述]，在[场景描述]中[动作描述]。[细节补充]。镜头[镜头运动]。[光影氛围]。[风格标签]。
```

**填充示例：**
```
青衫少年剑修身着飘逸青色道袍，在云雾缭绕的悬崖边缘拔出发光剑鞘中的古玉剑，灵力随剑身出鞘旋绕剑刃。镜头从中景缓慢推进至发光剑刃的特写。柔和晨曦光线，体积雾气。电影级仙侠风格，4K画质。
```

---

## 模板2：场景氛围型

```
[场景全景描述]，[环境细节1]，[环境细节2]。[动态元素描述]。镜头[镜头运动]。[色调氛围]。[风格标签]。
```

**填充示例：**
```
巍峨天宫悬浮于无尽云海之上，玉石柱身刻满发光的上古符文，丝绸旗幡在仙风中飘动。金色灵力粒子在空中缓缓飘浮。镜头向前滑行穿过宏伟的殿堂入口。温暖金色光线配合柔和体积雾。史诗仙侠美学，电影级光影。
```

## 模板3：战斗特效型

```
[角色A描述]与[角色B描述]在[战场场景]中[战斗动作]。[特效描述]。[冲击效果]。镜头[镜头运动]。[光影对比]。[风格标签]。
```
