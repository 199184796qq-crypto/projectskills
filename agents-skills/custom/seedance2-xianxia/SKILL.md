# Seedance2 仙侠风格视频提示词生成器

专为 Seedance2 视频生成模型打造的仙侠风格提示词工具，基于 Seedance2 的提示词规范和仙侠美学体系，帮助用户生成电影级仙侠视频片段。

## 何时使用这个Skill

当用户有以下需求时使用：

- 需要为 Seedance2 生成仙侠风格的视频提示词
- 想要创作仙侠短片、仙侠MV、仙侠特效视频
- 需要描述仙侠角色、场景、打斗、飞行等画面
- 想要生成多个版本的仙侠提示词进行对比
- 需要中文提示词直接用于 Seedance2 生成

## Seedance2 提示词核心规范

### 提示词结构（五要素）
每条提示词应包含以下要素，按重要性排列：
1. **主体描述**：角色外观、服装、动作
2. **场景环境**：仙侠世界观下的场景
3. **镜头语言**：机位、运镜、景别
4. **光影氛围**：光线、色调、氛围
5. **画面风格**：整体视觉风格定义

### 提示词长度建议
- 简洁模式：50-100 字（中文）
- 标准模式：100-200 字（中文）
- 详细模式：200-400 字（中文）

### 关键原则
- 使用中文提示词，自然语言描述
- 描述具体动作和变化过程，而非静态画面
- 强调运动感和时间流动
- 避免矛盾描述和过度堆砌

## 提示词生成流程

### 第一步：确认场景需求
询问用户：
- 想要什么类型的仙侠场景（修炼、战斗、飞行、日常、渡劫等）
- 主要角色描述（性别、身份、服装偏好）
- 情绪氛围（壮阔、唯美、紧张、神秘、悲壮）
- 视频时长偏好（影响提示词详细程度）

### 第二步：组装提示词
按照五要素结构，参考以下资源组装：
1. 角色与场景元素 → 见 `references/visual-elements.md`
2. 镜头与光影 → 见 `references/camera-and-lighting.md`
3. 风格标签 → 见 `references/style-tags.md`
4. 完整示例参考 → 见 `assets/prompt-examples.md`
5. 可复用模板 → 见 `assets/prompt-templates.md`

### 第三步：输出格式
为每个场景生成：
- 中文提示词（可直接复制使用）
- Seedance2 推荐参数建议（宽高比、时长等）

## 注意事项

1. 使用中文自然语言描述，直接可用
2. 描述动态过程而非静态画面，强调"变化"和"运动"
3. 镜头语言是提升视频质感的关键，不要省略
4. 避免在一条提示词中塞入过多场景切换
5. 光影描述对最终效果影响很大，务必包含
6. 每条提示词聚焦一个核心动作或场景转换
