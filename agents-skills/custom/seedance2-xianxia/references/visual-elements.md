# 仙侠视觉元素库

## 角色类型

### 剑修 / Sword Cultivator
- 白衣剑客、青衫剑仙、持剑少年/少女
- 关键词：flowing white robes, ancient Chinese sword, jade hairpin, spiritual aura

### 仙人 / Immortal
- 仙风道骨、羽衣霓裳、飘逸长发
- 关键词：ethereal immortal, celestial robes, glowing eyes, divine presence

### 魔修 / Demonic Cultivator
- 黑袍、血色眼瞳、暗色灵气
- 关键词：dark robes, crimson eyes, dark spiritual energy, ominous aura

### 妖族 / Spirit/Demon Clan
- 兽耳、尾巴、半人半妖形态
- 关键词：fox ears, mystical transformation, animal spirit features
