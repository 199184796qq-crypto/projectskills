# Seedance 2.0 最佳提示词模式（从官方案例提炼）

## 一、提示词写作核心原则

1. 用自然语言描述想要的画面和动作
2. 明确区分"参考"和"编辑"意图
3. 素材多时，用 `@对象` 标清每个素材的用途
4. 描述动态过程，强调时间线和动作变化
5. 镜头语言写清楚（景别、运镜方式、视角切换）

## 二、高频提示词模式

### 模式1：运镜复刻型
```
参考@视频1的运镜和转场效果，[主体描述]，[动作描述]
```
案例：`参考@视频1的运镜方式进行有节奏的推拉摇移，女星的动作也参考@视频1中女子的舞蹈动作，在舞台上活力十足地表演`

### 模式2：角色替换型
```
将@视频1中的[原角色]换成@图片1，参考@视频1的[保留元素]
```
案例：`将@视频1中的女生换成戏曲花旦，场景在一个精美的舞台上，参考@视频1的运镜和转场效果`

### 模式3：多素材组合型
```
@图片1的[角色]在@图片2的[场景]中，参考@视频1的[动作/运镜]
```
案例：`参考@图1的男人形象，他在@图2的电梯中，完全参考@视频1的所有运镜效果还有主角的面部表情`

### 模式4：分镜脚本型
```
0-3秒：[画面描述1]
3-6秒：[画面描述2]
6-9秒：[画面描述3]
```
案例：`0-2秒画面：快速四格闪切...3-6秒画面：特写银色磁吸扣"咔嗒"吸合...7-12秒画面：快速切换佩戴场景`

### 模式5：视频延长型
```
将@视频1延长[时长]，[新增内容描述]
```
案例：`将@视频1延长15秒。1-5秒：光影透过百叶窗...6-10秒：一粒咖啡豆从画面上方轻轻飘落...`

### 模式6：特效复刻型
```
参考@视频1的[特效名称]，[新主体]进行复刻
```
案例：`参考@视频1的粒子特效和材质，金色鎏金材质的沙砾从画面左边飘出`

### 模式7：创意广告型
```
[产品描述]，[场景设定]，[镜头运动]，[广告语/字幕出现方式]
```
案例：`对@图片2的包包进行商业化的摄像展示，包包的侧面参考@图片1，包包的表面材质参考@图片3`
