# 抖音短视频带货文案生成器

这个skill专门用于生成抖音平台的短视频带货文案，基于抖音算法特点和用户行为习惯，帮助创作高转化率的爆款文案。

## 何时使用这个Skill

当用户有以下需求时使用：

- 需要为产品创作抖音短视频带货文案
- 想要生成多个文案版本进行A/B测试
- 需要针对特定产品类型优化文案
- 想要学习爆款文案的创作技巧
- 需要快速批量生成文案

## 抖音带货文案核心原则

### 1. 黄金3秒法则
- 前3秒必须抓住注意力
- 使用疑问句、反转、痛点直击等开场方式
- 避免平铺直叙的介绍

### 2. 情绪价值优先
- 先打动情绪，再讲产品
- 常用情绪：怀旧、惊喜、共鸣、焦虑、好奇
- 让用户产生"这说的就是我"的感觉

### 3. 视觉化表达
- 用具体画面感的词汇
- 描述使用场景而非功能参数
- 让用户脑海中浮现画面

### 4. 信任背书
- 销量数据、用户评价、权威认证
- 老字号、传承、匠心等信任符号
- 真实的使用反馈

### 5. 行动召唤
- 明确的购买指引
- 制造紧迫感（限时、限量）
- 降低决策门槛

## 文案生成流程

### 第一步：了解产品信息
询问用户以下关键信息：
- 产品名称和类型
- 核心卖点（3个以内）
- 目标用户群体
- 价格区间
- 特殊优势（老字号、非遗、独家配方等）

### 第二步：选择文案风格
根据产品特性推荐合适的风格：
- **情感共鸣型**：适合食品、家居、母婴类
- **场景刺激型**：适合零食、美食、解压类
- **对比反转型**：适合有明显差异化的产品
- **痛点解决型**：适合功能性、实用性产品
- **知识科普型**：适合需要教育市场的新品类
- **明星同款型**：适合时尚、美妆类

### 第三步：生成多版本文案
为每个产品生成3-4个不同风格的文案版本，每个版本包含：
- 吸睛开场（1句话）
- 产品卖点（2-3个要点）
- 情感/理性诉求（核心段落）
- 行动召唤（CTA）
- 建议配合的视觉元素

### 第四步：优化建议
为每个文案提供：
- 适合的拍摄场景
- BGM选择建议
- 字幕重点标注
- 预估时长控制

## 文案模板库

### 模板1：怀旧情感型
```
开场：[童年/记忆相关的钩子]
主体：
- 传承XX年/老手艺
- 工艺细节（道工序、小时）
- 感官描述（色香味）
- 情感共鸣点
结尾：限时优惠 + CTA
```

### 模板2：深夜放毒型
```
开场："深夜放毒" / "这谁顶得住"
主体：
- 场景代入（时间、状态）
- 视觉刺激（油光、色泽）
- 嗅觉刺激（香味描述）
- 味觉刺激（口感细节）
结尾：使用场景 + 紧迫感 + CTA
```

### 模板3：对比反转型
```
开场："别再XXX了！"
主体：
- ❌ 普通产品的问题（3个）
- ✅ 我们产品的优势（3个）
- 差异化核心卖点
- 数据/证据支撑
结尾：限时特惠 + CTA
```

### 模板4：痛点解决型
```
开场：痛点场景提问
主体：
- 常见困扰列举
- 产品如何解决
- 适用场景（3个）
- 用户反馈/数据
结尾：让用户成为XX的人 + CTA
```

### 模板5：知识科普型
```
开场："你知道吗？" / "很多人不知道"
主体：
- 冷知识/误区
- 正确做法/选择标准
- 我们产品的专业性
- 权威背书
结尾：专业之选 + CTA
```

## 文案长度控制

- **15秒视频**：50-80字
- **30秒视频**：80-150字
- **60秒视频**：150-250字

## 高转化关键词库

### 信任类
传承、老字号、非遗、匠心、古法、秘制、手工、现做、0添加

### 紧迫类
限时、限量、前XX名、今日特价、手慢无、最后一天、仅此一次

### 数据类
复购率、好评率、销量XX万、XX人都在买、回头客

### 情感类
童年、记忆、妈妈的味道、家的感觉、治愈、解压、幸福感

### 场景类
追剧必备、下酒神器、办公室零食、深夜食堂、解馋利器

## 注意事项

1. **避免违规词汇**：最、第一、顶级等绝对化用语
2. **真实性原则**：不夸大、不虚假宣传
3. **平台规范**：符合抖音社区规范
4. **用户视角**：站在用户角度而非商家角度
5. **差异化**：避免同质化文案，突出独特性

## 使用示例

用户输入：
```
产品：四川麻辣牛肉干
卖点：手工制作、麻辣鲜香、真空包装
价格：29.9元/袋
```

生成4个版本文案，涵盖不同风格，每个包含完整的开场、主体、结尾和拍摄建议。
