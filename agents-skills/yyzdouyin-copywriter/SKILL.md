# 抖音短视频带货文案生成器

这个skill专门用于生成抖音平台的短视频带货文案，基于抖音算法特点和用户行为习惯，帮助创作高转化率的爆款文案。

## 杨鸭子定制规则（高优先级）

当用户明确提到“杨鸭子”时，默认按抖音千川素材来生成，优先级高于通用规则。

### 0. 本地项目归档（强制执行）

- 所有与“杨鸭子”有关的交付物必须保存到 `D:\电商\杨鸭子\codex`，不能只在对话中输出。
- 使用当天日期建立一级目录，格式固定为 `YYYY-MM-DD`。
- 每个日期目录下使用两位顺序号建立项目目录：`01`、`02`、`03`……
- 如果当天日期目录不存在，直接建立当天日期目录和首个项目 `01`。
- 如果当天日期目录已经存在，且当前任务没有明确指定或正在使用的项目，先询问用户是继续已有项目，还是建立新项目；只有用户同意新建后，才按现有最大编号递增创建下一个项目目录。
- 如果当前对话已经确定正在使用某个项目，后续相关交付物继续放入该项目，不要重复询问，也不要另建编号。
- 每个项目按内容类型建立 `文案`、`配音`、`视频` 子目录；生成哪类内容，就把文件保存到对应子目录。
- 每次生成或定稿文案时，除其他需要的格式外，必须在 `文案` 子目录再生成一份同名 `.txt` 纯文本文件；TXT 中保留可直接复制使用的文案正文，不依赖 Markdown 格式。
- 不得覆盖已有文件。发生同名文件时，先询问用户是覆盖、另存新版本，还是使用新项目。
- 回复用户时给出已保存文件或项目目录的可点击绝对路径。

### 0.1 火山API配音生成（归类到语音技能）

- 用户明确要求“用火山API生成配音”时，本技能只负责确定杨鸭子项目目录、文案 TXT 和 `配音` 输出路径。
- 火山远程语音生成统一使用 `volcengine-api` 技能的语音流程；必须遵守其审批、费用预估、临时 API Key、脱敏响应和 `ffprobe` 核验规则。
- 杨鸭子默认声音为：年轻的抖音电商女声，普通话，自然亲切，有食欲感，不要播音腔和夸张叫卖，语速相对较快，只要干净人声。

### 1. 主要用途
- 主要用于生成**抖音千川素材文案**
- 重点不是泛泛讲产品，而是服务于投流素材转化
- 默认优先生成**能消耗、能跑量**的素材，而不是只追求文案好看
- 写作目标优先级为：**能起量 > 能消耗 > 有转化 > 再考虑表达风格**

### 2. 固定文案结构
每条文案的主体结构默认为：
- **黄金开头**：前3秒必须抓人，可以是痛点、反问、反差、场景、情绪、嘴馋感
- **塑品**：把产品卖点、人群、场景、口味、痛点解决自然带出来
- **行动号召**：自然引导下单、进直播间、点链接、去下单、现在试试等
- 当用户要求“新的”“再来一条”“再来几条”“重写”时，开头类型要**随机切换**，优先从痛点型、场景型、反问型、反差型、故事型、本地认同型、口感型、幽默型等不同路线里轮换

### 3. 表格与正文关系
- 每条文案输出前，仍然必须先给横版表格
- 横版表格字段固定为：
  - 宣传什么卖点
  - 产品功效
  - 适用人群
  - 适用场景
  - 用户痛点
  - 优惠活动
  - 产品卖点
- **正文不要求严格按照表格顺序展开**
- 但正文整体必须把表格信息**阐述到位**，可以直接说，也可以通过场景、情绪、暗示、画面感带出来
- 其中“适用人群”字段在正文里必须有体现：只能通过生活状态、消费场景、语气、需求、作息等方式**暗示**对应人群
- **不能**在正文里直接写出“城市白领”“小镇青年”这类抖音投流人群画像标签
- 不能出现表格写了，但正文完全没体现的情况

### 4. 杨鸭子固定受众画像
默认受众为：
- **人群**：小镇青年、城市白领
- **性别**：男女都有，女性相对偏多
- **地域**：四川、广东、重庆
- **口味**：麻辣、五香

生成文案时，默认优先考虑这些受众的语言习惯、消费场景和口味偏好。

### 5. 风格要求
- 文案风格必须**多元化**，不能连续输出同一种口气
- 避免同质化，不能三条都像一个模板改词
- 可灵活使用：痛点型、场景型、情绪型、反问型、反差型、种草型、带货转化型
- 同一批次输出的多条文案，要明显区分开场方式、节奏和表达角度
- 当用户要求“重写”“再来一条”“再来几条”时，必须**重新构思**，不能只是把前面文案换几个词再输出
- 新文案要在开头抓法、框架节奏、卖点组合、场景切入上与前文有明显区别

### 6. 输出要求
每条都必须：
1. 先输出横版表格
2. 再输出“为什么用这个开头”
3. 再输出“大的框架”
4. 再输出文案正文
5. 再输出“拍摄开头建议”
6. 再输出“千川素材分析”
7. 最后做合规检查
8. 正文尽量符合千川素材节奏，简洁直接，利于口播或字幕投流
9. 行动号召要自然，不要太硬，但必须有转化指向
10. 每条文案输出后，必须进行一次合规自检

#### 拍摄开头建议要求
- 每条文案后必须补充“拍摄开头建议”
- 重点说明前3秒画面怎么拍，帮助提升停留和点击
- 开头画面建议不能平淡，要优先考虑**新、奇、特、反差、近景冲击、动作感、情绪感、生活意外感**
- 要主动给出更容易做出差异化的开头方案，避免总是“拿起产品说话”“普通特写”“平铺展示”这类过于常规的起手
- 开头建议要优先往**能吸引眼球、能制造停留、能和常规素材拉开差异**的方向给
- 至少包含：
  - **开头镜头内容**（拍什么）
  - **人物状态/动作**（怎么演）
  - **字幕建议**（前3秒打什么字）
  - **是否适合口播直出/素材混剪/剧情演绎**
- 如有必要，可额外补充：
  - **反差点/视觉钩子**（为什么这3秒更吸睛）

#### 千川素材分析要求
- 每条文案后必须补充一段“千川素材分析”
- 分析至少包含：
  - **开头类型**（痛点型/场景型/反问型/反差型/故事型/口感型等）
  - **是否偏跑量素材**
  - **核心抓手**（抓停留的点是什么）
  - **适合的人群状态**（通过场景和需求描述，不直接写投流标签）
  - **核心卖点承接是否清晰**
  - **转化收口是否自然**
- 分析语言要简洁直接，明确告诉用户这条素材为什么可能高效，或者为什么可能偏弱

#### 跨类目同人群对标法（新增强制参考）
- 生成带货短视频、千川素材、跑量素材时，不只找同品类对标，还要优先判断“相同人群”的跨类目爆款是否可借鉴。
- 判断对标时，核心不是“产品是否一样”，而是“背后购买/关注/被触发的人群是否高度重合”。
- 抄对标时，不抄表面画面，不机械照搬剧情，而是拆它为什么能让同一批人停留、点击、信任或下单。
- 拆跨类目爆款时，必须看四个点：
  - **词根**：素材里反复出现的关键词，包括卖点词、人群词、痛点词、流量词。
  - **元素**：素材里可见的场景、人物、动作、道具、服化道、产品状态。
  - **高光点**：真正让用户停留、点击、共鸣或产生购买冲动的瞬间。
  - **爆款句式框架**：可以迁移到其他产品的表达结构，而不是原句照抄。
- 其中“词根”优先级最高。写文案前要先提炼用户一听就知道“这跟我有关”的关键词，再围绕这些词组织开头、场景和转化。
- 生成多版本素材时，要主动变化对标来源：同品类对标、同人群跨品类对标、同痛点跨场景对标，避免所有文案都像同一个模板改词。
- 在“千川素材分析”里，如适用，补充一句“对标来源逻辑”：说明这条素材借的是同品类、同人群跨品类，还是同痛点跨场景。

#### 合规自检要求
- 必须检查文案**不能违规**
- 必须检查文案**不能违反广告法**
- 必须检查文案**不能违法抖音千川素材规范**
- 避免使用绝对化、极限化、保收益、虚假承诺、无法证实的数据/排名/权威背书等高风险表达
- 避免使用医疗功效、夸大效果、诱导性过强、低俗夸张、虚构用户反馈等不安全表述
- 每条输出时，在正文后固定追加：
  - **合规检查：通过/需调整**
  - 如果“需调整”，要指出哪一句有风险，并给出安全改写版本

#### 解释字段要求
- **为什么用这个开头**：要简要说明这个开头抓的是什么，比如痛点、反问、反差、场景、情绪、嘴馋感、地域认同、本地认知、女性共鸣等
- **大的框架**：要明确写出该条文案采用的整体结构，比如“痛点开头 → 塑品背书 → 口感强化 → 行动号召”或“场景代入 → 产品差异化 → 本地认知背书 → 转化收口”
- 这两个解释项是每条文案的固定组成部分，不能省略

#### 写作使用原则
- 这些信息属于高价值素材，可用于增强信任感、本地感、非遗感和产品差异化
- 文案中不要求每次全部写全，应根据时长和主题灵活取用
- 优先把“非遗手艺、南充本地小吃、红花街总店、59+门店、先卤后炸、50多种香料、皮酥骨脆、麻辣/五香”作为核心素材池
- 表达要自然，避免像资料念稿

## 何时使用这个Skill

当用户有以下需求时使用：

- 需要为产品创作抖音短视频带货文案
- 想要生成多个文案版本进行A/B测试
- 需要针对特定产品类型优化文案
- 想要学习爆款文案的创作技巧
- 需要快速批量生成文案

## 抖音带货文案核心原则

### 1. 黄金3秒法则
- 前3秒必须抓住注意力
- 使用疑问句、反转、痛点直击等开场方式
- 避免平铺直叙的介绍

### 2. 情绪价值优先
- 先打动情绪，再讲产品
- 常用情绪：怀旧、惊喜、共鸣、焦虑、好奇
- 让用户产生"这说的就是我"的感觉

### 3. 视觉化表达
- 用具体画面感的词汇
- 描述使用场景而非功能参数
- 让用户脑海中浮现画面

### 4. 信任背书
- 销量数据、用户评价、权威认证
- 老字号、传承、匠心等信任符号
- 真实的使用反馈

### 5. 行动召唤
- 明确的购买指引
- 制造紧迫感（限时、限量）
- 降低决策门槛

## 文案生成流程

### 第一步：了解产品信息
询问用户以下关键信息：
- 产品名称和类型
- 核心卖点（3个以内）
- 目标用户群体
- 价格区间
- 特殊优势（老字号、非遗、独家配方等）

### 第二步：选择文案风格
根据产品特性推荐合适的风格：
- **情感共鸣型**：适合食品、家居、母婴类
- **场景刺激型**：适合零食、美食、解压类
- **对比反转型**：适合有明显差异化的产品
- **痛点解决型**：适合功能性、实用性产品
- **知识科普型**：适合需要教育市场的新品类
- **明星同款型**：适合时尚、美妆类

### 第三步：生成多版本文案
为每个产品生成3-4个不同风格的文案版本，每个版本必须先输出一个横版表格，再输出具体文案。

**横版表格字段固定为：**
- 宣传什么卖点
- 产品功效
- 适用人群
- 适用场景
- 用户痛点
- 优惠活动
- 产品卖点

**输出顺序固定为：**
1. 先输出横版表格
2. 再输出“文案：”正文

每个版本包含：
- 横版表格（按固定字段输出）
- 吸睛开场（1句话）
- 产品卖点（2-3个要点）
- 情感/理性诉求（核心段落）
- 行动召唤（CTA）
- 建议配合的视觉元素

**补充要求：**
- 表格必须是横版，不能改成竖版字段列表
- 即使用户只要文案，也要先给表格，再给正文
- 如果用户指定某一个卖点方向，比如“用户痛点”或“产品卖点”，则“宣传什么卖点”字段填写对应方向，其余字段正常补全
- 文案需与表格内容保持一致，不能表格写一套、正文写一套

### 第四步：优化建议
为每个文案提供：
- 适合的拍摄场景
- BGM选择建议
- 字幕重点标注
- 预估时长控制

## 文案模板库

### 模板1：怀旧情感型
```
开场：[童年/记忆相关的钩子]
主体：
- 传承XX年/老手艺
- 工艺细节（道工序、小时）
- 感官描述（色香味）
- 情感共鸣点
结尾：限时优惠 + CTA
```

### 模板2：深夜放毒型
```
开场："深夜放毒" / "这谁顶得住"
主体：
- 场景代入（时间、状态）
- 视觉刺激（油光、色泽）
- 嗅觉刺激（香味描述）
- 味觉刺激（口感细节）
结尾：使用场景 + 紧迫感 + CTA
```

### 模板3：对比反转型
```
开场："别再XXX了！"
主体：
- ❌ 普通产品的问题（3个）
- ✅ 我们产品的优势（3个）
- 差异化核心卖点
- 数据/证据支撑
结尾：限时特惠 + CTA
```

### 模板4：痛点解决型
```
开场：痛点场景提问
主体：
- 常见困扰列举
- 产品如何解决
- 适用场景（3个）
- 用户反馈/数据
结尾：让用户成为XX的人 + CTA
```

### 模板5：知识科普型
```
开场："你知道吗？" / "很多人不知道"
主体：
- 冷知识/误区
- 正确做法/选择标准
- 我们产品的专业性
- 权威背书
结尾：专业之选 + CTA
```

## 文案长度控制

- **15秒视频**：50-80字
- **30秒视频**：80-150字
- **60秒视频**：150-250字

## 高转化关键词库

### 信任类
传承、老字号、非遗、匠心、古法、秘制、手工、现做、0添加

### 紧迫类
限时、限量、前XX名、今日特价、手慢无、最后一天、仅此一次

### 数据类
复购率、好评率、销量XX万、XX人都在买、回头客

### 情感类
童年、记忆、妈妈的味道、家的感觉、治愈、解压、幸福感

### 场景类
追剧必备、下酒神器、办公室零食、深夜食堂、解馋利器

## 注意事项

1. **避免违规词汇**：最、第一、顶级等绝对化用语
2. **真实性原则**：不夸大、不虚假宣传
3. **平台规范**：符合抖音社区规范
4. **用户视角**：站在用户角度而非商家角度
5. **差异化**：避免同质化文案，突出独特性
