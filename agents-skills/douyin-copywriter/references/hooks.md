# 开头钩子库

从7个爆款案例中提炼的钩子类型和创作公式，按场景分类，可直接套用。

---

## 一、钩子六大类型

### 类型1：反差型钩子
核心逻辑：前半句建立预期，后半句打破预期，观众因为意外而留下。

**案例原句：**
- "开着捷达来上班的高大威猛阳光善良有才和蔼……你唯独把帅气两个字给我漏掉了"（案例1）
- "这个开着二手A6，中午十二点才来上班的是我的老板，我是他花一千块请来的便宜运营"（案例6）

**创作公式：**
```
[看似正常/高大上的描述] + [突然自贬/反转]
```

**套用模板：**
- "开着XX来上班的[一堆好词]，唯独漏了[最想要的那个词]"
- "这个[看起来很厉害的人/事]，其实[反差真相]"
- "[高调描述身份] + [低调自嘲身价]"

---

### 类型2：矛盾型钩子
核心逻辑：一句话里藏两个对立的感受，观众因为"说出了我说不出的话"而留下。

**案例原句：**
- "说实话，小城市的幸福感更强，但又说不上来有什么幸福的"（案例3）

**创作公式：**
```
[一种普遍感受] + 但 + [说不清的反面感受]
```

**套用模板：**
- "说实话，[某种状态]挺好的，但又说不上来好在哪"
- "[做某件事]很爽，但每次做完又有点[负面情绪]"
- "大家都说[某种选择]对，但真正选了的人，没几个笑着的"

---

### 类型3：冲突型钩子
核心逻辑：先制造一个"敌人"或对立面，观众天然站队弱者，必须看下去。

**案例原句：**
- "我长这么大从来没见过这么小心眼且报复心极强的老板"（案例7）
- "要想生活过得好，必须老板接过早。怎么？你还坐副驾？现在都这个流量了，过来开车"（案例4）

**创作公式：**
```
[定性一个人/事为"坏的"] + [交代冲突起因]
```

**套用模板：**
- "我见过最离谱的[角色]，因为[起因]，直接[过分的行为]"
- "从来没想过，[某个关系]能因为[小事]闹成这样"
- "[看似正常的场景]，直到[冲突事件发生]"

---

### 类型4：热梗改编型钩子
核心逻辑：用观众已经熟悉的网络梗开场，一秒入戏，再接自己的内容。

**案例原句：**
- "青春没有售价，跟着老板走天下"（案例5，改编自"硬座直达拉萨"）
- "要想生活过得好，必须老板接过早"（案例4，改编自网络梗）

**创作公式：**
```
[热门梗的前半句] + [改编成自己场景的后半句]
```

**套用模板：**
- "青春没有售价，[你的版本]"
- "[经典前半句]，[行业/场景改编后半句]"
- 注意：改编要自然，后半句要跟自己的内容相关，不能为了用梗而用梗

---

### 类型5：身份/成就型钩子
核心逻辑：先用身份或成就制造好奇——这人什么来头？观众先对人感兴趣，再对内容感兴趣。

**案例原句：**
- "当你身边有个郭老关，同时开了烧烤店、火锅店、面店，还拥有一家设计公司的时候"（案例2）

**创作公式：**
```
[介绍一个人的多重身份/成就] + [一句展现性格的话或行为]
```

**套用模板：**
- "当你身边有个[称呼]，同时做着[业务1]、[业务2]、还搞了个[业务3]的时候……"
- "[年龄]+[看似不可能的成就]，他是怎么做到的"
- "认识[称呼]的人都知道，他最爱说的一句话是……"

---

### 类型6：痛点共鸣型钩子
核心逻辑：直接说出目标观众正在经历的困境，观众因为"他懂我"而留下。

**创作公式：**
```
[目标人群] + [他们正在经历的真实困境]
```

**套用模板：**
- "做[某行业]的兄弟，你有没有算过自己一单到底赚多少？"
- "想[做某事]的，我先泼盆冷水，这几个坑你一定会踩"
- "为什么你[能力不差]，但就是[得不到想要的结果]？今天说透"

---

### 类型7：恐吓+数据型钩子
核心逻辑：先用夸张后果制造紧迫感，再用具体数据证明方法有效，观众因为"怕错过"而留下。

**案例原句：**
- "如果所有老板都学会了故事型脚本，运营估计都得去要饭。当我随便拿出一条框架给一个研学校长拍完后，单条视频吸引了两百多名家长。"（案例9）
- "写带货文案没思路？今天你们掏着了，我就教你们一招可乐三步法"（案例8）

**创作公式：**
```
[学会XX的夸张后果] + [具体数据/案例证明]
```

**套用模板：**
- "如果所有[同行]都学会了[方法名]，[某个角色]估计都得去要饭"
- "[痛点问句]？今天你们掏着了，我就教你们一招[方法名]"
- "我[随便/顺手]用这个方法帮[某人]做了一条，结果[具体数据]"

---

### 类型8：对话式钩子
核心逻辑：不像在"做内容"，像在"跟你说话"。用吐槽、发牢骚的语气开场，观众因为"这人在跟我聊天"而留下。

**案例原句：**
- "美业你们爱谁干谁干，反正我是不干了"（案例10）

**创作公式：**
```
[行业/人群关键词] + [带情绪的吐槽或表态]
```

**套用模板：**
- "[行业]你们爱干干，反正我是[某个态度]了"
- "做[行业]的兄弟，我今天说句得罪人的话"
- "[人群关键词]，你们自己心里清楚，[一个扎心的事实]"

**与提问式钩子的区别：**
- ❌ 提问式："为什么今年美业人赚不到钱？"——像标题，没情绪
- ✅ 对话式："美业你们爱谁干谁干，反正我是不干了"——像同行在吐槽，秒代入

## 二、钩子创作通用原则

### 3秒法则
- 抖音前3秒没抓住人，观众就划走了
- 钩子必须在第一句话完成，不能铺垫
- 信息量要大：一句话里至少包含一个悬念、冲突或反差

### 钩子≠标题
- 标题是文字，钩子是说出来的第一句话
- 标题可以有悬念感，钩子要有"说话感"
- 好的钩子读出来像在跟你聊天，不像在念稿

### 钩子的三个禁忌
1. 不能自我介绍开头："大家好，我是XXX"——浪费3秒
2. 不能问候开头："今天给大家分享一个"——没有信息量
3. 不能太长：钩子超过两句就不是钩子了，是开场白

### 不同平台的钩子差异
- 抖音：必须一句话抓人，越短越狠越好
- B站：可以用2-3句铺设，观众耐心更好
- 小红书：可以用场景描写开头，氛围感比冲击力更重要
