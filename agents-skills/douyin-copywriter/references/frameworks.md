# 文案框架库

从8个爆款案例中提炼的可复用文案框架，按风格分类，直接套用。每个框架都标注了适用场景、节奏要求和关键注意点。

---

## 一、搞笑互动框架

来源：案例1（烧烤店）、案例2（火锅店）

### 双人互动版（2人出镜）
```
自嘲开场（3-5秒）
│ 用反差自贬建立人设，如"四千两百块的专业贴身保镖"
│
→ 日常场景展开（15-30秒）
│ 边干活边聊，产品/环境信息藏在动作和对话里
│ 节奏：员工捧→老板接不住→员工吐槽→老板反击，循环推进
│
→ 穿插真实故事（10-20秒）
│ 创业经历、兄弟情、朴素梦想——笑着笑着突然被打动
│
→ 段子式CTA收尾（3-5秒）
│ "来店里我请你吃烧烤，老板问起来我就说是我吃的"
```

### 群体互动版（3人以上出镜）
```
人设介绍开场（3-5秒）
│ 用身份/成就制造好奇："同时开了烧烤店、火锅店、面店"
│
→ 带人进场景（5秒）
│ "走，去我店头吃个火锅"——一句话完成场景切换
│
→ 群体互动推进（30-60秒）
│ 挨个问、轮番吐槽、集体点单，热闹感=真实感
│ 干货穿插其中，但每次科普完立刻用段子接住，防止变说教
│
→ 荒诞梗收尾（5-10秒）
│ 免单挑战、喝汤赌注等互动钩子，制造评论区话题
```

### 关键要素
- 卖点必须藏在段子里，不能单独介绍产品
- 每10-15秒必须有一个笑点或反转
- 口误、打岔、跑题是刻意设计的"真实感"
- 吹牛+被拆穿的循环是核心节奏引擎

## 二、情感共鸣框架

来源：案例3（荆门小城市）

### 独白体结构
```
矛盾感开场（3-5秒）
│ 说出一种大家有感觉但说不出的状态
│ "小城市的幸福感更强，但又说不上来有什么幸福的"
│
→ 具象场景串联（15-30秒）
│ 用3-5个生活碎片拼出情绪，每个场景只用一两句话
│ 菜市场碰到小学老师→超市排队遇上邻居奶奶→酒过三巡聊谁订婚
│ 像快速翻相册，信息密度高但不觉得累
│
→ 中段拉扯（10-15秒）
│ 在留下和离开、满足和不甘之间摇摆
│ "贪恋这份静" vs "山的另一边是不是该有更热闹的风"
│
→ 通感式收尾（5秒）
│ 不给答案，用一个身体感受结束
│ "安心也晕开想走的痒"——用"痒"代替心理描述
```

### 关键要素
- 具象化代替抽象化：不说"生活节奏慢"，说"街道总是带着缓慢半拍的冷静"
- 动词选择精准："栓在""泼在""晕开""沉在"——每个动词都带画面感
- 不用形容词堆砌，用场景本身传递感受
- 矛盾感贯穿全文，不给标准答案，观众要的是被理解
- 零对话，全程独白，适合配安静画面和BGM

## 三、牛马打工框架

来源：案例4（跟拍老板跑客户）、案例6（兑现福利续集）

### 跟拍时间线版
```
牛马金句开场（3-5秒）
│ 一句话建立打工人人设，改编网络梗效果最好
│ "要想生活过得好，必须老板接过早"
│
→ 时间线推进（30-60秒）
│ 按地点/任务切换段落，每到一个地点就是一个新剪辑点
│ 每段结构：到达→吐槽→干活→反差笑点
│ 用时间反差制造荒诞感："开车两小时，对接五分钟"
│
→ 穿插吃饭/休息（10秒）
│ 制造喘息节奏，苦中有甜
│
→ 收工段落（5-10秒）
│ 疲惫但有成就感，或账号运营话题收尾
│ "感觉一骑不如一骑，每天都在掉粉"——打破第四面墙
```

### 核心技巧：吐槽老板=变相夸老板
- "万恶的资本家"——但老板买了早餐
- "再不带我去吃饭，我就让你好看"——但老板马上就带去了
- 越骂观众越觉得这老板好，比正面夸有效一百倍

### 关键要素
- 人设靠语言习惯自带，不需要自我介绍
- 称呼体系要有辨识度："义父们""衣服们"代替"家人们"
- 业务信息无痕植入：用数据自己说话，像随口感慨
- 转场靠金句不靠特效："天空一声巨响""您的智能小跟班已上线"

## 四、粉丝运营框架

来源：案例5（出差天水）、案例6（兑现福利续集）

### 单期福利版
```
热梗开场（3-5秒）
│ 改编流行语定调："青春没有售价，跟着老板走天下"
│
→ 前情交代（5-10秒）
│ 说明不是纯玩，是忙完了/项目结束才出来的
│
→ 场景串联（20-30秒）
│ 出差/日常场景穿插，苦甜交替
│ "三天饿九顿"→"心心念念的麻辣烫今天才吃到"
│
→ 福利环节（15-20秒）
│ 从场景自然过渡到采购/抽奖，不是硬塞的环节
│ 交代物流细节增加可信度
│
→ 互动机制收尾（5-10秒）
│ 点赞=预算，粉丝=股东，每个动作都有奖励
│ "每一个点赞一毛钱，具体多少预算你们说了算"
```

### 系列化版（跨期连载）
```
第N期：承诺福利 + 设定规则（点赞=预算）
→ 第N+1期：兑现上期承诺 + 展示到货/开奖
→ 让中奖粉丝评论区证实（粉丝替你背书）
→ 预告下期更大福利（iPhone等），埋追更钩子
→ 没中奖的也发安慰奖（降低取关率）
```

### 关键要素
- "股东"称呼体系：把粉丝变成利益相关方，关注=投资，内容=回报
- 兑现是最强的信任货币："所见即所得"四个字打消一切疑虑
- 福利不是插播广告，是场景的自然延伸
- 系列视频的核心逻辑是"说到做到"，每一期都在积累信用

## 五、剧情反转框架

来源：案例7（离职开饭店+老板砸场子）

### 多重反转版
```
冲突定性开场（3-5秒）
│ 先给"反派"贴标签，观众立刻站队
│ "我长这么大从来没见过这么小心眼且报复心极强的老板"
│
→ 交代前因（5-10秒）
│ 离职/创业/分手等冲突起因，简短交代
│
→ 第一层冲突（15-20秒）
│ "反派"做了一件过分的事，观众愤怒值拉满
│ 迈凯伦+带人来找茬——有钱有势欺负人
│
→ 反转（10-15秒）
│ 真相揭开，"反派"其实是来帮忙/支持的
│ 观众情绪从愤怒→感动，落差越大传播力越强
│
→ 升华收尾（5秒）
│ 点出核心认知，不煽情但打动人
```

### 关键要素
- 弱者vs强者的对立是天然流量密码，观众本能同情弱者
- 反转必须出乎意料但合乎情理，不能为了反转而反转
- 剧情是外壳，核心认知才是内核
- 适合涨粉爆款，传播力最强的内容形式

## 六、干货教学框架

来源：案例8（可乐三步法）

### 方法论教学版
```
痛点问句开场（3秒）
│ "写带货文案没思路？"——一句话锁定目标观众
│
→ 抛出方法论名称（3秒）
│ 名字要简单好记有画面感："可乐三步法"
│
→ 三步拆解（10秒）
│ 把方法拆成3步，降低理解门槛
│
→ 逐个演示（30-50秒）
│ 每个技法配一组"原句→改编"对比
│ 每演示完一个就追问"这不就是你要的XX吗？"制造获得感
│
→ 教学即营销收尾（10秒）
│ 用刚教的方法反手推自己的产品/服务
│ "咱们也不白抄，就当今天的教材费"
│
→ 布置作业式收尾（3秒）
│ "记得回来交作业"——关注变成"上课"的一部分
```

### 五大台词改编技法（速查）
| 技法 | 方法 | 难度 |
|------|------|------|
| 句式嫁接 | 保留句式骨架，换主语和关键词 | 低 |
| 废话文学变卖点 | 绕口句式接产品卖点 | 中 |
| 共情改写 | 共情句式移植到产品场景 | 中 |
| 产品人格化 | 给产品一个角色人设 | 高 |
| 台词直接续写 | 不改原句，后面直接接产品 | 低 |

### 关键要素
- 方法论命名是第一个钩子，必须简单、好记、有画面感
- 每个技法都要有"原句→改编"的对比演示，光讲理论没人看
- 教学口吻但不端着，像朋友私下传授
- 最高级的教学是"教完你才发现我在打广告"

## 七、通用技巧（跨框架复用）

### 卖点软植入法
不单独介绍产品，把卖点藏在内容里：
- 藏在动作里：老板备货时随口说"我的菜品都是当天的现货"
- 藏在对话里：边吃边聊"安逸"，比"鲜嫩多汁"真实一万倍
- 藏在数据里："今天跑四个客户，预计两百公里以上"——不说公司多忙，数据自己说话
- 藏在转述里："老板说做他的客户就要享受他的服务"——服务理念一句话带过

### CTA自然化法
不说"关注我"，用内容本身引导：
- 段子包裹型："来店里我请你吃烧烤，老板问起来我就说是我吃的"
- 作业布置型："记得回来交作业"
- 利益绑定型："每一个点赞一毛钱，预算你们说了算"
- 悬念预告型："这还只是第一个坑，后面的更离谱"

### 押韵记忆锚点
一条视频放2-3句押韵句，钉在开头、转场、收尾：
- 开场定调："青春没有售价，跟着老板走天下"
- 转场过渡："发型搞到位，财运翻几倍"
- 收尾号召："你一下，我一下，老板重新打天下"
- 规律：五字或七字句，前半句铺场景，后半句接夸张或反转

## 八、故事型脚本框架（极致化痛点）

来源：案例9（研学机构招生）

### 适用场景
教育培训、本地服务、健康养生、亲子类——任何需要"先戳痛再给方案"的行业。核心逻辑：不卖产品，卖焦虑的解决方案。

### 五步结构
```
痛点问句开场（3-5秒）
│ 用问句锁定人群，让观众自己对号入座
│ "哪里的孩子周末非常可怜？"
│
→ 痛点对比（10-15秒）
│ 三方对比放大焦虑：A有优势、B有优势、你什么都没有
│ "大城市的孩子教育资源丰富，农村的孩子身体素质好，
│  而哪里的孩子只能玩手机？"
│
→ 情感升华（5-10秒）
│ 换一个更高的身份说话（教育者/专家/过来人）
│ 站在用户的立场替他说出心里话
│
→ 解决问题（5-10秒）
│ 轻描淡写带出业务，不说"报名"说"走一走"
│ "我要带哪里的孩子出去走一走？"
│
→ 回扣痛点收尾（3-5秒）
│ 不推销，重复痛点让用户自己做决定
│ "不希望孩子在美好的周末把自己框在家里"
```

### 关键要素
- 痛点对比用三方而非两方：两方对比是"你不好"，三方对比是"别人都好就你不好"，杀伤力翻倍
- 情感升华靠换身份：商家说"来报名"没人信，教育者说"孩子不该这样"家长自己就急了
- 解决方案越轻描淡写越好："走一走"比"报名我们的研学营"柔和十倍，抵触感归零
- 结尾回扣痛点而非喊口号：让用户带着焦虑离开，他自己会来找你

## 九、标准痛点五步法（转化向）

来源：案例10（标准痛点短视频制作方法）

### 适用场景
需要引流转化的行业：美业、教育、餐饮、本地服务、知识付费等。与框架八（故事型脚本）的区别：框架八偏品牌涨粉，本框架偏投流转化。

### 五步结构
```
对话式开头（3-5秒）
│ 像同行吐槽，不像念标题
│ 必须包含人群关键词（美业/餐饮人/宝妈）
│ "美业你们爱谁干谁干，反正我是不干了"
│
→ 场景化痛点（10-15秒）
│ 让用户"看到画面"，不是"听到问题"
│ "你家孩子总是能精准的激怒你"
│ 比"孩子叛逆怎么办"强十倍
│
→ 身份背书（5-10秒）
│ 经验年限 + 案例数量 + "太知道了"
│ "我做美业这么多年，接触这么多门店，太知道怎么解决了"
│
→ 实操方案（15-25秒）
│ 分步骤给具体做法，细节越"野路子"越可信
│ "第一步买个创可贴遮在线人数，第二步找水军捧场"
│
→ 趁热链接（5秒）
│ 资料包/评论区/朋友圈/直播间，四选一
│ 必须在用户"心动窗口期"内完成引导
```

### 开头的两个核心原则
1. **对话感 > 提问感**：吐槽式开头比提问式开头留人率高，因为吐槽有情绪，提问像念稿
2. **人群关键词必带**：不只给观众看，更给算法看，直接影响推送精准度和投流ROI

### 痛点描述的核心区分
| 写法 | 示例 | 效果 |
|------|------|------|
| ❌ 名词化 | "孩子叛逆怎么办" | 没画面，划走 |
| ✅ 场景化 | "你家孩子总能精准激怒你" | 秒回忆，留下 |
| ❌ 抽象化 | "门店获客难" | 正确的废话 |
| ✅ 画面化 | "每天守着空店刷手机等客人" | 扎心，代入 |

### 四种用户链接方式

| 方式 | 做法 | 适合场景 |
|------|------|---------|
| 资料包引流 | 免费资料需进群或私信领取 | 知识付费、教育培训 |
| 评论区互动 | 引导评论关键词，逐个回复 | 通用，自然流量 |
| 朋友圈观望 | 提示朋友圈有更多案例 | 高客单、需信任的行业 |
| 直播间引导 | 引导至直播间连麦咨询 | 付费投流素材 |

## 十、开头差异化迭代法（破解单品素材同质化）

### 核心问题
单品卖点少易导致素材同质化，且核心卖点不能省略，否则影响转化。

### 破解方法
将素材创作重心放在**开头的差异化迭代**上：
- 更换开头能改变人群触达角度，让全域算法匹配不同的核心受众小池子
- 核心卖点、痛点保持不变
- 开头后仍衔接产品核心卖点的硬广部分
- 仅定期迭代卖点的可视化画面即可

### 结构模板
```
差异化开头（3-5秒）
│ 情绪共鸣 / 点名受众 / 身份推荐 / 对话冲突 / 模拟线下 / 悬念反转
│
→ 核心卖点硬广（20-40秒）
│ 产品卖点、痛点解决方案，保持不变
│ 定期更换可视化画面，但话术逻辑不变
│
→ 转化引导（5秒）
│ CTA收尾
```

### 六种开头形式

#### 1. 情绪共鸣型
用情绪状态开场，让目标人群产生"说的就是我"的感觉
- "每天加班到深夜，回家还要带娃的宝妈们"
- "创业三年，还在为获客发愁的老板"
- "想副业赚钱，但不知道从哪开始的打工人"

#### 2. 点名受众型
直接点名目标人群，精准筛选
- "做餐饮的老板们，这条必须看完"
- "宝妈、学生党、上班族，都能用这个方法"
- "美业人注意了，这个坑90%的人都在踩"

#### 3. 身份推荐型
用身份背书建立信任
- "做了8年电商，我只推荐这一款"
- "作为两个孩子的妈妈，我必须说说这个"
- "干了十年餐饮，见过太多老板栽在这"

#### 4. 对话冲突型
用对话制造冲突和好奇
- "老板：这个月又亏了。员工：我早说了要换方法"
- "朋友问我：你怎么瘦这么快？我：就用了这个"
- "客户：你们和别家有什么不一样？我：听我说完你就明白了"

#### 5. 模拟线下型
还原线下真实场景
- "昨天店里来了个客人，问了我一个问题"
- "今天遇到个同行，聊完我才发现大家都在犯这个错"
- "上周有个学员私信我，说了这么一件事"

#### 6. 悬念反转型
先抛出反常识或意外的信息
- "所有人都说要先找场地，我说反了"

### 实操策略
1. **一个产品，准备6-10个不同开头**，每个开头对应一种人群触达角度
2. **核心卖点话术固定**，不要每条都重新写，保证转化逻辑稳定
3. **开头测试周期**：每个开头跑3-5天，观察数据后决定是否继续投放
4. **画面定期更新**：每2-3周更换一次卖点展示的画面素材，保持新鲜感
5. **数据复盘指标**：重点看完播率和转化率，完播率高说明开头有效，转化率高说明卖点有效

### 关键要素
- 开头差异化≠卖点差异化，卖点要稳定，开头要多变
- 每个开头要匹配不同的人群画像，不是随机换
- 素材团队聚焦开头创作，即便单品只有1-2个卖点，也能持续产出素材
- 算法会根据开头内容匹配不同的受众池，同一个产品可以触达更多潜在客户
