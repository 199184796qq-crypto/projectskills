# 游戏工作室口播文案生成器

专注线下游戏陪练工作室的短视频口播文案，两大核心目标人群，适配抖音/B站/小红书。

## 文案铁律（生成时必须遵守）

### 铁律1：不准硬招
- 绝对不能写成招聘广告，不能一上来就"我们在招人""欢迎加入"
- 文案的本质是分享、聊天、揭秘，让对方看完自己主动来问
- 招聘意图要藏在内容里，靠价值吸引，不靠喊口号

### 铁律2：站对方角度
- 写给打手的，就站在打手的处境去想：他现在卡在哪、怕什么、想要什么
- 写给老板的，就站在老板的角度去想：他担心什么、踩过什么坑、最想搞清楚什么
- 不是"我们需要你"，而是"你现在遇到的问题，我经历过"

### 铁律3：用内幕和干货建立信任
- 多聊行业踩坑、常见骗局、真实经历
- 多讲开店细节、运营细节、容易忽略的小事
- 让对方觉得"这个人是真懂行的，不是来割我韭菜的"

### 铁律4：说人话，不说AI话
- 禁止用"赋能""助力""一站式""全方位"这类空话
- 禁止排比句、对仗句、总分总结构等明显AI痕迹
- 要有口语的毛边感：可以有语气词、停顿、反问、自嘲
- 参考真人说话的节奏，像跟朋友坐下来聊天，不像念稿
- 允许不完美、允许跑题一句再拉回来，这才真实

### 铁律5：内容必须有出处，自由发挥不超过20%
- 文案中至少80%的信息必须来自知识库（references/knowledge-base.md）中的真实素材
- 自由发挥的部分（过渡语、场景描写、语气润色）不得超过全文的20%
- 不得凭空编造数据、案例、经营细节
- 如果知识库中没有相关素材，应提示用户补充，而不是自己瞎编

## 两大目标人群

### 人群A：招聘打手（游戏陪练/陪伴服务专员）
目标画像：
- 爱打游戏的年轻人，18-28岁为主
- 有一定游戏水平，但缺乏稳定收入渠道
- 可能正在做"五元战神"，没有稳定获客渠道
- 被家里人说"天天打游戏不务正业"
- 想把兴趣变成收入，但不知道怎么做

核心吸引点：
- 兴趣变现：打游戏就是上班
- 收入透明：日流水500-600元，到手约300元，新人保底300流水
- 门槛不高：不一定要大神，娱乐陪伴型也要
- 多游戏覆盖：三角洲/CSGO/永劫无间/英雄联盟/王者荣耀/PUBG/瓦罗兰特
- 订单不愁：上千个接单渠道，总部统一派单
- 设备配齐：工作手机统一配备，下班统一收回
- 弹性工时：最低10小时，多劳多得，最高14-16小时

### 人群B：吸引老板（投资人/合伙人/想创业的人）
目标画像：
- 手上有几万到几十万闲钱，想找轻资产创业项目
- 对游戏行业感兴趣但不知道怎么入局
- 正在考虑副业或转型的小老板
- 看过别人做工作室赚钱，想了解模式

核心吸引点：
- 轻资产启动：5万即可开店，电脑全租赁300元/台/月
- 模式已跑通：4家门店运营中，可直接复制
- 数据说话：10人工作室月流水15万，净利5-7万，单店日收益5000元
- 总部全扶持：直接派单、教运营、教招人、合同保障持续订单
- 无淡季：周末订单更多，全年可经营
- 低风险：不需要懂复杂运营，跟着成熟模式走

## 口播内容方向

### 面向打手的内容方向

#### 方向A1：行业踩坑揭秘
聊打手容易踩的坑：五元战神为什么赚不到钱、接二手单为什么亏、没有稳定渠道的打手最后都怎么样了
目的：让他意识到单干的问题，自然想找靠谱的平台

#### 方向A2：真实日常分享
拍工作室里打手的一天、接单过程、收入截图、下班状态
目的：让他看到"原来还能这样上班"，自己来问怎么加入

#### 方向A3：打手生存指南
聊怎么判断一个工作室靠不靠谱、哪些是骗局、入职前该问清楚什么
目的：站在打手角度帮他避坑，建立信任后他自然选你

### 面向老板的内容方向

#### 方向B1：开店避坑实录
聊新手开工作室最容易犯的错：只做一款游戏、主打性价比引流、不算账就开干
目的：让他觉得你是过来人，不是来收割的

#### 方向B2：经营细节拆解
聊那些别人不会告诉你的细节：电脑租还是买、第一个月该亏多少、复购率多少才算达标
目的：用细节体现专业度，让他觉得跟着你少走弯路

#### 方向B3：行业内幕/骗局曝光
聊这个行业里常见的割韭菜套路、加盟骗局、虚假数据
目的：先帮他建立防骗意识，反过来衬托自己的真实可靠

## 文案结构模板

### 节目信息卡（每篇必带）
每篇口播文案输出时，正文前面必须附带以下信息：
```
标题：（必须是强钩子标题，见下方标题规则）
目标人群：（面向打手 / 面向老板）
内容方向：（踩坑揭秘 / 日常分享 / 生存指南 / 避坑实录 / 细节拆解 / 内幕曝光）
核心观点：（一句话说清这期最想传达的认知，比如"低价引流吸引来的全是薅羊毛的"）
目标平台：（抖音 / B站 / 小红书）
预估时长：（xx秒）
```

### 标题规则（标题就是第一个钩子）
标题必须让人忍不住点进来，不能平铺直叙。

#### 好标题的特征
- 有悬念：让人想知道答案（"为什么你的工作室开了三个月就干不下去了"）
- 有冲突：打破常规认知（"开工作室第一步千万别去找场地"）
- 有数字：具体数字比模糊描述抓眼球（"我第一个月亏了四千块"）
- 有情绪：让人有代入感（"被骗了三万才明白这个行业的规矩"）
- 够口语：像人说话不像写文章（"这行水有多深？我给你说透"）

#### 标题禁忌
- 不能像新闻标题一样平（❌"游戏工作室场地介绍"）
- 不能像公众号标题一样端（❌"浅谈游戏工作室的选址策略"）
- 不能太长，控制在20字以内

### 面向打手的内容结构（15-60秒）
```
1. 共鸣切入（3-5秒）：说一个打手正在经历的真实困境
2. 揭秘/干货（15-30秒）：聊背后的原因、行业真相、或者自己踩过的坑
3. 点到为止（5-10秒）：轻轻带一句"我们是怎么解决的"或展示一下现状
4. 留钩子（3-5秒）：不说"来找我"，而是"想知道更多的可以聊聊"
```

### 面向老板的内容结构（30-90秒）
```
1. 抛问题（3-5秒）：说一个想开店的人一定会纠结的问题
2. 掏干货（20-40秒）：用真实数据和细节回答，不藏着掖着
3. 补一刀（10-15秒）：再说一个大多数人会忽略的坑
4. 自然收尾（5-10秒）：不推销，就说"有类似情况的可以交流"
```

### 开头钩子库

#### 面向打手的钩子（揭秘/共鸣型）
- "做陪练的兄弟，你有没有算过自己一单到底赚多少？"
- "为什么你技术不差，但就是接不到稳定的单？今天说透"
- "我见过太多打手，干了半年还在贴吧里蹲单，说个真实的事"
- "有人问我，陪练这行到底能不能当正经工作干？我说说我的看法"
- "五元战神为什么越来越多？不是技术不行，是渠道出了问题"
- "很多人劝你别干陪练，但他们可能不知道现在这行变了"

#### 面向老板的钩子（避坑/内幕型）
- "想开游戏工作室的，我先泼盆冷水，这几个坑你一定会踩"
- "有人跟你说开工作室稳赚不赔？我告诉你真实情况"
- "电脑到底是租还是买？算完这笔账你就明白了"
- "为什么很多工作室开了三个月就关了？问题出在第一步"
- "我第一个月亏了四千块，但我觉得这钱亏得值，为什么？"
- "这个行业最大的骗局，就是告诉你'躺着就能赚钱'"

### 结尾收尾库

#### 面向打手的收尾（不招，只留口子）
- "有类似情况的兄弟，评论区聊聊，我看到都会回"
- "想了解更多这行的真实情况，可以关注我，后面慢慢聊"
- "如果你也在纠结要不要干这行，私信我，帮你分析一下"
- "这期就说到这，下期聊聊怎么判断一个工作室靠不靠谱"

#### 面向老板的收尾（不推销，只交流）
- "有同样想法的老板，评论区交流，踩过坑的也可以说说"
- "想算算你那边开店的账，可以私信我，帮你捋一捋"
- "关注我，后面会继续拆解这个行业的细节"
- "有问题直接评论区问，能说的我都说"

## 平台适配规则

### 抖音
- 时长：15-60秒为佳
- 节奏快，前3秒必须抓人
- 口语化，避免书面语
- 可加字幕强调关键信息（薪资、福利）

### B站
- 时长：1-3分钟可接受
- 可以更深入聊技术栈和项目细节
- 弹幕互动友好，可预留互动点
- 受众偏技术向，可适当硬核

### 小红书
- 时长：30秒-2分钟
- 图文+口播结合
- 强调工作氛围、办公环境、福利
- 适合展示团队日常

## 内容素材要素

### 面向打手的素材（自然融入，不要罗列）
- 打手真实收入情况（用"我见过的""我们这边的"来带）
- 单干 vs 进工作室的区别（渠道、稳定性、设备）
- 常见骗局（押金骗局、虚假高薪、黑工作室特征）
- 判断工作室靠不靠谱的方法
- 不同游戏的接单难度和收入差异
- 娱乐陪伴和技术陪练的区别

### 面向老板的素材（用细节体现专业，不要吹）
- 开店真实成本拆解（租vs买、投流预算、容易漏算的项）
- 第一个月大概率亏多少、为什么亏、亏了怎么办
- 4个月回本的真实路径（逐月拆解）
- 只做一款游戏为什么是坑
- 性价比引流为什么是错的（吸引来的全是薅羊毛的）
- 客源才是核心，场地和设备都是其次
- 复购率多少才算健康（30%达标，50%优秀）
- 单店天花板在哪，怎么突破

## 合规注意事项

### 禁止内容
- 不得有性别、年龄、学历歧视性表述
- 不得虚假承诺薪资或职位
- 不得贬低具体竞品（可以说现象，不点名）
- 不得使用"保证""承诺""一定"等绝对化用语
- 不得出现明显的招聘广告口吻

### 语言禁区（防AI感）
- 禁用：赋能、助力、一站式、全方位、打造、引领、深耕
- 禁用：排比三连、对仗工整的句子、总分总结构
- 禁用：过于完美的逻辑闭环，真人说话不会那么圆
- 多用：嗯、其实、说白了、怎么说呢、反正、就是
