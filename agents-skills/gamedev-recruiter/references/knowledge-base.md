## 一、商业模式提炼

### 定位
- 线下游戏娱乐服务工作室（非代练/刷金币/卖装备）
- 主打热门游戏的陪伴与技术陪练服务

### 两大服务类型
1. **陪伴服务**：会聊天、提供情绪价值，靠客户满意度和复购
2. **技术陪练**：配备2-3个技术高手，专门带客户上分

### 主打游戏
- 三角洲、CSGO、永劫无间、英雄联盟等主流游戏

## 二、经营数据（可用于文案背书）

### 门店规模
- 4家门店运营中（3家社区店 + 1家写字楼店）
- 单店约10人规模

### 收入数据
- 单人日流水：500-600元，到手约300元
- 新人保底：日流水300元起
- 单店日稳定收益：5000元
- 月总流水：约15万
- 月净利润：5-7万

### 工作节奏
- 最低工时：10小时/天
- 弹性上限：14-16小时/天（自愿）
- 纯绩效制，多劳多得

## 三、成本结构（轻资产卖点）

- 电脑全部租赁，一台300元/月，无需购买
- 主要成本：房租 + 水电 + 运营推广费
- 前期启动资金压力小，适合轻资产创业起步

## 四、核心竞争力

### 客源体系
- 全平台接单，上千个接单渠道
- 订单量充足，忙时做订单分流
- 与其他工作室资源整合

### 管理体系
- 只招线下服务专员（员工称为"服务专员"）
- 统一配备工作手机，下班统一收回
- 服务闭环管理，保证客源稳定
- 无淡季，周末订单更多

## 五、合作/加盟模式

- 总部直接给合作伙伴派单
- 教运营、教招人，全程扶持
- 合同明确保证持续订单支持
- 先跑通业务，再带做私域复购

```
1. 开头引入（1句）：点明主题 + 承诺干货 + 圈定目标人群
   → "今天带大家了解...全程干货，想创业的朋友听完参考"

2. 业务概览（2-3句）：说清做什么 + 规模证明模式跑通

   → "只做线下服务，不搞灰色地带" + 两种服务类型详解

4. 收入与成本（4-5句）：用具体数字说话，降低决策门槛
   → 日流水、到手收入、成本结构、轻资产优势

5. 经营数据背书（2-3句）：月流水/净利/日收益，建立信任
   → "10人工作室月流水15万，净利5-7万"

7. 合作/招聘号召（3-4句）：降低合作门槛 + 承诺支持
   → 总部派单、教运营、合同保障

8. 总结收尾（1-2句）：提炼关键词 + CTA
   → "轻资产、模式跑通、正向现金流，关注我们"
```

## 九、人才管理哲学（核心金句）

### 核心原则："人才只筛选不培养"
- 网络竞技人才一定是筛选出来的、抢过来的，不是培养出来的
- 只选择不改变，该劝退劝退，能留下就留下
- 9年网络竞技最痛的经验

### 团队管理认知
- 员工绝大多数是来打工的，不是来陪你创业的
- 不要投入太多感情，不要太迁就某些员工
- 花钱是请人来办好事的，只为结果负责
- 事办好了该给奖金给奖金，办不好该辞退辞退
- 创业过程中不需要留一个人单纯来领工资、学习
- 一分耕耘一分收获

### 团队 vs 平台
- 互联网更新迭代太快，平台基本1-2年红利期，4-5年衰退期
- 可以没有平台政策扶持，但一定要有敢拼、敢打、能开荒的团队
- 平台没了，团队马上可以去下一个新平台把盘子打起来

## 十、行业避坑指南

### 坑1：只做一款游戏
- 只做一款游戏招人最难（如只做三角洲，招不到人）
- 多游戏覆盖更好招人：PUBG招一个、王者招一个、LOL招一个、瓦罗兰特招一个
- 不是"我想做什么游戏"，而是"我能招到什么样的员工"

### 坑2：只做技术电竞师
- 线下工作室一定是围绕娱乐电竞师去做的
- 纯技术门槛高、招人难、客源窄

### 坑3：五元战神现象
- 低价打手核心原因：没有稳定获客渠道
- 混迹于贴吧、评论区做截流，质量忽高忽低
- 工作室的价值就在于提供稳定获客渠道

## 十一、品牌 vs 赚钱（战略选择）

### 品牌俱乐部
- 注重抖音流量、话题度、舆论导向
- 售后和服务成本高，利润相对少
- 优势：拥有IP，有死忠粉，源源不断新客户
- 适合：想长期做品牌、未来有更大机会往上走

### 赚钱型俱乐部（转单模式）
- 闷声发大财，赚钱效率极高
- 跑通零到一后可无限复制
- 痛点：流量一停基本归零，没有IP沉淀
- 1000万月流水的品牌俱乐部，赚钱可能只抵得上300万的转单俱乐部

### 核心决策
- 先想清楚：最终是为了赚钱还是为了更大的名气
- 名气和利润不能兼得

## 十三、两大核心问题

- **有单没人** vs **有人没单**
- 一切基础建立在"有一条稳定的获客渠道"上
- 游戏工作室/俱乐部本质是"中介"——承接订单，匹配打手
- 获客流程跑通了，后端精细化运营才有意义

## 十四、新手开工作室正确步骤

### 第一步：找获客渠道（不是找场地！）
- 有自媒体经验 → 做抖音
- 什么经验都没有 → 做陪玩平台（只需简单养号）

### 第二步：跑通平台流程 + 养号
- 核心：让算法识别到你
- 所有操作的宗旨：让位置更靠前，让更多人看到你
- 类似淘宝搜索逻辑，销量高的排前面

### 第三步：解决员工问题
- 看当地能招到什么人，决定做什么游戏
- 身边有三角洲技术高手 → 做三角洲
- 招不到端游人才 → 做手游
- 原则：不是想做什么游戏，而是能招到什么人

### 第四步：跑通复购
- 复购达标线：老客户订单占比 ≥ 30%
- 优秀水平：50%-60%，甚至全部老客户
- 复购跑通 = 工作室零到一完成

## 十六、客群定位与平台收益结构

### 核心观点
- 工作室本身不需要定位客群，但要清楚"想赚哪一部分人的钱"
- 不同平台来的客户质量不同，利润结构完全不同

### 平台客群分层

#### 第一层：性价比订单粉（闲鱼/AD聚量等）
- 客群特征：纯价格敏感型，只看性价比
- 礼物收益：几乎没有
- 运营策略：快速接单 + 减少售后成本
- 利润结构：纯订单收入

#### 第二层：陪玩平台客户（PW平台）
- 客群特征：中间有10%-20%质量较高的客户
- 对声音、礼物打赏有一定兴趣
- 运营策略：主订单 + 侧重筛选高质量客户做礼物
- 利润结构：订单为主，礼物为辅

#### 第三层：抖音IP型客户（陪玩店/陪玩IP）
- 客群特征：因信任主播/店铺而下单，接受溢价
- 可做订单溢价：粉丝喜欢你，愿意付更高价格
- 后续延伸：礼物 + 冠名，客单价高，高质量老板多
- 运营策略：做好服务 → 提升存单比例 → 逐步涨价
- 利润结构：订单溢价 + 礼物 + 冠名

#### 第四层：音频/语音类客户
- 客群特征：看中声音、唱歌等特长，游戏只是媒介
- 订单溢价极高：平台10元/把的王者，可翻3-5倍甚至更多
- 利润结构：礼物 + 存单 + 冠名为主，订单为辅

## 十七、中小俱乐部核心竞争力

### 错误思路
- 主打性价比、体验单、低价引流 → 吸引来的全是薅羊毛客户
- 补贴打手接体验单 → 老客户留不下来
- 充值返现、小游戏补贴 → 思路完全错误

### 正确思路：售后服务 + 粘性
- 核心：让客户花一两千体验到大俱乐部花十几万、二十万的感觉
- 大俱乐部的优质老板反而享受不到好服务，这是小俱乐部的机会

### 具体做法
1. 先了解客户想要什么，再报价（不是一上来就推套餐）
2. 没达到目标，尽力去完成
3. 客服/店长每天寒暄问暖，维护关系
4. 所有投诉售后站在老板这边
5. 前期甚至可以少赚，先把母盘（核心客户群）稳下来
6. 母盘稳了再扩张，不急于赚快钱

## 十八、6人线下工作室投资详解（第三篇补充）

### 总投资：3-4万元

### 租电脑 vs 买电脑
- 租：300-400元/台/月，租10个月≈一台电脑钱
- 买：4000元配一台，用一年多还能折3000卖出，折旧率低
- 建议：条件充裕尽量买，长期更划算

### 其他成本
- 房租：押一付三，几千块
- 桌椅板凳：千把两千块搞定
- 投流预算（客源核心）：前期万把块钱

## 十九、4个月回本盈利周期

### 第一个月：收支平衡（目标）
- 实际大概率亏20%
- 6人工作室，无责底薪2000+/人，预计亏3000-4000元

### 第二个月：开始盈利
- 打手培养到位，积累一部分老客户
- 新客获取压力减小（老客户不需要前端获客成本）
- 目标净利润：5000-10000元
- 每个员工贡献利润：1000-2000元/人

### 第三个月：稳步增长
- 每个员工都有稳定老客户
- 单人日流水达到200-300元
- 单人月流水约8000-9000元
- 工作室月总流水约20000元

### 第四个月：模式成型
- 通过精细化礼物运营提升至25000-30000元/月
- 投资本金基本回收
- 工作室稳定运转

### 天花板认知
- 单店从2-3万再突破基本不可能
- 突破方式：复制开第二家、第三家
